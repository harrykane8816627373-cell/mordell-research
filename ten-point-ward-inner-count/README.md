# 十点全局最大构型恰有两个内点

2026-11-10。蒋丰灿研究项目，OpenAI Codex 协作。

在质量 9 的尺度下，**任一十点全局最大构型恰有两个平方半径小于 \(3/10\) 的点**。其余八点的平方半径落在 \((41/60,71/50)\cup(149/100,1539/1000)\)。这个结论不假定未知构型具有任何旋转或反射对称性，也不判断两个内点是否对径。

[先前的径向 Gram 证书](../ten-point-ward-population/README.md)只剩两种可能：两个或三个内点。这里用同一个全局上界核的**逐点缺额与径向矩罚项一起**排除三个内点。

设 \(R_i=\sum_{j\ne i}(h_{ij}-\log d_{ij})\)，\(F_0(u)\) 为[固定核](../ten-point-ward-upper/README.md)的第零阶径向特征，\(M=\sum_iF_0(u_i)\)，\(Q\succ0\) 为对应 Gram 块。记全局核的预算为 \(B\)。完整 Ward 与径向力修正在全局最大构型上求和为零，其余 Gram 块非负，故

\[
\sum_i R_i+M^TQM \le 2(B-\log\Delta)\le 2(B-\log V_{10})<2\cdot10^{-6},
\]

其中 \(V_{10}\) 是准确可达的整数见证值。这里每个无序点对在 \(\sum_iR_i\) 中恰好计两次。上式用的是全局核的同一个预算。

已有每对缺额不小于 \(-3/10000\)，因此每行 \(R_i\ge-27/10000\)。在标记平方半径 \(183/1250\le u_i\le3/10\) 时，新证书利用[三个精确行平衡](../ten-point-ward-radii/README.md)，证明较强的仿射下界

\[
R_i\ge -867/50000+u_i/10.
\]

此下界在 \(u_i=183/1250\) 处等于旧下界。证书用相应的有理乘子及完整 Bernstein 树覆盖整个闭区间。点对剪枝来自已证的 Schwarz、缩并域和半径禁区。

选固定有理 \(a,b\)，令 \(p(u)=F_0(u)^TQb-a(u-9/10)\)。利用 \(\sum_i u_i=9\) 及完成平方，得到

\[
M^TQM\ge \sum_i p(u_i)-b^TQb/4.
\]

接受器用一维 Bernstein 检验验证 \(p(u_i)+R_i>29/1000\) 在两个内层子区间都成立，并在两个允许的外带证明 \(p(u_i)+R_i>-61/5000\)。因此三个内点会使 \(\sum_iR_i+M^TQM>0.0005701\)，与同一核的上界矛盾。准确常数、乘子和一维覆盖在 [径向接受器](verify_radial.py)及[重放报告](verification_report.json)中。由两种可能中排除三点，结论成立。

从仓库根目录先重放[十点证明链](../docs/REPRODUCING.md#十点全局范围与局部锐界)的全局核、半径禁区、径向 Gram 证书，再执行：

```sh
python -B -S -O ten-point-ward-inner-count/verify_all.py
```

程序只使用 Python 标准库。本定理可将下一轮搜索加入每行的内点人口等式；它还没有证明所有全局最大构型落在候选的局部锐界邻域。
