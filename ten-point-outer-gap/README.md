# 十点全局最大构型的相邻外角与角向凹性

取总平方半径为 9。任一全局最大构型的八个外点按圆周次序排列。记相邻两方向的正向夹角为 \(\gamma_i\)，包括跨越整周的间隙。则

\[
\frac{59}{100}<\cos\gamma_i<\frac{39}{50},
\qquad i=1,\ldots,8.
\]

因此每个相邻外角在约 \(38.74^\circ\) 与 \(53.84^\circ\) 之间。此必要条件与已有[近对径配对](../ten-point-tight-pairing/README.md)同时成立，适用于全部全局最大构型。

## 用八个间隙的角度和分配缺额

设 \(G=h-\log d\) 为[曲率核](../ten-point-curved-kernel/README.md)的缺额，\(d\) 为平方点距。使用[角序分区](../ten-point-angular-upper/README.md)得到的逐类缺额下界。在此前允许的相邻边域中，取 \(\lambda=21/1000\)，分两段验证

\[
G+\lambda\gamma\ge
\begin{cases}
381/25000,&\cos\gamma\ge1/2,\\
553/20000,&\cos\gamma\le1/2.
\end{cases}
\]

第二个下界较大。若有一个间隙满足 \(\cos\gamma\le1/2\)，把上述下界在八条相邻边上求和，并用 \(\sum_i\gamma_i=2\pi<44/7\)，即得八条边的缺额和至少为 \(7(381/25000)+553/20000-\lambda(44/7)\)。该下界已超过其余 37 条边的补偿与全局预算。故所有相邻边都有 \(\cos\gamma>1/2\)。在 \([1/2,59/100]\) 和 \([39/50,106/125]\) 上，另分别验证 \(G\ge11/5000\)。这个下界超过其余 44 条边的补偿与全局预算，因而排除两段。

复核器用有理箱围住 \((u,v,t)\)，其中 \(u,v\) 是平方半径且 \(t\) 为点积。为认证含角度的下界，先由每个盒的端点给出 \(\cos\gamma=t/\sqrt{uv}\) 的上界，并向上取至步长为 \(1/512\) 的网格。对这个有理上界取 \(\arccos\) 下端，验收时用有理余弦下级数和余弦的严格单调性检查。余下的不等式用精确 Bernstein 系数与对数切线或曲率上界复核。所有根盒均完整覆盖。

## 与外角 Hessian 的接合

设 \(q=(u+v)/(2\sqrt{uv})\)。一条外外边对两角之差的对数能量负二阶导数为

\[
K(q,c)=\frac{1-qc}{(q-c)^2},\qquad c=\cos(\theta_i-\theta_j).
\]

在已有外带上有 \(q<41/40\)。在只要求八个相邻间隙满足上述界的角向凸多面体中，任意外外边有 \(c\le39/50\)。在该范围内 \(K\) 随 \(c\) 增、随 \(q\) 减。对所有边取 \(K\ge40/81\)，相隔一位、两位的边还分别有 \(K>52/25,37/50\)。两位的界来自连续两个间隙之和小于 \(2\pi/3\)，故其余弦大于 \(2(59/100)^2-1\)。

以这两个额外下界作为八点循环图的一步边、两步边权。循环 Fourier 模式中，第 1、7 模式的一步和两步 Laplacian 特征值分别为 \(2-\sqrt2>7/12\) 和 2。其他非零模式的一步特征值至少为 2。于是非恒定角位移的外外负曲率至少为

\[
8b+\min\{(52/25-b)7/12+2(37/50-b),\,2(52/25-b)\},\qquad b=40/81.
\]

在[原有点距分支](../ten-point-outer-angles/README.md)与新角多面体的交集中，沿用两条内外边提供的正曲率上界 \(219/100\)。固定平均外角的负 Hessian 下界从 \(173/100\) 提高到 \(317/100\)。

也可以直接在整个新角多面体上比较。任一内外半径比 \(s\) 在 \((23/100,113/250)\) 内，一条内外边的正曲率至多为 \(2s/(1-s)^2<151/50\)，无需限制这条边的平方点距。由于内点夹角余弦小于 \(-77/100\)，对每个外方向，两条内外边中至少一条的夹角余弦小于 \(17/50\)，该边曲率非正。在整个角多面体固定平均外角后，负 Hessian 下界因而是 \(117/50\)。任取其中的参考角 \(\widehat\theta\)，令 \(G_\theta\) 为投影到均值零空间的角梯度。该多面体上的对数距离积上界为 \(\log\Delta(\widehat\theta)+\|G_\theta\|^2/(2\cdot117/50)\)。

**半转推论。** 若某最大构型的两个内点对径，且外点按角序相隔四位的平方半径分别相等，把外角替换为 \((T\theta)_i=\theta_{i+4}-\pi\) 会保持内点及外半径固定。整体旋转半周和重标号保持角梯度为零。该替换也保持平均角与每个相邻间隙的界。严格凹性迫使 \(T\theta=\theta\)，因此构型具有半转对称。内点对径及外点配对等半径仍是前提。
