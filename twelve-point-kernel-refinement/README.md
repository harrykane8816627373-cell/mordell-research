## 1. 核及全局必要域保持相同的证明接口

先把构型缩放至质量11。任一全局最大点居中，按[严格子集定理](../finite-n/SUBSET_PROOF.md)，其点对三元组

```math
u=|x_i|^2,\quad v=|x_j|^2,\quad t=\operatorname{Re}(x_i\overline{x_j}),
\quad d=u+v-2t
```

必属于以下闭必要域的内部边界版本：

```math
0\le u,v\le121/72,\qquad t^2\le uv,\qquad d\ge1/3.
```

闭域更大，足以覆盖所有最大点；没有假设它们具备候选的D₃对称或径向分层。必要域的推导与质量缩放详见[原证明](../twelve-point-kernel-upper/README.md)。

本轮沿用原核的径向节点、矩中心和谐波投影特征，仅改变12个实对称矩块Qₖ。每个保存的十六进二进字面量解释为一个精确二进有理数。以H₀=1、H₁=t、Hₖ=2tHₖ₋₁−uvHₖ₋₂，定义

```math
K(u,v,t)=F(u)^TQ_0F(v)+\sum_{k=1}^{11}H_k(u,v,t)V_k(u)^TQ_kV_k(v).
```

全部Qₖ的有理LDL分解均有严格正主元，并逐项准确重构原矩阵。因此K为正半定核，任意有限构型都满足ΣᵢⱼKᵢⱼ≥0。特征的数值发现与真实候选取等号无关；此处不要求候选使核罚项恰为零。

B保持原冻结值7726135064073933/281474976710656，不将它当作精确候选值的对数。令b=(B−66)/12，

```math
p(u)=\frac{6u+b-K(u,u,u)/2}{11},\qquad
h(u,v,t)=p(u)+p(v)-K(u,v,t).
```

质量11给出Σᵢ<ⱼhᵢⱼ=B−ΣᵢⱼKᵢⱼ/2≤B。本轮在整个必要域上严格认证

```math
h(u,v,t)+c\ge\log d,\qquad c=\frac1{2500}=0.0004.
```

因此质量11的全局值满足logM₁₂⁽¹¹⁾≤B+66c=B+0.0264。相较旧证书的c=0.0021，这个补偿显著缩小；仍未降到候选锐值所需的零余量。

## 2. 连续证明实际覆盖了什么

接受器固定引用原已审查的[整数Bernstein与对数代码](../twelve-point-kernel-upper/verify_cover.py)，不改写旧算法或旧证据。它从新Q块完全重建h多项式；三轴次数上端19、19、11，共4800个Bernstein系数。

初始系数完全使用有理数变换，随后在2⁻⁴⁰网格向下取整。子盒中点de Casteljau细分继续向下取整，保留整个连续盒的下包围。对数在各盒用正有理切点的仿射切线作上界；切点对数经二次幂范围缩放、18项atanh级数和严格几何尾项包围。所有叶的阈值都向上取整，故通过的叶认证h+c≥log d在整个叶上成立。

Python无界整数的64位数位编码只加速这些精确运算。初始偏置数位为1132342777256079517至1169057862681189980，严格落在[0,2⁶²)内；凸中点细分保持范围。分栏求和、平均与哨兵比较的无进位、无借位证明沿原程序不变，不使用机器整数溢出行为或浮点数接受叶子。

剪枝也逐盒复核：完整位于u>v的盒可由精确交换对称跳过；最小|t|²大于u、v上端乘积的盒不含物理点对；整盒d上端低于1/3的盒不含必要域。未知构型的旋转或反射对称没有用于这些剪枝。

## 3. 从对数上界比较到真正可达值

旧整数点qᵢ=(aᵢ,bᵢ)给正有理量

```math
D=12\sum_i(a_i^2+b_i^2)-(\sum_i a_i)^2-(\sum_i b_i)^2,
\qquad P=\prod_{i<j}|q_i-q_j|^2.
```

质量11的可达值为132⁶⁶P/D⁶⁶，原质量12的V₁₂为144⁶⁶P/D⁶⁶。接受器复用冻结的整数见证重算与单调对数下端：二次幂缩放、64位向下有理尾数及80项正atanh和。它准确证明

```math
\log\!\left(\frac{103}{100}V_{12}^{(11)}\right)-(B+66c)>\frac3{1000}.
```

所以M₁₂⁽¹¹⁾<(103/100)V₁₂⁽¹¹⁾；缩放回质量12后比值不变。另重新重放12点真实根证书，其距离积区间下端严格大于V₁₂，因此C₁₂/M₁₂>100/103也成立。

## 4. 怎样发现这份核，哪些步骤不承担证明

发现阶段使用CVXPY/Clarabel优化Gram矩块，B额外差保持零；要求一个浮点正定下端作为数值稳定化。单靠随机点和SLSQP曾漏掉多个内部负谷。早期过深的DFS又反复细分同一个真负谷，未能及时扫到其他区域；它的局部最坏余量没有被当作全域保证。

改进后，发现用粗深度18的广域Bernstein分区、额外18000个全域样本、密集边界网格和彼此分离的局部负谷，联合生成切平面。11轮保存的核优化后，最终新核在c=0.0004下的完整浮点探索树闭合；随后本目录从所有精确系数重新重放这棵树，才接受全局结论。求解状态包含`optimal_inaccurate`，没有将该标签、浮点特征值、有限样本或探索树的零未决直接当作证明。

[发现摘要](discovery_summary.json)保留实际参数、各轮负谷、求解状态、环境与源文件哈希；它的作用是说明证书如何被找到，不参与对连续不等式正确性的假设。原15%界及原始失败核继续保留，不把历史探索结果改记为已完成的锐界。

下一步仍是消除余量，并把[候选刚性零集](../candidate-kernel/RIGIDITY.md)与[已认证局部上界区域](../candidate-basin/README.md)接合，最终证明候选值就是全局最大值。本轮只完成上述更紧的非锐全局包围。
