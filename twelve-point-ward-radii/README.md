# 十二点全局最大构型的半径分带与人口

2026-11-09。蒋丰灿研究项目，OpenAI Codex 协作。在质量11尺度，任意全局最大构型都恰有 **3 个点**的平方半径在 \( (3/25,6/25) \)，其余 **9 个点**的平方半径在 \( (47/50,71/50) \)。这把两点上界搜索的径向域缩为内内、内外、外外三个部分。候选的外侧还有两个半径层，现有必要条件允许外带九点有不同半径。锐值和构型唯一性仍待证明。

## 将全局值缺额分配到每个点

设 \(u=|x|^2,\ v=|y|^2,\ t=\operatorname{Re}(x\bar y)\)，写 \(G=h+c-\log(u+v-2t)\)，其中 \(h\) 是精确 Ward 核的两点函数，\(c=1/25000\)。上轮完整覆盖已证 \(G\ge0\)。全局最大点居中且完整驻定，故 Ward 修正的有序点对和为零。记 \(K\) 为正半定基核、\(B\) 为证书常数、\(V^{(11)}\) 为质量11下的可达见证，则

~~~math
\sum_{i<j}G_{ij}+\frac12\sum_{i,j}K(x_i,x_j)
= B+66c-\log\Delta(x)
\le B+66c-\log V^{(11)} < 66c.
~~~

最后一个严格比较由有理对数下端复核。左端每项点对缺额非负，每个谐波的完整基核和也非负，因此这一预算同时约束单个点的整行缺额和径向矩的二次型。 [已接受的 Ward 证书](../twelve-point-ward-upper/README.md)

## 两点仿射下界排除三段半径

标记一个点 \(x_i\)，固定 \(u=|x_i|^2\)。中心化和质量给

~~~math
\sum_{j\ne i}v_j=11-u,\qquad
\sum_{j\ne i}t_j=-u.
~~~

在三个待排除闭区间 \([0,3/25]\)、\([6/25,47/50]\)、\([71/50,33/20]\) 上，分成53个小区间。对每个小区间分别取两个有理系数 \(a,b\)。验证器逐盒证明

~~~math
G(u,v,t)\ \ge\ \frac1{4000}
+a\!\left(v-\frac{11-u}{11}\right)
+b\!\left(t+\frac u{11}\right).
~~~

每个盒的接受用精确 Bernstein 系数和对数切线上端。盒只按 Gram 条件或最小点距剔除，标记点的半径 \(u\) 与邻点半径 \(v\) 不作排序。合计重放99,603个节点，未决0。对标记点的11个邻点求和，仿射项抵消，得到整行缺额至少 \(11/4000>66c\)。这与全局值预算矛盾。另用删去一点的严格半径界 \(u<81/50<33/20\) 排除上端余段。 [删点界](../twelve-point-removal-domain/README.md) · [仿射系数](cuts.json) · [精确覆盖](cover.txt)

## 径向 Gram 块强制内带人口为三

记 \(Q_0\) 为 Ward 基核的径向块，\(m=\sum_iF_0(u_i)\) 为径向矩向量。前三个坐标是 \(\sum_i(u_i^j-\mu_j)\)，\(j=1,2,3\)，其中 \(\mu_j\) 从固定核精确读取。预算给 \(m^TQ_0m<132c\)。设 \(S\) 为 \(Q_0\) 删去首行首列后的块，解 \(Sy=(-4,1,0,0)^T\) 并令 \(w=(0,y)^T\)。用真实 Jacobian 调用生成有理解，复核程序逐项代回。它还验证 \(w^TQ_0w<20\)。

令

~~~math
p(u)=u^3-4u^2+4\mu_2-\mu_3.
~~~

\(w^TQ_0m\) 与 \(\sum_i p(u_i)\) 的差只来自首坐标 \(11-12\mu_1\)。验证器按有理数计算该误差，绝对值小于 \(1/10000\)。由 \(Q_0\) 的 Cauchy–Schwarz 不等式，

~~~math
|w^TQ_0m|^2\le (w^TQ_0w)(m^TQ_0m)<20\cdot132c.
~~~

以下四条仿射下界均由三次 Bernstein 系数验证。

|被下界的函数|内带下界|外带下界|
|---|---|---|
|\(p(u)\)|\(347/100-(26/5)u\)|\(509/100-(26/5)u\)|
|\(-p(u)\)|\(-199/50+(531/100)u\)|\(-263/50+(531/100)u\)|

内带人口至多2时，第一行对十二点求和，利用 \(\sum u_i=11\) 得 \(\sum_i p(u_i)\ge16/25\)。内带人口至少4时，第二行给 \(-\sum_i p(u_i)\ge41/100\)。扣除首坐标误差，两种情况均违反径向二次型上端。于是内带只能有三个点。
