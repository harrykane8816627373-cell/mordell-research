# 跨过二分之一：一般n层数与层半径分布的新必要条件

研究资料与项目发起：**蒋丰灿（Fengcan Jiang）**；推导与有理验收包含 OpenAI Codex 协作。2026-10-30。

K始终是全局最优构型相对其重心的**不同半径数**。本节联用[凸点对损失](PAIR_CONVEXITY.md)与[层周长运输](CIRCUMFERENCE_TRANSPORT.md)。角度任意，不预设规则环或晶格。

## 1. 只用有效初等预算的有限结论

对所有n≥10¹⁶，任意全局最优构型都有

~~~math
\boxed{K>\frac{5007}{10000}\sqrt n.}
~~~

这里只使用用户既有稳定性、半径界、圆盘精确分解，以及此前[已证有效可达下界](../radial-angular/RADIAL_LAYERS.md)所给

~~~math
\delta_n<E_n=\frac n{100}+\frac{77}6\sqrt n+\frac{35}4\quad(n\ge6).
~~~

它不需要外部线性渐近定理或未知有效阈值。10¹⁶是本证书的明确保守起点，不能把0.5007直接用于较小n；小n继续取已有层数保证的最大值。

**全部n的尾部证明。** 反设K≤k√n，k=5007/10000，取t=n⁻¹ᐟ⁴、a=t。n≥10¹⁶使t≤1/10000、√n≥10⁸，且E_n/n<10001/10⁶=:e。因为

~~~math
e(1+10^{-8})/2<(3/40)^2,
~~~

运输误差中的根式小于(3/40)t，平滑误差为t/8。删除正的t²/3项，得T_n>1−6t/5。因此

~~~math
\frac{\sum_jR_j}{n}
<k-\frac14+\left(\frac k4+\frac3{10}\right)t.
~~~

以π<355/113向外估计，全部尾部的相邻边平均距离上端不超过

~~~math
\frac{2(355/113)[k-1/4+(k/4+3/10)/10000]}
{1-2k/10^8}
<\frac{3151}{2000}.
~~~

但已精确证明P(3151/2000)>1003/100000，于是

~~~math
\frac{\delta_n}n>
(1-2k/10^8)\frac{1003}{100000}
>\frac{10001}{10^6}>\frac{E_n}n,
~~~

矛盾。以上全是有理比较；有限样例不是全尾部证明的替代品。

|n|本轮保证的最少层数|此前简式K>√n/2−(11/20)n¹ᐟ⁴给的层数|
|---:|---:|---:|
|10¹⁶|50,070,001|49,994,501|
|10²⁰|5,007,000,001|4,999,945,001|
|10²⁴|500,700,000,001|499,999,450,001|

只用同一初等预算，还有更精确的渐近表述

~~~math
\liminf_{n\to\infty}\frac{K_n}{\sqrt n}
\ge\frac14+\frac{3151}{4000\pi}>\frac{5007}{10000}.
~~~

## 2. 通用的渐近能量—层数接口

若已独立证明limsup δ_n/n≤e，并找到c∈(0,2)使P(c)>e，则

~~~math
\boxed{\liminf\frac{K_n}{\sqrt n}\ge\frac14+\frac c{2\pi}.}
~~~

证明：若某子列K/√n→k有限，上一节运输给ΣR_j/n≤k−1/4+o(1)，而n−2K=n(1−o(1))。相邻边凸预算遂使k<1/4+c/(2π)不可能，因为它强迫liminf δ_n/n≥P(c)>e。k≤1/4时周长上端非正或趋零，已同样不可能。无界子列不影响下界。

沿用仓库此前已注明的**外部线性能量展开与三角试探输入**，有limsup δ_n/n<1/800；本地没有在本轮重新证明这一外部展开。由于P(44/25)>1/750>1/800，得到

~~~math
\boxed{\liminf_{n\to\infty}\frac{K_n}{\sqrt n}
\ge\frac14+\frac{22}{25\pi}>\frac{53}{100}.}
~~~

这把项目此前的1/2渐近保证提高到超过0.53。**0.53的这条结论保留上述外部输入，未给它一个可直接用于有限n的起点。** 第1节0.5007的有效有限结论则独立于该输入。近期三角最小性预印本仍不作为本仓库新增已认证输入，范围保持[既有说明](../local-defect/LITERATURE_SCOPE.md)。

## 3. 不只总层数：每个环带中的层数与额外层的位置

令q_j=R_j/√n∈[0,1]，λ_n=n⁻¹ᐟ²Σ_jδ_(q_j)，它记录每个不同半径一次。只用E_n=O(n)，旧运输已保证点的q径向分布趋于2q dq。

对固定0<a<b≤1，容量m_j−1≤4√n q_j给

~~~math
\sum_{q_i\in(a,b)}\frac1{q_i}
\le(4\sqrt n+1/a)K_n((a,b)).
~~~

左边除以n趋于2(b−a)，因为点径向极限在a,b无原子。因此

~~~math
\boxed{\liminf\frac{K_n((a,b))}{\sqrt n}\ge\frac{b-a}{2}.}
~~~

a=0的情形由正a趋零得到。这是每个固定环带各自的必要层分布，不是单靠总层数推断。半径窗口必须固定，不能未经新估计改成随n缩小的微观环带。

若某子列K_n/√n有界并使λ_n弱收敛到λ，上述局部结论等价于

~~~math
\lambda\ge\tfrac12\,dq\quad\text{在}[0,1].
~~~

此外若P(c)>e，凸点对预算还迫使

~~~math
\int_0^1 q\,d\lambda(q)\ge\frac c{2\pi},\qquad
\int_0^1 q\,d(\lambda-\tfrac12dq)
\ge\frac c{2\pi}-\frac14.
~~~

所以超出均匀基础层密度的额外层必须携带正的半径加权质量，不能只堆在中心。e=1/800、c=44/25时右端为22/(25π)−1/4>3/100。由于q≤1，也再次推出总层数系数超过0.53。

## 4. 有限短边和矩预算的同步改善

精确积分P(8/5)>13/1600，联合此前已证全局缺额上端，给八点短边至多12对、百点至多101对。八点改回原z尺度，若

~~~math
\sum_i|z_i|^4\ge101/10,\qquad |\sum_i z_i^2|\ge4/5,
~~~

则距离平方≤128/175的点对至多2对。该四阶矩门槛从此前51/5降为101/10；证明仍是一个径向Dirichlet下端加k=2驻点角向下端，再加3条短边的代价即超过523/5000。准确分数见[layers_verification.json](layers_verification.json)。没有声称此条件类通过其他全部旧判据。

一般n有限最优构型、完整八点锐界及层数的精确领先常数均未由此确定。新常数不是文献最优性声明，程序接受也不等于整篇形式化验证。
