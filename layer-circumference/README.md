# 层周长、凸重叠损失与径向层分布

研究资料与项目发起：**蒋丰灿（Fengcan Jiang）**；推导及程序包含 OpenAI Codex 协作。2026-10-30。承接1154906739d7e15e08f4e0de0a5881141a01f28a。

本轮把此前单层谱容量、全局径向运输和短边重叠损失接成一个周长预算。它不预设层内等角，也不依赖某个数值优化构型。**一般n的完整最优构型及八点完整锐界仍未解决。**

## 1. 径向层数跨过二分之一

K是相对重心的不同半径数。仅用项目既有初等有效能量预算，严格得到

~~~math
\boxed{K>\frac{5007}{10000}\sqrt n\qquad(n\ge10^{16}).}
~~~

此前有效式的领先系数为1/2。新起点很大且保守，小n继续联合已有保证；不是把新系数直接用于所有n。

若沿用仓库已注明的外部线性能量展开及三角试探输入，还得到

~~~math
\boxed{\liminf K_n/\sqrt n\ge\frac14+\frac{22}{25\pi}>\frac{53}{100}.}
~~~

这条超过0.53的渐近结论保留外部输入，**没有宣称其有限有效起点**。上面0.5007的有限结论独立于该展开。

## 2. 新连接：同层边的凸预算

精确无序点对损失P(d)=2(g−T²g)(d)在全部正距离凸且非增。因此同一层给定半径和人口时，等角使这一损失项最小；这不等同于完整全局乘积最优。

从人口至少3的层取循环相邻边，总数至少n−2K，总长度不超过2πΣR_j。于是

~~~math
\delta_n\ge(n-2K)P\!\left(\frac{2\pi\sum_jR_j}{n-2K}\right).
~~~

新的径向测试f_a(q)=(1−q)min(1/a,1/q)再把ΣR_j/n控制为K/√n−1/4加明确有限误差。接近旧最少层数时，相邻点平均距离被压低，重叠点对代价便超过可达下界留下的缺额预算。

## 3. 层自身的分布与短边统计

写q=R/√n。每个固定窗口(a,b)⊂[0,1]都满足liminf K_n((a,b))/√n≥(b−a)/2。任何有限弱极限层测度λ均支配(1/2)dq；额外层还必须承载明确正的半径加权质量。它比只给总层数更细，没有确定角向晶格或微观窗口中的人口。

精确积分验收还把力为1尺度、截止8/5的短边上限收紧为：

|点数|上一轮|本轮|
|---|---:|---:|
|8|17对|12对|
|100|136对|101对|

八点若原尺度四阶矩≥101/10、二阶幂和模≥4/5，短边仍至多2对；对应原尺度距离平方阈值128/175。新矩门槛低于上一轮51/5。
