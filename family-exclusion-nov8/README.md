# 非线性缺额导出的完整多环家族排除

蒋丰灿研究项目，OpenAI Codex 协作。2026-11-08。

本专题把[已证相位缺额](../phase-deficit-sharp/README.md)与已有整数可达见证准确比较：保留 exp(D) 的前九个正项，得到家族上界 U/E_8(D)，其中 E_8(D)=sum_(k=0)^8 D^k/k!。

|指定家族，全部连续相位|家族上界 / 已保存可达见证值|结论|
|---|---|---|
|16 点四正方形环，半径 9/10、1、11/10、6/5|(0.04490398721963, 0.04490398721964)|完整排除于全局最优者|
|同上四半径各变化正负 1/10000 的整个盒|(0.04704991411673, 0.04704991411674)|整个半径盒完整排除|
|25 点人口 8、6、3、8，半径 4/5、9/10、1、11/10|(5.179, 5.180)×10^-11|此前已排除，本轮只加强比较|

上述区间端点均为准确有理数，来自整数比较。十六点两族的所有值小于一个已有真实可达值的 5%，因此不能是全局最优；原显示界 U/(1+D) 尚未完成这两个排除。

**排除范围限于列出的正规环人口与半径比例或半径盒。** 这里没有得到无约束 M_16、M_25 的上界或锐值，也未覆盖所有多环构型。

从仓库根目录运行：

```bash
python -B -S -O family-exclusion-nov8/verify_all.py
```

仅需 Python 标准库。程序固定原相位核心、三份证书和旧整数见证的哈希，重新接受完整非线性证书，再独立中心化、归一化和相乘整数坐标的全部距离。保存的浮点梯度和目标值不参与证明。
