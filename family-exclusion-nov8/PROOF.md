# 用非线性相位缺额排除完整固定多环家族

2026-11-08。蒋丰灿研究项目；本轮桥接证明及精确核验包含 OpenAI Codex 协作。这里把[已认证非线性相位缺额](../phase-deficit-sharp/PROOF.md)转成与已有真实可达构型的严格比较。证明不增加最优构型的对称假设。

## 1. 保留指数的正项

指定正规环人口与半径区间的非线性证书已经证明，对该家族的每组连续相位和整个半径盒都有

```math
F\le Ue^{-D},\qquad D>0.
```

其中 F=(n/Q)^N Delta，N=n(n-1)/2，是中心化构型归一化到 Q=n 后的距离平方乘积；U 是同一固定家族的有理端点上端。此前显示的 U/(1+D) 只保留了 exp(D) 的前两项。

定义

```math
E_8(D)=\sum_{k=0}^{8}\frac{D^k}{k!}.
```

exp(D) 的所有遗漏项均为正，故

```math
\boxed{F\le Ue^{-D}<U/E_8(D).}
```

右侧仍是准确有理数，可直接与真实构型的可达值比较。这一步没有额外相位取样，也没有缩小原有半径盒的连续覆盖范围。

## 2. 已保存整数构型给严格可达值

使用[此前整数见证](../symmetry-breaking/integer_witnesses.json)中的 n=16 与 n=25 两行。整份输入文件固定为 SHA-256

```text
73e5f42ef78db59dd0ff3e05227caf75eb3834a02486c509767c8534c3c954d5
```

只使用保存的整数坐标，不接受该文件中的浮点目标值、梯度、停止状态或最优性标签。

设整数平面点 w_i=(a_i,b_i) 互异，S=sum w_i，令

```math
D_{\rm mass}=n\sum_i|w_i|^2-|S|^2
            =\sum_{i<j}|w_i-w_j|^2>0.
```

明确取 z_i=(n w_i-S)/sqrt(D_mass)，则 sum z_i=0，sum |z_i|^2=n，且

```math
\boxed{V_n=\Delta(z)
=\frac{n^{2N}\prod_{i<j}|w_i-w_j|^2}{D_{\rm mass}^N}\le M_n.}
```

这是真实可行构型的准确有理值，不要求整数点本身是驻点、局部最大或全局最大。程序独立用两两平方距离和与总矩公式核对 D_mass，再用整数中心化坐标重新计算同一归一化乘积。

两行见证的质量整数分别是

```math
D_{{\rm mass},16}=2560000003871403262,\qquad
D_{{\rm mass},25}=6249999988153697320.
```

如果对一个完整家族认证了 U/E_8(D)<V_n，就得到

```math
\forall z\text{ 属于该家族},\qquad
\Delta(z)<V_n\le M_n.
```

因此全局最优构型不能属于该指定家族。这里的 U/E_8(D) 是家族上界，V_n 是 M_n 的下界；没有把二者的比较误写成无约束 M_n 的上界。

## 3. 十六点：排除四正方形环及整个半径盒

固定家族由四个同心正规正方形环构成，人口为 (4,4,4,4)。半径分别为 (9/10,1,11/10,6/5)，允许所有连续相位。整个盒版本允许每个半径在其中心值正负 1/10000 内独立变化。

已认证 D 分别为 119489373/20000000 和 119455433/20000000。重新接受原相位证书后，计算 R=U/(E_8(D)V_16)，得到准确有理十进区间

```math
0.04490398721963<R_{\rm fixed}<0.04490398721964<1/20,
```

```math
0.04704991411673<R_{\rm box}<0.04704991411674<1/20.
```

显示的十进端点都是分母 10^14 的有理数，程序实际通过整数交叉比较证明以上严格关系。故这两个完整家族中的所有归一化乘积，甚至都小于已保存十六点可达见证值的 5%。固定家族以及整个连续半径盒，都不能包含十六点全局最优者。

此前同一非线性 D 的有理显示界 U/(1+D) 与 V_16 的比值分别约为 2.15180、2.25181，未实现这个排除。即使用旧二次循环缺额代入本轮同阶 E_8，两比值仍约为 1.41536、1.48162，也未排除。因此这里是非线性缺额与保留指数正项联合后，得到的**列出家族的完整排除后果**。这不是对所有四环半径或任意十六点构型的全域覆盖，也不作最早发现该具体排除的文献优先权声明。

## 4. 二十五点：保留已有排除的真实状态

第三个家族的人口为 (8,6,3,8)，固定半径为 (4/5,9/10,1,11/10)，相位全部自由。D=795833/5000000。对旧 n=25 整数可达见证重新比较，得

```math
\frac{5179}{10^{14}}<\frac{U}{E_8(D)V_{25}}<\frac{5180}{10^{14}}<1.
```

即比值位于 (5.179,5.180)×10^-11。该家族已经被此前较弱的 U/(1+Gamma) 排除，本轮只是进一步收紧准确比较，不把它列为新增的定性家族排除。

## 5. 固定输入与接受范围
