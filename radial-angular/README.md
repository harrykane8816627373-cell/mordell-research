# 一般 n 最优构型：更强层数定理、混合矩能量与人口—半径优化

研究资料与项目发起：**蒋丰灿（Fengcan Jiang）**；推导、程序及独立交叉审阅包含 OpenAI Codex 协作。2026-10-28。承接提交 `c276ac27f01d7f0fdb9d90565a31162b6afbb855`。

本轮得到更强的一般最优构型必要条件，并提出一个精确的新构造方法。**尚未确定一般 n 的最优人口、各层角度或全局锐值；八点完整无条件锐界、精确γ仍开放。**

```math
M_n=\max_{\sum|z_i|^2=n}\Delta_n(z),\quad
\Delta_n(z)=\prod_{i<j}|z_i-z_j|^2,\quad
U_n=n^{n/2}\left(\frac{2n}{n-1}\right)^{n(n-1)/2}e^{-n(n-1)/4}.
```

## 1. 层数下界显著加强

K为任一全局最大构型相对重心的不同半径数。现在有

```math
\boxed{K>\frac3{22}\sqrt n\quad(n\ge2),\qquad
\liminf_{n\to\infty}\frac{K_n}{\sqrt n}\ge\frac{101}{250}.}
```

此前分别为√n/12和11/50。新证明在实际半径变量中保留空隙能量权重，并优化平滑半径；不要求各层规则角度，也不需要额外的外半径截断。

更一般地，取x=√((n−1)/n)z、δ=log(Uₙ/Δₙ)，若中心半径|xᵢ|可被K条半径带覆盖，总宽度至多W，则对任意h>0有

```math
\boxed{\delta\ge
\frac{9n^2}{64(K+1)^2}
\left(1-\frac W{\sqrt2}-\frac{2hK}{\sqrt n}\right)_+^4
-n\left(\frac{h^2-1}{2}-\log h\right).}
```

这是厚带的稳定版本；W度量的是**半径宽度**。h=1、W=0时，新界在K<√n/2仍有正信息，旧界只到K<√n/4。显式全n常数使用已有多环下界及等半径稳定性结果；渐近常数还使用此前注明的外部线性渐近定理和三角试探常数，未新增结晶假设。

## 2. 径向加权角向矩补足跨层抵消

旧的pₖ=Σxᵢᵏ可能因不同半径层抵消而为零。新测试函数在支撑圆内取wᵏ|w|²ʲ，在外部接调和衰减尾项，形成正定Gram矩阵。对同一平滑参数h和支撑平方半径S，得到

```math
\delta\ge n^2D(\overline{\nu_h})
+\sum_k A_k^*H_k^{-1}A_k-n\psi(h),
\qquad
(H_k)_{j\ell}=\frac{(k+j)(k+\ell)}{k+j+\ell}S^{k+j+\ell}.
```

测量A可通过有限圆盘多项式平均精确计算。径向次数0恢复旧全纯矩界；次数增加后下界不减。第一级有显式额外平方罚项。六点例{±3,±4,±5i}/√20中，p₁=p₂=p₃=0，但新方法已检测到64/625的角向缺额。

实现还提供整类复矩区间的对偶证书，可以与同一h下的径向层数或人口空带下界相加。重叠的径向证书取最大值；同一角向模式的非正交测试须保留Gram矩阵；平滑修正只扣除一次。

## 3. 保留整数人口与精确空隙积分

平滑支撑的空带内，CDF为一个整数j除以n；不必放松成自由实数。对于平方半径空带(a,b)，其径向能量恰为

```math
I(a,b;j/n)=\frac{j^2}{2n^2}\log\frac ba
-\frac{j}{2n}(b-a)+\frac{b^2-a^2}{16}.
```

已知j时直接积分，未知j在整数范围内时用凸性作完整最小化。n=100的一个非空厚两带类，10点平方半径在[1/25,1/20]、90点在[109/100,11/10]，给δ≥75+100log2>425/3，超过全局最优预算1657/12，因而整类被排除。这里只排除明示条件类，没有执行全域覆盖。

## 4. 新构造：联合选择人口和全部半径

对于给定正规多环人口mᵢ、内侧人口Sᵢ，角平均对数乘积的最优平方半径有闭式

```math
t_i^*=\frac{2S_i+m_i-1}{n-1}.
```

偏离这些半径的角平均损失，恰为一个相对熵N·D_KL。所有有序偶人口组合的角平均目标可用整数动态规划精确优化，再对选定构型的全部正负相位求实际乘积。**代理目标的最优不等于原乘积的全局最优。**

在2≤n≤100的99项比较中，新显式构型相对此前完整已存包络提高87项，恰为13≤n≤100除17外的全部点数。比较包含上轮45项内环收缩改善及所有旧一步上升见证。n=28至少提高512.96%；n=95达到旧下界的121.4022倍以上。这些比值只针对旧可达下界，不是未知Mₙ的相对误差。

另对99个所选固定人口、固定半径的家族，认证全部连续旋转的最大值至多比所给符号构型大百万分之一。这说明这些指定环的纯旋转余量已很小；后续应重点检查半径扰动、人口变化和非规则角度，而不是把这个受限最优误当成一般构型结论。

### 新下界反过来约束任意全局最优者

将新构型P₁₀₀的精确因子逐项作有理对数包围，得到

```math
\log(U_{100}/M_{100})\le\log(U_{100}/P_{100})
\le1.128852585095<\frac94.
```

但新层数主式在n=100、K≤3、h=1时给δ≥9/4，矛盾。因此**任何百点全局最大构型至少有4个不同半径**，无需假定其为正规多环。这里是全局上下界与构型约束的实际联合推论；不是把所给构造的6层当成真实最优层数。另计算了n=30的联合示例，见[因子化对数与预算重放](joint_budget_verification.json)。
