# 用实际半径空隙加强层数界：可变平滑、加权量化与人口精确积分

研究资料与项目发起：**蒋丰灿（Fengcan Jiang）**。推导、程序及交叉审阅包含 OpenAI Codex 协作。2026-10-28。

本节继续使用仓库已有的圆盘库仑分解与可达下界。新的步骤是在**半径**而非平方半径上计算平滑支撑的覆盖长度，保留径向能量的真实权重，并优化平滑半径。由此将旧的统一半径层数下界从 \(\sqrt n/12\) 提高为 \(3\sqrt n/22\)，将已有渐近保证从 \(11/50\) 提高为 \(101/250\)。本文不要求每层角度规则，也没有求出一般 n 的最优构型或完整八点锐值。

## 1. 记号与结论

沿用

```math
\Delta_n(z)=\prod_{i<j}|z_i-z_j|^2,\qquad
M_n=\max_{\sum|z_i|^2=n}\Delta_n(z),\qquad
N=\frac{n(n-1)}2,
```

```math
U_n=n^{n/2}\left(\frac{2n}{n-1}\right)^N e^{-N/2},\qquad
\delta(z)=\log\frac{U_n}{\Delta_n(z)},\qquad
x_i=\sqrt{\frac{n-1}n}z_i.
```

取任意 h>0，平滑圆盘半径为 \(r=h\sqrt{2/n}\)，并定义

```math
\psi(h)=\frac{h^2-1}2-\log h\ge0.
```

假设这组点的中心半径 \(|x_i|\) 被 K 个径向区间覆盖，区间总长度为 W，允许区间相交。对任意归一化、无碰撞构型，均有

```math
\boxed{\displaystyle
\delta(z)\ge
\frac{9n^2}{64(K+1)^2}
\left(1-\frac W{\sqrt2}-\frac{2hK}{\sqrt n}\right)_+^4
-n\psi(h).}
```

右端还可以与0取最大。这里 W 是**半径的总宽度**，不是平方半径的总宽度；不要求所有点位于某个预设外圆盘内。

特别地，若 K 是精确的不同半径数，取 W=0、h=1，得

```math
\boxed{\displaystyle
\delta(z)\ge\frac{9n^2}{64(K+1)^2}
\left(1-\frac{2K}{\sqrt n}\right)_+^4.}
```

对任意全局最优构型，K 相对于其重心计数，则

```math
\boxed{K>\frac3{22}\sqrt n\qquad(n\ge2),}
```

并且对任意全局最优构型列都有

```math
\boxed{\displaystyle
\liminf_{n\to\infty}\frac{K_n}{\sqrt n}\ge\frac{101}{250}.}
```

前一个结论使用已有有效多环可达下界，以及旧稿中 n≥8 时等半径正多边形不稳定的结论。后一个结论还使用已有的线性渐近项及 \(\gamma_D-\gamma_\triangle<1/800\)。这些输入的出处与限制见第6节。

## 2. 改变平滑半径时必须扣除的代价

设 \(\mu_h=n^{-1}\sum_i\sigma_r(\cdot-x_i)\)，\(\mu_0\) 为半径 \(\sqrt2\) 的均匀圆盘概率，\(\nu_h=\mu_h-\mu_0\)。[已有圆盘证明](../asymptotics/README.md)对任意 r>0 都给

```math
H_n(x)\ge n^2 I_V(\mu_h)+n\log r-\frac n4-\frac{n^2r^2}4.
```

连续平衡分解为

```math
I_V(\mu_h)-I_0=D(\nu_h)+2\int\zeta\,d\mu_h\ge D(\nu_h).
```

与 h=1 的基线 L_n 比较，注意

```math
n\log r-\frac{n^2r^2}4
-\left[\frac n2\log(2/n)-\frac n2\right]
=n\log h-\frac n2(h^2-1)=-n\psi(h).
```

在 \(\sum|x_i|^2=n-1\) 的尺度，\(H_n(x)-L_n=\delta(z)\)，故

```math
\delta(z)\ge n^2D(\nu_h)-n\psi(h)
\ge n^2D(\overline\nu_h)-n\psi(h).
```

\(\overline\nu_h\) 表示旋转平均。改变 h 可以缩小平滑支撑，但必须保留这个负的基线修正；不能把 h≠1 时的径向能量直接代替原缺额。

记半径累计分布为 \(G_h(t)=\mu_h\{|w|\le t\}\)，则已有径向 Gauss 公式给

```math
D(\overline\nu_h)=\int_0^\infty
\frac{(G_h(t)-G_0(t))^2}t\,dt,\qquad
G_0(t)=\min\{t^2/2,1\}.
```

这是半径变量的公式，因此没有平方半径变量中额外的1/2。

## 3. 一个空径向区间的精确权重代价

设 \((a,b)\subset[0,\sqrt2]\) 是平滑支撑的空区间，则其上 \(G_h(t)=c\) 为常数。若 a>0，直接积分并对自由实数 c 取最小，得到

```math
\min_c\int_a^b\frac{(c-t^2/2)^2}t\,dt
=\frac{b^4-a^4}{16}
-\frac{(b^2-a^2)^2}{16\log(b/a)}.
```

这一步暂时不要求 c 是某个整数人口除以 n，故给出安全下界。更强的纯多项式估计为

```math
\boxed{\displaystyle
\int_a^b\frac{(c-t^2/2)^2}t\,dt
\ge\frac{(a+b)(b-a)^3}{24}.}
```

证明：置 v=b/a>1，所需不等式等价于

```math
\log v\ge\frac{3(v^2-1)}{v^2+4v+1}.
```

两边在 v=1 时相等，且差的导数为

```math
\frac1v-\frac{12(v^2+v+1)}{(v^2+4v+1)^2}
=\frac{(v-1)^4}{v(v^2+4v+1)^2}\ge0.
```

若 a=0，c≠0 时能量发散；c=0 时能量为 \(b^4/16\ge b^4/24\)，所以同一个下界成立。

由于 \(t^{1/3}\) 是凹函数，

```math
\left(\int_a^b t^{1/3}\,dt\right)^3
\le (b-a)^3\frac{a+b}2.
```

因此这个空区间的能量还满足

```math
\int_a^b\frac{(c-t^2/2)^2}t\,dt
\ge\frac1{12}\left(\int_a^b t^{1/3}\,dt\right)^3.
```

这里的 \(t^{1/3}\) 权重是由真实径向能量得出的量化权重；将它预先替成统一最小值，会损失下面较大的层数常数。

## 4. 覆盖长度与加权空隙求和

若一条中心半径带为 \([A,B]\subset[0,\infty)\)，它产生的平滑支撑只可能落在

```math
[\max\{A-r,0\},B+r],
```

其长度至多 \((B-A)+2r\)。所以 K 条带的平滑支撑与 \([0,\sqrt2]\) 的交集，总长度至多 \(W+2Kr\)。无需假设带的上端小于 \(\sqrt2\)；与目标区间取交只会缩短覆盖。

支撑补集由至多 K+1 个空区间组成，总长度至少

```math
L=(\sqrt2-W-2Kr)_+.
```

令这些区间上的 \(\int t^{1/3}dt\) 分别为 \(A_j\)。对非负递增函数 \(t^{1/3}\)，在 \([0,\sqrt2]\) 内具有指定长度 L 的集合，其积分最小值由 \([0,L]\) 给出。因此

```math
\sum_j A_j\ge\int_0^L t^{1/3}\,dt=\frac34L^{4/3}.
```

第3节及 Hölder 不等式给

```math
D(\overline\nu_h)\ge\frac1{12}\sum_j A_j^3
\ge\frac{(\sum_j A_j)^3}{12(K+1)^2}
\ge\frac{9L^4}{256(K+1)^2}.
```

代入 \(r=h\sqrt{2/n}\)，再代入第2节的基线修正，即得第1节主不等式。

旧方法在平方半径上用每层至多 \(8/\sqrt n\) 的统一宽度，只有 K<\(\sqrt n/4\) 时得到正的覆盖剩余。本节在 h=1、W=0 时，对 K<\(\sqrt n/2\) 都有正罚项。这是常数改善的几何来源，而非执行更大的数值搜索。

## 5. 全 n 与渐近层数常数

### 5.1 有效有限 n 的3/22常数

[已有多环下界联合圆盘上界](../source-review/RADIAL_LAYERS.md)给全局最优缺额

```math
\delta_n:=\log(U_n/M_n)
<E_n:=\frac n{100}+\frac{77}6\sqrt n+\frac{35}4
\qquad(n\ge6).
```

旧稿还给 n≥8 时 K≥2：等半径驻点只能为正 n 边形，而此时有不稳定方向。n≤7 时 K≥1 已经严格大于 \(3\sqrt n/22\)。因此只需考虑 K≥2。

假设 \(K\le(3/22)\sqrt n\)。则 \(\sqrt n\ge44/3\)，且 \(K+1\le3K/2\le9\sqrt n/44\)。取 h=1 的新主不等式给

```math
\frac{\delta_n}n\ge
\frac9{64(9/44)^2}\left(1-\frac3{11}\right)^4
=\frac{1024}{1089}.
```

另一方面，\(\sqrt n\ge44/3\) 使有效上包满足

```math
\frac{\delta_n}n
<\frac1{100}+\frac{77}6\frac3{44}
+\frac{35}4\frac9{1936}
=\frac{179211}{193600}<\frac{1024}{1089},
```

矛盾。故对所有 n≥2 均有 \(K>3\sqrt n/22\)。本论证没有使用未知渐近余项的起始阈值。

若不调用旧的等半径稳定性结果，新主不等式及有效上包仍独立给出较弱的 \(K>\sqrt n/10\)：反设 K≤\(\sqrt n/10\)，由 K≥1 知 n≥100，且 K+1≤2K；主式迫使 \(\delta_n/n\ge36/25\)，而 \(E_n/n\le1657/1200<36/25\)。

### 5.2 可变平滑提高渐近常数

已有线性项和严格三角／圆盘常数比较给

```math
\frac{\delta_n}n\longrightarrow\gamma_D-\gamma
\le\gamma_D-\gamma_\triangle<\frac1{800}.
```

固定 h>0。若沿子列 \(K_n/\sqrt n\to c>0\)，新主式给

```math
\liminf\frac{\delta_n}n\ge
\Phi_h(c):=\frac{9(1-2hc)_+^4}{64c^2}-\psi(h).
```

若 c=0，主式的第一项趋于无穷，同样矛盾；无需把 \(K+1\) 不合法地直接替成 K。函数 \(\Phi_h\) 在 \(0<c<1/(2h)\) 上严格递减。

仅取 h=1、c=2/5，便有 \(\Phi_1(2/5)=9/6400>1/800\)，已把渐近保证提高到2/5。再取

```math
h=\frac{99}{100},\qquad c_0=\frac{101}{250},
```

可进一步严格核验

```math
\Phi_h(c_0)>\frac1{800}.
```

一个简短的有理验收是：用 y=1/199 的 atanh 级数4项上包 \(\log(100/99)\)。设

```math
T=2\sum_{j=0}^{3}\frac{y^{2j+1}}{2j+1}
+\frac{2y^9}{9(1-y^2)},\qquad
\psi(h)\le\frac{h^2-1}2+T.
```

则纯有理运算给

```math
\frac{9(1-2hc_0)^4}{64c_0^2}
-\left[\frac{h^2-1}2+T\right]
>\frac1{800}.
```

左侧约为0.00128041245，约数仅便于阅读，比较由有理数承担。若 \(\liminf K_n/\sqrt n\le c_0\)，抽取实现该下极限的子列；上述单调性与已知缺额极限产生矛盾。因此采用保守的简洁表述 \(\liminf K_n/\sqrt n\ge101/250\)。

更精细的常数可以继续优化 h，或取方程 \(\Phi_h(c)=1/800\) 的根。这里不声称99/100是最佳平滑参数，也不声称101/250是层数的最优渐近常数。

## 6. 已知人口与精确径向空隙的有限证书

如果一个空隙 \((a,b)\) 内累计人口已知为 m，则 c=m/n，无需再对 c 自由取最小。其能量恰为

```math
\int_a^b\frac{(m/n-t^2/2)^2}t\,dt
=\frac{m^2}{n^2}\log(b/a)
-\frac m{2n}(b^2-a^2)+\frac{b^4-a^4}{16}.
```

a=0 时仅 m=0 有限，此时能量为 \(b^4/16\)。给定平方半径带及人口，可以用根式的等价有理平方比较，判断每条带的平滑支撑位于空隙左侧还是右侧；若任何带可能进入空隙，接受程序直接拒绝该空隙。多个互不相交空隙的能量可以相加，最后扣除一次 \(n\psi(h)\)。

例如 n=100，全部库仑尺度平方半径位于 \([49/50,1]\)，取 h=1 及半径空隙 \([0,4/5]\)。由于

```math
\frac{49}{50}-\frac1{50}-\frac{16}{25}=\frac8{25}>0,
\qquad
\left(\frac8{25}\right)^2
>4\frac1{50}\frac{16}{25},
```

每个平滑圆盘都在这个中心盘之外，所以 m=0。精确积分给

```math
\delta(z)\ge100^2\frac{(4/5)^4}{16}=256.
```

它比旧示例的 \(1225/6\) 更大；仍然是这个整类径向构型的上界证书。由于全局最优 \(\delta_{100}<1657/12<256\)，该厚环不含全局最大者。此例与层数主定理均没有假定角度规则。

程序 [radial_layers.py](radial_layers.py) 还实现任意有理 h 的证书、厚径向带总宽、已知人口的精确积分，以及输入已证缺额上包后的层数二分排除。`minimum_layers` 的输出是必要条件；它不会自行证明用户提供的可达下界有效。

## 7. 复核、联合接口与尚未解决的问题

运行

```bash
python -B -S -O verify_radial_layers.py
```

接受入口核对对数区间、根式方向、空隙代价、导数恒等式、有限与渐近常数、真实人口积分和非法输入，并生成 [radial_layers_verification.json](radial_layers_verification.json)。有限样例不代替第2至5节的普遍解析证明。

本节只使用仓库[圆盘分解](../asymptotics/README.md)、[原有效多环下界与旧层数证明](../source-review/RADIAL_LAYERS.md)及其中明确注明的外部渐近定理。等半径稳定性输入归用户原有成果，不登记为本节新证明。更大的层数常数来自新的径向空隙估计与平滑参数选择。

在同一个 h 下，本节的 \(D(\overline\nu_h)\) 下界可以与经过正交性证明的角向能量下界相加，再扣除一次 \(n\psi(h)\)。不同 h 得到的是不同完整下界，应取最大值，不能直接相加。层数主式、精确空隙积分及人口罚项若描述同一径向能量区域，也不能未经分区证明就重复累加。

新结论说明全局最优者需要更多不同半径，并给近似环层的厚度与人口限制；没有给出各层的唯一人口、分离尺度或角向排布。完整八点锐界、一般 n 的简洁最优构型公式、γ的精确值及全局晶格结晶仍开放。本节不作全球优先权声明，程序及协作审阅不等于外部同行评审或整篇形式化证明。
