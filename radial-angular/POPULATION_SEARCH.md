# 用角平均联合优化环人口和半径：精确动态规划与相位余量

研究资料与项目发起：蒋丰灿（Fengcan Jiang）；本轮推导、程序及交叉审阅包含 OpenAI Codex 协作。2026-10-28。

此前只收缩一个内环。本节改为同时选择**全部环人口和全部半径**，以角平均为精确可优化的目标，再验证实际构型。该代理目标的全局最优不等于实际距离乘积的全局最优；原平面问题仍然开放。

## 1. 对给定人口，角平均最优半径有闭式

取 h∈{0,1} 个原点，以及按半径递增的正规多边形环，人口为 m_i≥2，平方半径为 t_i>0。记

```math
n=h+\sum_i m_i,\quad N=\frac{n(n-1)}2,\quad
S_i=h+\sum_{j<i}m_j,\quad A_i=2S_i+m_i-1,\quad e_i=\frac{m_iA_i}{2}.
```

这些构型已中心化。设每个环独立均匀旋转，用 E_θ 表示角平均。单环判别式和交叉 resultant 的角均值给出

```math
\mathbb E_\theta\log\Delta
=\sum_i m_i\log m_i+\sum_i e_i\log t_i.
```

证明交叉项时，i<j 的项写为 `t_j^(m_i m_j)|1−a exp(iφ)|^(2g)`，其中 `g=gcd(m_i,m_j)`、`L=lcm(m_i,m_j)`、`a=(t_i/t_j)^(L/2)<1`。均匀旋转使 `E log|1−a exp(iφ)|=0`。中心点贡献 `t_i^(h m_i)`，已包含在 S_i 中。

在总二阶矩约束 `Σ m_i t_i=n` 下，因 `Σ e_i=N`，加权算术几何平均或严格凹性给出唯一最优半径

```math
\boxed{t_i^*=\frac{A_i}{n-1}=\frac{2S_i+m_i-1}{n-1}.}
```

`A_(i+1)−A_i=m_i+m_(i+1)>0`，故这个解自动保持严格径向顺序。它不是对实际乘积驻点方程的求解。

最大角平均的指数为正有理数

```math
P_{\rm av}(m,h)=\frac{\prod_i m_i^{m_i}A_i^{m_iA_i/2}}{(n-1)^N}.
```

`m_i A_i` 总为偶数。连续相位空间紧致，各环半径不同使乘积严格正，所以至少一个相位达到 `Δ≥P_av`。因此该数本身就是已证的存在性下界；不需要把某组浮点旋转当作见证。

## 2. 任意半径的径向损失恰为相对熵

令

```math
w_i=\frac{e_i}{N}=\frac{m_iA_i}{n(n-1)},\qquad
v_i=\frac{m_it_i}{n},\qquad
\sum_iw_i=\sum_iv_i=1.
```

在任意允许半径处，角平均的损失有**精确恒等式**

```math
\boxed{\log P_{\rm av}-\mathbb E_\theta\log\Delta
=N\sum_iw_i\log\frac{w_i}{v_i}
=N\,D_{\rm KL}(w\Vert v).}
```

非负性由 `Σw_i log(v_i/w_i)≤logΣv_i=0` 得到，等号仅在 t_i=t_i*。对任意具体相位，还有完整径向、角向分解

```math
\log\Delta=\log P_{\rm av}-N D_{\rm KL}(w\Vert v)+C(t,\theta),
\quad C=2\sum_{i<j}g_{ij}\log|1-a_{ij}e^{i\phi_{ij}}|,
```

以及

```math
2\sum_{i<j}g_{ij}\log(1-a_{ij})\le C
\le2\sum_{i<j}g_{ij}\log(1+a_{ij}).
```

这给出一个用于正规多环区域排除的接口：径向偏离的相对熵罚项可以和角向最大补偿同时计算。如果该上端低于已有可达下界，则该族不含全局最优。它不适用于一般不规则角度的点集，不能据此断言任意最优构型必须有正规多环结构。

## 3. 全部有序偶人口可用整数动态规划精确处理

实现取 `h=n mod 2`，所有非中心环人口均为偶数。于是每个交叉 L 都是偶数；正负多项式相位的实际乘积也完全有理。该限制不是对全局最优构型的假设。

设已经放置 s 个点（含原点），再加一个偶人口 m 的环，其 A=2s+m−1，代理目标分子增加整数因子

```math
m^m(2s+m-1)^{m(2s+m-1)/2}.
```

令 D[h]=1，按 s 递增，执行

```math
D[s+m]\leftarrow\max\left\{D[s+m],\;
D[s]m^m(2s+m-1)^{m(2s+m-1)/2}\right\}.
```

终点 `D[n]/(n−1)^N` 就是上述代理目标在**全部有序偶数组合**中的精确最大值。后续奖励只依赖总人口 s，故最优前缀替换不会损失未来选择；这是动态规划完备性的理由。q=(n−h)/2 时，转移总数恰为 q(q+1)/2。实现先检查完整预算；拒绝时不返回部分搜索最优值。整数可能很大，转移数是状态预算，不是多项式位复杂度承诺。

原稿完整环 `m_i=6i` 的角平均最优参数为 `6i²−1`，而非原来的 `6i²`。更大的有限改善来自重新选择人口：小余数不再被强制放在最外环。

## 4. 实际构型、相位上界与复核范围

对动态规划选择的人口及 A_i，程序调用既有图分解，精确优化新固定半径下的**全部正负相位**。原点额外贡献 `A_i^m_i`；未经缩放的二阶矩恰为 `n(n−1)`，故实际平方半径是 `A_i/(n−1)`。

程序另用每个交叉 resultant 的三角不等式计算**全部连续旋转**的上界：把 `|B^p exp(iφ)−A^p|` 替换为 `B^p+A^p`。逐对上界不一定同时可达，所以这是上界证书。它只约束所选人口和半径，不能去掉这个条件。

在 2≤n≤100 的99项实际复核中，新构型相对此前完整下界包络提高87项：恰为13≤n≤100中除17以外的全部点数。比较保留旧多环、格点、保存整数构型、矩项、旧相位、全部已公开一步有理上升和上一轮内环收缩的45项改善。代表性严格增益下端如下：

|n|中心点h|环参数(m_i,A_i)|比此前完整包络至少提高|
|---|---|---|---|
|13|1|(4,5),(8,17)|32.79%|
|14|0|(4,3),(10,17)|97.55%|
|28|0|(4,3),(10,17),(14,41)|512.96%|
|95|1|(6,7),(12,25),(18,55),(26,99),(32,157)|12040.22%|
|100|0|(2,1),(8,11),(14,33),(20,67),(26,113),(30,169)|5711.14%|

这些百分数只是相对旧有限构造包络的增益，不是相对未知 M_n 的误差。以 n=28 为例，符号为(−,+,−)；以上参数与 `t_i=A_i/27` 已完整指定可达见证。此前保留的更强值继续用于 n≤12 和 n=17。

本次99个所选构型均满足严格有理证书

```math
\max_{\text{全部连续旋转，所选半径人口}}\Delta
\le (1+10^{-6})\Delta_{\text{所给符号}}.
```

这是所检99个有限家族的结果，不是全 n 定理；部分点数实际达到连续相位上界。它说明这些指定环仅靠旋转尚能获得的增益已经很小。更有希望的下一步是允许半径继续变化、改变人口，或打破每环正规角度；相对熵恒等式提供了前两项的统一分析入口。

`verify_population_search.py` 重算65个旧上升见证；独立穷尽至n=22的3070个有序偶数组合核对DP；独立枚举n≤30的128个全部符号值；并以3个有理坐标例直接核对距离乘积及原点因子。所有决定使用整数或 Fraction；实际报告见 `population_search_verification.json`。


代理目标的精确最优、某些固定半径相位家族的严格最优、全部所选相位的微小余量，都不证明一般 n 的全局最优构型，也没有改变已知线性渐近常数范围。本文不作全球优先权或整篇形式化证明声明。

## 5. 把实际新下界直接送回一般构型约束

这里可以得到无需假定正规多环的结论。设 P_n 为上面实际构型的乘积，任意全局最优者均满足

```math
\delta(z^*)=\log(U_n/M_n)\le\log(U_n/P_n).
```

`verify_joint_budget.py` 将 log P_n 分解为小整数的对数及小角向修正 `log(1+q)`，以有理区间包围，避免对巨大距离乘积直接展开高次对数级数。实际计算得到

```math
\log(U_{30}/M_{30})\le0.357749464266,\qquad
\log(U_{100}/M_{100})\le1.128852585095.
```

小数端点均向上取整。将这些严格预算代入本专题的[通用半径层数界](RADIAL_LAYERS.md)，在相同平滑参数集合 h∈{1,99/100} 下，旧有效极坐标余项预算只给出 n=30、100 的必要层数分别为1、2；新预算则给出分别至少2、4层。特别地，

```math
\boxed{\text{任意100点全局最优构型至少有4个不同半径。}}
```

此结论对一般角度成立，半径按中心化全局最优构型计数，包含可能的原点层。它不声称层数恰为4，也不声称本次构型全局最优。n=30至少2层也可能由其他既有结构条件得到，此处只展示统一预算接口的实际变化。核验报告 `joint_budget_verification.json` 保存了最后被排除的层数及严格矛盾证书；这两个点数以外未登记本节的联合计算结果。
