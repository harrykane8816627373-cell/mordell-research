# 保留整数人口的精确径向空带证书

研究资料与项目发起：**蒋丰灿（Fengcan Jiang）**；推导、精确程序及交叉审阅包含 OpenAI Codex 协作。2026-10-28。

本节在已有径向 Dirichlet 能量上保留两项信息：空带内的累计人口是一个确定的整数除以 n；积分的 \(1/s\) 权重可以精确保留。它补充只计空带长度的统一层数约束，并可与角向矩投影罚项相加。没有穷尽所有人口序列或全部构型，也没有由必要约束反推最优构型的存在。

## 1. 空带中的累计人口不能自由选择

沿用

```math
x_i=\sqrt{\frac{n-1}{n}}z_i,\quad
r=\sqrt{\frac2n},\quad
\mu=\frac1n\sum_i\sigma_r(\cdot-x_i),\quad
F(s)=\mu\{|w|^2\le s\},
```

其中 \(\sum_i|x_i|^2=n-1\)。已有能量分解和旋转正交分解给出

```math
\delta(z):=\log\frac{U_n}{\Delta_n(z)}\ge n^2D(\bar\nu),
\qquad
D(\bar\nu)=\frac12\int_0^\infty
\frac{(F(s)-\min\{s/2,1\})^2}{s}\,ds.
```

若平方半径区间 \((a,b)\subset[0,2]\) 与每个平滑圆盘的径向支撑都不相交，则每个圆盘完整位于内侧或外侧。设内侧有 j 个圆盘，则整个空带内 \(F(s)=j/n\)。这里 j 是整数；不能把它重新优化成任意实数而仍声称保留了实际人口信息。

对 \(0<a<b\le2\) 和 \(c=j/n\)，该空带的**精确能量**为

```math
\boxed{\quad
I(a,b;c)=\frac{c^2}{2}\log\frac ba
-\frac c2(b-a)+\frac{b^2-a^2}{16}.
\quad}
```

它只是 \(\tfrac12\int_a^b(c-s/2)^2ds/s\) 的直接积分。若 a=0，则有限能量要求 c=0，此时 \(I(0,b;0)=b^2/16\)。本节的所有积分端点都是**库仑尺度的平方半径**，不要与使用实际半径端点的层数定理混淆。

自由实数 c 的最小点和最小值为

```math
c_* = \frac{b-a}{2\log(b/a)},\qquad
J(a,b)=\frac{b^2-a^2}{16}
-\frac{(b-a)^2}{8\log(b/a)}.
```

完整平方恒等式为

```math
\boxed{\quad
I(a,b;c)=J(a,b)+\frac12\log\frac ba\,(c-c_*)^2.
\quad}
```

所以指定人口的偏离给出一个额外非负项。它和自由空带下界占用的是同一段径向能量，应使用该完整式或取较强者；不能把两个完整径向下界直接相加。

## 2. 未指定 j 时的整数最小化

若只知累计人口 \(j\in\{j_-,\ldots,j_+\}\)，其中 \(0\le j_-\le j_+\le n\)，则仍有安全下界

```math
D(\bar\nu)\ge\min_{j_-\le j\le j_+,\ j\in\mathbb Z}I(a,b;j/n).
```

这是关于 j 的严格凸二次式，连续最优值是 \(nc_*\)。除区间端点截断外，只需它两侧相邻的整数。程序用对数的有理上下端包围 \(nc_*\)，保留覆盖该区间的向下、向上整数，再以有理区间比较这些候选。若精度不足而使候选区间过大，程序明确拒绝计算，不跳过潜在最优整数。

对多个互不重叠的空带，分别最小化并相加仍是合法下界，因为真实构型在每个带上的实际整数人口都属于相应允许集合。但这些独立最小值未必能同时由一条单调人口序列达到。因此本节没有把独立最小化宣称为完整人口序列的最优解，更没有宣称执行了整个构型空间的覆盖。

## 3. 从有宽度半径带认证一个空带和其人口

设一个有确定人口的平方半径带为 \(q\in[\alpha,\beta]\)，平滑圆盘半径平方 \(r^2=2/n\)。若

```math
(\sqrt\beta+r)^2\le a,
```

则整带的全部平滑圆盘都位于空带内侧；若

```math
(\sqrt\alpha-r)_+^2\ge b,
```

则全部位于外侧。如果每个带都可归入内外两类，空带及内侧总整数人口就被完整认证，不要求任何角度规则或驻点条件。

这些比较不需要浮点根式。第一式等价于

```math
a-\beta-r^2\ge0,\qquad
(a-\beta-r^2)^2\ge4\beta r^2.
```

对于 b>0，第二式等价于

```math
\alpha-r^2-b\ge0,\qquad
(\alpha-r^2-b)^2\ge4r^2b.
```

程序同时检查人口总和为 n，以及半径带与总矩 \(n-1\) 相容。这些检查本身不证明条件类非空；需要时另给具体构型。

## 4. 一个由实际人口排除的厚两带整类

取 n=100，库仑尺度平方半径满足：10 个点位于 \([1/25,1/20]\)，90 个点位于 \([109/100,11/10]\)，并满足规定总矩99。

此时 \(r^2=1/50\)。第3节的有理平方比较证明，所有内带平滑圆盘位于 \(s\le1/5\)，所有外带平滑圆盘位于 \(s\ge4/5\)。因此 \((1/5,4/5)\) 是空带，其累计人口恰为10，\(c=1/10\)。精确积分给

```math
\delta(z)\ge10000\,I(1/5,4/5;1/10)
=75+100\log2>\frac{425}{3}.
```

最后只用了 \(\log2>2/3\)，由 atanh 正项级数第一项即得。已有一般 n 可达下界给全局最优者的预算

```math
\delta_{100}<\frac{1657}{12}<\frac{425}{3}.
```

故这个角度任意、有确定人口的厚两带整类**不含全局最大构型**。它非空：内圈取平方半径 \(1/20\) 的正十边形，外圈取平方半径 \(197/180\) 的正九十边形，两者都中心化，且

```math
10\cdot\frac1{20}+90\cdot\frac{197}{180}=99,
\qquad \frac{109}{100}<\frac{197}{180}<\frac{11}{10}.
```

在完全相同的单个积分单元上，旧的 \(1/s\ge1/b\) 有理多项式证书仅给 \(\delta\ge225/2\)，低于上述预算；若把累计人口自由优化，精确空带下界约为50.394，也低于预算。本例说明保留人口与积分权重对这个有限证书有决定作用。它没有声称旧方法经任意细分仍无法排除该类；细分确实可使旧积分近似趋近精确值。

## 5. 与角向联合能量及复核

径向能量与非零 Fourier 角向能量正交。因而本节互不重叠空带的能量之和，可以与已证的角向幂和、混合矩 Gram 投影罚项相加。若不同径向证书覆盖同一能量区域，必须避免重复计数；简单的安全做法是先对完整径向下界取最大值，再加角向罚项。

[population_gap.py](population_gap.py) 使用标准库有理运算，并复用先前 `joint-bounds/subset_moment.py` 的带尾项对数包围。执行

```bash
python -B -S -O radial-angular/verify_population_gap.py
python -B -S -O radial-angular/verify_population_gap.py --write-report
```

[复核报告](population_gap_verification.json)记录2112项根式消去比较、464组整数最小化与4796个完整允许计数的对照，以及上述厚两带排除证书。理论量词由正文承担，有限样例不能代替其解析证明。没有得到新的未知点数锐值、完整八点上界或一般 n 的最终最优构型。
