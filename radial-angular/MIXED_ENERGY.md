# 径向加权角向矩：可递增的精确 Gram 能量证书

研究资料与项目发起：**蒋丰灿（Fengcan Jiang）**；推导、代码及交叉审阅包含 OpenAI Codex 协作。2026-10-28。

此前角向界只使用全纯幂和 pₖ=Σxᵢᵏ。不同半径层的同一角向模式可能互相抵消，使pₖ=0，却仍保留明显的角向不均匀。本节加入径向权重，给出一个有理 Gram 矩阵证书；旧界是它的第零级。该方法给必要条件和构型类上界，不由满足条件反推最优性。

## 1. 可调平滑与联合不等式

设n≥2，Σ|zᵢ|²=n，构型无碰撞，x=√((n−1)/n)z。记δ(z)=log(Uₙ/Δₙ(z))，Uₙ为此前圆盘上界。任取h>0，令

```math
r=h\sqrt{2/n},\quad
\mu_h=\frac1n\sum_i\sigma_r(\cdot-x_i),\quad
\nu_h=\mu_h-\mu_0,\qquad
\psi(h)=\frac{h^2-1}{2}-\log h\ge0.
```

这里μ₀是半径√2的均匀背景圆盘。对任意有限角向模式集合及非负整数dₖ，取R≥max|xᵢ|+r、S=R²，并定义复向量

```math
A_{k,j}=\sum_i x_i^k
\sum_{\ell=0}^j
\binom{k+j}{\ell}\binom j\ell
\frac{r^{2\ell}}{\ell+1}|x_i|^{2(j-\ell)},
\quad 0\le j\le d_k,\quad k\ge1,
```

以及正定矩阵

```math
(H_k)_{j\ell}=\frac{(k+j)(k+\ell)}{k+j+\ell}
S^{k+j+\ell}.
```

则

```math
\boxed{\delta(z)\ge n^2D(\overline{\nu_h})
+\sum_k A_k^*H_k^{-1}A_k-n\psi(h).}
```

上划线是旋转平均，星号为复共轭转置。对于h=1，最后一项为零。对于h≠1，必须扣除nψ(h)，不能直接沿用h=1的δ≥n²D不等式。增大同一模式的径向次数dₖ，或加入新的k，投影下界均不减。**同一模式下不同测试函数的罚项通常不能直接逐项相加；必须保留其Gram矩阵。**

## 2. 测试函数及矩阵的独立推导

对k≥1、j≥0，先定义复函数

```math
\Phi_{k,j}(w)=\begin{cases}
w^k|w|^{2j},&|w|\le R,\\
R^{2k+2j}/\overline{w}^{k},&|w|>R.
\end{cases}
```

其实部和虚部分别作实测试函数。两段在圆周连续，外段调和且衰减，梯度平方可积。对同一k，两实部的Dirichlet内积等于两虚部的内积；实虚交叉内积为零。不同k相互正交，并与所有径向函数正交。

写aⱼ=k+2j，直接极坐标积分给圆内贡献

```math
\frac{a_j a_\ell+k^2}{2(a_j+a_\ell)}R^{a_j+a_\ell},
```

圆外贡献为kR^(aⱼ+aℓ)/2。相加后恰为Hₖ的上述元素。矩阵严格正定：若一个实线性组合的梯度范数为零，它在无穷远衰减故为零函数；圆内不同径向幂次的系数于是全部为零。

设uₐ为νₕ势的非径向部分。弱分部积分给

```math
\langle u_a,\Re\Phi_{k,j}\rangle_D
=\frac1n\Re A_{k,j},\qquad
\langle u_a,\Im\Phi_{k,j}\rangle_D
=\frac1n\Im A_{k,j}.
```

这是因为角向电荷为μₕ−μ̄ₕ，支撑位于|w|≤R；径向背景对测试函数的积分为零。因此**背景圆盘可以超出R**。圆盘平均的测量公式来自有限二项式展开：

```math
\int w^{k+j}\overline{w}^{j}\,d\sigma_r(w-x)
=x^k\sum_{\ell=0}^j
\binom{k+j}{\ell}\binom j\ell
\frac{r^{2\ell}}{\ell+1}|x|^{2(j-\ell)}.
```

展开中只有相同次数的圆盘位移及其共轭配对保留，且∫|v|^(2ℓ)dσᵣ(v)=r^(2ℓ)/(ℓ+1)。这一步不能只对非调和多项式直接使用调和均值性质。

在各有限测试空间上作Dirichlet正交投影，得到n²D(νₕ−ν̄ₕ)≥ΣA*H⁻¹A。与径向能量正交相加，再代入[可调平滑分解](RADIAL_LAYERS.md)，即得第1节。有限投影空间的嵌套性直接证明单调性。这里没有宣称已计算无限层级，或由有限层级恢复全部原能量剩余项。

## 3. 第一级的简明公式

只取j=0,1。令pₖ=Σxᵢᵏ、qᵢ=|xᵢ|²，则

```math
A_{k,0}=p_k,\qquad
A_{k,1}=\sum_i x_i^k\left(q_i+\frac{k+1}{2}r^2\right).
```

显式消元得到

```math
\boxed{A_k^*H_k^{-1}A_k
=\frac{|p_k|^2}{kS^k}
+\frac{k+2}{S^{k+2}}
\left|\sum_i x_i^k\left(q_i+\frac{k+1}{2}r^2-S\right)\right|^2.}
```

第一项正是旧全纯矩界，第二项总非负。当pₖ=0时，它仍可检测Σqᵢxᵢᵏ≠0的同一角向模式。这种增强不依赖驻点或任何规则角度。

一个精确例：取未归一化六点

```math
v=\{3,-3,4,-4,5i,-5i\},\qquad
x=v/\sqrt{20},\qquad \sum|x_i|^2=5.
```

有p₁=p₂=p₃=0，而Σ|xᵢ|²xᵢ²=−36/25。取h=1、r²=1/3、S=3；支撑条件由

```math
3-5/4-1/3=17/12>0,\qquad (17/12)^2>4(5/4)(1/3)
```

严格满足。旧k=1,2,3全纯矩罚项之和为零；新一级罚项已给

```math
\delta(z)\ge\frac4{3^4}\left(\frac{36}{25}\right)^2
=\frac{64}{625}.
```

此例说明信息增强，并不宣布一个新的六点锐值，也没有声称旧方法的更高角向模式全部为零。

## 4. 整类区间证书：使用对偶式避免反矩阵区间运算

对于任意指定复系数向量a，有

```math
A^*H^{-1}A\ge2\Re(a^*A)-a^*Ha.
```

若只知道每个Aⱼ的实部、虚部各落在有理区间中，可按系数符号从区间端点得到Re(a*A)的严格下端，H则由指定有理S精确计算。所得下端与0取最大，是该整类上的安全角向罚项。不同k可相加；同一k的多个独立证书可以取最大值，或统一放入一个Gram投影。

把它与同一h下的[半径层数罚项](RADIAL_LAYERS.md)或[人口已知空隙积分](INTEGER_GAPS.md)相加，再扣除nψ(h)的上包。若结果超过可达下界Lₙ给出的log(Uₙ/Lₙ)上端，就排除该整类。这保留了“指定假设→区域上界→与下界矛盾”的完整逻辑；没有遍历全域就不能称为无条件锐值证明。

## 5. 精确实现与范围

[mixed_energy.py](mixed_energy.py)的矩阵、线性方程和对偶端点均使用Fraction。输入有理点v时先中心化，取f=(n−1)/Σ|vᵢ|²。每个Aₖ,ⱼ有共同实因子f^(k/2)，所以平方投影中只出现fᵏ，仍完全有理。h和S也可取有理数；自动支撑使用向上包围的平方根。扣除的ψ使用对数下端，保证最终下界方向安全。

[verify_mixed_energy.py](verify_mixed_energy.py)独立展开二维笛卡尔多项式并积分圆盘矩，核对Gram矩阵、Schur公式、投影嵌套、区间对偶和实际点积；有限测试不代替上述一般证明。当前程序没有调用浮点优化器，不将小残差、投影界或必要约束当成全局最优证明。
