# 十点最大构型的细化半径带

蒋丰灿研究项目，OpenAI Codex 协作。

在质量 \(\sum_i|x_i|^2=9\) 下，任意十点全局最大构型恰有两个平方半径在 \((37/500,43/250)=(0.074,0.172)\) 内的点，其余八点的平方半径均在 \((169/200,164/125)=(0.845,1.312)\) 内。此前的两个允许区间为 \((0.054,0.217)\) 和 \((0.74,1.39)\)。本证书同时保留此前对内点对夹角、中点和距离的约束。[细化全局核与内点证书](../ten-point-banded-kernel-refined/README.md)

## 标记半径的逐行缺额

设 \(u=|x_i|^2\) 为标记点的平方半径，对其任意邻点记 \(v=|x_j|^2\)、\(t=\operatorname{Re}(x_i\bar x_j)\)、\(d=u+v-2t\)。以 \(I\) 表示原内带的指示函数。最大构型的质量、质心、完整力与两个内点分别给出
\[
\sum_{j\ne i}(v-1+u/9)=
\sum_{j\ne i}(t+u/9)=
\sum_{j\ne i}\big((u-t)/d-5u/9\big)=
\sum_{j\ne i}\big(I(v)-(2-I(u))/9\big)=0.
\]

记 \(f_{ij}=h(u,v,t)-\log d\)，其中 \(h\) 为细化全局核的两点上界函数。在每个待排除的标记半径小区间中，用四个固定的有理乘子证明
\[
f_{ij}\ge\frac{61}{200000}
+a(v-1+u/9)+b(t+u/9)+g\big((u-t)/d-5u/9\big)
+e\big(I(v)-(2-I(u))/9\big).
\]
同一标记小区间的四个乘子在两个邻点带和两个 \(t\) 符号区间上保持一致。乘以正数 \(d\) 后，用精确 Bernstein 系数和对数的有理切线上端逐盒核验。盒可由既有点距、Gram 条件、Schwarz 删点条件、缩并条件及内点对几何条件排除。标记点和邻点的半径不作排序。对九条边求和，得到 \(R_i=\sum_{j\ne i}f_{ij}\ge549/200000\)。

| 内点 | \([0.054,0.074]\) | 37,744 |
| 内点 | \([0.172,0.217]\) | 41,104 |

## 同一全局预算下的矛盾

细化核满足 \(\sum_{i<j}h_{ij}\le B\)。设 \(V\) 为质量 9 下的整数见证值，程序以有理对数下界重算 \(B-\log V<10^{-6}\)。因此任一全局最大构型都满足 \(\sum_{i<j}f_{ij}\le B-\log V<10^{-6}\)。

唯一内内边的缺额至少为 \(-9/100000\)，其他边的缺额至少为 \(-3/40000\)。若标记的是内点，唯一内内边已计入它的整行，余下 36 边的总缺额下界为 \(-36(3/40000)\)，故总缺额至少为 \(9/200000\)。若标记的是外点，余下 36 边包括唯一内内边与 35 条其他边，故总缺额至少为 \(3/100000\)。两者都大于 \(10^{-6}\)。这排除表中的四段闭区间。

## 内点中点与外点重心

记两个内点为 \(x,y\)，唯一内内边仍用原来的缺额下界。设 \(Q_1\) 为细化全局核的一阶谐波 Gram 块，\(Z_j=\sum_i x_i(u_i-1)^j\)。所有 Gram 罚项非负，由同一个全局预算得到
\[
Z^*Q_1Z \le 2\left(B-\log V+44\frac{3}{40000}+\frac{9}{100000}\right)
<\frac{3391}{500000}.
\]
一阶谐波采用原始幂基。完整力给 \(Z_0=Z_1=0\)，所以可以只用 \(Q_1\) 的后四行列组成的主块 \(Q\)。

在两个新半径带上取五次多项式 \(g(u)=\sum_{j=0}^5 a_j(u-1)^j\)，逼近内带指示函数 \(I(u)\)。令 \(a'=(a_2,a_3,a_4,a_5)^T\)。复核器在每带验证
\[
\sqrt u\,|g(u)-I(u)|<e_{\rm band}+s(u-9/10),
\qquad (e_{\rm in},e_{\rm out},s)=(0.00534,0.02000,-0.0432535).
\]
右侧严格为正，因此程序可先平方再用一维 Bernstein 系数验证这两个不等式。质量守恒使线性项求和为零。用复内积的 Cauchy–Schwarz 不等式，
\[
|x+y|
\le \left|\sum_i x_i g(u_i)\right|+\sum_i|x_i|\,|I(u_i)-g(u_i)|
<\sqrt{\frac{3391}{500000}\,(a')^TQ^{-1}a'}+2e_{\rm in}+8e_{\rm out}.
\]
程序复核 \(Q\) 正定，将 [Jacobian 的有理解](jacobian_midpoint_solve.json) 逐项代回线性方程 \(Qw=a'\)，再平方核对右侧小于 \(239/1000\)。因此内点中点的模小于 \(239/2000\)，平方模小于 \(57121/4000000\)。完整构型居中，八个外点的重心是 \(-(x+y)/8\)，其模小于 \(239/8000\)。
