# 十点半转分支的径向消元与部分覆盖

假设质量九的全局最大构型具有半转对称。把五个点对平方，旋转后得到内像 \(w_0=a>0\) 和四个角序外像 \(w_j=r_j u_j\)，其中 \(|u_j|=1\)。在已证的[径向范围](../ten-point-angular-radii/README.md)内，\(0.89<r_j<1.271\)，由[内边距离](../ten-point-inner-edge/README.md)得 \(43/400<a<53/400\)。原外点相邻角加倍，给四个外像的相邻正向间隙。其余弦在 \((-1519/5000,271/1250)\)，正弦大于 \(19/20\)。任意两个相隔两位的外像夹角余弦小于 \(-81/100\)。这些界由[相邻外角](../ten-point-outer-gap/README.md)复核。

## 固定角度后的唯一径向分支

循环重排，使半径最小的外像编号为 2。令 \(b(r)=(17-10r)r\)。它在已证外带上严格递减，逆函数为

\[
r(b)=\frac{17+\sqrt{289-40b}}{20}.
\]

固定 \(a,r_1\) 和四个外方向。二阶 Ward 方程给

\[
b_3u_3+b_4u_4=-b(a)-b(r_1)u_1-b_2u_2.
\]

由于 \(\det(u_3,u_4)>19/20\)，可将 \(b_j=b(r_j)\) 表示为 \(b_j=\alpha_j-\eta_j b_2\)，其中

\[
\eta_3=\frac{\det(u_2,u_4)}{\det(u_3,u_4)},\qquad
\eta_4=\frac{\det(u_3,u_2)}{\det(u_3,u_4)}.
\]

外带和最小半径条件等价于 \(b_2,b_3,b_4\) 各落在给定区间且 \(b_2\ge b_1,b_3,b_4\)。这些线性不等式在 \(b_2\) 上切出一个区间。又有 \(|\eta_3|<5/8\) 和 \(\eta_4<0\)。在该区间的内部，因 \(r_2\le r_j\) 且 \(b'(r)=17-20r<0\)，质量函数的导数满足

\[
\frac{d}{dr_2}(r_2+r_3+r_4)=1-\eta_3\frac{b'(r_2)}{b'(r_3)}-\eta_4\frac{b'(r_2)}{b'(r_4)}>\frac38.
\]

因此 \(r_2+r_3+r_4=9/2-a-r_1\) 在可行区间上至多有一个解，可用标量单调条件定位三个剩余径向变量。这给出一种互补的六连续参数表示，其中四个外角始终作为独立输入。

质量方程还可直接清去根式。令 \(D_j=289-40b_j(r_2)\) 及 \(L=20(9/2-a-r_1-r_2)-34\)，则

\[
(L^2-D_3-D_4)^2-4D_3D_4=0.
\]

这是 \(r_2\) 的次数至多四的方程，附加 \(L>0,L^2>D_3+D_4\) 可恢复两个正平方根的和。Jacobian 对 \(x^2-A\) 与 \((L-x)^2-B\) 的精确结式独立给出同一个消元式。[原生结式结果](jacobian_resultant.json)

## 精确部分覆盖

反射并重排角序后，可令 \(\operatorname{Im} u_2\ge0\)。在两张有理参数图中使用

\[
u_2=\sigma\frac{1-t^2}{1+t^2}+i\frac{2t}{1+t^2},\qquad
\sigma=\pm1,\quad 0\le t\le1.
\]

另外三个方向由前三个相邻间隙的余弦及正平方根得到。每图的连续变量是 \(a,r_1,t\) 与三个间隙余弦。每个参数盒都用 Ward 仿射式、外带、最小半径约束与质量方程收紧 \(r_2,r_3,r_4\) 的区间。对于当前 \(r_2\) 区间，还在整个区间上包围质量函数的导数。若该导数下端大于 \(1/8\)，则用区间中点的残差完成一次 interval Newton 收缩，再把所得区间传回三个半径。这里所用导数包括向当前物理区间外延伸的根式，只在整个延伸段的根式均为正时收缩。原构型最小平方点距、[半转外半径跨度](../ten-point-half-turn-dispersion/README.md)严格大于 \(47/2000\) 及外像角序给出几何剪枝。

也可用逐点力剪枝。写 \(D_{ij}=|w_i-w_j|^2\)，完整力在半转分支上的实部和虚部均为零。

\[
0=\frac92-5r_i+\sum_{j\ne i}\frac{r_i^2-r_j^2}{D_{ij}},\qquad
0=\sum_{j\ne i}\frac{2r_i r_j\det(u_i,u_j)}{D_{ij}}.
\]

其中 \(r_0=a,u_0=1\)。若任一分量的区间不含零，则可排除参数盒。距离积区间使用 \(\Delta=4^5\prod_i r_i\prod_{i<j}D_{ij}^2\)，可与已有的严格可达阈值比较。算术以 \(2^{-43}\) 为网格，所有结果都用整数向外舍入。平方根的浮点候选由整数平方比较校正。二分以整数中点切开闭盒，两子盒覆盖整个父盒。

## 多维相关残差与收缩

从深度 18 起，把当前六个参数和半径 \(r_2\) 组成七变量盒 \(X\)。用 Ward 仿射式及外带逆函数明确表示 \(r_3,r_4\)，并将质量余量与十个逐点力分量组成十一维函数 \(F\)。这些函数在整个盒的根式及点距分母均有正下界时光滑。程序用向外舍入的自动微分计算 \(DF(X)\)。每个中间表达式还保留盒中心 \(c\) 处的区间值，再将自然区间与 \(f(c)+Df(X)(X-c)\) 交叉收紧。整个过程保留了 Ward 消元后半径与角度的相关性。

若某个原始残差或均值形式残差的区间不含零，就可排除盒。对余下盒，取中心 Jacobian 的七个独立行，并提议一个 \(2^{-43}\) 网格的有理矩阵 \(Y\)。中心行的选择和近似逆使用浮点计算，验收只使用实际提议的有理矩阵。在任何真根 \(x\) 处，都有

\[
x=c-YF_{\rm sel}(c)+(I-YJ)(x-c),
\]

其中 \(J\) 是中心至 \(x\) 线段上所选 Jacobian 行的平均值。因此 \(J\in DF_{\rm sel}(X)\)，右侧的区间包围给出 Krawczyk 收缩。程序还对区间线性关系 \(YJ(x-c)=-YF_{\rm sel}(c)\) 作两轮 Gauss–Seidel 收缩。若所得区间与原盒不相交，便排除盒。交集非空时收紧七个变量，前六个参数的收缩区间用作随后二分的父盒。以上恒等式对每个实际提议的 \(Y\) 都成立。

默认重放两图到深度 25，共访问 5,997,898 个节点。多维检验直接排除 330,387 个盒，另有收缩后在子盒上的间接排除。未决叶数由标量收缩版的 2,323,490 降至 1,907,359，约少 17.9%。未决叶仍须排除或进入候选局部锐界。[复核报告](verification_report.json)

## 复核

在仓库根目录运行 `python -B -S -O ten-point-half-turn-radial-cover/verify_all.py`。这个可选覆盖入口需支持 `__int128` 的 GNU C++20 编译器，可用 `--compiler` 指定路径。程序在临时目录编译，接受上游证书并重放完整的有限深度树。用 `--depth` 可执行不同深度的探索。[固定输入](source_manifest.json)
