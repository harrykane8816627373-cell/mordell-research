## 2. 联合方法及完整推导

沿用当前较小整数箱 A=ceil(q√(2(n−1)/n))，完整枚举最大值记为 Gₙ(q)。全局最大点 z 最近整数圆整并中心化后写成 z+h，E=Σ|h|²≤n/(2q²)。原稿 Gaussian 稳定矩阵为

```math
(Bh)_i=\sum_{j\ne i}\frac{h_i-h_j}{(z_i-z_j)^2},
\qquad \|B\|\le\lambda=\frac{n-1}2.
```

由于 B1=B*1=0，从每一行的欧氏范数与零和正交投影得

```math
\sum_{j\ne i}\frac1{|z_i-z_j|^4}\le\lambda^2(1-1/n).
```

令 rᵢⱼ=(hᵢ−hⱼ)/(zᵢ−zⱼ)，t=max|rᵢⱼ|<1。一次项由力方程抵消、二次项由原稳定条件控制之后，原稿和本轮均给

```math
\log\frac{M_n}{\Delta_n(\widehat{z+h})}
\le(n-1)E+\frac{2}{3(1-t)}\sum_{i\lt j}|r_{ij}|^3.
```

原始圆整误差的每个点模≤1/(√2q)，中心化不改变差值，故 |hᵢ−hⱼ|≤√2/q。逐行 Hölder 给

```math
\sum_{j\ne i}|z_i-z_j|^{-3}
\le(n-1)^{1/4}\left(\sum_{j\ne i}|z_i-z_j|^{-4}\right)^{3/4}
\le\frac{\lambda^{3/2}(n-1)}{n^{3/4}}=:s.
```

对称正权 aᵢⱼ=|zᵢ−zⱼ|⁻³的加权图二次型满足

```math
\sum_{i\lt j}a_{ij}|h_i-h_j|^2
\le2\sum_i|h_i|^2\sum_{j\ne i}a_{ij}\le2sE.
```

只对其中一个圆整差值取模长上界，其余保留平方范数，得到原修订稿的三阶估计：

```math
\sum_{i\lt j}|r_{ij}|^3
\le\frac{\sqrt2}{q}\sum_{i\lt j}a_{ij}|h_i-h_j|^2
\le\frac{(n-1)^{5/2}}{n^{3/4}q}E
\le\frac{n^{1/4}(n-1)^{5/2}}{2q^3}.
```

最后一步使用 E≤n/(2q²)。不能只把所有圆整差值粗暴替换成同一个最大值，否则会丢掉这里保留的范数改善。

旧稿三阶范数控制与较新的严格子集点距可以直接联合。n≥3 时 |zᵢ−zⱼ|²>4/(n−1)，所以

```math
t\le\tau:=\frac{\sqrt{(n-1)/2}}q\lt1.
```

于是联合误差可取

```math
\boxed{\displaystyle
E_{\rm row}(n,q)=\frac{n(n-1)}{2q^2}
 +\frac{n^{1/4}(n-1)^{5/2}}{3(1-\tau)q^3}.}
```

该三阶分子沿用原修订稿，改善发生在较强点距所给的分母及较小的完整网格箱。当前可移植实现还与下面的另一已有估计取最小。

此前的平方和控制给

```math
E_{\rm pair}(n,q)=\frac{n(n-1)}{2q^2}
\left(1+\frac{n\tau}{6(1-\tau)}\right).
```

因此 Gₙ(q)≤Mₙ≤Gₙ(q)exp(min{E_row,E_pair})；q≥n 时还可加入旧35/72有理上包取最小。每个候选误差都有效，取最小不需要假设三者哪一个对所有 n 都更好。

## 3. 有理实现和未执行计划
