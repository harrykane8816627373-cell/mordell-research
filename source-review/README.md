## 2. 不要求规则角度的半径层数定量界

令 K(z) 为全局最优构型相对重心的不同半径数。将旧多环有效下界与现有圆盘库仑缺额联合，得到

```math
\boxed{\displaystyle
\log\frac{U_n}{M_n}\ge
\frac{n^2}{192(K+1)^2}
\left(2-\frac{8K}{\sqrt n}\right)_+^3.}
```

其中 Uₙ为已公开圆盘上界。旋转平均降低零质量电场能，而 K 层圆盘平滑后的平方半径支撑只覆盖至多 K 段，每段宽≤8/√n；未覆盖区间产生明确能量代价。[完整证明](RADIAL_LAYERS.md)进一步给出

```math
\boxed{K(z)\gt\frac{\sqrt n}{12}\quad(n\ge2),\qquad
\liminf_{n\to\infty}\frac{K(z^{(n)})}{\sqrt n}\ge\frac{11}{50}.}
```

全 n 的1/12版本还使用原稿已证的正多边形不稳定性；不调用该结论也有1/16版本。有限界不依赖未知的渐近余项速率；11/50的渐近加强使用已有线性项及三角晶格试探下端。半径层上的角度完全任意，未假设正多边形或反射对称。

## 3. 恢复完整下界包络，再作严格改善

将旧多环 Dₙ加入此前公开下包络，在2≤n≤100中即有42个点数提高。再恢复原稿保存的 n=6,…,12 整数构型，n=10、11、12也提高。此后才比较本轮相位和中心化改善，最终在这个**完整恢复的旧包络**上又有43个点数严格提高。

新增构造只需各环二项式参数取±号，在两个固定符号方案中择优；交叉resultant由差变和而不下降，且对每个 n≥7至少一对严格提高。单点外环再精确中心化。[证明与范围](POLAR_REFINEMENT.md)、[99个点数的精确比较](lower_bound_comparison.json)、[可移植构造代码](polar_refinement.py)。

十二点的整个双正六边形家族还可精确优化，取得

```math
\frac{2^{102}5^{15}}{3^{57}},\qquad
r_1^2,r_2^2=1\pm\sqrt{7/27}.
```

它仍低于原稿保存的十二点整数构型，故不声称刷新十二点最佳下界，更不称它为 M₁₂。

## 4. 联合现有估计，避免重复或无效路线

- [更强删除损失](DELETION_REFINEMENT.md)：对数Jensen损失的最佳统一二次系数 h(T)=(T−1−logT)/(T−1)²，使删点径向罚项由原1/[4(n−1)]加强为 cₙ>1/[4(n−2)]，并能直接加入一般子集方差。
- [混合网格误差](HYBRID_GRID.md)：把原稿完整稳定矩阵的三阶范数控制与较新的严格点距联合，再与平方和估计取最小。八点1%充分计划从 q58降到 q55；大型网格未执行，不能当作新的八点数值上界。
- [量化谱层障碍](QUANTITATIVE_SPECTRAL_GAP.md)：将原有“有限层不锐”加强为显式正缺口，并明确应转向原稿已经建立的实混合平方或关键值增广模型。它量化方法限制，不改善 Mₙ 本身。
