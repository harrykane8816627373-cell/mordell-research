# 恢复原有全 n 极坐标构造，并作统一相位及中心化改善

研究资料与项目发起：蒋丰灿。2026-10-27。用户原修订稿 `anc/all_n_rings_section.tex` 的全 n 有理极坐标构造及其三项渐近式是既有成果。本节在该明确构型上给出两个不用数值寻优的改善。

## 1. 原构造和符号相位

令 k 最大且 n₀=3k(k+1)≤n，r=n−n₀。内环人口、平方半径分子依次为

```math
(m_a,b_a)=(6j,6j^2)\quad(1\le j\le k),
```

r>0时加外环 (r,n+n₀)，各平方半径为 b_a/n。它们人口和为 n、总二阶矩为 n，半径严格递增。原稿所有环相位为0。

现在为每环选择 s_a∈{−1,+1}，令其点为二项式的根：

```math
z^{m_a}=s_a(b_a/n)^{m_a/2}.
```

这只将该环旋转0或π/m_a，不改变半径、人口或总二阶矩。记 g_ab=gcd(m_a,m_b)，L_ab=m_am_b/g_ab。本构造每个交叉 L_ab 均为偶数，环间 resultant 绝对值平方给出精确正有理数

```math
D_n(s)=\frac1{n^N}\prod_a m_a^{m_a}b_a^{m_a(m_a-1)/2}
\prod_{a\lt b}
\left|s_b^{m_a/g_{ab}}b_b^{L_{ab}/2}
      -s_a^{m_b/g_{ab}}b_a^{L_{ab}/2}\right|^{2g_{ab}}.
```

每个绝对值要么是 b_b^(L/2)−b_a^(L/2)，要么是二者之和。原值 D_n 正是全部取差的情况。因此**任意**这些符号相位都不减小原有构造值。

## 2. 只需两组符号，所有 n≥7 都严格改善

取以下两种固定方案：所有 s_a=−1；或第一环 s₁=+1、其他 s_a=−1。令 P_n 是这两种有理值的最大者，则

```math
P_n\ge D_n\quad(n\ge2),\qquad
\boxed{P_n\gt D_n\quad(n\ge7).}
```

证明：n≥18时 k≥2，前两内环人口为6、12。全部负号使它们交叉 resultant 中的两项异号，所以差变成和，严格增大，其余交叉项均不减小。

当7≤n≤17时恰有两个环，人口为6、r。令 p=6/g、q=r/g，则 p,q互素。若其奇偶不同，全部负号已使交叉项变成和；若同为奇数，第一环取正号、第二环取负号使其变成和。所有半径严格不同，故每次将正差变成正和均严格改善。n≤6只有一个环，两种符号只产生整体旋转，值相同。

## 3. 单点外环的中心化改善

r=1时，其余环的重心为0，仅外环单点贡献非零和。无论上述符号如何，点和的模平方均为 (n+n₀)/n。先中心化所得总二阶矩为

```math
Q_{\rm cen}=n-\frac{n+n_0}{n^2}.
```

重新缩放到规定总二阶矩 n，将乘积严格乘上正有理因子

```math
\left(\frac{n}{Q_{\rm cen}}\right)^N
=\left(\frac{n^3}{n^3-n-n_0}\right)^N\gt1.
```

其余情况所有环人口至少2，原构造已中心化，无此增益。定义完成相位和必要中心化的值为 P_n^cen，则仍是每个 n 的明确可达正有理下界，且对每个 n≥7严格大于用户原有 D_n。

## 4. 一个可简写的十二点例

两个正六边形分别取平方半径1/2和3/2，相差半个六边形角步长，则

```math
\boxed{M_{12}\ge P_{12}=\frac{3^{27}7^{12}}{2^{30}}.}
```

原先同相位构造为 D₁₂=3²⁷13¹²/2⁴²，提升比为 (14/13)¹²。两圈人口相同，因此没有与原稿“不等人口两圈不可能驻点”定理冲突；这里也不声称该十二点构型达到全局最大。

还可以把整个双正六边形家族精确优化。以 u,v 表示平方半径，约束为 u+v=2；给定半径时，两个六次幂参数相反使交叉 resultant 最大。置 t=uv∈(0,1]，全部相位与半径的优化遂化为

```math
\Delta(t)=6^{12}t^{15}(8-6t)^{12},\qquad
\frac{d}{dt}\log\Delta(t)=\frac{120-162t}{t(8-6t)}.
```

该导数在 t=20/27 前正后负，t↓0时乘积趋于0，故得到全家族唯一最优半径积。其平方半径为 1±√(7/27)，值为

```math
\boxed{\displaystyle
M_{12}\ge Q_{12}=\frac{2^{102}5^{15}}{3^{57}}
\gt\frac{3^{27}7^{12}}{2^{30}}.}
```

这是对全部两圈正六边形相位与半径的精确家族最大，不是对任意十二点的全局证明。`twelve_two_ring_maximum()`实现其精确有理值。

完整恢复原稿保存的整数构型后，原有十二点有理下界实际上高于本节 Q₁₂。因此该家族优化不刷新十二点最佳已知下界；最终包络保留原保存构型。不得因只比较此前公开的较小包络而遗漏这一更强旧结果。

## 5. 渐近界限不会因此被误报为锐值

原稿把交叉项写成 T=Σ2g log(1−q_ab)，其中 0<q_ab<1，并证明一般点数 T=O(√n)，在 n=3k(k+1)子列为O(1)。符号旋转只能将某些 log(1−q)改成log(1+q)。因

```math
0\le\log\frac{1+q}{1-q}\le-2\log(1-q),
```

全部相位增益被 −2T 控制。中心化因子的对数为O(1)。故 P_n^cen 与 D_n 具有同一三项渐近式

```math
\log P_n^{\rm cen}
=\left(\frac12\log2-\frac14\right)n^2
 +\frac n2\log n+\left(\frac12\log6-\frac12\right)n+O(\sqrt n).
```

因此原稿已经证明的线性缺额仍然存在：其与真实 M_n 的每点对数差趋于 γ−γ_pol>1/200。有限 n 的统一严格改善不等于解决该微观能量缺额。

## 6. 精确比较范围

独立 Fraction 比较覆盖2≤n≤100。恢复原 D_n 已在42个点数严格提高此前公开下包络：14–18、27–36、50–54、56–60、74–84、86–91。再完整恢复原稿 n=6,…,12 的保存整数构型后，n=10、11、12 的包络也提高。这个完整旧成果包络上，两组符号与中心化的新改善在43个点数胜出：上述42个点数加61。此前只恢复Dₙ而未加入保存构型时会得到44项（额外含12）；这里使用完整比较，避免把弱于用户已有结果的十二点构造误报为刷新下界。

这些范围只是有限精确比较，不宣称 P_n^cen 对所有 n 均胜过所有已有下界。全 n 严格比较 P_n^cen>D_n 由第2、3节解析证明承担。

可移植核心实现为 `polar_refinement.py`，只用标准库；最终完整比较由 `compare_envelopes.py`、`saved_rational_bounds.json`及`lower_bound_comparison.json`承担。后者明确区分此前公开、完整恢复及本轮改善三个包络。
