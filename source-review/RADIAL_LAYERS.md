# 联合多环下界与库仑缺额：一般最优构型至少有平方根量级的半径层

研究资料与项目发起：蒋丰灿（Fengcan Jiang）；本次来源核对及补充推导包含 OpenAI Codex 协作。2026-10-27。

原修订稿已证明：固定 K 个规则正多边形环有二次指数亏损；任意全局最优构型的不同半径数趋于无穷。本节联合原稿的有效多环下界与已经公开的圆盘库仑缺额，把后一个定性结论有效化。不要求每层角度规则，也不要求反射或其他对称性。

## 1. 定量结论

设 z 是总二阶矩 n 的任一全局最大构型，K=K(z) 是相对于其重心的不同半径数。全局最大者重心为零。沿用

```math
N=\frac{n(n-1)}2,\quad c_* =\frac12\log2-\frac14,
\qquad
U_n=n^{n/2}\left(\frac{2n}{n-1}\right)^N e^{-N/2}.
```

则有完整有限 n 必要条件

```math
\boxed{\displaystyle
\log\frac{U_n}{M_n}
\ge\frac{n^2}{192(K+1)^2}
\left(2-\frac{8K}{\sqrt n}\right)_+^3.}
```

这里 x₊=max(x,0)。右端仅在 K<√n/4 时提供正信息；这是一条半径层数约束，不是有限 n 锐值公式。它直接推出有效的统一弱界

```math
\boxed{K(z)\gt\frac{\sqrt n}{16}\qquad(n\ge2).}
```

再联合原稿已证明的“等半径驻点必为正多边形，且 n≥8 的正多边形不稳定”，可加强为

```math
\boxed{K(z)\gt\frac{\sqrt n}{12}\qquad(n\ge2).}
```

结合已有线性渐近项和已核验的三角/圆盘常数，还得到对任意一列全局最优构型

```math
\boxed{\displaystyle\liminf_{n\to\infty}\frac{K(z^{(n)})}{\sqrt n}
\ge\frac{11}{50}.}
```

有限常数 1/12 和渐近常数 11/50 不声称最优。半径可以任意接近；本定理计数的是精确的不同半径，而不是给出环层之间的统一分离距离。

## 2. 由圆盘平滑得到径向能量下界

使用[已发表的精确能量分解](../asymptotics/README.md)。令

```math
x_i=\sqrt{\frac{n-1}{n}}z_i,\qquad r=\sqrt{\frac2n},
\qquad \mu=\frac1n\sum_i\sigma_r(\cdot-x_i),
\qquad \mu_0=\frac1{2\pi}{\bf1}_{|x|\le\sqrt2}\,dx,
\qquad \nu=\mu-\mu_0.
```

σᵣ是均匀圆盘概率测度。记对数能量 D(ν)=∬−log|x−y|dν(x)dν(y)。分解的其余两项非负，故

```math
\log(U_n/M_n)\ge n^2D(\nu).
```

ν具有紧支撑、有界密度且总质量零。零质量的 Dirichlet 表示为

```math
D(\nu)=\frac1{2\pi}\int|\nabla(g*\nu)|^2\,dx,
\qquad g(x)=-\log|x|.
```

将电荷绕原点作旋转平均得到径向电荷 ν̄。平方范数的凸性给 D(ν)≥D(ν̄)。令 F_μ(s)=μ{|x|²≤s}；旋转平均不改变这个累计分布。径向 Gauss 公式或对圆周对数平均直接求导，给出

```math
D(\bar\nu)=\frac12\int_0^\infty
\frac{\bigl(F_\mu(s)-\min\{s/2,1\}\bigr)^2}{s}\,ds.
```

证明常数：若 C(ρ)=ν̄{|x|≤ρ}，则径向势导数为−C(ρ)/ρ，Dirichlet 积分等于∫C(ρ)²dρ/ρ；置 s=ρ²即得1/2系数。这一步允许平滑圆盘重叠，未使用点距分离。

## 3. 半径支撑中的空区间必有能量代价

已有全局半径界给 |x_i|≤√2。若一个圆盘中心的半径为 R，它的平方半径支撑包含于

```math
I_R=[\max\{R-r,0\}^2,(R+r)^2].
```

每个区间长度不超过 4√2r=8/√n：R≥r 时长度为4Rr；R≤r 时长度≤4r²≤4√2r。由于只有 K 个不同的中心半径，F_μ的变化支撑位于至多 K 个这样的区间内。因此这些区间在[0,2]内的覆盖总长度≤8K/√n。

其补集由至多 K+1 个空区间组成，总长度至少 L=(2−8K/√n)₊。在每个长度 ℓ 的空区间(a,b)内，F_μ(s)为常数 c，而 F_μ₀(s)=s/2。又 1/(2s)≥1/4，故其能量贡献至少

```math
\frac14\int_a^b(c-s/2)^2\,ds
\ge\frac{\ell^3}{192}.
```

最后一步把 c 当作自由实数求最小，最小点为(a+b)/4。即使真实累计质量常数受到额外约束，该自由最小仍是合法下界。对所有空区间求和，再用∑ℓ³≥(∑ℓ)³/(K+1)²，就得第1节的有限主不等式。

## 4. 对所有有限 n 有效的平方根下界

原稿的明确多环构造 Dₙ≤Mₙ满足：令 k 为3k(k+1)≤n的最大整数，对 n≥6有

```math
\log D_n\ge c_*n^2+\frac n2\log n+\gamma_{\rm pol}n
-21k-\log(k+1)-9,
\qquad \gamma_{\rm pol}=\frac12\log6-\frac12.
```

现有圆盘上界给

```math
\log U_n\lt c_*n^2+\frac n2\log n+\gamma_D n-\frac14,
\qquad\gamma_D=\frac34-\frac12\log2.
```

使用已核验的初等常数

```math
\gamma_D-\gamma_{\rm pol}=\frac54-\frac12\log12\lt\frac1{100},
\qquad \log(k+1)\le k,\quad k\le\sqrt{n/3}\le\frac7{12}\sqrt n,
```

得到

```math
\delta_n:=\log(U_n/M_n)
\lt\frac n{100}+\frac{77}6\sqrt n+\frac{35}4.
```

若 K≤√n/16，由 K≥1知 n≥256，并有 L≥3/2、K+1≤√n/8。主不等式迫使 δₙ≥9n/8。但当 n≥256 时

```math
\frac{\delta_n}{n}
\lt\frac1{100}+\frac{77}{96}+\frac{35}{1024}
\lt\frac98,
```

矛盾。n<256时 K≥1已经严格大于√n/16，所以结论对所有 n≥2成立。这里未使用未知的渐近余项速率。

进一步，n≥8 时全局最优构型不能只有一个半径：旧稿证明此时等半径驻点只能是正 n 边形，而它有不稳定方向。于是 K≥2。若 K≤√n/12，则 n<144 时立即矛盾；144≤n<576 时迫使 K=1，也矛盾。对 n≥576，利用 K+1≤3K/2≤√n/8 和 L≥4/3，有限主式给 δₙ/n≥64/81。但同一有效上包给

```math
\frac{\delta_n}{n}
\lt\frac1{100}+\frac{77}{144}+\frac{35}{2304}
\lt\frac{64}{81}.
```

再次矛盾，得到全 n 的1/12版本。额外调用的旧多边形稳定性定理不可省略；1/16版本则不需要它。

## 5. 利用微观线性常数的渐近加强

已有定理给 log Mₙ=c_*n²+(n/2)log n+γn+o(n)，故 δₙ/n→γ_D−γ≤γ_D−γ△。公开的严格有理常数证书给

```math
\gamma_D-\gamma_\triangle\lt\frac1{800}.
```

若某个子列的 K/√n趋于 c≤11/50，由有限主式得

```math
\liminf\frac{\delta_n}{n}
\ge\frac{(2-8c)^3}{192c^2}
\ge\frac{9}{6050}\gt\frac1{800};
```

c=0时右侧理解为无穷。函数在0<c<1/4严格递减，所以上述比较成立。这与已有线性常数界矛盾，完成渐近加强。更准确的常数可取方程(2−8c)³/(192c²)=γ_D−γ△在(0,1/4)内的唯一根；本节采用简单有理数展示结论。

这里使用已有重整化能量定理及三角晶格试探下端；并未证明全体微观构型中的三角晶格极小性。K的增长率本身也没有给出每个有限 n 的全局最大值。
