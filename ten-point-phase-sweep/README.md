# 十点两组径向邻域的外角相位覆盖

取总平方半径为 9，把内点写成 \(m\pm\sqrt w\,e\)，其中 \(|e|=1\)。旋转使 \(e=1\)。设八个外点的平方半径按角序为 \(r_1,\dots,r_8\)。本证书检查主候选和已认证鞍点周围的两组参数范围。

| 参照构型 | 容差 \(\varepsilon\) | 结论 |
|---|---:|---|
| 两矩形主候选 | \(3/20000\) | 范围内的全局最大构型只可能在主候选轨道上 |
| 已认证近优鞍点 | \(1/500\) | 范围内没有全局最大构型 |

两组范围都要求 \(|\operatorname{Re}m|,|\operatorname{Im}m|\le\varepsilon\)，且 \(w\) 和各 \(r_j\) 分别与参照构型的同名量相差至多 \(\varepsilon\)。平方半径必须能按一个循环重标号分别和参照构型配上。主候选的参照角从第一象限较靠实轴的外点开始，鞍点从正实轴的外点开始。证书允许未知构型的外点相位任意变化，也允许中点非零和外层对径关系被破坏。

## 相位变量与参考角

两个参照构型的外平方半径序列都在相隔四位时重复。循环重标四位给平均外角加 \(\pi\)，同时保留上述径向配对条件。因而把实际与参照平均外角的差写成 \(\phi=2\arctan t\)，只需覆盖 \(-1\le t\le1\)。

每个 \(t\) 小区间使用一组固定的角修正。三次旋转给成有理半角正切，第四次是前三次旋转之积的逆。四次旋转再对后四点复用。小角范围保证八个角修正的实数和为零。复核器用点积、行列式检查修正后八个相邻间隙全部在[认证的凸角域](../ten-point-outer-gap/README.md)中。把这些方向整体旋转 \(\phi\)，并用实际半径得到参考构型 \(Z_{\rm ref}(t)\)。既有角向严格凹性给出

\[
\log\Delta(Z)\le \log\Delta(Z_{\rm ref})+\|G\|_2^2/(2\kappa),
\qquad \|\theta-\theta^{\rm ref}\|_2\le\|G\|_2/\kappa
\]

其中第二式用于全局驻点，\(G\) 是参考处的均值零角梯度。[新半径与角度比较](../ten-point-inner-midpoint/README.md)给出 \(\kappa=161/50\)。对外外边先将角力写成 \(\sin\psi/(q-\cos\psi)\)，其中 \(q=1+(\sqrt u-\sqrt v)^2/(2\sqrt{uv})\)。共同相位在这些项中消去。对一个外点 \(z\)，两条内外边的角力和是

\[
-4\operatorname{Im}\frac{w+m(z-m)}{(z-m)^2-w}.
\]

用这两种表达计算区间梯度可保留同一相位和同一对内点产生的抵消。若参考半差满足 \(\|a^{\rm ref}-a^*\|_2+(40/161)\|G\|_2\le 7/250\)，[局部锐界](../ten-point-quartic-midpoints/README.md)保证该小区间内的全局最大点属于候选轨道。

## 如何严格排除一个相位区间

取同一组角修正，使用区间中点相位和参照构型的精确径向数据，得到能量锚点 \(W\)。它有质量 9，且成对对径。令 \(D=Z_{\rm ref}-W\)、\(F_i(W)=\sum_{j\ne i}(W_i-W_j)/|W_i-W_j|^2-5W_i\)。使用 \(\log x\le x-1\) 得

\[
\log\Delta(Z_{\rm ref})-\log\Delta(W)
\le 2\operatorname{Re}\sum_i\overline{F_i(W)}D_i
+\sum_{i<j}\frac{|D_i-D_j|^2}{|W_i-W_j|^2}-5\|D\|^2.
\]

由于锚点对径，两内点中点偏移的线性贡献精确抵消。外点的线性项分成半径变动与相位变动，公共相位项在所有外点上先求和，再取上界。平方项用正权 Laplacian 的行和界控制。由 \(|d(2\arctan t)/dt|\le2\)，相位偏离区间中点的角度至多为区间宽。由此得到对整个区间及全部径向扰动的有理对数增量上界。再加角力残差项，用指数的正项级数和几何余项换回距离积，与主候选值的有理下界严格比较。
