# 从精确半径计数到稳定的径向人口分布与带宽证书

2026-10-28。研究资料与项目发起：蒋丰灿；本轮推导含 OpenAI Codex 协作。本文是在已公开圆盘库仑分解和半径层数结果上的补充，不将原有分解或弱等分布重新登记为首次结果。

本节有三个接口：对任意构型的径向分布偏差给出能量罚项；对所有全局最优构型给显式人口误差；给有限有理区间树可接受的整类径向带上界。小分布误差只是必要条件，不能反推全局最优。

## 1. 归一化、已有能量输入与普遍适用范围

令 n≥2，N=n(n−1)/2，z 为任意满足 Σ|zᵢ|²=n 的无碰撞构型，不要求驻点、稳定或预设重心。记

```math
\Delta_n(z)=\prod_{i\lt j}|z_i-z_j|^2,\qquad
U_n=n^{n/2}\left(\frac{2n}{n-1}\right)^N e^{-N/2},
\qquad\delta(z)=\log\frac{U_n}{\Delta_n(z)}\ge0.
```

取 x=αz，α=√((n−1)/n)，r=√(2/n)，并令 μ=(1/n)Σσᵣ(·−xᵢ)，μ₀为半径√2圆盘上的均匀概率，ν=μ−μ₀。此前精确能量分解对每个这种构型给出

```math
\delta(z)\ge n^2D(\nu),\qquad
D(\nu)\ge\frac12\int_0^\infty
\frac{(F(s)-F_0(s))^2}{s}\,ds,
\quad F(s)=\mu\{|x|^2\le s\},\quad F_0(s)=\min\{s/2,1\}.
```

第二式来自旋转平均不增加零质量Dirichlet能和径向Gauss公式，原文已给完整常数。此处不需要全局最大者的半径界；μ可有质量在半径√2以外，圆盘也可以重叠。

## 2. 任意CDF偏差有立方能量代价

设 0≤s₀≤2。若 ε=F(s₀)−s₀/2>0，则 F 的单调性给

```math
F(s_0+t)-F_0(s_0+t)\ge\varepsilon-t/2
\quad(0\le t\le2\varepsilon).
```

整个三角区位于[0,2]，因为 s₀+2ε=2F(s₀)≤2。若 ε=s₀/2−F(s₀)>0，则向左有同样的三角下界，左端 s₀−2ε=2F(s₀)≥0。因此两种情况下，在1/(2s)≥1/4下都有

```math
D(\nu)\ge\frac14\int_0^{2\varepsilon}(\varepsilon-t/2)^2\,dt
=\frac{\varepsilon^3}{6}.
```

s>2时，|F(s)−F₀(s)|=1−F(s)≤1−F(2)，由s=2的情形控制；s<0时两CDF均为0。故

```math
\boxed{\|F-F_0\|_\infty\le
\left(\frac{6\delta(z)}{n^2}\right)^{1/3}.}
```

这是所有规范构型上的定量能量必要条件，不仅是最优点的性质。

## 3. 从平滑分布转回实际点数：完整尺度校正

记 Gₓ(t)=n⁻¹#{i:|xᵢ|≤t}。每个圆盘移动长度≤r，所以对t≥0

```math
F((t-r)_+^2)\le G_x(t)\le F((t+r)^2).
```

目标半径CDF G₀(t)=min(t²/2,1)在整个正半轴上是√2-Lipschitz。因此

```math
\|G_x-G_0\|_\infty\le
\left(\frac{6\delta(z)}{n^2}\right)^{1/3}+\sqrt2r
=\left(\frac{6\delta(z)}{n^2}\right)^{1/3}+\frac2{\sqrt n}.
```

实际 z 的平方半径CDF为 P_z(s)=n⁻¹#{|zᵢ|²≤s}=Gₓ(α√s)。α²=(n−1)/n，且

```math
\sup_{s\ge0}|\min\{\alpha^2s/2,1\}-\min\{s/2,1\}|=1/n.
```

所以得到完整原尺度结论

```math
\boxed{\displaystyle
\sup_{s\ge0}\left|
\frac1n\#\{i:|z_i|^2\le s\}-\min\{s/2,1\}
\right|
\le\left(\frac{6\delta(z)}{n^2}\right)^{1/3}
+\frac2{\sqrt n}+\frac1n.}
```

注意最后1/n来自原问题与库仑最优尺度的差，不可遗漏。这个证明没有先假定点在全局半径盘内，也没有假定角度规则。

## 4. 全局最优的有效人口与环带约束

若 Lₙ≤Mₙ是任意已证可达下界，则对每个全局最优构型，可将 δ(z)替成已证上包 log(Uₙ/Lₙ)。原稿有效极坐标余项还给完全显式的全n输入（n≥6）：

```math
\delta_n=\log(U_n/M_n)
\lt\frac n{100}+\frac{77}{6}\sqrt n+\frac{35}{4}=:E_n.
```

因此设

```math
e_n=\min\left\{1,
\left(\frac{6E_n}{n^2}\right)^{1/3}
+\frac2{\sqrt n}+\frac1n\right\},
```

则每个全局最优构型的原尺度中心盘人口满足

```math
n(\min\{s/2,1\}-e_n)\le\#\{|z_i|^2\le s\}
\le n(\min\{s/2,1\}+e_n),
```

当然还可与0、n取交。对环带a<|zᵢ|²≤b，把两端CDF相减，误差至多2neₙ。故径向CDF误差有效地为O(n⁻¹ᐟ³)，人口误差为O(n²ᐟ³)，而不必诉诸未知o(n)起始阈值。常数在小n时可能使结论退化为[0,n]；不宣称它改善每个小点数锐界。

再用已发表线性项与 γ_D−γ△<1/800，可得任意全局最优列

```math
\limsup_{n\to\infty} n^{1/3}\|P_{z^{(n)}}-F_0\|_\infty
\le (6/800)^{1/3}.
```

这只是该方法给出的保证，不声称最优收敛速率，也不确定γ或有限n最大值。

### 一个更强的中心空洞推论

令 R=minᵢ|xᵢ|。由 Σ|xᵢ|²=n−1知R<1，所以b=(R−r)₊²<2。在[0,b]上μ无质量，径向积分直接给

```math
\delta(z)\ge\frac{n^2}{2}\int_0^b\frac{(s/2)^2}{s}\,ds
=\frac{n^2}{16}(R-r)_+^4.
```

因此对任意规范构型（仍无需驻点或全局半径上界）

```math
\boxed{\displaystyle
\min_i|z_i|\le\sqrt{\frac n{n-1}}
\left[\sqrt{\frac2n}+2\left(\frac{\delta(z)}{n^2}\right)^{1/4}\right].}
```

对全局最优者输入有效δₙ上包，得到至少一个点距重心O(n⁻¹ᐟ⁴)。它不声称存在精确原点，也不声称最优微观尺度已经由本法恢复。

## 5. 有宽度的半径带：精确层数约束的稳定版本

假设某个构型的库仑尺度平方半径 |xᵢ|²均在[0,2]内，并被K个区间覆盖，其长度之和为W。区间可以相交，也不要求各带有任何角度规律。先将覆盖区间与[0,2]取交，不妨0≤α≤β≤2；这在上述支撑假设下不损失覆盖，只会减少总宽W。对一条[α,β]带，圆盘平滑后的平方半径支撑位于

```math
[\max\{\sqrt\alpha-r,0\}^2,(\sqrt\beta+r)^2].
```

它的长度至多(β−α)+8/√n。若√α≥r，直接展开得额外2r(√α+√β)≤4√2r；若√α<r，则额外α+r²+2r√β≤2r²+2√2r≤4√2r。于是平滑支撑在[0,2]内总覆盖长≤W+8K/√n。

用原空区间积分证明，不改变其余常数，得到

```math
\boxed{\displaystyle
\delta(z)\ge\frac{n^2}{192(K+1)^2}
\left(2-W-\frac{8K}{\sqrt n}\right)_+^3.}
```

W=0恢复精确半径计数定理；W>0时它仍约束近环层和有厚度的带，不会因把点半径稍微扰动就自动失去意义。全局最优者的已有半径界保证上述[0,2]假设。对任意构型使用时，该假设需要另外核验。

## 6. 可用于有限区域上界的纯有理证书

这里给出不计算圆相交面积、不做浮点积分的证书。对库仑尺度平方半径qᵢ=|xᵢ|²、r²=2/n，选有限组不重叠的有理区间[aⱼ,bⱼ]⊂[0,2]，bⱼ>0。由三角不等式，每个点的平滑支撑为

```math
\ell_i=(\sqrt{q_i}-r)_+^2,\qquad u_i=(\sqrt{q_i}+r)^2.
```

对整个区间有

```math
L_j:=\frac1n\#\{u_i\le a_j\}\le F(s)
\le U_j:=\frac1n\#\{\ell_i\le b_j\}.
```

故D(ν)至少为下列正有理数之和：

```math
J_j=\frac1{2b_j}\left[
\int_{a_j}^{\min(b_j,2L_j)}(L_j-s/2)^2\,ds
+\int_{\max(a_j,2U_j)}^{b_j}(s/2-U_j)^2\,ds\right],
```

空积分按0理解。这是对F(s)允许质量区间的距离平方作积分，并以1/(2s)≥1/(2bⱼ)替换权重，所以全部由三次多项式有理值计算。

根式比较也可以用整数/有理数完成。例如uᵢ≤a当且仅当a−qᵢ−r²≥0且(a−qᵢ−r²)²≥4qᵢr²；下端比较按qᵢ≤r²及剩余非负量分情况平方即可。程序实现这些等价判断，不用浮点平方根。

于是对具有所给径向数据的**整类**规范构型，

```math
\boxed{\Delta_n(z)\le U_n\exp\left(-n^2\sum_jJ_j\right).}
```

同样可以只给带[αᵢ,βᵢ]及每带确定人口：用βᵢ判断整带必在aⱼ内，用αᵢ判断整带可能在bⱼ内，即得相同安全证书。若其指数下界超过已证log(Uₙ/Lₙ)上端，整类都不可能包含全局最大者。它是区域排除接口；没有覆盖全部径向区域时，不能把某一次计算写成新的无条件Mₙ全局上界。

一个完全有理的整类例：n=100，所有库仑尺度平方半径位于[49/50,1]。取唯一积分单元[0,7/10]。由于

```math
(49/50+1/50-7/10)^2=(3/10)^2
\gt4(49/50)(1/50),
```

每个平滑圆盘都在该单元之外，L=U=0。上述有理单元公式给δ(z)≥1225/6，而全局最优者已有有效上包δ₁₀₀<1657/12，二者矛盾。故整个有厚度、角分布任意的环域都不可能含全局最优者。这个比较没有数值极值搜索。

事实上只要求全部|xᵢ|²≥49/50也足够；上端可以取由总矩保证的n−1。相同平方比较对所有n≥100成立，因为49n²−4200n+2500在100处为正且其后递增。有理单元下界为49n²/2400，而有效全局上包除以n随n递减，其在100处为1657/1200<49/24。于是每个n≥100的全局最优者必有一点满足|xᵢ|²<49/50。该具体常数只作整类证书示例，不声称是最小半径的最强阈值。

实现与独立有理检查见 `radial_distribution.py`、`verify_radial_distribution.py`。理论的通用量词由本文证明承担，有限样例不代替全n分析。
