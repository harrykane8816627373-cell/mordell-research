# 用人口的二进赋值精确分解全部正负相位

研究资料与项目发起：蒋丰灿（Fengcan Jiang）；本次精确相位分解、证明与实现包含 OpenAI Codex 协作。2026-10-28。

此前已发表的有理极坐标构造用两个固定正负相位方案择优。本节不改变环的人口和半径，而是把**全部**正负相位的最优选择分解成独立有限子问题，并用有理乘积精确求解。优化范围仍只是这个明确相位家族，不是任意平面构型，也不是全部连续相位或半径。

## 1. 环的精确乘积与正负相位

取按平方半径递增的环数据(mᵢ,bᵢ)，mᵢ为正整数、bᵢ为正整数，平方半径为bᵢ/n。各环点由

```math
z^{m_i}=s_i(b_i/n)^{m_i/2},\qquad s_i\in\{-1,+1\}
```

给出。假定所有交叉 Lᵢⱼ=lcm(mᵢ,mⱼ)都是偶数。旧极坐标构造满足该条件，因为除可能的单个外环外，内环人口均为偶数。

记gᵢⱼ=gcd(mᵢ,mⱼ)，pᵢⱼ=Lᵢⱼ/2。交叉 resultant 的模平方为

```math
n^{-m_im_j}
\left|s_j^{m_i/g_{ij}}b_j^{p_{ij}}
-s_i^{m_j/g_{ij}}b_i^{p_{ij}}\right|^{2g_{ij}}.
```

令D(s)为完整距离平方乘积，D(+)为全正号的值。每个交叉因子只能在正差和正和之间切换。定义正有理增益

```math
R_{ij}=\left(
\frac{b_j^{p_{ij}}+b_i^{p_{ij}}}
     {b_j^{p_{ij}}-b_i^{p_{ij}}}\right)^{2g_{ij}}\gt1.
```

这是确切比值，不需要对数近似或浮点相位搜索。

## 2. 二进赋值使跨类作用只剩一元项

令eᵢ=ν₂(mᵢ)，即人口中因子2的指数，Cₑ={i:eᵢ=e}。

- 若eᵢ=eⱼ，则mᵢ/g和mⱼ/g都为奇数。因此交叉增益为Rᵢⱼ当且仅当sᵢ≠sⱼ。
- 若eᵢ<eⱼ，则mᵢ/g为奇数、mⱼ/g为偶数。因此交叉增益为Rᵢⱼ当且仅当**较高赋值环**的符号sⱼ为−1，与较低赋值环符号无关。eᵢ>eⱼ的情形对称。

为每个环定义一元因子

```math
A_i=\prod_{j:e_j\lt e_i}R_{ij},
```

这里Rᵢⱼ按无序点对理解。则全部相位有精确分解

```math
\boxed{\displaystyle
\frac{D(s)}{D(+)}
=\prod_i A_i^{\mathbf1_{s_i=-1}}
 \prod_{i\lt j,\ e_i=e_j}
 R_{ij}^{\mathbf1_{s_i\ne s_j}}.}
```

取对数后，它是同赋值类内部的正权割项，加每个顶点的一元奖励；不同赋值类之间已没有符号耦合。这个图形式只是帮助理解，接受程序直接比较有理乘积。

## 3. 独立类枚举即得全正负家族最优

对每个赋值类定义

```math
F_e(s_{C_e})=
\prod_{i\in C_e}A_i^{\mathbf1_{s_i=-1}}
\prod_{i\lt j,\ i,j\in C_e}R_{ij}^{\mathbf1_{s_i\ne s_j}}.
```

由于类之间完全独立，

```math
\boxed{\displaystyle
\max_{s\in\{\pm1\}^{k}}D(s)
=D(+)\prod_e\max_{s_{C_e}\in\{\pm1\}^{|C_e|}}F_e(s_{C_e}).}
```

每个最大值在一个显式有限集合中取得；有理数交叉相乘即可比较。最小赋值类没有一元因子，整类翻转符号不改变其值，因此可固定该类第一个符号为+1。设其赋值为e₀，枚举状态数为

```math
\sum_e2^{|C_e|-\mathbf1_{e=e_0}},
```

而不是直接枚举2ᵏ个全部相位向量。这不声称多项式复杂度：最大的类仍可很大。程序超过状态预算时在枚举开始前拒绝，不会把部分搜索写成全家族最优。

若旧极坐标构造有单点外环，其中心化增益为

```math
\left(\frac{n^3}{n^3-n-n_0}\right)^{n(n-1)/2}.
```

它与符号无关，所以仍可在上述类优化完成后精确相乘。其他环人口至少2，重心为零。此处没有遗漏某些符号方案中心化后失去可达性的情况。

## 4. 全 n 的有理下界及一个明确改善

将旧polar数据代入，记精确类优化并必要中心化后的值为Pₙ^graph。它是每个有限n的明确正有理可达下界，且

```math
M_n\ge P_n^{\rm graph}\ge P_n^{\rm two\ signs}\ge D_n.
```

后两者是此前的两个固定相位方案和原同相位构造。n≥7时旧两方案已严格改善Dₙ，故这里同样严格。并不声称每个n都严格改善旧两方案；例如环数很少时旧方案可能已经最优。

三十点是一个简洁例。人口为6、12、12，平方半径为1/5、4/5、8/5。新最优符号为(+1,−1,+1)，相比旧两个方案最大值的改善恰为

```math
\boxed{\displaystyle
\frac{P_{30}^{\rm graph}}{P_{30}^{\rm two\ signs}}
=\left(\frac{90155}{84693}\right)^{12}\gt2.}
```

推导：同赋值的两个十二点环由差变和，增益为(65/63)²⁴；外十二点环改取正号会失去它与六点环的增益(262145/262143)¹²。二者相除并约分得到所示值。程序同时核对全部8组符号，确保不是只比较这一个候选。严格大于2由整数比较90155¹²>2·84693¹²决定，十进数只供展示。

## 5. 完整比较与渐近边界

`verify_phase_graph.py --baseline <source-review目录>`在2≤n≤100对99个相位家族逐一独立枚举全部符号，并核对类优化结果。比较对象是已经恢复原多环、全部保存整数构型、两方案相位/中心化、方格、三角格、旧扰动、已公开低阶矩项和十二点家族值的完整包络。

本次相位类优化在完整包络上严格提高13项：

30、50、54、56、58、74、78、80、82、84、86、88、90。

它在旧两个相位方案本身上提高32项。核验包括768个一般人口对的奇偶分解、2186个直接完整符号乘积、99个完整家族最大值，独立类枚举共655状态。数据见`phase_graph_comparison.json`；各点数环参数及符号足以精确重建值。n≤30另存完整有理值，较大分子分母以哈希记录，避免不必要的巨大十进输出。

所有正负相位的总增益都被原交叉项的−2T控制，因此仍是O(√n)，单点中心化只贡献O(1)。所以Pₙ^graph仍有旧polar线性系数γpol=(log6)/2−1/2，并没有消除已证明的微观线性亏损。这个有限家族的全局优化，不能当成原问题Mₙ的全局最优。
