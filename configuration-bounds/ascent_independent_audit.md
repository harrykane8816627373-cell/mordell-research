# 有理上升单步证书的独立审阅

2026-10-28。作为相位图推导之外的交叉检查，本审阅只读取`rational_ascent.py`与`ascent_audit.md`，没有改写该实现。

解析核对通过：

- 成对求和给Σvf=N，故残差r=共轭f−(N/Q)v同时零和、与v复Hermitian正交，并有Σfr=R。Q(v+tr)=Q+t²R因此没有遗漏线性规范化项。
- 对固定正整数d，点坐标a+i√d b的四则运算、共轭和平方范数均在Q中。模上包C=max(|a|+d|b|)合法，因为√d≤d；C²≤(d+1)A来自二维Cauchy，因子d+1不可不加说明地省去。
- Taylor尾项的系数正确：2Re log(1+w)≥2Rew−|w|²/(1−|w|)。tC<1/2使总损失≤2t²A，规范化再损失至多Nt²R/Q，恰给2tR−Ht²≥tR。
- R>0时A,C,H都正，t=R/(H+2CR)确为正有理数且tC<1/2，无碰撞。代码额外核对after/before>1+tR与解析exp(tR)>1+tR一致。
- 以初始F₀推出归一化点距下界a，随后S≤n(n−1)²/a、A≤nR/(aQ)及CQ≤n(n−1)(d+1)/a给正确的统一B。因此每步log增益≥S/B，有限驻点残差预算的方向和严格性成立。
- 小残差不是全局误差界。三点共线和五点原点加正方形都是应保留的次优零残差对照，主稿已经明确这一限制。

独立程序`ascent_phase_independent_check.py`检查14个d=1、3的非驻点有理样例，以只含正项的atanh级数下包实际log增益，再和证书比较；零和、复切向正交、新总矩、C²上包及增益公式均通过。另3个驻点对照也通过。该抽验不代替普遍解析证明，也没有运行全文有限步数预算或推断全局最优。
