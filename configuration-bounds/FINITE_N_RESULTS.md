## 1. 统一记号与当前包络

```math
M_n=\max_{\sum_i|z_i|^2=n}\prod_{i\lt j}|z_i-z_j|^2,
\qquad N=\frac{n(n-1)}2.
```

设旧完整包络为 Lₙᵒˡᵈ，它保留已恢复的多环、保存整数构型、两方案相位和中心化、方格、三角格、旧扰动、低阶矩项和十二点家族值。令 Pₙᵍʳᵃᵖʰ 为规定人口和半径下的全部正负相位最大值，Aₙ为指定种子各做一次有理上升后的最大值，则合并下界为

```math
L_n^{\rm new}=\max\{L_n^{\rm old},P_n^{\rm graph},A_n\}
\le M_n\le U_n,
\qquad
U_n=n^{n/2}\left(\frac{2n}{n-1}\right)^N e^{-N/2}.
```

上界 Uₙ为已有无条件圆盘上界，本次没有刷新其常数。已知的小 n 锐界及其他旧上界仍可取最小值。相位家族定义对每个有限 n 均适用；状态预算超限时程序会拒绝完整枚举。本次实际完成相位比较2≤n≤100、一步上升比较2≤n≤30，没有把未执行范围写成计算结果。

## 3. 上升证书能证明多少

对中心化的互异有理构型，力残差 rᵢ=overline(fᵢ)−Nvᵢ/Q，fᵢ=Σⱼ≠ᵢ1/(vᵢ−vⱼ)。[明确步长证明](ascent_audit.md)给出

```math
\log\frac{F(v+tr)}{F(v)}
\ge\frac{R^2}{H+2CR}\gt0\qquad(R\gt0).
```

因此也有 log Mₙ−log F(v)≥R²/(H+2CR)。这是当前候选距全局值的缺口下界，不能倒读成误差上界。有限步残差停止也只保证接近驻点；三点共线和五点中心正方形已展示零残差仍可次优。

## 4. 条件上界怎样约束有限构型

令 δ(z)=log(Uₙ/Δₙ(z))。已有库仑分解和本次[有效径向证明](radial_audit.md)将任意平方半径带内的人口，转为明确的 δ 下界；因此整类构型满足 Δₙ≤Uₙexp(−d)。对全局最优者，合并下界又给 δ≤log(Uₙ/Lₙⁿᵉʷ)，两端可以直接排除构型类。

例如 n=100，库仑尺度 x=√((n−1)/n)z 的所有平方半径若落在[49/50,1]，不论角度如何，都有 δ≥1225/6；而已有构造保证全局最优者 δ≤1657/12。于是整个有厚度环域都被排除。该结论属于带明确半径条件的上界，不能写成对任意构型都成立的更小无条件上界。

对任意归一化无碰撞构型，本次还证明

```math
\sup_{s\ge0}\left|
\frac1n\#\{i:|z_i|^2\le s\}-\min\{s/2,1\}
\right|
\le\left(\frac{6\delta(z)}{n^2}\right)^{1/3}
+\frac2{\sqrt n}+\frac1n.
```

在全局最优者处代入任何已认证下界即可得到有限 n 的圆盘或环带人口区间。小径向偏差是必要约束，不能反推全局最优；这里也没有证明一般最优构型具有某种固定多边形或多环对称性。
