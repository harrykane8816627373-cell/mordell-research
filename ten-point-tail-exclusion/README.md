# 十点全局最大构型的外侧半径上端

蒋丰灿研究项目，OpenAI Codex 协作。

在质量 \(\sum_i|x_i|^2=9\) 下，任一十点全局最大构型恰有两个平方半径小于 \(3/10\) 的点，其余八点均满足
\[
\frac{41}{60}<|x_i|^2<\frac{71}{50}.
\]
此前允许的最外区间 \((149/100,1539/1000)\) 已全部排除。证明适用于每个全局最大构型，无需假定对称性。[原径向分带](../ten-point-ward-radii/README.md) · [恰好两个内点](../ten-point-ward-inner-count/README.md)

## 最外区间的点数与逐点行

将三个允许的径向区间放宽为闭区间 \(I=[0,3/10]\)、\(O=[41/60,71/50]\)、\(T=[149/100,1539/1000]\)。当最大构型在 \(T\) 内有 \(k\) 个点时，必有 \(k\le3\)。否则取其中四点，其余六点的平方半径之和至多 \(9-4(149/100)=76/25\)，小于已证的下界 \(1986/625\)。[六点子集下界](../ten-point-collapse-domain/README.md)

对一个标记的最外点，令 \(u\) 为它的平方半径。对任一邻点记 \(v=|x_j|^2\)、\(t=\operatorname{Re}(x_i\overline{x_j})\)、\(d=u+v-2t\)。用原 Ward 核记 \(f_{ij}=h(u,v,t)-\log d\) 和 \(R_i=\sum_{j\ne i}f_{ij}\)。以下五个量各自在九个邻点上准确求和为零：
\[
v-1+u/9,\quad t+u/9,\quad (u-t)/d-5u/9,\quad
\mathbf{1}_{I}(v)-2/9,\quad \mathbf{1}_{T}(v)-(k-1)/9.
\]
前三项来自质量、居中及完整力方程。后两项来自两个内点及共有 \(k\) 个最外点。分支 \(k=1\) 时，标记点的邻点只在 \(I,O\) 内。

将标记半径的整段 \(T\) 划为十二个相邻闭区间。在每一小段上取一组固定的有理乘子，并在每个允许的邻点区间上证明 \(f_{ij}\ge l_k/9\) 加上述五项的线性组合。区间内两个指示函数为常数。乘以正数 \(d\) 后，按有理 Bernstein 系数和对数切线上端复核。必要域剪枝沿用点距、Gram、删两点 Schwarz 及已证明的缩并约束，标记半径与邻点半径不作排序。九边求和得到 \(R_i\ge l_k\)：

|最外点数 \(k\)|每个最外点的整行下界 \(l_k\)|精确覆盖节点|
|---:|---:|---:|
|1|\(3/250\)|14,348|
|2|\(1/125\)|21,198|
|3|\(1/1000\)|31,540|

## 合并全局缺额与径向 Gram 能量

记 \(B\) 为同一个 Ward 核的预算，\(V\) 为质量 9 尺度下的整数见证值，\(c=3/10000\)。由已接受的全局证书和本次有理对数比较，
\[
f_{ij}\ge-c,\qquad B-\log V<10^{-6},\qquad
\sum_{i<j}f_{ij}+\tfrac12\sum_{i,j}K_{ij}
=B-\log\Delta\le B-\log V.
\]
这里 \(K\) 为未作 Ward 或径向力修正的正半定核，修正在完整驻点上求和为零。[全局 Ward 证书](../ten-point-ward-upper/README.md)

若 \(k=1\)，标记点的九条边有缺额和至少 \(l_1\)。其余 36 对各至少为 \(-c\)，故总缺额至少 \(l_1-36c=3/2500\)，超出预算。

若 \(k=2,3\)，径向块给出额外限制。令 \(Q\) 为零阶 Gram 块，\(S=\sum_i F_0(u_i)\) 为径向特征和。对固定的有理 \(a,b\)，令 \(p(u)=F_0(u)^TQb-a(u-9/10)\)。利用 \(\sum_i u_i=9\) 及完成平方，
\[
S^TQS\ge\sum_i p(u_i)-b^TQb/4.
\]
在 \(I,O,T\) 上分别对 \(p\) 验证严格有理下界，使用三带人口 \(2,8-k,k\) 求和。两组有理 \(a,b\) 分别给 \(k=2\) 时 \(S^TQS>0.00842148\)，\(k=3\) 时 \(S^TQS>0.02074020\)。因每对在 \(\sum_iR_i\) 中计两次，
\[
\sum_i R_i+S^TQS\le2(B-\log V)<2\cdot10^{-6}.
\]
另一方面，最外点的行给 \(k l_k\)，其余各行至少为 \(-9c\)。上面的径向能量下界由此给两个分支的左侧分别严格大于 \(0.00282148\) 和 \(0.00484020\)，矛盾。
