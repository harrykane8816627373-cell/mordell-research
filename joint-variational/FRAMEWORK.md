# 矩、层与点距的共同变分预算

研究资料与项目发起：**蒋丰灿（Fengcan Jiang）**；推导及精确程序包含 OpenAI Codex 协作。整理于2026-10-31，承接a7f17cace1d91dfe4ceee512018d4aa6f5f96eee。

本框架的目标是保留已有方法之间的相关性。它不是把全部旧下界机械相加，也不把稳定性slack转换成能量。核心是将层周长测试加入**同一个受约束Dirichlet变分问题**，再用点对代价的全局仿射下端消去剩余能量变量。

## 1. 各种输入承担不同数学角色

原问题仍为Σ|z_i|²=n下最大化Δ=∏_(i<j)|z_i−z_j|²，δ=log(U_n/Δ)。沿用

~~~math
w_i=\sqrt{(n-1)/2}\,z_i,\qquad
q_i=w_i/\sqrt n,
~~~

其中q现在表示复坐标，径向函数的自变量为|q|。全局最优者有|q_i|≤1、同层人口m_j−1≤4√n r_j。默认平滑半径为1/√n，背景为单位均匀盘。

|输入|进入框架的方式|不可采取的操作|
|---|---|---|
|已认证可达构型|给δ上端E，用于最终比较|把近似驻点残差当作全局上端|
|径向矩、同模式角向矩、空洞|测量向量m及其完整Gram H|非正交投影分别相加|
|驻点恒等式|闭合或限制实际测量区间|对非驻点输入强行设残差为零|
|径向层容量、半径及子集条件|构型可行域，以及周长测试不等式|将几何slack直接记作能量|
|点对代价|按无序边分配资源；与Dirichlet项相加|同一短边在多个图或层中重复记账|
|已有总线性缺额|与本轮总下界取较大者|未经分解再把完整总缺额加入本轮下界|

已有径向—角向正交性仍可使用；偏心空洞通常含角向分量，必须连同这些模式放入完整Gram。当前自动适配器构造径向多项式和**中心**空洞；任意偏心空洞还需提供已证的周长测试交叉项，本轮未自动构造它。

## 2. 受约束能量与条件运输

选定一个实Dirichlet能量子空间X，令u为n倍电势在X中的正交投影，φ_1,…,φ_d及f_a均属于X。A必须是X正交补内的已证能量下端，使n²D≥A+‖u‖²；典型选择是X取全部径向场、A取角向能量下端。对一般非径向完整Gram也可取X为整个空间而A=0。设

~~~math
H_{ij}=\langle\phi_i,\phi_j\rangle_D,\quad
m_i=\langle u,\phi_i\rangle_D=n\int\phi_i\,d\nu.
~~~

取此前层周长函数f_a(r)=(1−r)min(1/a,1/r)，记

~~~math
H_f=\|f_a\|_D^2=(1+a^{-2})/2,\qquad
c_i=\langle\phi_i,f_a\rangle_D.
~~~

完整投影给出三个量

~~~math
J=m^TH^{-1}m,\quad p=c^TH^{-1}m,\quad
h=H_f-c^TH^{-1}c\ge0.
~~~

若t是投影后的实际剩余能量，那么

~~~math
\|u\|_D^2=J+t,\qquad
n\int f_a\,d\nu\ge p-\sqrt{ht}.
~~~

J、p和h应当同时保留。只减去J却仍沿用原来的运输范数H_f，或者忽略p的符号，都会丢失相关性；将J和一个含同一矩的完整旧径向下界再相加则不安全。

## 3. 几何把运输与点对项相连

令K为不同半径数，R_j=√n r_j为力为1尺度的层半径。既有容量和平滑误差给

~~~math
\sum_jR_j\le V_0-\frac14 n\int f_a\,d\nu,
~~~

~~~math
V_0=K\sqrt n+\frac K{4a}
-\frac n4(1-a+a^2/3)+\frac1{32a^3}.
~~~

在人口至少3的层取循环相邻边，不重复计对，总数L≥n−2K，总长度≤2πΣR_j。

设P(d)是此前的完整无序重叠损失。对任何已证全局仿射下端

~~~math
P(d)\ge\alpha-\beta d\quad(d>0),\qquad \alpha\ge0,\ \beta>0,
~~~

这些边的代价至少α(n−2K)−2πβΣR_j。允许仿射式在某些距离为负；它始终是合法下端。

令A符合第2节的能量子空间条件，C为**不使用上述循环边**的额外点对代价，则

~~~math
\delta\ge A+C+J+t+\alpha(n-2K)
-2\pi\beta(V_0-p/4+\sqrt{ht}/4).
~~~

对t≥0准确完成平方，得到本轮主证书

~~~math
\boxed{\delta\ge A+C+J+\alpha(n-2K)
-2\pi\beta(V_0-p/4)-\frac{\pi^2\beta^2h}{16}.}
~~~

它对n>2K适用；用于“至多K层”类也安全，因为增加K会使该下端下降。最终与独立已证上端E比较，严格超过E便排除整类。

## 4. 移位Gram是同一个公式的另一种表达

设θ=πβ/2。完成Hilbert空间平方可直接写成

~~~math
\|u\|^2+\theta\langle u,f_a\rangle
\ge(m+\theta c/2)^TH^{-1}(m+\theta c/2)
-\theta^2H_f/4.
~~~

代回上一节即恢复主证书。这说明它是**一个**受约束变分下端。加入新的有效测试时，移位投影值不会降低：旧测试系数补零仍然可用。因此可以逐步纳入径向高阶矩、已闭合驻点矩、局部测试，而不改变总预算规则。

## 5. 尚未确定的部分

本轮实现了全局点对支撑线、完整径向Gram、中心空洞、整盒对偶、无序边资源账本和实际百点条件类验收。尚未完成全部构型域的分支覆盖，未确定一般n最优层数或八点完整锐界。Gram、Schur、Hilbert空间完成平方及凸对偶都是标准工具，不作框架发明或全球优先权声明。
