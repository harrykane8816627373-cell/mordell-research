# 十二点分带 Ward 核的全局上界

2026-11-09。蒋丰灿研究项目，OpenAI Codex 协作。令 \(V_{12}\) 为固定整数见证的可达值，\(C_{12}\) 为经验证的真实候选值。严格成立

~~~math
V_{12}<C_{12}\le M_{12}<\frac{15000}{14999}V_{12},
\qquad
\frac{C_{12}}{M_{12}}>\frac{14999}{15000}.
~~~

候选值超过全局最大值的99.99333%。全局上界比可达值高不到 \(1/14999\)。锐值和最大构型的分类仍待证明。

## 三个必要点对域

在质量11尺度，任意全局最大构型恰有三个点的平方半径在 \(I=(3/25,6/25)\)，其余九个在 \(O=(47/50,71/50)\)。利用 \(u,v\) 交换对称，所有点对都落在 \(I\times I\)、\(I\times O\)、\(O\times O\) 的闭包，加上 \(t^2\le uv\) 和 \(u+v-2t\ge1/3\)。精确覆盖在三个闭包上运行。未知全局最大点无需任何对称假设。 [分带定理](../twelve-point-ward-radii/README.md) · [最小距离](../finite-n/SUBSET_PROOF.md)
