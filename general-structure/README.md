# 一般点数的连续相位结构与严格环对缺额

研究资料与项目发起：蒋丰灿（Fengcan Jiang）；推导与代码包含 OpenAI Codex 协作。2026-11-04。

本专题在已有多环公式和符号相位图之外，处理固定人口、固定半径下的**全部连续相位**。一般 n 的锐值、全部最优构型及全局三角晶格极小性仍未确定。

**已证明的结构结论：** 令 e_i=nu_2(m_i) 为各正规环人口的二进赋值。所有环对同时达到各自最大交叉乘积，当且仅当最小 e_i 最多重复两次、其余 e_i 互异。所有不相容人口家族都有一个奇三角循环，并有显式正对数缺额

```math
\Gamma_T=\left(\sum_{ij\in E(T)}
\frac{(L/L_{ij})^2}{g_{ij}\eta_{ij}}\right)^{-1},
\qquad
\eta_{ij}=\frac{4r_i^{L_{ij}}r_j^{L_{ij}}}
{(r_i^{L_{ij}}+r_j^{L_{ij}})^2}.
```

边不重叠三角形的缺额可以相加，给该固定家族的严格有理上界 F<=U_pair/(1+sum Gamma_T)。**这不是无约束 M_n 的上界。**

对 K>=3，能够同时最大化所有环对的正规环至少需要 2^{K-1}+4 个非中心点。与已有全局层数定理结合，n>=4096 时这种每对环都独立取最大的多环模型不可能是全局最优；带有相位竞争的正规多环仍被保留。

**十二点精确见证：** 三个正方形环 r=4/5、1、6/5 的二项式相位取 0、2pi/3、4pi/3，其归一化距离积严格超过同一半径、同一人口下全部 8 组 +/- 符号相位最优值的两倍，精确比值约 2.00394。这只改善该固定符号家族；没有宣称改善仓库已有的无约束十二点下界。完整证明、精确比值与一般 n 推论见[连续相位证明](CONTINUOUS_PHASES.md)。

在仓库根目录运行：

```bash
python -B -S -O general-structure/verify_all.py
```

仅需 Python 标准库，所有接受检查在 -O 下保留。程序独立计算 Sylvester 行列式核对 resultant，穷尽人口多重集及全部符号选择，并在 Q(sqrt(3)) 中直接相乘十二点的 66 个距离平方。全连续相位定理由解析证明承担，有限枚举不被当作连续域覆盖。
