# 连续多环相位：相容性、奇循环与严格乘积缺额

研究资料与项目发起：蒋丰灿（Fengcan Jiang）；推导、整理与精确程序包含 OpenAI Codex 协作。2026-11-04。

本专题承接原稿的多环 resultant 公式及[已有正负相位图](../configuration-bounds/phase_graph.md)。新增的是对**全部连续相位**的取等相容性分类及定量缺额，而非把已知 resultant、二进赋值或驻点方程重新列作新发现。证明自包含；没有全球优先权声明。

## 1. 固定人口和半径，保留全部连续相位

第 i 条正规环有 m_i>=2 个点，半径 r_i>0、物理旋转角 theta_i；不同环半径互异。根多项式为

```math
P_i(X)=X^{m_i}-r_i^{m_i}e^{im_i\theta_i}.
```

还允许 h=0 或 1 个原点。各环和为零，因此整体已经中心化，n=h+sum m_i，Q=sum m_i r_i^2 与相位无关。归一化目标为 F=(n/Q)^N Delta，N=n(n-1)/2。

令 g_ij=gcd(m_i,m_j)，L_ij=lcm(m_i,m_j)。已有 resultant 恒等式给交叉距离平方乘积

```math
X_{ij}=
\left|r_i^{L_{ij}}e^{iL_{ij}\theta_i}
      -r_j^{L_{ij}}e^{iL_{ij}\theta_j}\right|^{2g_{ij}}
\le (r_i^{L_{ij}}+r_j^{L_{ij}})^{2g_{ij}}.
```

等号当且仅当 L_ij(theta_i-theta_j)=pi (mod 2pi)。单环内部乘积是 m_i^{m_i} r_i^{m_i(m_i-1)}，原点与该环的乘积是 r_i^{2h m_i}。所以独立最大化所有交叉因子得到相位松弛上端

```math
U_{\rm pair}=\left(\frac nQ\right)^N
\prod_i m_i^{m_i}r_i^{m_i(m_i-1)+2hm_i}
\prod_{i<j}(r_i^{L_{ij}}+r_j^{L_{ij}})^{2g_{ij}}.
```

这是**固定人口、固定半径的相位家族上界**。它不能直接作为任意 n 点构型的上界。

## 2. 所有交叉因子能否同时取等：完整分类

写 e_i=nu_2(m_i)，即 m_i 中因子 2 的指数。

**定理 1。** 存在连续相位使 F=U_pair，当且仅当：最小 e_i 最多出现两次，其余每个 e_i 最多出现一次。一旦能够取等，已经可以选各环二项式常数的相位为 0 或 pi；不必另找非实相位。

**必要性。** 对任意三个环 i,j,k，令 L=lcm(m_i,m_j,m_k)。沿定向三角形将三条取等式分别乘 L/L_ij、L/L_jk、L/L_ki 再相加。左侧望远镜消去，故必须有

```math
0=\pi\left(\frac L{L_{ij}}+\frac L{L_{jk}}+\frac L{L_{ki}}\right)
\pmod{2\pi}.
```

若三个人口的最大二进赋值至少出现两次，则每条边都包含至少一个最大赋值，三个整数 L/L_ab 全是奇数，右侧为 pi (mod 2pi)，矛盾。因此任何三个人口的最大赋值只能出现一次。若某个非最小赋值重复，取这两个环和一个更低赋值环即矛盾；若最小赋值出现三次，也矛盾。这证明所列条件必要。

**充分性。** 设 c_i=r_i^{m_i} e^{im_i theta_i}。先把所有 c_i 的符号都取 -1；若最小赋值恰有两个环，再把其中一个改为 +1。若 e_i<e_j，则 m_i/g_ij 为奇数、m_j/g_ij 为偶数，而较高赋值环 j 的符号必为 -1，于是 c_i^{m_j/g_ij} 与 c_j^{m_i/g_ij} 方向相反。唯一允许的同赋值环对位于最小类，其两符号相反、两个指数均为奇数，也达到最大。所有环对同时取等。

此定理分类的是**相位松弛上端的取等性**。它不说明所给构型驻定，也不说明其全局最优；还须保留[完整逐点力余式](../symmetry-breaking/STATIONARITY.md)与全部二阶条件。

## 3. 不相容三角形有显式正缺额

取定理 1 中被排除的三个环 T。对其边 ij 记

```math
a_{ij}=L/L_{ij}\quad\text{(均为奇数)},\qquad
A_{ij}=r_i^{L_{ij}},\quad B_{ij}=r_j^{L_{ij}},\qquad
\eta_{ij}=\frac{4A_{ij}B_{ij}}{(A_{ij}+B_{ij})^2}\in(0,1).
```

**定理 2。** 对这三个环的任意连续相位，有

```math
\sum_{ij\in E(T)}
\log\frac{(A_{ij}+B_{ij})^{2g_{ij}}}{X_{ij}}
\ge \Gamma_T,
\qquad
\boxed{\Gamma_T=
\left(\sum_{ij\in E(T)}\frac{a_{ij}^2}{g_{ij}\eta_{ij}}\right)^{-1}>0.}
```

**证明。** 对定向边取 e_ij 为 L_ij(theta_i-theta_j)-pi 在 [-pi,pi] 中的代表。定向三边加权和是 pi 的奇数倍，故绝对值至少 pi。边对数缺额恰为

```math
\delta_{ij}=-g_{ij}\log\left(1-\eta_{ij}\sin^2(e_{ij}/2)\right)
\ge \frac{g_{ij}\eta_{ij}}{\pi^2}e_{ij}^2.
```

这里使用 -log(1-x)>=x，以及 sin(|e|/2)>=|e|/pi；半径互异保证 eta<1，故没有碰撞或对数端点问题。带权 Cauchy 不等式给

```math
\left|\sum a_{ij}e_{ij}\right|^2
\le\left(\sum\frac{a_{ij}^2}{g_{ij}\eta_{ij}}\right)
     \left(\sum g_{ij}\eta_{ij}e_{ij}^2\right).
```

代入左侧至少 pi^2 即得结论。pi 在最终常数中完全消去。

对若干**边不重叠**的不相容三角形求和，令 Gamma=sum Gamma_T，得

```math
\boxed{F\le U_{\rm pair}e^{-\Gamma}
       \le\frac{U_{\rm pair}}{1+\Gamma}.}
```

更一般地，若对所有不相容三角形选有理权 lambda_T>=0，且每条边的权重总和不超过 1，也可取 Gamma=sum lambda_T Gamma_T。每条边只能支付一次缺额，不能把重叠三角形无权相加。本实现按 Gamma_T 从大到小贪心选边不重叠三角形，没有声称求解最优加权打包。

当各 r_i 为正有理数时，所有 Gamma_T、U_pair 及 U_pair/(1+Gamma) 均是严格有理数。也可以对半径区间给 eta_ij 的安全下端，从而把同一证明接入连续域分支定界；本次程序只认证给定半径，不声称已经执行区间覆盖。

## 4. 十二点例：连续相位超过全部符号相位两倍

取三个正方形环，半径分别为 4/5、1、6/5。它们的人口赋值全相同，不能同时最大化三个交叉因子，且

```math
\Gamma=\frac{207360000}{216002897}>0.9599.
```

所以这个全部连续相位家族的最大值至多为 U_pair/(1+Gamma)，独立环对上界存在可量化的严格空隙。

另一方面，取二项式常数的相位为 0、2pi/3、4pi/3，即物理旋转角为 0、pi/6、pi/3。对每对环令 A=r_i^4、B=r_j^4，交叉因子恰为 (A^2+AB+B^2)^4。因此该可达值与**同一人口、同一半径下全部 8 组符号相位中的最大值**之比是

```math
\frac{52683087981963717553045822904169560038216434586857283041}
     {26289735752399568063842469449117496201774787038750390625}
>2.
```

这个例子说明：此前符号图准确求解了其有限家族，但不足以代替全部连续相位优化。它没有被宣称刷新仓库现存的无约束十二点下界，更没有被宣称是十二点最优构型。

核验除 binomial resultant 计算外，另在 Q(sqrt(3)) 中直接列出全部 12 个点、相乘全部 66 个距离平方，并准确归一化；目标值不依赖浮点三角函数。

## 5. 一般 n 的结构含义：完全独立环对只能容纳对数多个环

**推论。** 对 K>=3 条人口至少 2 的正规环，若所有环对能同时最大化交叉因子，则非中心总人口满足

```math
\sum_i m_i\ge 2^{K-1}+4.
```

此整数下界可达：人口取 3、3、2、4、...、2^{K-2}。证明如下。若最小赋值为 0 且重复两次，这两个奇人口均至少为 3，其他 K-2 个互异正赋值人口至少为 2、4、...、2^{K-2}，相加恰为所列下界。若最小赋值至少为 1 且重复两次，总人口至少为 2^K，不小于所列下界。若最小赋值不重复，按不同赋值依次取最小人口，所得下界更大。因此有限 K 的最小总人口分别是 2、4、8、12、20、36、...。

这与已有[全局最优者层数定理](../collective-stability/RING_POPULATION.md)有明确接口。该既有定理不要求各层等角，给总半径层数 K_total>sqrt(n)/pi。若最优构型恰由上述正规环和至多一个原点组成、且每对环都达到独立最大，那么 K_total<=2+log_2 n。对 n>=4096，sqrt(n)/pi>sqrt(n)/4>2+log_2 n，矛盾。

最后一个初等比较在 n=4096 时为 16>14；函数 sqrt(n)/4-2-log_2 n 的导数为正，因为 sqrt(n)log 2>8，而 log 2>1/2。因此覆盖全部 n>=4096。

故 **n>=4096 时，所有环对同时取最大值的正规多环模型不可能是全局最优构型**。这是使用既有层数定理的条件结构排除；它没有排除带相位竞争的正规多环，也没有证明真实最优者一定是晶格或具有任何固定旋转群。

## 6. 接下来值得计算的对象

连续相位间的竞争由频率 L_ij 及其整数循环控制，而完整驻点力又限制各环人口与半径。可先用本专题的全相位严格上界排除指定家族，再对保留的连续相位临界点执行既有逐点力余式和完整 Hessian 检验。靠近半径时 eta 接近 1，循环缺额有效；半径悬殊时 eta 很小，该定量界可能弱，不能借严格正性声称它总能闭合全局锐界。

从大量有限 n 的数值下界到一般最优结构，还缺全体候选的连续域覆盖、逐点物理条件及微观能量极小性。本文新增的结构定理缩小了一个具体多环松弛模型的取等范围，没有解决所有 n 的锐值。

文献背景：多边形涡旋相对平衡已有长期研究，例如 Celli、Lacomba、Pérez-Chavela 的 [On polygonal relative equilibria in the N-vortex problem](https://arxiv.org/abs/0811.1785)。该文摘要所列双等人口环分类不被引用为本专题连续多环取等定理的证明。小点数现状另见 Ji、Xu、Yu 的 [Optimal Configurations for Mordell's Problem](https://arxiv.org/abs/2611.03088v1)。本专题没有使用任何未重现的外部分类来证明定理 1、2。
