# 十点分带核的 0.34% 上界与内点定位

2026-11-15。蒋丰灿研究项目，OpenAI Codex 协作。

记 \(M_{10}\) 为全局最大值，\(V_{10}\) 为固定整数见证值，\(C_{10}\) 为真实 \(D_2\) 候选的值。此证书在同一质量尺度下给出

\[
V_{10}<C_{10}\le M_{10}<\frac{5017}{5000}V_{10}.
\]

在质量 9 下，任一全局最大构型恰有两个内点。设 \(u,v\) 为它们的平方半径，\(t\) 为实内积，\(m\) 为中点。证明进一步给出

\[
0.054<u,v<0.217,\qquad -0.135<t<-0.100,
\qquad |m|^2<1/40,\qquad \frac{t}{\sqrt{uv}}<-2/3.
\]

两内点的平方距离小于 \(3/5\)。其余八点仍在平方半径带 \((0.74,1.39)\)。由于完整构型居中，它们的重心是 \(-m/4\)，故它的模小于 \(1/\sqrt{640}\)。[两个径向带的证明](../ten-point-counted-radii/README.md) · [最外带排除](../ten-point-tail-exclusion/README.md)

## 两类点对的缺额预算

沿用已接受的[分带核接口](../ten-point-banded-kernel/README.md)，保留十个正定 Gram 块和总和预算 \(B\)。调整 Ward、径向力及 19 个依赖半径带的零和修正系数。对全局最大构型，修正项的总和为零，所以 \(\sum h_{ij}\le B\)。

证书验证唯一内边的缺额 \(f_{II}=h_{II}-\log d_{II}\) 至少为 \(-9/100000\)，其他 44 条边的缺额均至少为 \(-3/40000\)。按各类边的准确数量求和得到

\[
\log M_{10}\le B+\frac9{100000}+44\cdot\frac3{40000}.
\]

有理对数下界证明右侧比 \(\log((5017/5000)V_{10})\) 至少小 \(1/250000\)。反过来，利用其余 44 条边的下界单独控制内边，得到

\[
f_{II}\le B-\log V_{10}+44\cdot\frac3{40000}<\frac{3301}{10^6}.
\]

已知 \(t<0\)。附加的内点树覆盖全部允许的负内积内点对，逐盒验证几何结论，或者证明缺额至少为 \(3301/10^6\)，或者排除违反已证必要条件的盒。角度通过 \(9t^2>4uv\) 与 \(t<0\) 判定。[较早的内点证书](../ten-point-inner-pair/README.md)

## 精确重放

按照[复现指南](../docs/REPRODUCING.md)先运行前置十点证书，然后从仓库根目录运行：

```sh
python -B -S -O ten-point-banded-kernel-refined/verify_all.py
```

标准库接受器用整数和有理数重放六个分带根盒，以及单独的内点树。核系数通过有限数值搜索发现，接受时对每个叶重新核对 Bernstein 系数和对数切线上端。全局锐值还需排除候选局部证明范围之外的构型。[复核报告](verification_report.json) · [固定输入](source_manifest.json)
