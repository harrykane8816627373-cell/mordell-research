## 1. 数学命题与固定输入

对 n∈{25,35,42,46}，存在无碰撞构型 z，使

```math
\sum_i z_i=0,\qquad \sum_i|z_i|^2=n,\qquad
\sum_{j\ne i}\frac{z_i-z_j}{|z_i-z_j|^2}=\frac{n-1}{2}z_i.
```

每个构型是模整体旋转的严格局部极大轨道。其存在与局部唯一性指向所存的旋转规范盒，不是所有驻点或全局最优轨道的唯一性。

发现种子是[11月5日保存的改进整数构型](../finite-search-nov5/integer_witnesses.json)。每行证书保留原整数坐标，验证程序检查它们与固定哈希的源文件逐点相同。高精度计算只生成二进有理中点和矩阵，正式接受不运行浮点 Newton、Cholesky、特征值或优化器。

## 2. 复用的通用认证定理

令 λ=(n−1)/2，F 为上式左侧减 λz。选 y₀=0、x₀>0，删除 y₀ 变量及 F₀y 方程，得到 d=2n−1 维实系统 f。旋转恒等式恢复遗漏方程；求和及与位置作实内积恢复中心化与质量 n。这些性质在根处精确成立，不把浮点预先归一化当作证明。

对证书的精确中点 c、半径 r=2⁻⁸⁰ 的立方盒 X 与精确有理矩阵 C，程序在整个 X 上验证无碰撞、x₀>0，以及

```math
\|Cf(c)\|_\infty<r/4,\qquad
\sup_{X}\|I-CDf\|_\infty<1/4.
```

因此 x↦x−Cf(x) 是从 X 到自身内部的压缩映射。其唯一固定点是 f 的唯一根；C 的可逆性由同一严格范数界推出。

另给精确有理矩阵 W，计算整个 X 上的

```math
G=-W^TDfW,\qquad
\min_i\left(G_{ii}-\sum_{j\ne i}|G_{ij}|\right)>0.
```

对称严格 Gershgorin 界证明 G 正定，也迫使 W 可逆，故 Df 严格负定。真实根处完整 Jacobian J=DF 满足 J(iz)=0，且旋转方向的 y₀ 分量为 x₀>0，所以完整空间恰为这个零方向和规范切片的直和。完整 Lagrangian Hessian 2J 的惯性为

```math
(\#\text{负},\#\text{零},\#\text{正})=(2n-1,1,0).
```

又有 Jz=−2λz，球面切空间上的惯性为 (2n−2,1,0)。因此在质量约束上模整体旋转严格局部极大。这个结论允许每个点独立移动，超出任何固定正规环、指定对称群或低阶模式子块的范围。

通用定理、完整解析 Jacobian 和整数区间实现来自原专题；本次仅使用固定版本并增加新的实际输入、验算结果及取值比较。程序在2⁻³⁸⁴格上对乘除向外舍入，中点分母是2²⁵⁶，辅助矩阵分母是2¹⁹²。

## 4. 已认证根的目标值比较

程序同时对整个盒的所有平方点距乘积给出 Δ 的有理上下端。在根处质量恰为 n，因而无需再对盒内各点逐一作质量归一化。

对任意互异整数种子 p_i=(x_i,y_i)，设 N=n(n−1)/2，D=nΣ|p_i|²−|Σp_i|²、P=Π|p_i−p_j|²。中心化并规范到质量 n 后的可达目标为 V(p)=n^(2N)P/D^N。因此可直接用分数比较根的 Δ 区间与新旧保存整数见证的准确值。
