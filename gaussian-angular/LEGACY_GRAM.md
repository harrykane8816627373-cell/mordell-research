# 与旧第四角向两测试安全联合

研究资料与项目发起：**蒋丰灿（Fengcan Jiang）**；推导及有理验收包含 OpenAI Codex 协作。2026-10-31。

四转高斯探针含k=4、8、12,…，所以不能在保留旧k=4能量后完整再加一个独立高斯下端。本节构造准确交叉项，再对同一个Gram使用固定对偶。

## 1. 旧测试及其真实测量

设S≥1且全部默认平滑点盘位于|q|²≤S。沿用旧全局圆周Green测试

~~~math
K_{k,S}(q)=\begin{cases}q^k,&|q|^2\le S,\\S^k/\bar q^{\,k},&|q|^2>S,\end{cases}
\qquad F_{k,S}(q)=q^k(S-|q|^2)_+.
~~~

实、虚测试的Gram对角元分别为kSᵏ、S^(k+2)/(k+2)；K与F互相正交。写p_k=Σq_iᵏ、Q_k=Σ|q_i|²q_iᵏ。它们的实际n倍测量为

~~~math
m_K=p_k,\qquad
m_F=\left(S-\frac{k+1}{2n}\right)p_k-Q_k.
~~~

这里使用真实圆盘多项式均值，没有把非驻点Q_k强行替换成驻点恒等式。对真实驻点可再接入旧闭合关系，但其前提不能省略。

## 2. 交叉项的闭式级数

对一个四转探针，各高斯中心的平方半径相同，记ρ²，C_k=Σ中心权重·aᵏ。设

~~~math
x=\rho^2/(4t),\quad y=S/(4t),\quad z=S\rho^2/(16t^2),
~~~

~~~math
B_k(z)=\sum_{l\ge0}\frac{z^l}{l!(l+k)!},\qquad
T_k(z,y)=\sum_{l\ge0}\frac{z^l I_{k+l}(y)}{l!(l+k)!}.
~~~

则复交叉项为

~~~math
c_K=\frac{2kS^k}{(4t)^k}e^{-x-y}B_k(z)C_k,
~~~

~~~math
c_F=\frac{2(k+1)S^{k+1}}{(4t)^k}e^{-x}T_k(z,y)C_k-\frac S k c_K.
~~~

取其实、虚部即可接入实Gram。第一式来自K在|q|=√S处的法向导数跳；第二式来自−ΔF的盘内多项式和圆周边界项。末尾−(S/k)c_K不能漏掉。

实现另用⟨F,φ⟩_D=−(2π)⁻¹∫FΔφ，将拉普拉斯完全移到光滑高斯上，独立包围同一交叉项。它不显式使用圆周导数跳；两种表达式在验收中吻合。

## 3. 整个区间矩阵使用固定有理对偶

对旧Re/Im K、Re/Im F及有限高斯探针的完整Gram H、实际测量m，任何固定实向量v均给

~~~math
n^2D_{\rm angular}\ge2v^Tm-v^THv.
~~~

在m和H都以有理区间表示时，配对按v的符号取下端，惩罚按v_iv_j的符号取最坏上端。中点解只用于选择v，选定后向有理网格取整；接受覆盖整个区间矩阵，不假设中点就是实际Gram，也不需要把区间逆矩阵误当成精确逆。

新旧投影之间也可用Schur补解释：高斯测量先扣去旧测试预测，Gaussian Gram先扣去旧投影部分，再计算残余能量。当前固定对偶直接使用完整矩阵，数值上不需要显式相减后再求一个病态残余逆。

增加测试时，旧对偶补零仍然合法；若自动选出的单一新向量较差，应保留旧值并取最大。本文的两个尺度实际验收值严格高于所列各单尺度值。

## 4. 实际构型与整个一参数族的严格增益

采用此前九点q坐标：0、(±7/9,0)、(0,±7/9)、(±4/9,±4/9)。在旧、新两边使用同一个有效支撑S=5/4。旧完整k=4两复测试投影约为0.1216187799644966。

两个探针分别为：

|探针|t|第一组中心半径|第二组中心|
|---|---:|---:|---|
|1|1/24|3/4|第一组按3/5+4i/5转动|
|2|1/16|1/2|同上|

保留全部新旧交叉项后，固定有理对偶认证角向能量>0.1288；相对指定旧完整投影，增益严格超过5.9%。该投影仍小于独立算出的真实总缺额0.31090926258752094。

进一步取

~~~math
s\in[1/4-10^{-7},1/4+10^{-7}],\quad
a(s)=\frac{1-2s^2}{1+2s^2},\quad b(s)=\frac{2s}{1+2s^2},
~~~

构型为0、(±a,0)、(0,±a)、(±b,±b)。恒等式a²+2b²=1保证q总矩始终为4，z=(3/2)q始终满足原总矩9。该区间上a递减、b递增，完整平滑支持都在S内。

高斯的全局Lipschitz常数不超过1/√(2t)；圆盘平均继承同一常数。由各点位移总和，包围两个Gaussian实际测量；旧p₄、Q₄则以有理端点多项式包围。中心选择的同一个固定对偶在**整个参数区间**上给

~~~math
\text{旧指定投影}\ <0.122,\qquad
n^2D_{\rm angular}>0.128.
~~~

更精确的全族新下端约为0.1287033507879717，旧投影上端约为0.12162104340400579；前者大于后者的21/20。这也给该族距离乘积的严格类上端Δ₉<U₉exp(−16/125)。

这是一维、保持四转/反射结构的真实归一化构型族，不是全部实坐标的独立盒。没有声称它是驻点、通过全部旧判据、优于全部旧高阶投影，或给出M₉的新全局上界。
