# 高斯核、真实圆盘平均与旋转模式

研究资料与项目发起：**蒋丰灿（Fengcan Jiang）**；推导及精确程序包含 OpenAI Codex 协作。2026-10-31。

本节独立构造静态Dirichlet测试，不调用波方程局部平滑定理。阅读OpenAI论文得到的启发及未完成的直接迁移，保留在[原始评估](imported-review/TRANSFER_ASSESSMENT.md)。

## 1. 尺度与高斯Gram

沿用q=√((n−1)/(2n))z、Σ|z_i|²=n，默认平滑半径R=1/√n，μ=n⁻¹Σσ_R(·−q_i)，ν=μ−μ₀，μ₀为单位均匀盘。Dirichlet规范为⟨f,g⟩_D=(2π)⁻¹∫∇f·∇g，旧分解给δ≥n²D(ν)。

令φ_(a,t)(q)=exp(−|q−a|²/(4t))，t>0。两核的Gram为

~~~math
H_{ij}=\frac{2t_it_j}{(t_i+t_j)^2}
\left(1-\frac{|a_i-a_j|^2}{4(t_i+t_j)}\right)
\exp\left(-\frac{|a_i-a_j|^2}{4(t_i+t_j)}\right).
~~~

证明：两指数的乘积以m=(t_j a_i+t_i a_j)/(t_i+t_j)为中心，积分是4πt_it_j/(t_i+t_j)乘最后的指数。其中心二阶矩为4t_it_j/(t_i+t_j)；展开(q−a_i)·(q−a_j)，再除以8πt_it_j，即得上式。对角元恒为1/2。交叉项可为负，必须保留。

高斯不紧支撑，但函数和梯度迅速衰减；用光滑截断取极限即可完成同一弱能量投影，不需额外支撑假设。

## 2. 四分之一转动滤除低模式

取同一半径上的两个不同四转轨道a,b，定义

~~~math
\Psi(q)=\sum_{j=0}^3[\phi_{i^ja,t}(q)-\phi_{i^jb,t}(q)].
~~~

同半径使角向平均精确抵消。又有Ψ(iq)=Ψ(q)，因此只含非零的4倍角向模式。它与所有径向测试、中心空洞和周长函数正交，也与全部k=2、3角向测试正交，包括这些模式的径向加权测试。

本轮的标准轮廓为a=(1/2,0)、b=(3/10,2/5)、t=1/16。程序用完整8×8高斯Gram认证

~~~math
0<H_\Psi=\|\Psi\|_D^2<487/2000.
~~~

它约为0.24346043221472286。该轮廓并非已优化的最优测试。

## 3. 真实圆盘平均不能用点值替代

测量为M_Ψ=n∫Ψdν=Σ_i T_RΨ(q_i)。背景项精确为零。对单高斯，置D=|q_i−a|²、x=D/(4t)、y=R²/(4t)，极坐标与I₀正级数给

~~~math
T_R\phi_{a,t}(q_i)=e^{-x}
\sum_{l=0}^\infty\frac{(xy)^l}{(l!)^2}
I_l(y),\qquad I_m(y)=\int_0^1u^m e^{-yu}\,du.
~~~

程序以160项（末项负）的Taylor积分下端及下一项上端包围I_m。Bessel部分取0≤l≤64，再以递减项比的几何尾和向外包围。e⁻ˣ先缩到参数≤1，用正指数级数及尾和取倒数，之后逐次平方；每步向外取40位有理网格。

独立验收包括I_m的分部积分递推、指数与旧atanh对数区间的对照，以及上一轮原字节九点算例的完整重放。

当前实现明确限制指数参数≤128、I_m参数y≤16、Bessel参数≤256、模式阶≤16，并拒绝超出计算预算的输入。数学公式本身无这些限制；没有将程序拒绝某个参数解释为排除某种构型。

## 4. 任意尺度与旋转的精确不变性

定义Ψ_(γ,θ)(q)=Ψ(e^(−iθ)q/γ)，γ>0。在二维中更换变量使梯度平方与面积Jacobian精确抵消，故

~~~math
\|\Psi_{\gamma,\theta}\|_D^2=H_\Psi.
~~~

同一结论也直接见于高斯Gram：中心乘γ、时间乘γ²，公式的每个无量纲比均不变。旋转不改变距离。零径向分量及4倍模式性质也保持。

这是[全尺度角向平衡](DISTRIBUTION.md)的依据。程序的有限尺度检查核对实现；任意γ、θ的量词由上述解析换元承担。这里改变的是探针尺度，默认点盘平滑半径仍然是1/√n。
