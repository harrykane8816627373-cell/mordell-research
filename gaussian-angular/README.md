## 1. 全尺度的平滑角向平衡

标准探针Ψ由两个等半径四转高斯轨道相减，角向平均为零。对任意缩放γ>0及旋转θ，范数恒为H_Ψ<487/2000。任意已证全局缺额上端E因此给

~~~math
\boxed{\sup_{\gamma>0,\theta}|M_{\gamma,\theta}|/n
\le\sqrt{487E/2000}/n.}
~~~

M采用实际平滑圆盘平均；不是直接对原子点取Gaussian值。已有有效E_n=O(n)使这个平滑加权对比得到全尺度O(n⁻¹ᐟ²)界，未将它说成硬圆盘人口误差阶的改善。

[核与真实平均](KERNELS.md) · [一般n与百点分布定理](DISTRIBUTION.md)

## 2. 旧第四模式与两个尺度的完整Gram

Ψ会与k=4、8,…模式重叠。本轮推导它与旧全纯及一级混合测试的准确交叉项，保留完整Gram，并用固定有理对偶接受区间矩阵。

九点有理算例在相同支撑下，旧完整第四模式两复测试投影约为0.12162；联合两个尺度后严格超过0.1288，增益超过5.9%。一个真实归一化的一参数族上，统一增益仍超过5%。这不是仅将一个新Gaussian下界与旧能量直接相加。

[完整交叉证明及一参数族](LEGACY_GRAM.md) · [精确验收](multiscale_verification.json)

## 3. 百点四层条件下的局部角向限制

记A_(2,3)=C₂|Σz_i²|²+C₃|Σz_i³|²，系数沿用旧驻点投影。对百点全局最优者，在所有缩放与旋转方向：

- 若K≤4，标准Gaussian对比|M|<0.4285。
- 若再有A_(2,3)≥0.7，收紧到|M|<0.114。
- 若K≤4且全部原尺度半径平方≥8/99，则|M|<0.351。

这些是带前提的点分布约束，未证明百点至少五层或完整最优分类。[证明与尺度](DISTRIBUTION.md) · [共同预算验收](joint_budget_verification.json)
