# 八点：不限制 p₇ 的旋转不变幂和管域

蒋丰灿（Fengcan Jiang）研究项目，OpenAI Codex 协作，2026-11-01。承接 `c954da2b1e4a1dbdb9ea698cb9902eeffc85fdfc`。这是既有局部刚性的加强，完整八点锐界仍开放。

## 1. 结论与尺度

使用力常数1的尺度 w=√(7/2)z，令 p_k=Σw_i^k。参考构型 w* 是原点和半径2的正七边形，Σ|w_i*|²=28，候选距离乘积 T=4²⁸7⁷。记 d(w) 为到其全部旋转、重排轨道的欧氏距离。

**定理。** 设八点互异、Σw_i=0、Σ|w_i|²=28。如果

```math
|p_2|\le\frac1{10},\quad |p_3|\le\frac15,\quad
|p_4|\le\frac25,\quad |p_5|\le\frac45,\quad
|p_6|\le\frac85,\quad |p_8|\le\frac{32}5,
```

则 d(w)<1/20，且

```math
\boxed{\log\frac{\Delta_w(w)}T\le-\frac{d(w)^2}{35}.}
```

因此整个管域内只有参考轨道能达到 T。若另有真实逐点驻点方程，则即使不假设目标值，也只能是该轨道。**不对 p₇ 作任何额外假设，不要求预先选定旋转，也不预设稳定性或对称性。** 相应原 z 尺度的乘积阈值是 8²⁸/7²¹。

旧[局部盒](../power-moment/LOCAL_RIGIDITY.md)的条件是适当旋转后 |p₂|,…,|p₆|,|p₈|≤1/10、|p₇−896|≤1/10。它包含于本管域；第7节提供严格在旧盒全部旋转之外的新管域见证。这里不据此声称优于所有历史方法。

## 2. c₇ 自由时的 Newton 误差

令 q=w/2，s_k=Σq_i^k=p_k/2^k，Σ|q_i|²=7。条件统一为 |s_k|≤ε=1/40，k∈J={2,3,4,5,6,8}。写根多项式

```math
P(X)=X^8+aX+\sum_{k\in J}c_kX^{8-k},\qquad a=c_7.
```

中心化使 s₁=c₁=0。Newton 恒等式给 |c_k|≤b_k，其中 b₀=b₁=0，按 k=2,3,4,5,6,8 顺序计算

```math
b_k=\frac{\varepsilon+\varepsilon\sum_{j=2}^{k-2}b_j}{k}.
```

**不使用 |s₇|≤ε，也不对 c₇ 设这个界。** k=8 中唯一可能的 s₇、c₇ 项分别是 c₁s₇ 和 c₇s₁，二者为零；因此 b₈ 仍与自由变量无关。验证器只为 J 中的指标建立系数界。

## 3. 归一化先使自由尺度远离零

设 R=max|q_i|。由 Σ|q_i|²=7，有 R²≥7/8>(187/200)²。取一个模为 R 的根并除以其八次幂，得到

```math
|a|\ge R^7\left(1-\sum_{k\in J}\frac{b_k}{R^k}\right)
\ge\left(\frac{187}{200}\right)^7
\left(1-\sum_{k\in J}\frac{b_k}{(187/200)^k}\right)
>\left(\frac{23}{25}\right)^7.
```

最后两个括号的正性和严格有理比较见[报告](tube_verification.json)。所以 a≠0，t=|a|^(1/7)>23/25。选择 θ 使 a/(t⁷e^(7iθ))=−1；在 X=te^(iθ)Y 下，归一化后的多项式为

```math
Y^8-Y+\sum_{k\in J}d_kY^{8-k},\qquad
|d_k|\le b_k/(23/25)^k.
```

这是通过多项式实际确定尺度和相位，没有从浮点数估计 p₇。

## 4. 八个根盘与自由尺度的消除

以0及七次单位根为圆心，取 r=7/800。盘互不相交。对 P₀(Y)=Y⁸−Y，在原点盘边界有

```math
|P_0|\ge r(1-r^7),\qquad
|P-P_0|\le\sum_{k\in J}\frac{b_k}{(23/25)^k}r^{8-k}.
```

在任何外根 η（η⁷=1）的盘边界，展开 (η+h)⁷−η⁷，可得

```math
|P_0|\ge(1-r)\left(7r-\sum_{j=2}^7{7\choose j}r^j\right),\qquad
|P-P_0|\le\sum_{k\in J}\frac{b_k}{(23/25)^k}(1+r)^{8-k}.
```

两处误差均严格小于边界下端。Rouché 定理给每盘恰一个根。设 u 为旋转、重排后的 q，v 为参考根向量（||u||²=||v||²=7），则 ||u−tv||²<8t²r²。反三角不等式给

```math
|t-1|<\sqrt{8/7}\,tr,\qquad
t<\frac1{1-(15/14)r}<\frac{100}{99}.
```

利用两向量相同的归一化长度，有准确恒等式

```math
\|u-tv\|^2=t\|u-v\|^2+7(t-1)^2.
```

所以回到 w 尺度，

```math
d(w)^2\le4\|u-v\|^2<32tr^2
<32\frac{100}{99}\left(\frac7{800}\right)^2<\frac1{400}.
```

这一步消除了 p₇ 对应的自由径向尺度，无须额外限制 p₇−896。

## 5. 改善逆平方算子的扰动常数

沿用[已逐对重建并精确验证的稳定谱](../power-moment/LOCAL_RIGIDITY.md)：参考逆平方 Laplacian B(w*) 的奇异值平方为 0,1,1/2,1/2,1/4,1/4,1/16,1/16。

能量 E(w)=Σ|w_i|²/2−Σ_(i<j)log|w_i−w_j| 的实 Hessian 在固定旋转切片 T={h:Re〈iw*,h〉=0} 上下端大于2/7。参考最小点距 d₀>12/7。若 ||w−w*||≤ρ，则各差向量误差≤√2ρ；由 (z⁻²)'=−2z⁻³，每条边权变化绝对值至多

```math
\eta=\frac{2\sqrt2\rho}{(12/7-\sqrt2\rho)^3}.
```

对任意复向量 x,y，Laplacian 的逐边表达式和 Cauchy–Schwarz 给

```math
|x^*(B(w)-B(w^*))y|
\le\eta\left(\sum_{i<j}|x_i-x_j|^2\right)^{1/2}
          \left(\sum_{i<j}|y_i-y_j|^2\right)^{1/2}
\le8\eta\|x\|\|y\|.
```

使用 Σ_(i<j)|x_i−x_j|²=8||x||²−|Σx_i|²，避免旧逐行和界的额外损失。取 ρ=1/20、√2<99/70，精确认证

```math
\|B(w)-B(w^*)\|\le
\frac{16(99/70)\rho}{(12/7-(99/70)\rho)^3}
<\frac27-\frac1{35}.
```

故整个固定切片与凸球交集上的 Hessian 下端大于1/35。验证器重新运行旧 cyclotomic 实际逐点力及完整谱检查，不只信任保存的特征值列表。

## 6. 从严格凸性到目标值排除

选取到参考轨道距离最小的旋转和重排后，h=w−w* 满足 Re〈iw*,h〉=0，且 ||h||=d(w)<ρ。整条线段位于固定切片与球内。参考梯度为零；积分二阶导数得

```math
E(w)-E(w^*)\ge\frac{d(w)^2}{70}.
```

由于两端二阶矩都为28，log(Δ_w/T)=−2(E(w)−E(w*))，即得定理。若 w 也驻定，切片上的严格凸性使两个梯度零点只能重合，因此驻点结论不要求预先达到 T。不能由这个局部能量估计外推全空间凸性。
