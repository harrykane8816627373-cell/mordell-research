```math
|p_2|\le1/10,\ |p_3|\le1/5,\ |p_4|\le2/5,
|p_5|\le4/5,\ |p_6|\le8/5,\ |p_8|\le32/5

\log\frac{\Delta_w}{4^{28}7^7}\le-\frac{d^2}{35},
```
