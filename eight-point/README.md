## 新进展：半径四倍、六矩门槛五倍

令 w=√(7/2)z，p_k=Σw_i^k；d 为到原点加半径2正七边形轨道的欧氏距离。对 Σ|w_i|²=28 的八点构型，

```math
d\le1/5\quad\Longrightarrow\quad
\log\frac{\Delta_w}{4^{28}7^7}\le-\frac{d^2}{30}.
```

不要求预设驻点、稳定性或中心化。目标值排除半径从1/20扩大到1/5。若另有中心化及

```math
|p_2|\le1/2,\quad |p_3|\le1,\quad |p_4|\le2,\quad
|p_5|\le4,\quad |p_6|\le8,\quad |p_8|\le32,
```

则 d²<3/100，亦被排除，除非是候选轨道。六个条件旋转不变，模长门槛均提高五倍，**p₇ 无额外条件**。

[完整证明](ENERGY_BASIN.md) · [精确报告](energy_basin_verification.json) · [两种扩大区域的实际见证](energy_witnesses.json) · [当前剩余清单](OPEN_BRANCHES.md)

新方法直接估计目标的对数余项，使用实际距离加权 Laplacian 的准确范数2，并以七次单位根的正交性控制全部根误差。没有声称半径1/5球上 Hessian 处处正定，也没有据此分类所有低于目标的真实驻点。
