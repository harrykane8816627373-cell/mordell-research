# 八点剩余覆盖清单

2026-11-01，第二阶段。所有 p_k 均为力1尺度 w=√(7/2)z 的幂和，d 为到中心正七边形候选轨道的欧氏距离。

## 待排除的准确对象

非候选的全局挑战者必须同时满足：八点互异、Σw=0、Σ|w|²=28；逐点真实力方程；完整逆平方算子范数≤1；全部已证子集、点距、半径和矩约束；Δ_w≥4²⁸7⁷。零矩分类的引用保留[此前状态页](../configuration-bounds/PROOF_STATUS.md)所列依赖。

[新证明](ENERGY_BASIN.md)排除了 d≤1/5 的非候选部分，及整个旋转不变管域

```math
\mathcal T_{\rm new}=\left\{\max_{k\in\{2,3,4,5,6,8\}}|p_k|/2^k\le1/8\right\}.
```

旧 ε=1/40 六矩管域及旧全矩邻域已包含其中；旧11个目标盒继续有效。p₇ 在新管域内无额外限制。

未排除的非候选挑战者必须有 d>1/5。若沿用旧零矩分支分类，还须 p₂p₃≠0，并至少满足下面一项。六项可以重叠，**只是剩余外包，不是已证存在的驻点分支**。

## 接受边界

现有报告固定 `full_eight_point_exclusion_proved=false`。较大区域内“全部驻点唯一”也没有被证明；新目标界只排除达到或超过候选值的非候选构型。没有实际穷尽证据时，不能用验证器通过或局部扩张替代全域量词。
