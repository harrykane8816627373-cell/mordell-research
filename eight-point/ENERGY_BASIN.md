# 八点：直接对数余项、四倍排除半径与五倍矩管域

蒋丰灿（Fengcan Jiang）研究项目，OpenAI Codex 协作，2026-11-01。承接 `d1558d4b4c72722ec7f239f1252cd6b9e049123d`。继续使用作者的驻点与稳定性框架、此前已精确重建的候选稳定谱；没有引入新的全域分类论文。

## 1. 两个目标值排除定理

力1尺度 w=√(7/2)z，参考 w* 是原点和半径2的正七边形；Σ|w_i|²=28，T=4²⁸7⁷。d(w) 表示到参考构型全部旋转、重排轨道的欧氏距离。

**定理A（直接能量区域）。** 对任何满足 Σ|w_i|²=28 的八点构型，若 d(w)≤1/5，则

```math
\boxed{\log\frac{\Delta_w(w)}T\le-\frac{d(w)^2}{30}.}
```

该球内除参考轨道外均严格低于 T。此处不要求预设驻点、稳定性或中心化；小距离也保证互异性。半径从此前的1/20提高到1/5，是**欧氏半径四倍**，不是体积四倍。

**定理B（无额外 p₇ 条件的更大管域）。** 若另有 Σw_i=0，记 p_k=Σw_i^k，并满足

```math
|p_2|\le\frac12,\quad |p_3|\le1,\quad |p_4|\le2,\quad
|p_5|\le4,\quad |p_6|\le8,\quad |p_8|\le32,
```

则 d(w)²<3/100<1/25，因而适用定理A。六个矩模长门槛均为[上一管域](MOMENT_TUBE.md)的五倍，仍**不额外限制 p₇**，且不预先选择旋转。

本次认证的是整个区域内的目标值排除。**没有证明更大区域内所有真实驻点都只能是候选**；较低目标值的其他驻点不由这个目标界单独排除。此前小管域中的驻点刚性继续有效。完整八点锐界仍未证明。

## 2. 实际距离加权 Laplacian 的范数恰为2

定义正半定 Hermitian 矩阵 L₀，使

```math
h^*L_0h=\sum_{i\lt j}\frac{|h_i-h_j|^2}{|w_i^*-w_j^*|^2}.
```

它与此前复逆平方矩阵 B₀ 不同，不能把两者的谱混用。取中心向量 c，及只支撑外七点的 v_k=(ζ^(kj))，ζ=e^(2πi/7)，有

```math
L_0c=\frac74c-\frac14v_0,\qquad
L_0v_0=-\frac74c+\frac14v_0,
```

```math
L_0v_k=\left(\frac14+\frac{k(7-k)}8\right)v_k,\qquad1\le k\le6.
```

因此完整谱为 0,2,1,3/2,7/4,7/4,3/2,1，特别地

```math
\sum_{i\lt j}\frac{|h_i-h_j|^2}{|w_i^*-w_j^*|^2}\le2\|h\|^2.
```

[验证器](verify_energy_basin.py)在 Q(ζ₇) 中从每条实际逆差乘其共轭重新生成 L₀，检查上述完整作用及特征多项式，保留非单位正交基的度量 diag(1,7,…,7)。没有用浮点特征值决定接受。

## 3. 直接展开目标，避免整个球内的 Hessian 扰动损失

取使距离最小的旋转和重排，令 h=w−w*，于是 Re〈iw*,h〉=0。参考最小点距大于12/7。定义

```math
u_{ij}=\frac{h_i-h_j}{w_i^*-w_j^*},\qquad
|u_{ij}|\le\frac{\sqrt2\|h\|}{12/7}\le\frac{33}{200}=:s\lt1,
```

最后使用 ||h||≤1/5、√2<99/70。参考真实力方程及相同二阶矩给

```math
2\Re\sum_{i\lt j}u_{ij}
=2\Re\sum_i\overline{w_i^*}h_i=-\|h\|^2.
```

由收敛的 log(1+u) 级数，

```math
\log\frac{\Delta_w}T
=-\|h\|^2-\Re(h^TB_0h)+R.
```

注意这里是 hᵀB₀h，不是 Hermitian 形式 h*B₀h。[此前完整稳定谱](../power-moment/LOCAL_RIGIDITY.md)使固定旋转切片上的二次项至少为 (2/7)||h||²。

把对数余项的三、四次项保留，余下各项使用1/k≤1/5，得到

```math
|R|\le2\sum_{i\lt j}|u_{ij}|^2
\left(\frac s3+\frac{s^2}4+\frac{s^3}{5(1-s)}\right)
\le4\|h\|^2\left(\frac s3+\frac{s^2}4+\frac{s^3}{5(1-s)}\right).
```

s=33/200 时，准确有理比较是

```math
\frac27-4\left(\frac s3+\frac{s^2}4+\frac{s^3}{5(1-s)}\right)
=\frac{7992559}{233800000}>\frac1{30}.
```

从而得到定理A。这里仅使用参考点的二次谱与实际对数余项，没有声称半径1/5的整个球上 Hessian 都正定。

## 4. 利用一个小根改善自由径向尺度

取 q=w/2、s_k=p_k/2^k，六个条件统一为 |s_k|≤ε=1/8，k∈J={2,3,4,5,6,8}。仍写

```math
P(X)=X^8+aX+\sum_{k\in J}c_kX^{8-k},\qquad a=c_7,
```

并使用上一证明的 Newton 系数界 |c_k|≤b_k。c₇ 不设小量上界；s₁=c₁=0 使 b₈ 不涉及 s₇。

先令 R₀=187/200，由 Σ|q_i|²=7 保证存在更大模长根，得到

```math
|a|\ge A_0:=R_0^7\left(1-\sum_{k\in J}b_k/R_0^k\right)>0.
```

在 |X|=r_c=1/20 上，精确比较确认

```math
r_c^8+\sum_{k\in J}b_kr_c^{8-k}\lt A_0r_c.
```

以 aX 为主项的 Rouché 定理给一个小根 |q_i|<1/20。剩余七个根的平方模总和大于7−1/400，所以其中必有模长大于999/1000。再次使用根方程可得

```math
|a|\ge A_1:=\left(\frac{999}{1000}\right)^7
\left(1-\sum_{k\in J}\frac{b_k}{(999/1000)^k}\right)
>\left(\frac{24}{25}\right)^7.
```

故 t=|a|^(1/7)>24/25。消去相位后令 q=te^(iθ)Y，多项式成为

```math
P_t(Y)=Y^8-Y+\delta P(Y),\qquad
\delta P(Y)=\sum_{k\in J}d_kY^{8-k},\quad
|d_k|\le D_k:=b_k/(24/25)^k.
```

采用 r=3/50 的八个参考根盘，上一证明相同的中心/外盘边界公式仍被严格满足。每盘恰有一个实际根 a_i+h_i，其中 a₀=0，其他 a_i 为七次单位根，|h_i|<r。归一化的粗反三角界先给 t<11/10。

## 5. Parseval 控制全部根误差，而非逐点最大误差

P₀(Y)=Y⁸−Y 在中心的导数为−1、外根的导数为7。六个指数 8−k 模7互不相同，因此

```math
\sum_{i=0}^7\left|\frac{\delta P(a_i)}{P_0'(a_i)}\right|^2
=|d_8|^2+\frac17\sum_{k\in J}|d_k|^2
\le A^2:=D_8^2+\frac17\sum_{k\in J}D_k^2.
```

验证器逐对检查36个实际 cyclotomic Fourier 内积，中心的 d₈ 项另行保留，不能把它漏掉。

由每个实际根方程展开，

```math
h_i=-\frac{\delta P(a_i)}{P_0'(a_i)}+e_i,\qquad |e_i|\le L|h_i|,
```

其中

```math
L=\max\{L_c,L_o\},\quad L_c=r^7+\sum_{k=2}^6D_kr^{7-k},
```

```math
L_o=\frac17\left[
\sum_{j=2}^8{8\choose j}r^{j-1}
+\sum_{k\in J}D_k\sum_{j=1}^{8-k}{8-k\choose j}r^{j-1}\right].
```

k=8 的内层和为空。准确计算 L<426/1000<1，遂有 ||h||²≤A²/(1−L)²。该步骤只估计已经通过 Rouché 匹配的根，不把一次 Newton 迭代当成根存在或唯一性证明。

用两向量相同二阶矩的恒等式消去 t−1，得到

```math
d(w)^2\le4t\|h\|^2
\lt\frac{22}{5}\frac{A^2}{(1-L)^2}
\lt\frac3{100}\lt\frac1{25}.
```

这证明定理B，且相比仅用八个根盘的最大半径 √8r，显著减少了根匹配中的损失。

## 6. 两种非空见证和接受边界

[energy_witnesses.json](energy_witnesses.json)保存两组有理原始点；全部通过准确中心化和二阶矩归一化后检查。

- **更大管域见证**：六个 |s_k| 的严格上端都不超过1/8，且 |p₂|>1/10，故在上一管域的全部旋转之外。它有非零 p₂、p₃，通过246个既有严格真子集条件及旧低阶矩椭圆，但有明确非零真实力残差。全部28对距离的直接有理乘积也严格小于 T。没有把它称作新驻点或优于所有旧排除方法的难例。
- **更大欧氏区域见证**：把原中心点先移到1/10再中心化、归一化。一点平方模大于1/400且小于1；候选点半径只有0或2，因此无论怎样旋转、重排，其轨道距离都大于1/20。Machin 有理 π 区间和带余项的正弦、余弦 Taylor 界另给匹配距离平方小于1/25。报告中的距离平方下端约0.00765、上端约0.00875；显示小数不参与接受。

第二个见证只说明欧氏排除球严格扩大，不要求它满足定理B的六矩条件。两种扩张的量词不能混淆。
