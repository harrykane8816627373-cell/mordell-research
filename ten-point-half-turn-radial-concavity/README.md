# 半转分支的五个径向变量由四个角唯一确定

考虑质量九的半转对称全局最大构型。平方映射把五个点对送到 \(w_i=r_i e^{i\theta_i}\)。令 \(w_0=a>0\) 为内像，四个外像按角序排列。给定这四个外角，下面的定理保证至多存在一组可能的五个半径。半转临界方程由此可按四个角搜索。角变量仍须满足角向平衡或另行验证目标上界。

令 \(s_i=\log r_i\)，取满足下列条件的闭凸域 \(K\)

\[
\tfrac{43}{400}\le r_0\le\tfrac{53}{400},\qquad
\tfrac{89}{100}\le r_i\le\tfrac{1271}{1000}\ (1\le i\le4),\qquad
\sum_{i=1}^4s_i\ge4\log\tfrac{43}{40}.
\]

这里的凸性在 \(s\) 坐标中成立。内外半径带来自[内边](../ten-point-inner-edge/README.md)和[逐点半径界](../ten-point-angular-radii/README.md)。外半径之和至少为 \(9/2-53/400\)。将总和固定在该下端，在四维盒的质量截面顶点检查半径之积，最小值为 \(269001619879/200000000000>(43/40)^4\)。检查下端已足够，因为可逐个减小半径直至总和取到下端。检查顶点已足够，因为 \(\sum\log r_i\) 关于 \(r_i\) 是凹函数。因此 \(K\) 包含每个可能的最大构型，并且在 \(K\) 内恒有 \(\sum_{i=1}^4 r_i\ge43/10\)。

## 径向刚度与误差界

对每组满足[相邻角界](../ten-point-outer-gap/README.md)的固定角，定义 \(F(s)=\log\Delta-10\sum_{i=0}^4r_i\)。在整个 \(K\) 上有

\[
-\nabla_s^2 F\ \succ\ \tfrac14 I_5 .
\]

因而任意 \(s,s_*\in K\) 满足

\[
F(s_*)\le F(s)+\nabla F(s)\cdot(s_*-s)-\tfrac18\|s_*-s\|_2^2
       \le F(s)+2\|\nabla F(s)\|_2^2.
\]

若 \(s_*\) 是驻点，还有 \(\|s_*-s\|_2\le4\|\nabla F(s)\|_2\)。距离积在 \(r_i\) 中的齐次次数为 \(45\)，归一化 \(\sum r_i=9/2\) 下的最大点满足 \(\nabla_sF=0\)。固定角时 \(K\) 上的最大值总能取到，且严格凹性使其唯一。若最大值在 \(K\) 边界，须单独检验其是否满足驻点方程。

还有一个对称性推论。若四个外平方像的方向集合在复共轭下不变，反射最大构型会得到同一组方向上的又一个径向驻点。唯一性给出相应反射点的半径相等，原十点构型因此具有 \(D_2\) 对称。由[条件分类](../ten-point-d2-cover/README.md)，这时全局最大构型就是已认证的两矩形候选。

## 五阶矩阵的有限覆盖

写 \(c_{ij}=\cos(\theta_i-\theta_j)\)，\(d_{ij}=\cosh(s_i-s_j)\)。平方像的距离积公式给出

\[
F(s)=\text{常数}+9\sum_i s_i-10\sum_i e^{s_i}
       +2\sum_{i<j}\log(d_{ij}-c_{ij}).
\]

设 \(e_i\) 为坐标向量，每条边向 Hessian 贡献 \(b(d,c)(e_i-e_j)(e_i-e_j)^T\)，其中

\[
b(d,c)=\frac{2(1-cd)}{(d-c)^2}.
\]

\(\partial_c b\) 的符号由 \(2-d^2-cd\) 决定，在外外边上为正，在内外边上为负。固定 \(c\) 时，\(\partial_d b\) 的符号由 \(cd+c^2-2\) 决定。若 \(c\le0\)，该式为负。若 \(c>0\)，它随 \(d\) 递增。因此区间最大值总在两个端点之一。用每条边的上界替代 \(b\) 即给出 Hessian 的矩阵上界。这里保留了负的边权。

验证器按一周 \(2048\) 格表示方向。Python 用 Machin 公式和有理交错 Taylor 界生成精度为 \(2^{-16}\) 的余弦包围。初始每个角区间占 \(64\) 格。最小间隙使四个外像位于互异区间，故共有 \(\binom{32}{4}\) 个初始盒。用角序、加倍的相邻间隙余弦和对位余弦筛选角盒。

在每个参数盒上，以向上舍入的有理边权形成矩阵。剩下的外半径项 \(10\operatorname{diag}(r_1,\ldots,r_4)\) 是仿射且坐标单调的。在外半径盒与 \(\sum r_i\ge43/10\) 的交中，先检查半径下角。若下角不足以证明且总和低于截面，只需检查总和等于 \(43/10\) 的截面顶点。其余点在逐坐标意义上都控制某个截面点，整个截面是这些顶点的凸包。逐个顶点用有理 Schur 消元检验 \(-\nabla^2F-I/4\) 的正定性。每步向下舍入对角并额外扣除剩余维度个网格单位，覆盖非对角舍入的行和误差。未能验证的盒继续二分。
