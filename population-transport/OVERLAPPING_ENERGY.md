# 相交局部帽的 Green 核 Gram 与跨界面圆盘平均

研究资料与项目发起：**蒋丰灿（Fengcan Jiang）**；推导、精确程序及交叉审阅包含 OpenAI Codex 协作。2026-10-29。基于本轮仓库基线 `c33daad` 的补充。

[先前局部帽方法](../collective-stability/LOCAL_ENERGY.md)允许相同角向模式的**不相交**帽直接相加，并在整盘处于一个调和片时使用中心值公式。本节补上两项不同的能力：保留任意相交帽的完整精确 Gram；对跨过调和界面的圆盘作收敛的有理包围积分。后者不再要求整盘避开界面，也不假装跨界平均等于中心值。

结果是必要能量证书及条件类上界，没有计算全部构型域，也没有得到新的未知点数锐值。Green 核、Gram 投影及 Lipschitz 包围积分均为标准工具；本项目给出它们在本问题中的明确组合和接受入口，不作全球优先权声明。

## 1. 圆周 Green 核给出任意相交帽的精确 Gram

固定整数 k≥1。对平方半径 s>0，定义复测试函数

```math
K_s(w)=\begin{cases}
w^k,&|w|^2\le s,\\
s^k/\overline w^{\,k},&|w|^2>s.
\end{cases}
```

规定 \(K_0=0\)。其实部和虚部各有有限 Dirichlet 范数。采用仓库同一规范

```math
\langle f,g\rangle_D=\frac1{2\pi}\int\nabla f\cdot\nabla g.
```

直接分片作极坐标积分得到

```math
\boxed{\quad
\langle\Re K_s,\Re K_t\rangle_D
=\langle\Im K_s,\Im K_t\rangle_D
=k\min(s,t)^k.
\quad}
```

同模式的实虚交叉内积为零，不同 k 也正交。若 s≤t，内圆盘和外圆域各贡献 \(ks^k/2\)，中间环域的径向、角向交叉项恰好抵消。这也独立核对了系数中的 k。

对已有帽参数 \(0\le a<b<c\)，置

```math
\tau=\frac{b^k-a^k}{c^k-b^k},\qquad
\Phi_{a,b,c}=-K_a+(1+\tau)K_b-\tau K_c.
```

逐片展开恰为先前连续、紧支撑的环带帽：在 \(a<|w|^2<b\) 内为 \(w^k-a^k/\bar w^k\)，在 \(b<|w|^2<c\) 内为 \(\tau(c^k/\bar w^k-w^k)\)，其余为零。

写第 i 个帽的有限圆周核系数为 \(C_{i,s}\)。**不管帽的支撑如何相交**，它们的实部或虚部 Gram 都为

```math
\boxed{\quad
H_{ij}=k\sum_{s,t} C_{i,s}C_{j,t}\min(s,t)^k.
\quad}
```

所有平方半径为有理数时，整个矩阵精确有理。对角元化简为先前的

```math
H_{ii}=\frac{k(b_i^k-a_i^k)(c_i^k-a_i^k)}{c_i^k-b_i^k}.
```

将不同的正核半径排序，矩阵 \(\min(s,t)^k\) 是累加矩阵与正对角增量 \(s_j^k-s_{j-1}^k\) 的乘积，因而严格正定。帽的系数向量线性独立时，H严格正定；重复或其他线性相关帽只给半正定矩阵。实现保留全部相关项，并拒绝非正消元主元；它不会把相关帽当作独立能量重复计数。可先删除冗余测试，再调用当前接受入口。

## 2. 以实际圆盘平均为测量的联合能量定理

沿用 \(x_i=\sqrt{(n-1)/n}\,z_i\)、\(\sum|z_i|^2=n\)，任取 h>0，并令

```math
r=h\sqrt{2/n},\quad
\mu_h=\frac1n\sum_i\sigma_r(\cdot-x_i),\quad
\nu_h=\mu_h-\mu_0,\quad
\psi(h)=\frac{h^2-1}{2}-\log h.
```

其中 \(\mu_0\) 是半径 \(\sqrt2\) 的均匀平衡圆盘。已有精确分解给

```math
\delta(z)+n\psi(h)\ge n^2D(\nu_h),\qquad
\delta(z)=\log(U_n/\Delta_n(z)).
```

对每个模式及其有限独立帽族，定义**完整实际测量**

```math
M_{k,j}=\sum_i\int\Phi_{k,j}(w)\,d\sigma_r(w-x_i).
```

不要求圆盘避开任何界面。弱分部积分和完整 Gram 投影给

```math
\boxed{\quad
\delta(z)\ge n^2D(\overline{\nu_h})
+\sum_k M_k^*H_k^{-1}M_k-n\psi(h).
\quad}
```

证明与先前 Dirichlet 投影一致：所有帽的角向平均为零，因此背景测量和径向交叉项均为零；实虚各自使用同一个 H，两个实二次型合为复二次型。相同 k 的相交帽必须完整保留 H；不同 k 可以相加。这里测量是圆盘积分，不能在跨界时换成 \(\Phi(x_i)\)。

先前全局 j=0 全纯测试的正交例外仍有效：共同全局支撑圆覆盖全部帽时，它在帽支撑内调和，所以与紧支撑帽正交。同模式的 j≥1 全局径向加权测试一般不正交，不能未经联合 Gram 直接再加一次。

## 3. 一个覆盖所有跨界情况的有理平均包围

当前实现采用二维验证积分，不需要圆交面积的浮点近似、反三角函数，或对界面逐类列公式。先给出一个全局 Lipschitz 上端。

写 \(\Phi(Re^{i\theta})=f(R)e^{ik\theta}\)。作为二维实向量映射，它沿径向和切向的导数输出相互正交，算子范数为

```math
\max\{|f'(R)|,\;k|f(R)|/R\}.
```

在内外片上分别可取

```math
L_{\rm in}=k\left[b^{(k-1)/2}
+\mathbf1_{a>0}a^{(k-1)/2}\right],
```

```math
L_{\rm out}=k\tau\left[c^k b^{-(k+1)/2}
+c^{(k-1)/2}\right].
```

所以 \(L=\max(L_{\rm in},L_{\rm out})\) 是全局 Lipschitz 常数。帽在界面连续、各片梯度一致受控；沿任意线段逐片积分即可证明全局性质。代码以向上包围的有理平方根替代这些根式。另有安全幅值上端 \(|\Phi|\le b^{k/2}\)。

对位移圆盘 \(|u|^2\le r^2\)，选一个有理外包正方形并均分为网格。每格通过角点最大距离和到原点最小距离的整数／有理比较，判为全部在圆内、全部在圆外或与圆周相交。对中心为 \(u_C\)、面积为 A、半对角线上端为 \(d_C\) 的格，Lipschitz 性给

```math
\Re\Phi(x+u)\in[v-Ld_C,v+Ld_C],
\quad v=\Re\Phi(x+u_C),
```

虚部同样处理，并与全局幅值区间相交。

若一格全部在圆内，其积分由 A 乘这个区间包围；全部在圆外则为零。**边界格在圆内的面积只知道位于 [0,A]**，所以其贡献使用

```math
[A\min(0,v-Ld_C),\ A\max(0,v+Ld_C)].
```

这同时涵盖正负函数值，不把边界格默认为整格或空格。所有有限格贡献相加，再除以正数 \(\pi r^2\) 的有理区间，按符号向外除法，即得实虚矩形包围。

\(\pi\) 使用 Machin 恒等式 \(\pi=16\arctan(1/5)-4\arctan(1/239)\)，每个 arctan 的交错级数带下一项余量。格内中心值虽为精确有理数，累加时另向外取到共同有理网格，以避免大量互异分母膨胀；此取整误差已经计入区间。

因此该算法对所有圆盘位置都安全，包括同时跨多个帽界面、含原点或跨过支撑最外圆的圆盘。其不确定性随空间网格细化收敛到零：内部格总误差为 O(格宽)，边界格总面积也是 O(格宽)；代码的值取整网格为 \((10^{12}m)^{-1}\)，\(\pi\) 级数长度随网格边数 m 增长。因此取整与归一化误差也趋零。这里只证明收敛，没有声称某个固定网格对所有问题都已经足够细。

## 4. 用有理对偶式接收完整矩形包围

若 M 的每个实、虚分量都有有理区间，不能把不确定分量各取一个“最优值”后当作已证投影。对任何固定复向量 v，恒有

```math
M^*H^{-1}M\ge2\Re(v^*M)-v^*Hv.
```

代码以测量矩形的中点解精确有理方程，选取一个 v；随后对**整个矩形**按 v 的各分量符号取线性配对下端，并精确扣除 \(v^*Hv\)。结果与0取最大，是安全的角向下界。中点只负责选择测试向量，接受步骤覆盖整盒，不假设真实测量就是中点。

随着测量矩形收敛到实际 M，中点对偶下界收敛到这组固定帽的完整投影值。这里没有对帽的半径、数量或无限函数空间作全局优化。

一个防重复计数的代数检查：若测量恰为 \(M=H e_1\)，完整投影能量是 \(H_{11}\)；独立相加则给 \(H_{11}+H_{21}^2/H_{22}\)，在 \(H_{21}\ne0\) 时严格过大。验收程序明确检查这个反例。

## 5. 跨界面非空构型与一整个邻域类

取四个原坐标 \(v=\{1,-1,2,-2\}\)，中心为零、总矩10。令 \(f=3/10\)、\(x_i=\sqrt f\,v_i\)，则库仑总矩为3；相应 \(z_i=\sqrt{4/10}\,v_i\) 满足规定总矩4。默认 h=1 在原坐标中的平滑半径平方是 \(r_{\rm raw}^2=5/3\)。

取 k=2，两个相交帽的原坐标平方半径分别为

```math
(a,b,c)=(0,1,9),\qquad (0,2,16).
```

实际库仑尺度的参数均乘 f。原坐标 Gram 恰为

```math
H=\begin{pmatrix}81/40&88/45\\88/45&512/63\end{pmatrix},
\qquad\det H=179072/14175>0.
```

实际测量有共同因子 \(f^{k/2}\)，实际 H 有因子 \(f^k\)，两者在能量投影中抵消。因此可完全在原有理坐标中计算。

中心平方半径1、4与两个帽的四种组合，旧的“整盘在一个调和片”判断全部拒绝。新方法完整接收四种跨界情况。32×32网格已认证 \(\delta>0.1166169\)；64×64网格认证 \(\delta>0.3429576>1/3\)。这些小数只作展示，接受比较使用有理数。

还可不只检查一个构型。考虑所有有标签复点 y，满足

```math
\sum_i y_i=0,\qquad\sum_i|y_i|^2=10,
\qquad |y_i-v_i|\le1/1000.
```

这个类包含 v，故非空；点间距也保持正。归一化和原坐标平滑半径完全相同。每个圆盘中心偏移至多 η 时，帽平均的复值变化至多 Lη，所以每个总测量的实、虚分量各扩张 \(4L/1000\) 即覆盖整个类。对64×64网格包围作这项扩张后，精确对偶仍给

```math
\delta>0.3361223>1/3.
```

单位正四边形的可达值256给任意全局最大者缺额预算

```math
\delta_4\le\log(U_4/256)
=14\log2-6\log3-3<1/8.
```

故整个跨界面邻域类都不含全局最大者。该例只展示新接口确实覆盖了旧调和中心值公式不能直接使用的输入。**没有声称这类构型躲过了已有点距、局部稳定或其他几何排除；也没有把已知四点问题包装成新的未知锐值突破。**

## 6. 精确实现、接口与限制

[overlapping_energy.py](overlapping_energy.py)提供：

- `gram_matrix`：任意相交帽的精确 Green Gram；不要求相同模式支撑分离。
- `disk_average_rectangle`：所有跨界情况均有效的圆盘平均矩形。
- `dual_certificate`：相交同模式测试的完整区间对偶接受。
- `shape_certificate`：有理坐标中心化、精确尺度抵消、所有圆盘贡献，以及另行已证的同一 h 径向下界。平滑代价只扣一次。

输入非零径向下界仍须独立证明。相同径向能量上的两套完整下界应取最大值；不同角向模式才可直接求和。相关帽族的矩阵可能奇异，当前对偶入口拒绝非正主元，要求先去掉冗余测试。较粗网格可能只给零下界，这表示当前证书不足，不表示真实角向能量为零。

```bash
python -B -S -O population-transport/verify_overlapping_energy.py
python -B -S -O population-transport/verify_overlapping_energy.py --write-report
```

[核验报告](overlapping_energy_verification.json)记录64组独立分片极坐标 Gram 对照、3264个保留网格格子的几何检查、调和基准平均包围、4个旧接口拒绝、7项非法输入拒绝，以及上述单构型和邻域类证书。所有接受计算仅用整数、`Fraction` 和带余量的级数；没有用浮点圆交面积或抽样冒充严格积分。

理论中的普遍量词由正文证明，有限检查只核对实现。完整八点锐界、一般 n 最优构型及精确渐近常数仍未解决；本节不声称外部同行评审或整篇形式化证明。
