# 有效的半平方根层数界：一个覆盖所有 n≥10000 的简式

研究资料与项目发起：**蒋丰灿（Fengcan Jiang）**；推导、程序与交叉核验包含 OpenAI Codex 协作。2026-10-29。

本节将新的单层谱容量与径向运输定理，化为不含未知渐近阈值的有限结论。K始终相对重心计数。

## 1. 主结论

任意全局最大构型，在所有 n≥10000 时均满足

~~~math
\boxed{K>\frac{\sqrt n}{2}-\frac{11}{20}n^{1/4}.}
~~~

因此

~~~math
\boxed{\liminf_{n\to\infty}\frac{K_n}{\sqrt n}\ge\frac12.}
~~~

证明的输入为用户已有的二阶稳定性、初等有效可达下界，以及本轮的谱容量和径向运输。这里不需要精确线性渐近常数 γ 或未知有效起点的线性渐近展开。

该式是必要条件，未确定真实层数、人口、角度或全局锐值。实现对 n<10000 明确拒绝使用本节简式，较小点数可以使用本专题的通用运输接口和其他既有界。

## 2. 谱容量与径向运输的准确衔接

沿用库仑尺度 x=√((n−1)/n)z、Σ|x_i|²=n−1、δ=log(U_n/Δ_n)。由[同圆谱容量](ANGULAR_CAPACITY.md)，每一层半径R、人口m都有

~~~math
m-1\le 2\sqrt{2n}\,R.
~~~

取截断逆半径

~~~math
w_a(R)=\min\{a^{-1},R^{-1}\},\qquad w_a(0)=a^{-1}.
~~~

因为 Rw_a(R)≤1，同层总测量满足

~~~math
m w_a(R)\le 2\sqrt{2n}+\frac1a.
~~~

这一步同时覆盖单点层和可能的原点层，不存在除以零。记经验平均 A_a=n^{-1}Σw_a(|x_i|)，则

~~~math
\frac K{\sqrt n}\ge
\frac{A_a}{2\sqrt2+1/(a\sqrt n)}.
~~~

在h=1的既有圆盘平滑下，[径向运输证明](RADIAL_TRANSPORT.md)给0<a≤√2时

~~~math
A_a\ge \sqrt2-\frac a2
-\frac{\sqrt{\delta}}{\sqrt2\,na}
-\frac1{4na^3}.
~~~

其三个损失分别来自截断背景、Dirichlet对偶和从平滑平均转回点中心。最后一项不能因 w_a 在界面不可微而省略；原证明通过分布拉普拉斯及超调和均值给出严格控制。

## 3. 把旧初等可达下界代入

此前[有效径向证明](../radial-angular/RADIAL_LAYERS.md)给全局最优者的缺额上端

~~~math
\delta_n\le E_n=\frac n{100}+\frac{77}6\sqrt n+\frac{35}4.
~~~

对于 n≥10000，

~~~math
\frac{E_n}n\le
\frac1{100}+\frac{77}{600}+\frac{35}{40000}
=\frac{3341}{24000}<\frac7{50}.
~~~

现在取 a=n^{-1/4}，令 t=n^{-1/4}。得到

~~~math
A_a\ge
\sqrt2-t\left(\frac34+\sqrt{\frac{E_n}{2n}}\right)
>
\sqrt2-t\left(\frac34+\frac{\sqrt7}{10}\right).
~~~

同时分母为2√2+t。因此

~~~math
\frac K{\sqrt n}>
\frac12-\frac{t(5/4+\sqrt7/10)}{2\sqrt2+t}
\ge
\frac12-\frac{5/4+\sqrt7/10}{2\sqrt2}\,t.
~~~

只需很粗的有理根式界，就能验收最终常数：

~~~math
\sqrt2>\frac75,\qquad \sqrt7<\frac83,\qquad
\frac{5/4+\sqrt7/10}{2\sqrt2}
<\frac{13}{24}<\frac{11}{20}.
~~~

这证明第1节全部有限 n 的严格不等式。这里的h=1、a=n^{-1/4}只为得到简短可引用公式；通用接受器可对明示的其他有理a、h分别核验，某些有限点数还能更强。

## 4. 精确整数推论

本节简式本身给出：

|n|简式保证的最少不同半径数|
|---:|---:|
|10000|45|
|100000|149|
|1000000|483|
|100000000|4946|
|1000000000000|499451|

例如 n=10^8 时右端恰为4945。因为不等式严格，所以K≥4946，不能向下写成4945。

[实现](effective_layers.py)通过整数平方根给√n下端与四次根上端，再对严格下端取floor+1。表中不是对原最优化问题做大型点集搜索，只是普遍定理的整数推论；也不主张是所有已证方法中的最佳有限值。

[独立核验](verify_effective_layers.py)检查旧预算的精确代入、系数比较、603个根式外包、整数边界和非法范围；[报告](effective_layers_verification.json)保留完整分数。普遍结论的解析桥梁见正文，程序不替代这些证明。

本节结论不要求规则角度、反射对称或预设人口。一般 n 完整最优构型、八点完整锐界、精确γ和全局结晶继续开放。
