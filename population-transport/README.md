# 一般 n：谱人口容量、径向运输与有效二分之一层数界

研究资料与项目发起：**蒋丰灿（Fengcan Jiang）**；推导、精确程序及交叉审阅包含 OpenAI Codex 协作。2026-10-29。承接 c33daad3e33ac2305be911b7d4bc542ca85fe53a。

本轮把同层角向容量与径向能量测量直接连接，将全局最优构型的渐近层数保证推进到1/2，并给明确的有限 n 误差。同时扩大角向能量程序的适用范围，允许测试支撑相交、平滑圆盘穿过界面。

**一般最优构型、真实精确层数、八点完整锐界和精确γ仍未确定。**

## 1. 主结果：有效的二分之一系数

K为相对重心的不同半径数。任意全局最优构型满足

~~~math
\boxed{K>\frac{\sqrt n}{2}-\frac{11}{20}n^{1/4}\quad(n\ge10000),\qquad
\liminf_{n\to\infty}\frac{K_n}{\sqrt n}\ge\frac12.}
~~~

此前渐近下端是13/30。新的证明只用用户已有二阶稳定性、初等有效可达下界与本轮运输估计；不需要精确线性渐近项或未知有效起始阈值。它不说明K_n/√n真实收敛到1/2。

同一通用接受器对明示的有限参数族逐项核验，还给更强的特定点数证书：

|n|上述简式保证至少|明示有限参数族保证至少|
|---:|---:|---:|
|10000|45层|46层|
|1000000|483层|487层|
|100000000|4946层|4958层|
|1000000000000|499451层|499575层|

这张表是普遍必要条件的精确代入，没有枚举这些大型点集，也不主张有限参数族在所有参数中最优。

## 2. 新角向容量：不预设同层等角

同一半径R上取偶数m个点，按角序交错分成两组。稳定性范数界限制交叉相互作用和；角差凸性给它的下界。结果为

~~~math
m^2\le8(n-1)R^2\quad(m\text{偶数}),\qquad
(m-1)^2<8(n-1)R^2\quad(m\ge3\text{奇数}).
~~~

所以任意局部最大构型（也包括全局最大）都有新的全 n 界

~~~math
\boxed{K>\frac{n}{1+2\sqrt{2(n-1)}}.}
~~~

单点层有明确处理。完整整数人口预算保留奇偶差别；较小点数还可与其他既有必要条件取较强者。

同一方法进一步控制整个薄径向带，允许每个点半径不同。其Chebyshev有理判据证明：**八点局部最大不可能全部位于半径[0.99,1.01]中**，并给

~~~math
\sum_{i=1}^8(|z_i|^2-1)^2>\frac{39601}{10^8}.
~~~

这是原完整稳定性条件的进一步几何推论，不比完整算子本身更强，也不完成八点问题。

## 3. 逆半径测量把容量连接到全局径向分布

令x=√((n−1)/n)z，w_a(R)=min(1/a,1/R)。它的Dirichlet范数恰为1/(2a²)，截断处的负拉普拉斯跳项给平滑均值的二阶误差。对同一平滑参数h，若E为已证缺额上包、A为已证且与径向正交的角向能量下端，则

~~~math
\frac1n\sum_iw_a(|x_i|)
\ge\sqrt2-\frac a2
-\frac{\sqrt{E+n\psi(h)-A}}{\sqrt2\,na}
-\frac{h^2}{4na^3}.
~~~

谱容量又限制每一层对这个测量的贡献。把两个不等式联立即得带有效误差的层数界。只输入旧初等预算E_n=O(n)，就可推出第1节的1/2结论。

这给一个直接联合角向信息的接口：输入同h下、尚未扣除平滑代价的角向Gram下界A，缩小径向预算，再送入运输。另一个完整径向证书不能当作A重复扣除。

## 4. 相交局部测试与跨界面圆盘

新Green核的同模式Gram有精确公式

~~~math
\langle K_s,K_t\rangle_D=k\min(s,t)^k.
~~~

任意相交帽函数都可用完整Gram联合。圆盘可能穿过测试界面时，程序采用有理网格、Lipschitz区间和边界面积包围计算实际均值，避免错误使用调和中心值。网格细化有收敛证明。

实际四点输入中，旧中心值接口无法认证跨界情形，新接口得到严格正的联合能量及非空邻域排除证书。该例也可由旧几何条件排除，因此它证明的是新接口的适用扩展，不是新的未知锐值或此前所有方法遗漏的候选分类。
