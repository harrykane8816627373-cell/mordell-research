# 从交错角向测试到更强的同层与厚带人口容量

研究资料与项目发起：**蒋丰灿（Fengcan Jiang）**；本轮推导、程序及交叉审阅包含 OpenAI Codex 协作。2026-10-29。

用户原稿已证明的二阶稳定性算子界是本节输入。本节不要求同层等角；新增的是把同圆相位调整、交错点集和凸性联合起来，再推广到允许半径变化的薄环带。结论均为必要条件，不能由通过条件反推最优性。

## 1. 同一半径层的更强人口界

在 Σz_i=0、Σ|z_i|²=n 的无碰撞局部最大点，令 λ=(n−1)/2。原稿稳定性矩阵满足

~~~math
B_{ij}=-(z_i-z_j)^{-2}\quad(i\ne j),\qquad \|B\|\le\lambda.
~~~

原定理的归属、假设及完整算子见[用户修订主稿](../source-review/revised_main.tex)及[此前稳定性归约](../symmetry-breaking/PAIR_STABILITY.md)。

设某个以重心为圆心的圆周半径为 R，人口为偶数 m≥2。按角序写 `z_i=R exp(iθ_i)`，I、J分别取交错的m/2个点。由于

~~~math
B_{ij}=e^{-i\theta_i}e^{-i\theta_j}|z_i-z_j|^{-2},
~~~

取仅支撑在I上的 `u_i=exp(−iθ_i)`、仅支撑在J上的 `v_j=exp(iθ_j)`，原范数界直接给

~~~math
\sum_{i\in I,j\in J}|z_i-z_j|^{-2}\le\frac{\lambda m}{2}.
~~~

这是不同点之间的交叉项，不需要未知的B对角元。

对每个奇数 k∈{1,3,…,m−1}，令 α_(i,k) 为从第i点沿正角向到第i+k点的角差，保留跨过2π的计数。相邻角隙求和给 `Σ_i α_(i,k)=2πk`。函数 `csc²(α/2)` 在(0,2π)严格凸，故

~~~math
\sum_i|z_i-z_{i+k}|^{-2}
\ge\frac{m}{4R^2}\csc^2\frac{\pi k}{m}.
~~~

每个I×J点对在所有奇跳的定向总和中恰计两次。另有

~~~math
\sum_{k\text{ odd}}\csc^2\frac{\pi k}{m}=\frac{m^2}{4}.
~~~

因此交叉和至少为 `m³/(32R²)`，与范数上界联立得到

~~~math
\boxed{m^2\le8(n-1)R^2\qquad(m\text{ 偶数}).}
~~~

等号时奇跳k=1的Jensen必须取等，所以这些m点必须等角；正文没有把一般层预先假定为正规多边形。

若人口m≥3为奇数，取任意m−1点应用偶数结论，得到更精确的严格式

~~~math
\boxed{(m-1)^2<8(n-1)R^2\qquad(m\ge3\text{ 奇数}).}
~~~

否则等号将强迫任意m−1点子集都是同圆上的正(m−1)边形。这样的正多边形由其中任意一个顶点唯一决定；两个不同子集共享顶点却具有不同顶点集，矛盾。单点层只有 `R²≥0`，不能把严格式套到原点。

统一写 `e(m)=2 floor(m/2)`，同层必要条件为

~~~math
R^2\ge\frac{e(m)^2}{8(n-1)},
~~~

奇人口m≥3时严格。领先人口容量由旧间距法的π降低为2√2。新界适用于**所有局部最大点**；旧[环人口方法](../collective-stability/RING_POPULATION.md)使用全局严格子集间距，适用范围是全局最大点。不同方法仍可取联合必要条件。

## 2. 全n有限层数及完整整数人口预算

若人口为 m_1,…,m_K，写

~~~math
c(m)=m\,e(m)^2=\begin{cases}m^3,&m\text{ 偶数},\\m(m-1)^2,&m\text{ 奇数}.
\end{cases}
~~~

总矩给出

~~~math
\boxed{\sum_jc(m_j)\le8n(n-1).}
~~~

只要存在奇人口至少3的层，右侧不等式严格。人口1的层贡献零，原点不被遗漏。

函数 `f(x)=x(x−1)²` 在x≥1严格凸，且c(m)≥f(m)，所以

~~~math
\sum_jc(m_j)\ge\sum_jf(m_j)
\ge\frac{n(n-K)^2}{K^2}.
~~~

于是所有局部最大点都有全n有限保证

~~~math
\boxed{K>\frac{n}{1+2\sqrt{2(n-1)}}\qquad(n\ge2).}
~~~

严格性不能只从最后的非严格式猜测：K<n时，若有偶人口，c(m)>f(m)带来严格性；若只有奇人口，至少一层人口≥3，原人口预算严格。K=n时结论直接成立。这个有限界的领先常数为1/(2√2)，与下一专题用分布信息得到的更强渐近/有效结论用途不同。

给定n、K，程序进一步完整优化整数人口。关键交换恒等式：对两个偶人口a,b≥2，把它们替换为 `(a−1,b+1)` 或 `(a+1,b−1)`；两方案成本的平均值为

~~~math
a^3+b^3-2\big[(a-1)^2+(b-1)^2\big]<a^3+b^3.
~~~

因此最小成本人口中最多有一个偶数。若n−K为偶数，全部人口为奇数；由f的凸性，奇人口尽量均衡（相差至多2）。若n−K为奇数，完整枚举唯一偶人口，其余奇人口仍尽量均衡即可。这给出全部正整数人口分拆的精确最小值C(n,K)，不是只在某个人口家族内寻找较小值。

若C>8n(n−1)，排除所有K层局部最大；相等时，只有所有最小成本分拆都含奇人口≥3才严格排除。实现保留全部最小成本方案的这个标记。每次把人口r拆成a+b=r都会严格降低成本：r≥3时 `c(a)+c(b)≤r³−3r(r−1)<r(r−1)²≤c(r)`，r=2直接核对。因此C随K严格下降，可二分寻找最后排除的层数。

程序在枚举唯一偶人口前检查完整预算；大n预算不足时明确拒绝，不影响上述全n解析定理。实际记录n=8、100、1000、10000时，新的局部必要层数分别为2、4、12、36。它们不等于真实最优层数；本轮[运输及有效层数推论](EFFECTIVE_LAYERS.md)对全局最优者在大n给出更强保证。

## 3. 允许半径变化的薄环带：任意角度仍有容量

现在只要求某m个点的半径位于 `[a,b]`，0≤a≤b，b>0，宽w=b−a。令d₀²为已证明的最小点距平方下界：

~~~math
d_0^2=\frac{2n}{(n-1)^2}\quad\text{适用于局部最大},\qquad
d_0^2=\frac4{n-1}\quad\text{适用于全局最大}.
~~~

后一界来源于用户既有[严格子集定理](../finite-n/SUBSET_PROOF.md)；n=2的值由直接计算成立。必须保留薄带条件

~~~math
\boxed{2w^2<d_0^2.}
~~~

令 `M=e(m)` 为最大不超过m的偶数，`h=M/2`、`η=1−2w²/d₀²>0`。从带中任取M点。间距条件保证角度互异；若出现原点，它与带内另一点的距离不超过b=w<d₀，矛盾，因此相位调整也无零半径问题。

对其中一对点写角差α、半径r_i,r_j，令

~~~math
A=(r_i-r_j)\cos(\alpha/2),\quad
D=(r_i+r_j)\sin(\alpha/2),\quad d^2=A^2+D^2.
~~~

相位调整后

~~~math
\operatorname{Re}\big[e^{i(\theta_i+\theta_j)}B_{ij}\big]
=\frac{1-2A^2/d^2}{d^2}\ge\frac\eta{d^2}.
~~~

另外 `d²≤w²+4b² sin²(α/2)`。取

~~~math
F(\alpha)=\frac1{w^2+4b^2\sin^2(\alpha/2)}.
~~~

虽然F未必在整个(0,2π)凸，但所有实际角差满足 `4b²sin²(α/2)≥d₀²−w²>w²`。若u=sin²(α/2)，F的二阶导数符号由

~~~math
-w^2+(12b^2+2w^2)u-8b^2u^2
\ge-w^2+4b^2u>0
~~~

决定。所有允许角差落在同一个避开0和2π的区间，F在这个完整区间严格凸，所以每个奇跳仍能使用Jensen。若允许区间为空，本带原本已不可能满足间距，结论同样成立。

对交错I,J作同样范数测试并取实部，得到

~~~math
\boxed{\eta S_M(w,b)\le\lambda,\quad
S_M=\sum_{k\text{ odd}}\frac1{w^2+4b^2\sin^2(\pi k/M)}.}
~~~

**这一式约束整个带的人口，允许每个点半径不同。** 它不是把精确同层结论误用到厚带。

## 4. Chebyshev闭式使整个薄带接受完全有理

定义Chebyshev多项式 `T_0=1,T_1=x,T_(j+1)=2xT_j−T_(j−1)`。取

~~~math
x=1+\frac{w^2}{2b^2}\ge1.
~~~

`T_h(x)+1`的h个根按重数计，正是 `cos((2j+1)π/h)`。对根分解作对数导数可得

~~~math
\boxed{S_M(w,b)=\frac{T'_h(x)}{2b^2[T_h(x)+1]}.}
~~~

重根必须按重数计，程序的递推正是这个多项式的值与导数。T_h(1)=1、T'_h(1)=h²，所以w=0时S=M²/(16b²)，精确复原第1节偶人口界和csc平方和恒等式。对于正有理a,b，整个判据不含三角浮点或平方根。

一个明确整类证书：n=8，全部8点半径位于 `[99/100,101/100]`。只用局部基本间距，精确计算给出

~~~math
\eta S_8=\frac{407120106}{104142017},\qquad
\lambda-\eta S_8=-\frac{85246093}{208284034}<0.
~~~

因此该整个任意角度、任意带内半径的类没有局部最大，也没有全局最大。

它确实非空，且旧两点、全局点距和半径界并未排除整个类。取原始整数点

~~~math
\{(70,0),(49,49),(0,70),(-49,49),(-70,0),(-49,-49),(0,-70),(49,-49)\}/\sqrt{4851}.
~~~

其重心为0、总矩为8，两条平方半径分别是4802/4851、4900/4851，严格落在所述带内；最小距平方2842/4851>4/7、最大半径平方<7/4，全部28个旧两点slack均严格正。两条各4点层也分别通过旧立方人口预算和新的单层容量。新的失败来自把整个厚带作为8点联合测试，不能由每层分别通过反推整带通过。该整数形状沿用[上一轮块稳定性例](../collective-stability/BLOCK_STABILITY.md)，不登记为新构造。

直接推论：任意归一化八点局部最大构型，必有某点满足 `||z_i|−1|>1/100`。因此至少一个平方半径偏差的绝对值大于 `1−(99/100)²=199/10000`，从而有一般角度下明确的正径向方差缺口

~~~math
\boxed{\sum_{i=1}^8(|z_i|^2-1)^2>\frac{39601}{10^8},
\qquad\sum_{i=1}^8|z_i|^4>8+\frac{39601}{10^8}.}
~~~

第二式使用总二阶矩为8。它是必要条件，可作为八点剩余分支的径向输入；不声称强于原完整稳定性算子或所有既有矩层级，也不证明八点锐值。
