# 十点候选的显式局部锐界

2026-11-10。蒋丰灿研究项目，OpenAI Codex 协作。

记 \(Z^*\) 为[已经认证的十点 \(D_2\) 驻点](../candidate-global-screen/README.md)，在 \(\sum_i|z_i|^2=10\) 的尺度下取 \(C_{10}=\prod_{i<j}|z_i^*-z_j^*|^2\)。**任意十点构型只要到 \(Z^*\) 的旋转和重排轨道的欧氏距离不超过 \(1/100\)，其距离积就不超过 \(C_{10}\)，等号仅在候选轨道。** 这个半径是[旧保证](../candidate-basin/README.md)的 2621.44 倍。范围内的构型无需驻定、对称、居中或预设任何半径分层。轨道补集仍须单独排除。

## 反射分裂与三次项抵消

写 \(L(z)=\log\Delta(z)-(9/2)\sum_i|z_i|^2\)，其中 \(\Delta(z)=\prod_{i<j}|z_i-z_j|^2\)。选定实现轨道距离的旋转、重排，将待测构型写成 \(Z^*+\eta\)。对旋转角的一阶最小条件给 \(\langle \eta,q\rangle=0\)，其中 \(q=iZ^*\)，内积取实部。

采用已精确认证的反射置换 \(\psi\)。令 \(T\) 为逐点反射与 \(\psi\) 的组合，故 \(TZ^*=Z^*\)，\(T^2=I\)，且 \(L(Tz)=L(z)\)。将 \(\eta\) 正交分解成反射奇部分 \(\eta_-\) 与偶部分 \(\eta_+\)，记它们的范数为 \(s,t\)。设 \(H=-\tfrac12D^2L(Z^*)\)，\(P_\pm=(I\pm T)/2\)。接受器重放实际根的存在、唯一性及反射，随后验证

\[
H+qq^T/10-\tfrac{3}{40}P_- -\tfrac{22}{25}P_+\succ0.
\]

因此在 \(\eta\perp q\) 上，二次损失至少为 \((3/40)s^2+(22/25)t^2\)。计算用的是完整 20 维 Hessian，包含所有点独立移动的方向。

令 \(d_{ij}=z_i^*-z_j^*\)，\(w_{ij}=(\eta_i-\eta_j)/d_{ij}\)。所有 \(|d_{ij}|>7/10\)，且 \(\|\eta_i-\eta_j\|\le (10/7)\|\eta\|\)。故在半径 \(1/100\) 内，\(|w_{ij}|\le 1/49\)。逐对展开 \(2\operatorname{Re}\log(1+w_{ij})\)，常数项抵消，一次项由完整力方程消去。三次项为 \((2/3)\operatorname{Re}\sum_{i<j}w_{ij}^3\)。将其与在 \(T\eta\) 的展开取平均，含奇数个反射奇分量的项恰好消失。特别地，范数为 \(s\) 的较软子空间没有纯三次项。

取 \(L_k\) 为以 \(|d_{ij}|^{-k}\) 为边权的图 Laplacian，接受器验证 \(L_3\prec14I\) 和 \(L_4\prec17I\)。于是三次项绝对值至多为

\[
40(s^2t+t^3/3).
\]

例如混合项逐对由 \(2|(\eta_-)_i-(\eta_-)_j|^2|(\eta_+)_i-(\eta_+)_j|/|d_{ij}|^3\) 控制；对最后一个因子使用 \((10/7)t\)，其余两项由 \(L_3\) 控制。四次及以上的余项绝对值至多为

\[
\frac{1}{2(1-1/49)}\sum_{i<j}|w_{ij}|^4
\le \frac{17}{9600}(s^2+t^2),
\]

其中先取两次位移因子的上界 \((10/7)^2/100^2\)，然后对其余两次使用 \(L_4\)。以 \(s^2t\le st/100\)、\(t^3\le t^2/100\) 合并这些界，得到

\[
L(Z^*+\eta)-L(Z^*)\le-
\begin{pmatrix}s&t\end{pmatrix}
\begin{pmatrix}703/9600&-1/5\\-1/5&7151/9600\end{pmatrix}
\binom{s}{t}.
\]

右侧矩阵正定，行列式为 \(1340753/92160000\)。因此除 \(\eta=0\) 外严格小于零。在质量 10 球面上 \(L\) 与 \(\log\Delta\) 仅差常数，结论成立。

## 精确复核

从仓库根目录运行：

```sh
python -B -S -O ten-point-local-basin/verify_all.py
```

接受器只用标准库。它在根的整数区间上直接构造三个对称矩阵，并通过对角移位取得各自的统一有理矩阵下端，然后检查精确 LDL 的全部主元为正。可用 `--export-jacobian PATH` 导出这些有理下端，交给 Jacobian 的 `matrix.inertia.compute` 独立检查；实际结果的三个惯性分别为 \((20,0,0),(10,0,0),(10,0,0)\)。[源清单](source_manifest.json)固定已有根证书与反射证明的输入。
