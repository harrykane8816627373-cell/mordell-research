# 近邻代价与空洞代价联合：显式线性圆盘缺额

研究资料与项目发起：**蒋丰灿（Fengcan Jiang）**；推导及精确程序包含 OpenAI Codex 协作。2026-10-30。

本节保留旧圆盘平滑证明中已明确列出的重叠点对代价，再用[局部几何二择](LOCAL_ALTERNATIVE.md)保证它或局部空洞代价必须出现线性数量。所得常数很小，但阶数不同于此前趋零的Newton折扣。经典平滑分解和已有严格子集几何仍归原来源。

## 1. 主定理

令δ_n=log(U_n/M_n)，U_n沿用仓库圆盘上界。对每个整数n≥2，有

~~~math
\boxed{\delta_n\ge\frac{(n-11\sqrt n)_+}{2^{24}},\qquad
M_n\le U_n\exp\!\left[-\frac{(n-11\sqrt n)_+}{2^{24}}\right].}
~~~

因此对全部n≥484，δ_n≥n/2²⁵；并有

~~~math
\liminf_{n\to\infty}\delta_n/n\ge2^{-24}>0.
~~~

有限证明不调用外部线性展开或结晶定理，也不要求任何层等角。n≤121时此新式只给零，既有正Newton折扣及小点数专用锐界继续保留。

## 2. 必须保留的第三项

设x=√((n−1)/n)z、r=√(2/n)、μ=n⁻¹Σσ_r(·−x_i)、ν=μ−μ₀。此前[精确非负分解](../asymptotics/README.md)已经给

~~~math
\delta(z)=n^2D(\nu)+2n^2\int\zeta\,d\mu
+\sum_{i\ne j}[g(x_i-x_j)-T_r^2g(x_i-x_j)],\qquad g=-\log|\cdot|.
~~~

三项非负。本文没有把这个已有恒等式登记为新发现。它是经典圆盘涂抹/Onsager方法的本项目归一化；现代一手来源和自含推导见旧专题及Lauritsen [arXiv:2103.07975v2](https://arxiv.org/abs/2103.07975v2)。

令w=x/r，即[力为1的尺度](LOCAL_ALTERNATIVE.md)。点对损失只依赖d=|w_i−w_j|。旧显式下界给

~~~math
g(d)-T_1^2g(d)\ge\frac1{16}(1-d/2)_+^4.
~~~

简要复核：h=g−T₁g在0<d<1时为−log d−1/2+d²/2，且h≥(1−d)²。又g−T₁²g=h+T₁h。在两个单位盘的交集中取中点附近的小圆盘，将其面积比与h的下端相乘，即得四次项。

故每个d<c=15/8的无序点对，仅以两个有序项已贡献

~~~math
p=\frac18(1-c/2)^4=\frac1{524288}=32\kappa,
\qquad \kappa=2^{-24}.
~~~

在极大匹配中这些点对不共享端点，因此可以安全逐对计数。实际上不同点对损失本就可相加；匹配只为后续人口账本服务。

## 3. 每个能量空洞的准确尺度

w尺度的背景概率密度是1/(πn)，平滑盘半径1。零质量电荷的对数能量在整体缩放下不变。对背景内部、没有平滑质量的半径b空盘，取ψ=(b²−|w−v|²)_+，则

~~~math
\int\psi\,d\nu=-b^4/(2n),\qquad \|\psi\|_D^2=b^4.
~~~

Bessel或局部Gauss积分给n²D≥b⁴/4。不交空盘的测试梯度支撑不交，故H个这样的空盘贡献至少H b⁴/4。这里b=9/200，并有有理比较

~~~math
\frac{b^4}{4\cdot17}=\frac{6561}{108800000000}
\ge\frac1{16777216}=\kappa.
~~~

## 4. 能量与人口账本闭合

在一个全局最优构型上，取上节几何证明的极大匹配M、安静内点Q、边界人口B和不交空盘H。几何给

~~~math
Q\ge n-B-32M,\quad H\ge Q/17,\quad B<11\sqrt n
\quad(n\ge4).
~~~

精确能量分解保留了点对项和D项，因此二者可直接相加：

~~~math
\delta_n\ge pM+Hb^4/4
\ge\kappa(32M+Q)
\ge\kappa(n-B).
~~~

再与零取最大即得主式。n=2、3时主式右端为零，由旧δ_n≥0成立。这个证明没有将同一Dirichlet能量计算两次。

## 5. 可保留的角向项及不可直接相加的项

选一个全局支持圆，同时覆盖全部平滑盘和背景盘。各空洞泡紧支撑于圆内，而旧j=0全纯测试在那里调和，因此二者正交。故对任意已证全纯角向下端A，有更强的

~~~math
\delta_n\ge A+\kappa(n-11\sqrt n)_+.
~~~

例如可采用用户新包中的统一R_n=√2((n−1)/n+1/√n)和对应的正Newton折扣c'_n，使δ_n≥c'_n+κ(n−11√n)_+。旧更强分母的Newton界也继续取较强者。

**不能**未经联合Gram再把本线性修正与完整径向能量、或j≥1混合角向投影的完整下端相加；局部空洞已占用其中部分Dirichlet能量。安全做法是取两个完整证书的较大值，或回到实际空洞及完整Gram。

## 6. 有限比较和线性系数接口

例如n=144，主式给δ₁₄₄≥3/4194304≈7.15×10⁻⁷。旧纯Newton折扣c₁₄₄可由末项上包为小于10⁻¹⁰，因此在这个指定点数新项已严格更强。它不声称强于所有小点数专用上界。

若另沿用仓库[已经注明外部来源的线性展开](../asymptotics/README.md)，则δ_n/n→γ_D−γ，故

~~~math
\gamma\le\frac34-\frac12\log2-2^{-24}
<0.403426350115382569900758939272.
~~~

这是对本项目此前圆盘端点的明确正改善，幅度保守，没有确定γ。有限n主定理不需要这条外部展开；关于近期预印本和本地认证范围见[文献说明](LITERATURE_SCOPE.md)。本文不宣称给出文献中最强的常数。
