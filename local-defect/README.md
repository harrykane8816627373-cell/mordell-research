# 一般 n 的线性正缺额与径向—角向矩联合

研究资料与项目发起：**蒋丰灿（Fengcan Jiang）**；推导及精确程序包含 OpenAI Codex 协作。2026-10-30。承接本地提交 `ab06264d6d6f77b96e26e7d9805753caa3427d90`。

本轮的主要变化是保留圆盘涂抹时的重叠点对代价，再以局部几何强迫近邻或空洞出现线性数量，得到一个显式的线性正缺额。另一条路线建立匹配二阶矩的径向Gram层级，与驻点角向能量共用预算。**本轮未完成八点锐界、一般n有限最优构型的分类或本地结晶认证。**

## 1. 主结果：从趋零折扣推进到线性阶

沿用原归一化Σ|z_i|²=n、最优距离乘积M_n及圆盘上端U_n。对所有n≥2有

~~~math
\boxed{\log(U_n/M_n)\ge\frac{(n-11\sqrt n)_+}{2^{24}}.}
~~~

因此所有n≥484已有log(U_n/M_n)≥n/2²⁵；其渐近下端满足liminf log(U_n/M_n)/n≥2⁻²⁴。有限证明只用用户已有全局点距/半径、精确能量分解及初等圆弧和匹配计数，不依赖外部线性渐近余项或三角晶格最小性。

常数保守，但阶数与此前趋零的纯Newton折扣不同。例如n=144的新缺额下端为3/4194304，而旧Newton折扣可严格上包为小于10⁻¹⁰。小n仍应保留旧Newton正修正和专用锐界，不能只用本式的零下端。

|n|新线性缺额下端（近似值）|
|---:|---:|
|10000|0.0005304813385|
|1000000|0.05894899368|
|100000000|5.953907013|
|1000000000000|59603.98912|

上表只展示量级；程序接受准确分数。没有声称这些值接近真实最优缺额，也没有声称优于全部文献常数。

## 2. 新分布结构：近邻或微观空洞必须大量存在

在力为1的尺度w=√((n−1)/2)z，平滑盘半径为1，背景盘半径为√n。对距离<15/8的点对取极大匹配M；排除匹配端点附近及背景边界附近的点后，其余点必能产生半径9/200的平滑空盘。可选不交空盘数H满足

~~~math
32M+17H+B\ge n,\qquad B<11\sqrt n.
~~~

证明用“至多6个邻居，每个遮盖查询圆不到π/3”的有效常数。近邻通过旧精确重叠项付费，空盘通过局部Dirichlet能量付费，两者属于精确分解的不同项，可以相加。

这些空盘是单位圆盘平滑留下的未覆盖区，规则点阵也会有它们。该结论不排除三角式局部结构，也不是有限n构型分类。

## 3. 径向矩层级与八点联合区域

默认平滑的总二阶矩严格匹配背景。保留这个零测量，对径向测试(S−|w|²)_+^j建立完整Gram，可得到递增的径向能量下端。只用前两级，四阶矩偏差的系数就比忽略零测量时提高3倍。

对八点原尺度，记U₂=Σ|z_i|⁴、P_k=Σz_i^k，S=151/50。与上一轮驻点角向闭合正交相加，得到

~~~math
C_r(U_2-64/7)^2+C_2|P_2|^2+C_3|P_3|^2
+D_4|P_2|^4+D_5|P_2P_3|^2<523/5000.
~~~

全部系数为给定有理数。即使丢掉高阶项，也排除整个U₂≥52/5且|P₂|≥9/10的全局候选类；两个单独预算各自不足以排除它。

程序给出一个实际八点整数输入，核对其通过所列旧点距、半径、28对条件及四阶/六阶标量截断。它的旧八阶截断失败，因此不声称新例子通过此前全部必要条件。
