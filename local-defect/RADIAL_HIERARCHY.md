# 匹配二阶矩后的径向矩层级与八点联合预算

研究资料与项目发起：**蒋丰灿（Fengcan Jiang）**；推导及精确程序包含 OpenAI Codex 协作。2026-10-30。

本节将上一轮用于空洞的“二阶矩匹配”用于纯径向矩投影，再与已闭合的驻点角向能量正交相加。它是完整径向能量的一个下界，不另占一份独立径向预算。

## 1. 径向测试及准确Gram

用库仑尺度x、r²=2/n及同一平滑电荷ν=μ−μ₀。假设S≥2覆盖全部平滑点盘。对j≥1取

~~~math
F_j(w)=(S-|w|^2)_+^j.
~~~

默认平滑恰有∫dν=∫|w|²dν=0，故∫F₁dν=0。各径向测试的Gram为

~~~math
\boxed{H_{j\ell}=\frac{2j\ell}{(j+\ell)(j+\ell-1)}S^{j+\ell}.}
~~~

证明：置q=|w|²，Dirichlet内积为2∫₀ˢ q F'_j(q)F'_ℓ(q)dq。积分q(S−q)^(j+ℓ−2)即得。正定性由不同次数导数多项式的线性独立保证。

令B_j=n∫F_jdν，则每个有限层级都有

~~~math
\boxed{n^2D(\bar\nu)\ge B^TH^{-1}B.}
~~~

增大同一支持S下的次数，投影空间嵌套，右端不减。径向函数与所有非零角向Fourier模式正交，因此可与旧混合角向或上一轮驻点闭合能量相加。同一径向层级的非正交单项不能分别相加。

## 2. 平滑径向矩由中心半径准确给出

记q_i=|x_i|²，定义T_m=Σ_i∫|w|^(2m)dσ_r(w−x_i)。有限二项式与圆盘矩给

~~~math
T_m=\sum_i\sum_{a=0}^{m}
\binom ma^2\frac{r^{2a}}{a+1}q_i^{m-a}.
~~~

背景的n倍m阶矩为n2^m/(m+1)。因此B_j是

~~~math
\sum_{m=0}^{j}(-1)^m\binom jm S^{j-m}
\left(T_m-\frac{n2^m}{m+1}\right).
~~~

T₀=n、T₁=n，所以B₁严格为零。程序核对这些等式，不把未平滑的矩直接代入。

## 3. 四阶偏差的简式

只取j=1、2。Gram的H₁₁=S²、H₁₂=2S³/3、H₂₂=2S⁴/3。消去已知零测量B₁，Schur范数为2S⁴/9，故

~~~math
\boxed{n^2D(\bar\nu)\ge
\frac9{2S^4}\left(T_2-\frac{4n}3\right)^2.}
~~~

若忽略这个匹配的零测量，系数只有3/(2S⁴)。完整Gram在此给3倍的准确系数。

对八点，改回原z尺度，令U₂=Σ|z_i|⁴。因为

~~~math
T_2-32/3=(49/64)(U_2-64/7),
~~~

取上一轮同一支持S=151/50，径向能量至少

~~~math
C_r(U_2-64/7)^2,\qquad C_r=8441015625/266181427712.
~~~

原点加正七边形的U₂=64/7使这一低阶径向罚项恰为0；更高径向层级一般仍非零。不能因这一项为零就认定径向分布完全匹配背景。

## 4. 八点新联合必要区域

令P_k=Σz_i^k。上一轮驻点角向系数C₂、C₃及可选正四次项D₄、D₅均在[驻点闭合证明](../stationary-screening/STATIONARY_MOMENTS.md)给出。同一平滑、同一S下有

~~~math
\boxed{C_r(U_2-64/7)^2+C_2|P_2|^2+C_3|P_3|^2
+D_4|P_2|^4+D_5|P_2P_3|^2<523/5000.}
~~~

不使用高阶项，已经排除全部

~~~math
\boxed{U_2\ge52/5,\qquad |P_2|\ge9/10}
~~~

的八点全局最优者候选类。两个单项分别都低于缺额预算，但其和

~~~math
\frac{7662165525}{66545356928}>\frac{523}{5000}
~~~

严格超过预算。这保留了径向与角向信息的共同预算，而非分别过关。

## 5. 非空几何输入及真实比较范围

用八个整数点

~~~text
(±588,0), (0,±739), (±976,±776)
~~~

作中心化归一化。它们已中心化，平方尺度为4/4001369。该实际无碰撞输入有U₂≈10.4974、P₂≈1.0005、P₃=0，位于上述被排除类。

精确程序核对它通过全部28个旧两点slack、较强全局点距与半径限制，以及旧四阶和六阶标量稳定性截断。它也通过上一轮单独的P₂<8/7必要条件。

**它不通过旧八阶标量截断。** 本文明确保留这个失败，没有把该例说成“此前全部方法遗漏”的构型。它验证的是新联合接口、非空几何及所列较低阶条件的比较；输入本身不是驻点或最优者。
