## 2. 小径向缺额自动给出“一小点、七近圆点”

以下固定

```math
\varepsilon=1/1200,\quad \tau=1/32,\quad a=31/32,\quad b=33/32.
```

函数 f(t)=t(t−1)² 的导数为 (t−1)(3t−1)。在 [τ,a] 上，其最小值是两个端点值的较小者；在 [b,∞) 上递增。精确比较

```math
\varepsilon<\tau a^2,\qquad
\varepsilon<a\tau^2,\qquad
\varepsilon<b\tau^2
```

表明 E≤ε 时，每个 t_i 都在 [0,τ] 或 [a,b]。若近圆点至多6个，则总质量≤6b+2τ=25/4<7；若8个全是近圆点，则质量≥8a=31/4>7。因此恰有一个小点，标记为 q₀，其余记为 q₁,…,q₇。

```math
E_0=t_0(1-t_0)^2,\qquad E_r=\sum_{j=1}^7t_j(t_j-1)^2,
\qquad E=E_0+E_r.
```

于是 t₀≤E₀/a²。令 ρ_j=√t_j，u_j=q_j/ρ_j，并记


因为 √a≥a，所以


## 3. 全局比较：径向扰动只造成 O(E) 的能量误差

暂设所有点距平方大于 δ=27/250。对七个近圆点，精确分解

```math
|q_i-q_j|^2=\rho_i\rho_j|u_i-u_j|^2+(\rho_i-\rho_j)^2.
```

又有 (ρ_i−ρ_j)²≤2βE_r，故

```math
\rho_i\rho_j|u_i-u_j|^2>
\delta-2\beta\varepsilon=\frac{9925199}{92279250}>0.
```

因此七个 u_j 互异。令 Δ_circ=∏(i<j)|u_i−u_j|²。把21条近圆边和7条到小点的边分开，得到精确对数分解

```math
\log\frac{\Delta_q}{\Delta_{\rm circ}}
=4\sum_{j=1}^7\log t_j
 +\sum_{j=1}^7\log|1-q_0/q_j|^2
 +\sum_{i<j}\log\left(1+
 \frac{(\rho_i-\rho_j)^2}{\rho_i\rho_j|u_i-u_j|^2}\right).
```

最后一项由 log(1+x)≤x 及完整图平方恒等式控制为

```math
\frac{7\beta}{\delta-2\beta\varepsilon}E_r
=R E_r,\qquad R=\frac{172032000}{9925199}.
```

关键是前两项的**一阶项消去**。由质量及中心化，

```math
4\sum\log t_j\le-4t_0,
\qquad \sum_{j=1}^7\frac1{q_j}=-\bar q_0+Z,
\quad Z=\sum_{j=1}^7\frac{(1-t_j)\bar q_j}{t_j}.
```

加权 Cauchy–Schwarz 给 |Z|²≤7E_r/a²。再用 log|1−z|²≤−2Re z+|z|²，前两项之和至多

```math
\left(\frac7a-2\right)t_0+\frac{2\sqrt7}{a}\sqrt{t_0E_r}
\le hE_0+2k\sqrt{E_0E_r},
```

其中

```math

```

Young 不等式 2k√(E₀E_r)≤12E₀+(k²/12)E_r 和两个严格有理比较

```math
18-h-12=\frac{12858}{29791}>0,
\qquad18-R-\frac{k^2}{12}
```

最终给出

```math

```

本步骤没有假设角度靠近正七边形，也未使用驻点 Ward 投影。

## 4. 圆上七点的全局角向凹性

把七个近圆点按角度排列，取 θ₁<…<θ₇<θ₁+2π。令 θ_j*=α+2π(j−1)/7，并选 α 使 Σ(θ_j−θ_j*)=0。记 V_θ=Σ(θ_j−θ_j*)²。

在这个凸的有序角度域，函数

```math
F(\theta)=\sum_{i<j}\log\bigl(4\sin^2((\theta_i-\theta_j)/2)\bigr)
```

的二阶变分满足

```math
D^2F[v,v]=-\frac12\sum_{i<j}
\csc^2((\theta_i-\theta_j)/2)(v_i-v_j)^2
\le-\frac72\sum_jv_j^2\quad(\sum v_j=0).
```

正七边形处梯度为零、Δ_circ=T。沿连接 θ* 与 θ 的线段积分两次，即

```math
\boxed{\log(\Delta_q/T)\le18E-\frac74 V_\theta.}
```

所用完整图恒等式 Σ(i<j)(v_i−v_j)²=7Σv_i²−(Σv_i)²，由验证器核对全部28个二次项系数；全角度 Hessian 界的依据是上述解析推导。

## 5. 从径向距离到局部目标值缺口

记 d_q 为到中心单位正七边形轨道的距离，d_w=2d_q。

先看**距离下界**。任何旋转重排的坐标距离至少为对应半径距离。把候选的零半径分配给最小的 ρ₀，半径平方距离最小：把它改配给某个 ρ_i 所造成的差恰为 2(ρ_i−ρ₀)≥0。因此

```math
L=t_0+\sum_{j=1}^7(\rho_j-1)^2\le d_q^2.
```

而

```math
E\le\gamma L,\qquad
\gamma=b(1+b)^2=\frac{139425}{32768}.
```

若 d_q≤1/10，继承的局部能量定理及 15γ<64 给

```math
\log(\Delta_q/T)\le-\frac{2}{15}d_q^2
\le-\frac{2E}{15\gamma}\le-\frac E{32}.
```

反之，若 d_q>1/10，则按角度把七个近圆点与七次单位根配对，利用 |e^(ix)−e^(iy)|≤|x−y| 得到**距离上界**

```math
d_q^2\le t_0+\sum(\rho_j-1)^2+bV_\theta
\le E/a^2+bV_\theta.
```

将 V_θ>(1/100−E/a²)/b 代入第4节，并使用精确正余量

```math

\frac1{1200}=\frac{106387}{243555840}>0,
```

同样得到严格的 log(Δ_q/T)<−E/32。至此完成所有点距大于δ的情况。

也可以只对挑战者使用一个更短的桥梁：Δ_q≥T 时，第4节给 V_θ≤72E/7，因而


这直接把整个径向挑战者区域压进已有目标值排除球。
