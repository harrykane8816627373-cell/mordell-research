# 利用内点人数进一步锁定十点半径

蒋丰灿研究项目，OpenAI Codex 协作。

将十点构型归一化为 \(\sum_i u_i=9\)，其中 \(u_i=|x_i|^2\)。[原有半径证书](../ten-point-ward-radii/README.md)给出三个允许区间，[人数证书](../ten-point-ward-inner-count/README.md)证明每个全局最大构型恰有两个内点。用这两个条件可将各平方半径进一步限制为

\[
(43/1000,51/200)\;\cup\;(37/50,139/100)\;\cup\;(61/40,1539/1000).
\]

第一个区间仍恰含两个平方半径，后两个区间合计八个。和[独立的最外带排除](../ten-point-tail-exclusion/README.md)结合，可以去掉最后一个区间。

在原来的三个允许区间上记 \(I(u)=1\) 当且仅当 \(u<3/10\)。对标记点 \(i\)，人数给出第四个精确行等式

\[
\sum_{j\ne i}\left(I(v)-\frac{2-I(u)}9\right)=0,
\qquad u=|x_i|^2,\quad v=|x_j|^2.
\]

将这条等式与[质量、质心及径向力的三个行等式](../ten-point-ward-radii/README.md)配合。设 \(f=h-\log d\) 为[原固定全局核](../ten-point-ward-upper/README.md)的两点缺额，\(d=u+v-2t\)，\(t=\operatorname{Re}(x_i\bar x_j)\)。对五段标记半径，逐个小区间验证以下连续不等式：

\[
f\ge \frac1{800}+a(v-1+u/9)+b(t+u/9)+c((u-t)/d-5u/9)
 +e\left(I(v)-\frac{2-I(u)}9\right).
\]

四个有理乘子在同一标记小区间的所有邻点带上共用。对标记点的九条边求和后，四个修正项消失，其余 36 对各有缺额下界 \(-3/10000\)。所以总缺额至少为 \(9/20000\)，这会把总距离积压到已有可达见证以下。覆盖对每个标记小区间遍历原来的三个邻点半径带，不对标记点和另一点的半径排序。

两内点的平方距大于 \(2/5\)。若其中一个平方半径至多为 \(7/1000\)，另一个小于 \(3/10\)，则三角不等式给平方距不超过 \((\sqrt{7/1000}+\sqrt{3/10})^2<2/5\)。最后一步由接受器直接平方核验。结合五个闭区间的排除，得到所列开区间。

设两个内点的内积为 \(t\)，中点为 \(m\)。再用单条内边的缺额预算，证得

\[
-31/200<t<-4/125,\qquad |m|^2<23/200.
\]

其余 44 对各有下界 \(-3/10000\)，而见证值满足 \(B-\log V_{10}<10^{-6}\)。所以在最大构型中，任何一对的缺额都小于 \(13201/10^6\)。在整个内点对域上，附加的树逐盒验证上述两个几何限制，或证明缺额至少为这一阈值，或使用既有必要条件剪枝。中点平方模在两点坐标下为 \((u+v+2t)/4\)。

先按[复现指南](../docs/REPRODUCING.md)接受原全域核及内点人数，再运行 `python -B -S -O ten-point-counted-radii/verify_all.py`。程序以标准库中的整数和有理数逐节点重放 Bernstein 证书，核对各个区间端点与完整覆盖。[复核报告](verification_report.json)
