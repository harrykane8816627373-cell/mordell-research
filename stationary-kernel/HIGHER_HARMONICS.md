# 高阶 Ward 修正的矩补偿

设构型无碰撞，质量为 \(n-1\)，并满足完整驻点方程。记 \(u_i=|z_i|^2\)、\(p_r=\sum_i z_i^r\)，以及 \(M_k=\sum_i z_i^k\phi(u_i)\)，其中 \(\phi(u)=(1,u-1,\ldots,(u-1)^4)^T\)。对 \(k\ge4\)，取

```math
v_k=\left(-\frac{n-k-1}{n},1,0,0,0\right)^T.
```

完整力给 \(p_1=0\)。将乘子 \(n/2\) 代入 Ward 恒等式可得

```math
v_k^TM_k=\frac1n\sum_{r=2}^{k-2}p_rp_{k-r}.
```

这里的右端由低阶矩组成。以下补偿让这个高阶项进入两点核。完整力公式与低阶构造见 [Ward 零和修正](README.md)。

## 两点补偿

给定实向量 \(a\in\mathbb R^5\)，令 \(A_k=v_ka^T+av_k^T\)。设点的平方半径至多为 \(U\)，并取

```math
L_k\ge\max_{0\le u\le U}u^{k/2-1}|a^T\phi(u)|.
```

质量约束给 \(|a^TM_k|\le(n-1)L_k\)。再由 \(2|p_rp_{k-r}|\le |p_r|^2+|p_{k-r}|^2\)，得到

```math
M_k^*A_kM_k
=2\operatorname{Re}(\overline{v_k^TM_k}\,a^TM_k)
\ge-\frac{2(n-1)L_k}{n}\sum_{r=2}^{k-2}|p_r|^2.
```

记 \(H_r(u,v,t)=\operatorname{Re}((z\bar w)^r)\)，其中 \(u=|z|^2\)、\(v=|w|^2\)、\(t=\operatorname{Re}(z\bar w)\)。由于 \(\sum_{i,j}H_r=|p_r|^2\)，修正

```math
J_k(u,v,t)=H_k(u,v,t)\phi(u)^TA_k\phi(v)
+\frac{2(n-1)L_k}{n}\sum_{r=2}^{k-2}H_r(u,v,t)
```

在上述完整驻点上的有序点对总和非负。可取 \(U=n-1\) 覆盖全部质量 \(n-1\) 的驻点，也可用全局最大点的必要半径界选更小的 \(U\)。将 \(J_k\) 加入基础核并重新计算对角修正，便得到一个适用于全局上界搜索的两点表达式。

## 十二点的四阶修正

取 \(n=12\)、\(k=4\) 和 \(U=121/72\)。此时 \(v_4=(-7/12,1,0,0,0)^T\)，补偿项为 \((11/6)L_4H_2\)。只需给 \(u a^T\phi(u)\) 在 \([0,U]\) 上的绝对值作上界。若将它展开为 \(\sum_{j=0}^5 c_j u^j\)，其五次 Bernstein 系数为

```math
b_i=\sum_{j=0}^i c_jU^j\frac{\binom{i}{j}}{\binom{5}{j}},
\qquad i=0,\ldots,5.
```

取 \(-L_4\le b_i\le L_4\) 即可保证所需上界。这是对 \(a\) 和 \(L_4\) 的线性约束，可以直接加入半正定搜索。

若候选具有 \(m\) 阶旋转对称性，则 \(4\le k\le m+1\) 时，补偿涉及的 \(p_2,\ldots,p_{k-2}\) 全部为零。因此新项在候选上的有序和也为零。十二点的 \(D_3\) 候选允许四阶项，十九点的 \(D_6\) 候选允许四至七阶项。奇数 \(k\) 时可用一个有理数 \(R\ge\sqrt U\) 把 \(L_k\) 的约束化为整次幂多项式的上界。

这里给出的是可加入搜索的补偿公式。十二点的 Ward 覆盖使用零至三阶修正。高阶项给出的新上界仍需完整连续覆盖。
