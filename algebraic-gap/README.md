# 八点非零矩的全局定量耦合

2026-11-01。研究发起：蒋丰灿（Fengcan Jiang）；OpenAI Codex 协作。

**在旧椭圆、真实驻点方程和候选目标值门槛的交集中，必有**

```math
\boxed{|p_2|\ge10^{-36}|p_3|.}
```

这里 w=√(7/2)z，Σ|w_i|²=28，p_k=Σw_i^k。该结论不预设构型靠近中心七边形，也不使用完整二阶稳定性。因而它可以继续与稳定性、严格子集界、旧矩盒和[较大能量排除区域](../eight-point/ENERGY_BASIN.md)取交集。

常数很弱：本次只关闭 0<|p₂|<10⁻³⁶|p₃| 的细楔形区域，**没有排除全部 p₂p₃≠0 的挑战者，八点锐界仍未完成**。下面同时保留一个可用于后续区间筛选的目标值—矩联合不等式。

## 1. 准确前提与尺度

八点互异，并满足

```math
\sum_iw_i=0,\quad\sum_i|w_i|^2=28,\quad
\sum_{j\ne i}\frac1{w_i-w_j}=\bar w_i,
```

以及旧必要条件与挑战门槛

```math
|p_2|^2+\frac{27}{350}|p_3|^2<16,\qquad
\Delta_w\ge4^{28}7^7.
```

令 q=w/2，s_k=Σq_i^k。则 Σ|q|²=7、力常数 κ=4、Δ_q≥T=7⁷，且

```math
|s_2|^2+\frac{54}{175}|s_3|^2<1.
```

写根多项式

```math
P(X)=X^8+tX^6+sX^5+aX^4+bX^3+cX^2+dX+u.
```

注意此处系数字母 s 不代表某个幂和：t=−s₂/2=−p₂/8，s=−s₃/3=−p₃/24。因此

```math
|t|\le1/2,\qquad |s|\le61/100.
```

## 2. 用中心化和质量给全部系数一个显式外包

对 |X|=R，AM–GM 与 Σq=0 给

```math
|P(X)|\le\left(R^2+\frac78\right)^4.
```

对 X^(8−j) 的系数用 Cauchy 估计，选 R²=7(8−j)/(8j)。结合常数项的 AM–GM 界，可取

```math
(|a|,|b|,|c|,|d|,|u|)
\le\left(\frac{49}4,\frac{101}{10},\frac{343}{54},3,

```

这只是粗系数外包，没有宣称这些高阶矩已经进入[六矩管域](../eight-point/ENERGY_BASIN.md)。[验证器](verify_all.py)以分数检查 Cauchy 界及 P、P′、P″ 系数向量的欧氏范数上界

```math
A=18,\qquad B=60,\qquad C=171.
```

把 t 沿线段缩到0时，其余系数冻结；整条系数线段仍在上述外包内。无需假设这条线段上的多项式都对应真实驻点。

## 3. 原整数证书的齐次提升

令 δ=Res(P,P′)，并定义

```math
R(Y,T)=\operatorname{Res}_X(P,(Y+TX)P'-P''),\qquad
R_0(Y)=R(Y,0),\quad R_t(Y)=\partial_TR(Y,0).
```

真实驻点满足 g_i=P″(q_i)/P′(q_i)=8q̄_i。因此

```math
R_0=\delta\prod_i(Y-g_i),\qquad R_t=R_0''.
```

后一个等式可在八个互异的 g_i 处检验：R_t(g_i)=q_iR₀′(g_i)，而 R₀″(g_i)/R₀′(g_i)=2Σ(j≠i)1/(g_i−g_j)=q_i。两边次数至多6。

对 j=1,…,6，定义

```math
E_j=[Y^{6-j}]R_t-(8-j)(7-j)[Y^{8-j}]R_0.
```

R₀ 的 Y⁷ 系数恒为0，故 E₁ 与旧程序中的 [Y⁵]R_t 一致。再定义

```math
(G_1,\ldots,G_6)=(E_1/4,E_2/24,E_3/16,E_4/32,E_5/64,E_6/128),
\qquad G_7=[Y^6]R_0/4.
```

真实驻点有 G₁=…=G₆=0，并且

```math
G_7=16\delta\bar t.
```

旧2026-10-16证明包在 t=0、s=1 图表中保存了完整整数恒等式 Dδ²=ΣQ_jG_j；D≠0，七个乘子共7123项。本次重新从 P 构造结果式并检查了全部14179个整数系数，使用的源文件字节由[证书](certificate.json)固定。

给 s,a,b,c,d,u 赋权3,4,5,6,7,8。δ 的权为56，G_j 的权依次为55,54,53,52,51,50,54。给旧 Q_j 的每项补上非负整数次 s，使其权依次为

```math

```

每个乘积的权都等于115=3+2·56。故旧恒等式严格提升为


其中 δ₀=δ(0,s,a,b,c,d,u)，H_j=Q_j^hom/D。该式是多项式恒等式，对 s=0 也有效；不需要选立方根或除以 s。

## 4. 沿 c₂ 方向的统一导数界

以下导数均关于系数 t。Sylvester 行范数、行列式多线性与 Hadamard 不等式给

```math
L_\delta=7A^6B^8+48A^7B^7
=122252797839605760000000.
```

在 |Y|=1 上，令 D₀=B+C=231。R₀ 的7行来自 P、8行来自 YP′−P″，导数行范数分别≤1、36。因此

```math
L_0=7A^6D_0^8+288A^7D_0^7.
```

为 R(Y,T) 使用两多项式均按8次填充的16阶 Sylvester 矩阵。P 首一保证即使 T=0 降次，填充结果式仍正确。对 T 求一次、再对 t 求一次导数，分别计入8个 P 行、7个未替换行和1个 XP′ 行，得到

```math
L_t=64A^7D_0^7B+2016A^8D_0^6B+48A^8D_0^7.
```

## 5. 联合目标值条件与线性楔形排除

记 Δ=Δ_q=|δ|。用第3节恒等式、真实驻点的 G_j 值及第4节导数界，得到

```math
\boxed{|s|\max(0,\Delta-|t|L_\delta)^2
\le |t|\bigl(K+16M_7\Delta\bigr).}
```

这条目标值—低阶矩条件本身无需 Δ≥T。它使用旧椭圆给定的统一系数外包；后续可以在更小系数盒上重新计算 M_j 和行范数。这里只证明筛选规则，未执行全域盒覆盖。

若 |t|Lδ≤Δ/2，且 Δ≥T=7⁷，则

```math
|s|\le|t|\left(\frac{4K}{T^2}+\frac{64M_7}{T}\right).
```

若 |t|Lδ>Δ/2，则 |s|≤61/100 给

```math
|s|\le|t|\frac{2(61/100)L_\delta}{T}.
```

记两个括号上端的最大值为 C_*。精确分数检查给 3C_*≤10³⁶；再用 t=−p₂/8、s=−p₃/24，即得首页结论。当前这组粗估不能认证10⁻³⁵，验证器对此另作检查。
