## 2. 一般 n 的显式有限上下界

设 n≥2，N=n(n−1)/2，P_n=∏_{k=0}^{n−1}k!，S_m(x)=∑_{k=0}^m x^k/k!，Δ_n=∏_{i<j}|z_i−z_j|²。以下最大值均在 ∑|z_i|²=n 上取。

### 2.1 高斯平均下界

令 Z_i 独立，密度 π^−1 exp(−|z|²)。Vandermonde 展开和复高斯正交性

    E[Z^k overline(Z)^l] = δ_{kl} k!

给出 EΔ_n(Z)=n!P_n。令 μ=n^−1∑Z_i，W_i=Z_i−μ。距离积平移不变，所以 EΔ_n(W)=n!P_n。向量 W 是零和复超平面（复维数 d=n−1）上的标准复高斯。

写 W=RU，其中 U 均匀分布于该超平面的单位球面，R 与 U 独立，R² 服从 Gamma(d,1)。距离积的齐次次数为 2N，故

    EΔ_n(W)=E[R^(2N)] EΔ_n(U)
            = (N+n−2)!/(n−2)! · EΔ_n(U).

半径 √n 的球面平均值为 n^N EΔ_n(U)，不超过最大值。因此

    M_n ≥ n!(n−2)! n^N P_n /(N+n−2)!.

这里 Gamma 的形状参数为 n−1，不是 n。n=2 时下界精确为 4。

### 2.2 截断指数的凹性和上界

对 m≥1 有恒等式

    (S'_m(x))² − S_m(x) S''_m(x)
      = x^(m−1)/m! · ∑_{k=0}^{m−1}(m−k)x^k/k!.

右边在 x>0 严格为正，故 log S_m 在 [0,∞) 凹。该恒等式也说明不能用未经检验的一般正系数多项式替换 S_m 并直接套用同样的凹性。

矩阵 A_ik=(α^k/k!)^(1/2) z_i^k，0≤k≤n−1，满足

    |det A|²=α^N Δ_n(z)/P_n,
    ∑_k |A_ik|²=S_{n−1}(α|z_i|²).

Hadamard 与 Jensen 依次给出

    α^N Δ_n/P_n
      ≤∏_i S_{n−1}(α|z_i|²)
      ≤S_{n−1}(α)^n.

这证明附件所述上界。再用 S_{n−1}(α)≤e^α，取 α=N/n，得到

    M_n ≤ e^N (n/N)^N P_n.

### 2.3 最优参数

令 p_k(α)=α^k/(k! S_{n−1}(α))，0≤k≤n−1。以 s=log α 为变量，上界的对数导数为 n E_p[k]−N，其导数为 n Var_p(k)>0。α↓0 时 E[k]→0，α↑∞ 时 E[k]→n−1，因此存在且仅存在一个导数零点。该点是唯一全局最小点，并满足

    ∑_{k=0}^{n−1}(2k−(n−1)) α^k/k!=0.

这证明的是“上界函数”的唯一最优参数，不是 Mordell 构型唯一性。

## 3. 渐近展开

Euler–Maclaurin 或 Stirling 求和给出

    log P_n = (n²/2)log n −3n²/4 +(n/2)log(2π) +O(log n).

设 Ubar_n=e^N(n/N)^N P_n，并设 L_n 为第 2 节下界。利用 N=n(n−1)/2 得到

    log Ubar_n
      = ((log 2)/2−1/4)n² +(n/2)log n +(n/2)log π +O(log n).

另一方面，P_n 和 n^N 在上下界之比中消去：

    log(Ubar_n/L_n)
      = N−N log N +log((N+n−2)!)−log(n!)−log((n−2)!)
      = (2−log 2)n +O(log n).

两式夹逼 M_n 即得

    log M_n = ((log 2)/2−1/4)n² +(n/2)log n +O(n).

此处 O(n) 的意义是 n→∞ 的统一渐近误差，不是当前小点数上的数值证书。渐近律与加权 Fekete/对数气体背景相关；本审核没有作原创优先权声明。

## 4. 确定性高斯整数构造及其渐近证明

取模平方排序（平局按实部、虚部字典序）的前 n 个高斯整数 v_j，令 μ=n^−1∑v_j。恒等式

    D_n=n∑|v_j|²−|∑v_j|²=∑_{i<j}|v_i−v_j|²

说明 D_n 是严格正整数。令 z_j=n(v_j−μ)/√D_n，则

    ∑z_j=0，∑|z_j|²=n，
    Δ_n(z)=(n²/D_n)^N ∏_{i<j}|v_i−v_j|² ∈ Q_{>0}.

证明渐近时，令 R_n 为所取格点的最大模。用单位方格覆盖圆盘及边界厚度 O(1) 的圆环得到

    n=πR_n²+O(R_n)，
    ∑|v_j|²=(π/2)R_n⁴+O(R_n³).

末层半径相同的格点只有 O(R_n)，所以任意指定的平局规则都不影响这些主项。相同的方格 Riemann 和证明 v_j/R_n 的经验测度趋于单位圆盘均匀测度，故 μ/R_n→0，D_n/(n²R_n²)→1/2。于是 z_j 的经验测度趋于半径 √2 的均匀圆盘。

需要控制的是 log|z−w| 的负奇点，而不只是弱收敛。由于格点彼此不同，归一化最小间距为 a_n=n/√D_n，并有 a_n≍n^−1/2。对固定 j，用方格计数有

    #{i:0<|z_i−z_j|≤ρ} ≤ C(nρ²+1)

（把 C 加大可吸收圆周边界项）。取 ρ=2^−L，将 0<距离≤ρ 分成二进圆环。最细圆环的层数为 O(log n)，得到

    (1/n²)∑_{i≠j, |z_i−z_j|≤ρ} |log|z_i−z_j||
      ≤ C ρ²(1+|log ρ|)+C(log n)²/n.

因此先 n→∞ 再 ρ↓0 时，此部分一致趋零。配置有界使正对数部分无需额外尾部控制。对截断连续核作弱收敛，再移去截断，便得到

    log Δ_n(z)/n²
      = (1/n²)∑_{i≠j}log|z_i−z_j|
      → ∬log|z−w| dν(z)dν(w).

半径 R 的均匀圆盘在内部的对数势为

    U(z)=log R−1/2+|z|²/(2R²).

再平均 |z|²=R²/2，能量为 log R−1/4。R=√2 时即 c=(log 2)/2−1/4。第 3 节给 log M_n/n²→c，故 log M_n−log Δ_n(z)=o(n²)。

这个结论仅是二次指数尺度的渐近最优性，不给有限 n 的全局最大值。

## 5. 多环、两环方程与十点反例

第 a 圈是 f_a(z)=z^(m_a)−R_a 的零点，其中 R_a=r_a^(m_a)e^(im_a θ_a)。单圈判别式模平方贡献为 m_a^(m_a) r_a^(m_a(m_a−1))。如另有原点，原点至该圈贡献 r_a^(2m_a)。

两圈的交叉距离积是 |Res(f_a,f_b)|²。令 g=gcd(m_a,m_b)，L=lcm(m_a,m_b)。由根的相位差枚举，resultant 的绝对值为

    |r_a^L e^(iL θ_a)−r_b^L e^(iL θ_b)|^g.

相乘便得附件的完整多环公式。若圈之间有重合点，两边同时为零；用于正下界时必须取互异配置。

两圈相对相位可令两复数方向相反，最大交叉因子为 (r^L+s^L)^(2g)。设 x=r²/s²，约束 a r²+b s²=n 给 s²=n/(a x+b)。齐次次数检查 N=A+B+ab 后得到附件的单变量式。对其对数求导、乘以 x(a x+b)(1+x^(L/2))，整理得到

    Ab−a(B+ab)x+b(A+ab)x^(L/2)−aBx^(L/2+1)=0.

若 L 为奇数，这不是 x 的普通多项式；置 x=s² 后才得到整指数多项式。即使解完该方程，也只解决该两环家族的内部优化。

n=10 时，u=1/8、v=39/32，P(z)=(z²−u)(z⁸+v⁴)。内圈平方半径 u，外圈平方半径 v。2u+8v=10，且两圈半径不同，根均互异。多环公式给

    D_10=4u ·8⁸ v²⁸ (u⁴+v⁴)⁴。

将它除以 C_10=10⁴⁵/9³⁶，标准库 Fraction 精确计算证明比值 >113/100，十进表示 1.139872102103…。这是中心正九边形的严格全局反例；它不确定 M_10。

## 6. 中心正多边形的完整二阶稳定性

设 n=m+1，r²=n/m，ω=e^(2πi/m)，中心构型 z*=(0,r,rω,…,rω^(m−1))。对距离对求和或直接用其根多项式可得驻点方程

    ∑_{j≠i}1/(z_i−z_j)=(m/2) overline(z_i).

记 λ=m/2，复对称算子

    (Bh)_i=∑_{j≠i}(h_i−h_j)/(z_i−z_j)²。

受约束切空间上的二次项为

    −Re(h^T Bh)−λ||h||²。

先取零和方向。写 h_0=−mc，圆周 h_{j+1}=c+∑_{k=1}^{m−1}a_k ω^(kj)。正交性给

    ||h||²=m(m+1)|c|²+m∑|a_k|²。

根单位恒等式的推导不需要数值求和。令

    A_k=∑_{l=1}^{m−1}ω^(kl)/(1−ω^l),
    C_k=∑_{l=1}^{m−1}(1−ω^(kl))/(1−ω^l)²。

配对 l 与 m−l 得 A_0=(m−1)/2；又

    A_(k+1)−A_k=−∑_{l=1}^{m−1}ω^(kl)，
    C_(k+1)−C_k=A_k。

所以 A_k=k−(m+1)/2，1≤k≤m，而

    C_1=(m−1)/2，C_k=(k−2)(k−m)/2，2≤k≤m。

圆周单 Fourier 模式的 B 系数是 D_k=1+C_k。因此

    D_1=(m+1)/2，
    D_k=1−(k−2)(m−k)/2，2≤k≤m−1。

在使用上述正交范数归一化之后，B 的 Takagi 奇异值分块为：

* 模式 k=1：λ。球面切条件留下纯旋转方向；实径向方向不属于切空间。
* 中心平移块与模式 k=2：m/√(m+1)，两个同值。具体双线性项为 2m(m+1)c a_2/r²。
* 模式 k=3,…,m−1：|D_k|/r²；k 和 m+2−k 成对。

中心块在 m≥4 时严格小于 λ。记 q=floor((m−2)²/4)，其余模式最大负系数对应 1−q/2。它们都严格小于 λ，等价于 q<m+3；在 m=4,…,8 成立，在 m=9 取等号，在 m≥10 不成立。

一般方向再分解为零和方向加共同平移。B 在共同平移上为零，这一块二次项为 −λ||h||²，严格负。因此在 n=5,…,9，受约束 Hessian 的唯一零方向是整体旋转，其余均严格负。标准有限维 Taylor 展开或旋转切片得到模旋转的严格局部最大。

特别需要区分 n=5：中心正方形值 C_5=5¹⁰/4⁶ 小于正五边形值 5⁵，但它仍是严格局部极大点。这里没有矛盾。

在 n=10，二阶型除旋转外有额外零方向。因此第 6 节的计算本身不推出严格局部最大。附件声称有效四次项 −510|a|⁴，但没有提供 a 的规范、横向变量消去过程、所有四次耦合或余项。该数值和 n10 严格局部最大本次均不提升为已核定定理。

## 7. n≥11 的显式改善：完整余项证明

设 m≥10，按附件取 k=floor((m+2)/2)、q=floor((m−2)²/4)、b 为偶 m 时 1、奇 m 时 2，

    A_m=bm(q−m−3)/2，H=m+2，
    t=min{1/(2H), A_m/(4NH³)}。

因为 q−m−3=floor(m²/4−2m−2)，它在 m=10 为 3，并在 m≥10 严格递增，所以 A_m>0。

按附件定义 h_0=0，偶 m 圆周 h_j=rω^(kj)，奇 m 为 r(ω^(kj)+ω^((m+2−k)j))。Fourier 正交性给

    ∑h_i=0，∑overline(z_i*)h_i=0，||h||²=bn。

因此 y=(z*+th)/√(1+bt²) 仍零和且平方模和为 n。

令 d_ij=(h_i−h_j)/(z_i*−z_j*)。原点至圆周的 d 模至多 b。圆周两点的差商是几何和；单模式至多 k，双模式至多 k+(m+2−k)=H。因此所有 |d_ij|≤H，且 |td_ij|≤1/2，所有扰动点互异。

驻点方程和正交性给 ∑_{i<j}d_ij=0。利用第 6 节的 Fourier 二次式及 2k−2=m（偶 m）或 k+(m+2−k)−2=m（奇 m），得到

    ∑_{i<j}d_ij²=bm(1−q/2)。

复对数的幂级数余项满足

    |2 Re(log(1+w)−w+w²/2)|
       ≤2|w|³/[3(1−|w|)]≤(4/3)|w|³。

加上归一化项 −Nlog(1+bt²)，并使用 log(1+x)≤x，得到

    log Δ_n(y)−log C_n
      ≥A_m t²−(4/3)NH³t³
      ≥(2A_m/3)t²>0。

这比附件的 (A_m/3)t² 更强。它是所有 n≥11 的显式、无数值搜索的严格改善证书，不需要 n10 四次项。

## 8. 共线子类的精确基准

在直线上作平移、旋转可把点写成实数 x_i，中心化只会减少总能量，从而归一化可增加距离积。因此最大者可取 ∑x_i=0。对固定顺序 x_1<…<x_n，考虑

    F(x)=2∑_{i<j}log(x_j−x_i)−((n−1)/2)∑x_i²。

其 Hessian 严格负，F 在无穷远和碰撞处趋于 −∞，故只有一个全局极大驻点。驻点方程为

    ∑_{j≠i}1/(x_i−x_j)=((n−1)/2)x_i。

对 monic p(x)=∏(x−x_i)，用 p''(x_i)/(2p'(x_i)) 的根公式，得到

    p''−(n−1)x p'+n(n−1)p=0。

因此是 suitably scaled Hermite 多项式。驻点方程乘以 x_i 求和，直接得 ∑x_i²=n。由 Hermite 递推或 resultant 得其归一化判别式

    R_n=∏_{k=1}^n k^k /(n−1)^N。

为完整核对判别式，令 H_n 的 monic 物理学家规范为 h_n=2^−n H_n。其递推为 h_n=xh_(n−1)−((n−1)/2)h_(n−2)，导数 h_n'=n h_(n−1)。令 J_n=|Res(h_n,h_(n−1))|。在 h_(n−1) 的根上代入递推得

    J_n=((n−1)/2)^(n−1) J_(n−1)，J_1=1。

因此 |disc(h_n)|=n^n J_n=2^−N∏_{k=1}^n k^k。该根系平方和为 n(n−1)/2；缩放 √(2/(n−1)) 得到 R_n 公式。高斯项在目标球面为常数，所以 F 的唯一全局最大同时解决直线子类。验证程序精确检查 R_6/C_6=2/729。

## 9. 网格上界和其余待补材料

仅有“指定整数网格”和“Section 8”的引用，无法恢复 B_n(q)：格点间距、搜索边界、归一化方式、是否先中心化、重复点处理都缺失。K_n=n(n−1)(2n−1)/4 本身是一个显式数，但没有网格定义，量词不闭合。所以

    B_n(q)≤M_n≤B_n(q) exp(K_n/q²)

及其有理版本本次只作为来源中的待补陈述收录。即使后续补齐，也必须穷尽该网格；采样构型只能给下界。
