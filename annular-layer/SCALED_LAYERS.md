# 可变平滑、统一m−1层质量与有限层数加强

研究资料与项目发起：**蒋丰灿（Fengcan Jiang）**；OpenAI Codex协作，2026-10-31。

## 1. 沿用的尺度和输入

原约束Σ|z_i|²=n，δ=log(U_n/Δ)，w=√((n−1)/2)z，q=w/√n。R_j是w尺度不同层半径，r_j=R_j/√n。全局最优者重心为零，r_j≤1；既有谱容量给m_j−1≤4R_j，既有严格子集给全局点距至少√2（均为w尺度）。本节的m−1凸结论本身不需要点距。

取q尺度平滑半径h/√n。记ν_h为平滑经验分布减单位均匀盘，ψ(h)=(h²−1)/2−log h。由[已有可变平滑分解](../radial-angular/RADIAL_LAYERS.md)保留完整无序点对项，得到

~~~math
\delta+n\psi(h)\ge n^2D(\nu_h)+\sum_{i<j}P(|w_i-w_j|/h).
~~~

障碍势非负而被丢弃。这里P=2(g−T₁²g)，已经含两个有序项。缩放恒等式g(d)−T_h²g(d)=g(d/h)−T₁²g(d/h)说明参数h只进入d/h；不能只放大损失而省去nψ(h)。

## 2. 每层质量m−1，不再丢弃两个人口

记F(t,S)=tP(S/t)，t>0，且F(0,S)=0（S≥0）。P≥0、P'≤0及凸性给F对t非减、对S非增，并为凸透视。

- m≥3：循环相邻无序边各计一次。旧角隙Jensen给代价≥mP(2πR/(hm))≥(m−1)P(2πR/[h(m−1)])。
- m=2：只有一个无序点对，其距离≤2R，故代价≥P(2R/h)≥P(2πR/h)，正是m−1=1的式子。
- m=1：右端按零质量定义为0。

因此所有层都有同一结论。各层实际使用的点对不重叠；m−1是保守凸质量，**没有声称共有n−K条实际不同边**。透视的次可加性再给

~~~math
\boxed{\delta+n\psi(h)\ge
(n-K)P\!\left(\frac{2\pi\sum_jR_j}{h(n-K)}\right).}
~~~

单点层可以贡献零质量、正周长；把全部层周长放进分母只会降低右端。此式用于K<n。

## 3. 同一h下的径向周长运输

沿用f_a(r)=(1−r)min(1/a,1/r)，0<a≤1。它的背景均值B=1−a+a²/3，Dirichlet范数H=(1+a⁻²)/2，分布拉普拉斯上端a⁻³。圆盘均值误差按半径平方变化：T_(h/√n)f_a≤f_a+h²/(8na³)。

若独立已证δ≤E，则n²D(ν_h)≤E+nψ(h)，所以

~~~math
T=1-a+a^2/3-\frac{\sqrt{(E+n\psi(h))H}}n
-\frac{h^2}{8na^3}
\le\frac1n\sum_i f_a(|q_i|).
~~~

谱容量逐层给m_j f_a(r_j)≤4√n(1−r_j)+1/a，仍覆盖原点。于是

~~~math
\frac{\sum_jR_j}{n}\le
\frac K{\sqrt n}+\frac K{4an}-\frac T4.
~~~

结合上一节得到[scaled_circumference.py](scaled_circumference.py)的有限接受器。Dirichlet与点对各由同一修正预算约束；此处没有把两份预算相加。更精确的同份预算接口见[环带对偶](ANNULAR_DUAL.md)。

## 4. 所有n≥10¹⁴的严格定理

只使用此前有效初等可达预算E_n=n/100+(77/6)√n+35/4（n≥6）。取h=109/100，k=51/100，反设K≤k√n。令t=n⁻¹ᐟ⁴、a=t。全部n≥10¹⁴都有t≤1/3000、√n≥10⁷。

24项有理对数区间及预算的单调性证明

~~~math
E_n/n+\psi(109/100)<143/8000=:e.
~~~

又有e(1+1/3000²)/2<(19/200)²及1+19/200+h²/8<5/4。因此T>1−5t/4，整个尾部的缩放平均距离上端为

~~~math
\frac{2\pi_+[k-1/4+(k/4+5/16)/3000]}
{h(1-k/10^7)}<\frac32,
\qquad \pi_+=3141592653589794/10^{15}.
~~~

沿用4096格透镜积分、24项正对数下和及12项交错反正切，[精确核验](scaled_verification.json)给

~~~math
P(3/2)>179/10000.
~~~

于是δ/n+ψ(h)≥(1−k/10⁷)179/10000>143/8000，与修正预算矛盾。得

~~~math
\boxed{K>\frac{51}{100}\sqrt n\quad\text{对所有 }n\ge10^{14}.}
~~~

这是所有n的尾部推理，程序中的有限例子用于核对通用接受器；未用抽样代替一般量词。相比旧0.5007、10¹⁶的定理，系数提高且起点降低。n=10¹⁴时保证至少5,100,001层；不是对一亿亿个点做构型搜索。

本轮还有只用同一初等预算的更强**渐近**系数0.513，其证明必须保留各环带人口，不能由本节单个全周长界直接推出。见[ANNULAR_DUAL.md](ANNULAR_DUAL.md)。
