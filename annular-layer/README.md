# 可变平滑与环带人口对偶：更强的一般n层数定理

研究资料与项目发起：**蒋丰灿（Fengcan Jiang）**；推导与精确程序包含 OpenAI Codex 协作。2026-10-31，承接2fb42ba98d881b2d5c5b42e931e4fc9dde088873。

本轮把同层凸损失、可变圆盘平滑、径向分布、全局点距以及既有移位Gram和高斯角向界进一步联合。**一般n的完整最优构型、八点完整锐界和百点至少五层仍未解决。**

## 1. 已严格加强的层数结果

K是全局最优构型相对重心的不同半径数，允许各层角度任意。

|输入与量词|此前保证|本轮保证|
|---|---|---|
|仅既有有效初等预算，有限n|K>0.5007√n，n≥10¹⁶|**K>0.51√n，所有n≥10¹⁴**|
|仅同一初等预算，渐近|liminf K/√n>0.5007|**liminf K/√n>0.513**|
|保留此前外部线性能量及三角试探输入，渐近|liminf K/√n>0.53|**liminf K/√n>0.556**|

最后一行没有有限有效起点；前两行不依赖该外部渐近输入。完整有理对偶实际给出约0.5134454150及0.5563134682，正文保守陈述较短分数，不主张这些常数最优。

## 2. 连接方式

同层人口m的点对损失可以保守压成质量m−1的凸透视项，统一覆盖人口1、2的层。因此总量从旧n−2K提高到n−K。结合谱容量，透视项自变量还精确满足d≥π/(2h)，使受限支撑线和按半径分配的价格成为合法工具。

对固定径向分区，各带人口n_j、层数K_j，构造明确α_j≥0及统一价格λ>0后，有

~~~math
\boxed{\delta\ge A_h+\sum_j\alpha_j(n_j-K_j)
-\lambda\sqrt n K-n\psi(h).}
~~~

A_h是一份同一平滑半径下的完整Dirichlet能量下端，ψ(h)=(h²−1)/2−log h。未知K_j时可以用max α_j·K保守外包。实际径向人口趋于均匀盘人口，再由2048个固定环带的精确对偶得到上面的渐近常数。没有把固定分区当作随n缩小的微观人口结论。

## 3. 百点条件约束也进一步收紧

全局点距使所用全距离支撑线至多漏掉一个小半径单点层，其余层按完整人口付费。指定中心空洞还能消去这一个例外。把它接回既有径向Gram，百点K≤4时：

|必要条件|此前|本轮|
|---|---:|---:|
|二阶幂和模，P₂=Σz_i²|<2.7|**<2.35**|
|再有全部原尺度半径平方≥8/99时，二阶幂和模|<2.25|**<1.7**|
|所有相似尺度、旋转的标准高斯对比模|<0.4285|**<0.375**|
|再有上述半径下界时，高斯对比模|<0.351|**<0.27**|

另给出低阶角向能量至少11/20时的全尺度高斯对比模<0.073。完整角向能量与P₂、P₃椭圆分别受0.572和指定空洞下0.298限制；[证明与准确前提](FINITE_JOINT.md)。这些条件限制“如果只有四层”的分布，不能据此宣布百点至少五层。
