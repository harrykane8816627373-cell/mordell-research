## 完整证明

固定λ=(n−1)/2、L=logΔ−λΣ|z|²，取既有规范y₀=0、x₀>0。令c为[已认证数据](../validated-maxima/certificates.json)的二进有理中点。先实际重放原压缩证书，确认微小盒c±2⁻⁸⁰内的唯一真实驻点z*。

对较大闭立方体X=c±r，用原整数区间程序包围全部实Jacobian J=DF，其中2F=∇L。保存的精确有理W使G=−WᵀJ(X)W的每一行都满足Gᵢᵢ−Σⱼ≠ᵢ|Gᵢⱼ|>0。程序在整盒认证此式，而非只在中点取数值特征值。它证明L在整个规范盒上严格凹；z*位于盒内部且完整力为0，因此整个X都满足L(z)≤L(z*)，等号只有z*。在Σ|z|²=n上，L与logΔ只相差常数，候选值上界成立。

再说明欧氏轨道距离条件。对候选先选已记录的旋转与重排，程序验证z*₀=a≥1、全部|z*ᵢ|≤2。假设某构型在同一标号下到z*的欧氏距离≤δ=r/16。每个点误差因此≤δ，且|z₀|≥a−δ>0。乘ρ=conj(z₀)/|z₀|将第一点旋到正实轴。由三角不等式，|ρ−1|≤2δ/(a−δ)≤4δ，故

```math
|\rho z_i-z_i^*|\le\delta+4\delta(2+\delta)\le11\delta.
```

原存在盒的坐标误差≤2⁻⁸⁰，且程序核验32·2⁻⁸⁰≤r，所以旋转后每个自由实坐标到c的距离严格小于r。于是它进入上述严格凹性区域。允许一开始任意整体旋转与重排即得到整条候选轨道周围的声明。

## 怎样接入全局证明

若后续全局有效的正定核、矩或点对证书能证明每个全局最大点到候选轨道的距离不超过表中门槛，便与此整区域上界接合，直接得到Mₙ等于候选值。全局范围锁定必须另行证明，不能由候选局部稳定或有限搜索推出。

从仓库根目录执行：

```bash
python -B -S -O candidate-basin/verify_all.py
```
