# 在完整抛物区域积分：圆盘接近相切时的7/2次幂下界

研究资料与项目发起：**蒋丰灿（Fengcan Jiang）**；推导及精确程序包含 OpenAI Codex 协作。2026-10-30。

本节沿用[已有圆盘精确缺额分解](../asymptotics/README.md)，改进其中的单点对下端。新步骤是在交叠区的抛物子区域上完整积分，保留非对称权重，不再只取中间一个小圆盘。所有距离均为力为1的尺度w=√((n−1)/2)z，平滑半径1。

## 1. 每个无序点对包含两个有序项

置g=−log|·|、T为单位圆盘平均，h=g−Tg。已知

~~~math
h(s)=\begin{cases}-\log s-1/2+s^2/2,&0<s<1,\\0,&s\ge1,\end{cases}
\qquad h(s)\ge(1-s)_+^2.
~~~

并有g−T²g=h+Th。定义一对距离为d的**无序点对的总代价**

~~~math
P(d)=2[g(d)-T^2g(d)].
~~~

这个2已包含在本文全部P公式中，不再另乘一次。对于d≥√2>1，h(d)=0，故P(d)=2Th(d)。

## 2. 抛物积分下界

令√2≤d<2，ε=1−d/2、D=2(d−1)>0。把平均圆盘的位移写成

~~~math
v=(-d/2+s,y),\qquad
|y|\le\sqrt{D\varepsilon},\quad
|s|\le a(y):=\varepsilon-y^2/D.
~~~

在这个抛物区域，d/2±s≥d/2−ε=d−1>0。利用√(A²+y²)≤A+y²/(2A)，得到

~~~math
|v|\le d/2-s+y^2/D\le1,\quad
|d+v|\le d/2+s+y^2/D\le1.
~~~

因此区域整体位于两个单位盘交集内，且

~~~math
h(|d+v|)\ge(a(y)-s)^2.
~~~

注意这里保留a−s，而非替成a−|s|；后者会使积分再损失4倍。直接积分给

~~~math
\int_{-a}^{a}(a-s)^2ds=8a^3/3,\qquad
\int_0^1(1-u^2)^3du=16/35.
~~~

除以平均盘面积π并计入两个有序项，得

~~~math
\boxed{P(d)\ge\frac{512\sqrt{2(d-1)}}{105\pi}
\left(1-\frac d2\right)^{7/2}.}
~~~

旧小圆盘法给(1−d/2)⁴/8。例如d=8/5时，新接受器下端>0.006083119669，旧下端为1/5000；所列d中改善幅度详见[验收报告](overlap_cost_verification.json)。没有声称这个有限d下端就是精确P(d)。

## 3. 统一截止值与有理接受

右端平方除去正数常量后为2(d−1)(1−d/2)⁷，导数为

~~~math
(1-d/2)^6(9-8d)<0\quad(d\ge\sqrt2).
~~~

所以对全部√2≤d≤c<2，可把右端统一取在c处。程序以Machin有理包围验收π<355/113，再比较

~~~math
\frac{512^2\,2(c-1)(1-c/2)^7}{105^2(355/113)^2}\ge p^2.
~~~

两边非负，故这就是P(d)≥p的纯有理充分证书；无需显示小数或不受控平方根。实际返回数值时再取平方根下端。

## 4. 近接极限的领先系数也是准确的

此处说的是两个平滑圆盘刚开始交叠的d↑2极限，不是全局最优构型或结晶极限。对1<d<2，极坐标给准确的一维式

~~~math
P(d)=\frac4\pi\int_{d-1}^{1}
s\arccos\!\left(\frac{d^2+s^2-1}{2ds}\right)h(s)\,ds.
~~~

令η=2−d、s=1−ηu。角函数θ满足

~~~math
1-\cos\theta=
\frac{2\eta(1-u)-\eta^2(1-u)^2}{2d(1-\eta u)}.
~~~

于是θ/√η→√(1−u)，h(1−ηu)/η²→u²。对η≤1/2，分母一致为正；1−cosθ≥2θ²/π²给角函数的C√(1−u)上包，而h(1−ηu)/η²≤2u²。这提供可积支配函数，故

~~~math
\lim_{d\uparrow2}\frac{P(d)}{(2-d)^{7/2}}
=\frac4\pi\int_0^1u^2\sqrt{1-u}\,du
=\frac{64}{105\pi}.
~~~

第2节解析下端在同一归一化下也趋于64/(105π)，因此它保留了这个近接极限的准确领先系数。程序用有理π上包时另保留明确舍入余量，不把舍入后的数值声称为精确系数。
