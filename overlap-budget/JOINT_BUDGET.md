# 短边图、径向矩和角向矩共用缺额预算

研究资料与项目发起：**蒋丰灿（Fengcan Jiang）**；推导及精确程序包含 OpenAI Codex 协作。2026-10-30。

本节把新的精确点对下端接入已有能量预算。它所使用的点对代价位于Dirichlet能量之外，因此可以与一个已证的完整Dirichlet投影下端相加；这与把同一径向或角向能量重复计算不同。

## 1. 一般短边人口上界

取√2≤c<2，令E_c为力为1的尺度中距离≤c的无序点对数量。每一对的代价至少P_lower(c)。若已独立证明全局缺额δ_n≤B，并有n²D(ν)≥D_lower，则

~~~math
\boxed{E_c\le\left\lfloor
\frac{B-D_{\rm lower}}{P_{\rm lower}(c)}\right\rfloor.}
~~~

当B<D_lower时，整个输入类已经被排除，程序返回该状态，不将负数当作人口。D_lower可以是一个径向与角向正交投影的和；不能把上一节已包含空洞和点对的完整线性缺额再次作为D_lower。

可达下界越强，B越小，短边图越受限。该约束控制无序点对数量，不是“各点都只能有同一个邻居数”，也不单独决定点集结构。

## 2. 与原稳定性算子的基本比较

力为1的尺度下，原稳定性矩阵B_op满足‖B_op‖≤1且B_op 1=0。因此‖B_op‖_F²≤n−1。每个距离≤c的无序点对至少在非对角元中贡献2/c⁴，故局部最大者已有基本界

~~~math
E_c\le\left\lfloor(n-1)c^4/2\right\rfloor.
~~~

这只是原完整算子条件的一条标量推论，不重新登记为原算子之外的新定理。新全局能量界在下列指定点数更紧：

|n，c=8/5|上述局部Frobenius上端|仅用已证全局缺额的能量上端|
|---|---:|---:|
|8|22对|17对|
|100|324对|136对|

百点预算取已认证整数见证给出的δ≤413923829261/500000000000；八点预算取原点加正七边形给出的δ<523/5000。P_lower(8/5)>0.006083119669，全部判断使用准确分数。

## 3. 八点加入径向与角向后，17对可降到2对

此节改回原z尺度。记U₂=Σ|z_i|⁴，P_k=Σz_i^k。上一轮的径向及驻点角向Dirichlet下端为

~~~math
C_r(U_2-64/7)^2+C_2|P_2|^2+C_3|P_3|^2
+D_4|P_2|^4+D_5|P_2P_3|^2.
~~~

全部有理系数及其来源见[径向层级证明](../local-defect/RADIAL_HIERARCHY.md)和[驻点闭合](../stationary-screening/STATIONARY_MOMENTS.md)。保留精确点对项后，还有可相加的至少(3/500)E_(8/5)。所以每个全局最优者必须满足

~~~math
\boxed{C_r(U_2-64/7)^2+C_2|P_2|^2+C_3|P_3|^2
+D_4|P_2|^4+D_5|P_2P_3|^2+\frac3{500}E_{8/5}
<523/5000.}
~~~

因此若U₂≥51/5且|P₂|≥4/5，短边至多2对；整个再有E_(8/5)≥3的类被排除。这里一条短边在原z尺度的平方距离阈值是128/175。三个下端的准确和为

~~~math
\frac{3487539215477}{33272678464000}>523/5000.
~~~

这是一个径向、角向及局部点距统计的联合区域，不能由“每个单项各不超过总预算”替代。

## 4. 非空四参数厚类

取原坐标

~~~text
(±616,0), (0,±760), (±953,±780),
~~~

再恢复总二阶矩8，平方尺度为2/1995137。它有U₂≈10.2052、P₂≈0.8049、P₃=0、4条上述短边。它通过上一轮所展示的低阶径向—角向联合预算；加入点对项才违反本节预算。

更强地，令四个正参数616、760、953、780分别独立变化±1/100，保持所示反射结构再归一化。程序对全部参数盒进行Fraction区间包围，证明：

- 整盒U₂>51/5、P₂>4/5；
- 四条指定短边的平方距离上端<128/175；
- 整盒仍通过上一轮所展示的低阶联合预算。

因此这确实是非空、有宽度的联合排除证书。它是反射结构内的四参数盒，没有声称是所有16个实坐标的独立全域盒。

中心整数输入还通过所列旧点距、半径、28个两点slack及四阶/六阶标量条件；但其旧八阶标量条件失败。本文明确保留这一失败，不声称它通过全部旧必要条件。
