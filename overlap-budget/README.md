# 重叠点对积分、顶点覆盖与短边联合预算

研究资料与项目发起：**蒋丰灿（Fengcan Jiang）**；推导及精确程序包含 OpenAI Codex 协作。2026-10-30。承接 `57edc9458539aab2fed6c6b1715d622ac364eb46`。

本轮将上一轮线性缺额系数提高37倍，并把保留的点对代价接入径向—角向共同预算。新步骤包括交叠区的抛物积分、共享端点的顶点覆盖，以及余集更大间距的装点。**一般n有限最优构型和八点完整锐界仍未由本轮确定。**

## 1. 新的有限线性缺额：系数提高37倍

沿用Σ|z_i|²=n的最优距离乘积M_n、N=n(n−1)/2，以及圆盘上端U_n=n^(n/2)(2n/(n−1))^N exp(−N/2)。对所有n≥2，严格得到

~~~math
\boxed{\log(U_n/M_n)\ge\frac{37}{2^{24}}(n-11\sqrt n)_+.}
~~~

同一有限公式的系数相对上一轮恰好提高37倍；全部n≥484有缺额≥37n/2²⁵。证明不依赖外部线性渐近余项或结晶结论。小n继续保留此前正Newton修正和专用锐界。

参数接受器不限于一个常数组：对给定有理c,t,b及人口预算逐项核查，接受后就给一般n定理。本轮明确验收32倍简式与37倍证书，没有声称已优化全部参数。

## 2. 单点对下界保留相切极限的准确领先项

采用力为1的尺度w=√((n−1)/2)z，平滑半径1。距离d的无序点对包含两个有序重叠项。对√2≤d<2，新下端为

~~~math
P(d)\ge\frac{512\sqrt{2(d-1)}}{105\pi}(1-d/2)^{7/2}.
~~~

它来自交叠区内的完整抛物子区域积分。解析下端与准确P(d)在d↑2时，都以64/(105π)·(2−d)^(7/2)为领先项；这里的准确性仅指两个平滑圆盘相切极限，不是全局能量锐值。

例如截止距离8/5时，新接受器每对下端>0.006083119669，旧小圆盘下端为1/5000。程序对π和平方根向安全方向包围。

## 3. 最优点集的短边图人口约束

令E_c表示力为1尺度中距离≤c的无序点对数量。已证全局缺额上端B与一个Dirichlet下端D_lower给

~~~math
E_c\le\left\lfloor\frac{B-D_{\rm lower}}{P_{\rm lower}(c)}\right\rfloor.
~~~

它可以与完整径向—角向投影共用预算，因为点对损失位于Dirichlet能量之外。不得将已经包含点对和空洞的总线性缺额再次当成D_lower。

|c=8/5|原局部Frobenius人口界|全局能量人口界|
|---|---:|---:|
|八点|22对|17对|
|百点|324对|136对|

百点结论使用此前已认证的实际整数构型下界。这是全局最优者的必要短边统计，不是对所有构型的结论，也不把简单Frobenius截断等同于完整二阶算子。

## 4. 八点径向、角向与短边三方联合

改回原z尺度，记U₂=Σ|z_i|⁴、P₂=Σz_i²。若八点全局最优者满足

~~~math
U_2\ge51/5,\qquad |P_2|\ge4/5,
~~~

则距离平方≤128/175的点对**至多2对**。该阈值对应力为1尺度的8/5；没有把两种尺度混用。

程序还给出一个反射结构内的四参数有理盒：整个盒通过此前展示的低阶径向—角向预算，但有4条指定短边，因而被保留点对代价的新预算排除。其中心输入旧八阶标量条件失败，本文保留这一事实，不声称此前全部判据都遗漏了它。
