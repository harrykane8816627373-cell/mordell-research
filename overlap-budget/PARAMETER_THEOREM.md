# 顶点覆盖与更稀疏余集：可复用的线性缺额参数证书

研究资料与项目发起：**蒋丰灿（Fengcan Jiang）**；推导及精确程序包含 OpenAI Codex 协作。2026-10-30。

本节承接上一轮[近邻或空洞证明](../local-defect/LOCAL_ALTERNATIVE.md)。改变两处计数，并采用新的抛物点对下端，将同一有限公式的系数提高37倍。参数验收只是充分判据，不声称在全部参数中最优。

## 1. 通用参数与局部几何

在力为1的尺度，全局最优者点距≥√2、支持于半径√n盘内。取有理c,t,b>0，√2≤c<2、t>1+b，记

~~~math
R=1+b,\quad U=t+R,\quad L=2(t+b).
~~~

选一个已证q<cos(2π/7)。若

~~~math
\max_{r,s\in\{c,U\}}(r^2+s^2-2qrs)<c^2,
~~~

则一个c分离余集中，距离某点不超过U的邻居至多6个。又若

~~~math
c^2>t^2-R^2,\qquad
\beta=(c^2+t^2-R^2)/(2ct)>\sqrt3/2,
~~~

每个半径R邻居盘在半径t查询圆上遮盖角度小于π/3。因此只要该点离背景边界至少t+b，就能产生一个半径b的平滑空盘。证明同上一轮圆弧论证，参数比较由本接受器逐项验证。

## 2. 用全部短边和顶点覆盖，减少一半端点损失

令E为所有距离≤c的无序点对数量。对每条边选一个端点，取这些端点的并集S。于是S覆盖每条边，且|S|≤E；删去S后，余集间距>c。

原来的匹配法每支付一条边最多删除两个端点。这里可以使用所有边，即使它们共享端点，因为精确缺额本就按点对逐项相加。选择顶点覆盖不需要求解最小顶点覆盖；按索引选每条边的较小端点即可。

若正整数A满足

~~~math
(1+\sqrt2U)^2<A+1,
~~~

则每个所选端点的U邻域至多含A个点，全部排除人口≤AE。再排除背景边界人口B，安静内点数Q满足Q≥n−B−AE。

## 3. 用余集的更大间距装点

安静内点都在删点余集中，彼此距离>c。因此从Q点中选择距离>L的点时，不能继续浪费这个更强间距。若正整数G满足

~~~math
(1+2L/c)^2<G+1,
~~~

贪心每次至多删除G点，能给H≥Q/G个不交能量空盘。证明仍是以半径c/2开小盘比较面积；对应空盘中心与原点的位移为t，所以原点间距>L使空盘不交。

若a=t+b满足a+1/√2<2，上一轮环带装点对n≥4给

~~~math
B<4(a+\sqrt2)\sqrt n.
~~~

令有理C>4(a+√2)，便有B<C√n。程序同时验证内环半径为正、端点与余集两个不同装点公式。

## 4. 通用能量接受条件

设κ>0，并用[新的点对积分](PARABOLIC_PAIR.md)证明P(c)≥Aκ，再要求b⁴/4≥Gκ。则精确能量分解给

~~~math
\delta_n\ge P(c)E+Hb^4/4
\ge\kappa(AE+Q)\ge\kappa(n-B).
~~~

与零取最大，可得对所有n≥2的有限式

~~~math
\boxed{\delta_n\ge\kappa(n-C\sqrt n)_+.}
~~~

n=2、3时所认证参数的右端为零，旧δ≥0即可处理。点对项与空洞Dirichlet项来自精确分解的不同部分，可以相加。

只使用零级全纯角向项时，仍可借其与紧支撑空洞测试的正交性保留额外罚项。完整径向或一级混合投影不能未经联合Gram再独立加在上述线性下端上。

## 5. 两个已认证固定参数

|证书|c|t|b|A|G|C|κ|
|---|---:|---:|---:|---:|---:|---:|---:|
|简式32倍|191/100|11001/10000|1/10|16|12|11|1/2¹⁹|
|37倍|1913/1000|11017/10000|127/1250|16|12|11|37/2²⁴|

均采用q=3117/5000。Machin区间证明π<355/113，再以余弦有限交错下和证明q<cos(2π/7)。全部比较均为有理式，特别是P(c)的接受只需平方比较。

主推论为

~~~math
\boxed{\log(U_n/M_n)\ge\frac{37}{2^{24}}(n-11\sqrt n)_+
\quad(n\ge2).}
~~~

同一(n−11√n)形状使它相对上一轮系数恰好提高37倍。对所有n≥484，缺额≥37n/2²⁵，渐近下端≥37/2²⁴。常数仍保守，不确定真正线性能量或最优构型。

若沿用项目已注明来源的线性展开，才进一步得到γ≤3/4−log(2)/2−37/2²⁴。这是对本项目圆盘端点的收紧，不是对全部文献的最优性声明；近期文献与本地认证边界继续沿用[说明](../local-defect/LITERATURE_SCOPE.md)。
