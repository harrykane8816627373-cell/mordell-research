# 连续环相位的最优分数打包与半径盒证书

研究资料与项目发起：蒋丰灿（Fengcan Jiang）；本轮推导、代码与核验包含 OpenAI Codex 协作。2026-11-05。

本专题接续[连续相位取等与三角形缺额](../general-structure/CONTINUOUS_PHASES.md)。上一专题已经提出允许分数三角形权重的接口，本轮将其实现为**可独立验证最优性的有理线性规划**，再加入一般奇加权循环和整个半径盒。没有把已有 resultant、线性规划对偶或三角形接口称为新发现；不作全球优先权声明。

所有结论的作用域均为指定人口、半径或半径区间的正规环家族。这里的“最优”仅指所列有限循环预算的线性规划最优值，不表示已经求出真实相位最小缺额，更不表示求出无约束 M_n。

## 1. 任意奇加权循环的严格缺额

第 i 环人口 m_i>=2，半径 r_i>0、物理相位 theta_i；半径严格递增。还允许 h=0 或 1 个原点。令

```math
n=h+\sum_i m_i,\quad Q=\sum_i m_i r_i^2,\quad
N=n(n-1)/2,\quad F=(n/Q)^N\Delta.
```

各环自身中心化，Q 与所有相位无关。对环对 e=ij 定义

```math
g_e=\gcd(m_i,m_j),\quad L_e=\operatorname{lcm}(m_i,m_j),\quad
A_e=r_i^{L_e},\quad B_e=r_j^{L_e},\quad
\eta_e=\frac{4A_eB_e}{(A_e+B_e)^2}\in(0,1).
```

已知交叉 resultant 为

```math
X_e=|A_e e^{iL_e\theta_i}-B_e e^{iL_e\theta_j}|^{2g_e}.
```

因此独立最大化各环对给出的上端为

```math
U_{\rm pair}(r)=\left(\frac nQ\right)^N
\prod_i m_i^{m_i}r_i^{m_i(m_i-1)+2hm_i}
\prod_{i<j}(A_{ij}+B_{ij})^{2g_{ij}}.
```

设 delta_e=log((A_e+B_e)^{2g_e}/X_e)>=0。归一化、同环和原点项完全抵消，故

```math
\log\frac{U_{\rm pair}(r)}{F}=\sum_e\delta_e.
```

**循环定理。** 取任意简单定向循环 C=(i_1,...,i_k,i_1)，令 L_C=lcm(m_i:i in C)，a_e=L_C/L_e。若整数 sum_(e in C) a_e 为奇数，则对所有连续相位

```math
\sum_{e\in C}\delta_e\ge\gamma_C,
\qquad
\boxed{\gamma_C=\left(\sum_{e\in C}\frac{a_e^2}{g_e\eta_e}\right)^{-1}>0.}
```

**证明。** 沿循环定向，对边 e=i->j 取 epsilon_e 为 L_e(theta_i-theta_j)-pi 在 [-pi,pi] 中的一个代表。由于相位项望远镜消去，

```math
\sum_{e\in C}a_e\epsilon_e
=-\pi\sum_{e\in C}a_e-2\pi\ell,
\qquad \ell\in\mathbb Z.
```

右侧是 pi 的奇数倍，绝对值至少 pi。单边仍满足

```math
\delta_e=-g_e\log(1-\eta_e\sin^2(\epsilon_e/2))
\ge g_e\eta_e\epsilon_e^2/\pi^2.
```

使用 -log(1-x)>=x 和 sin(|epsilon|/2)>=|epsilon|/pi。再由带权 Cauchy 不等式，

```math
\pi^2\le\left|\sum a_e\epsilon_e\right|^2
\le\left(\sum\frac{a_e^2}{g_e\eta_e}\right)
    \left(\sum g_e\eta_e\epsilon_e^2\right).
```

消去 pi^2 即得结论。循环定理不要求每个 a_e 为奇数，只要求其和为奇数；上一专题的坏三角形是其特例。

## 2. 用精确原始与对偶证书消除重复预算

选定有限循环集合 S，每个循环都满足上述奇性条件。令 A_(e,C)=1 当 e 属于 C，否则为 0。考虑线性规划

```math
P_S=\max\left\{\sum_{C\in S}\gamma_C\lambda_C:
\lambda_C\ge0,\ \sum_{C\ni e}\lambda_C\le1\ \forall e\right\}.
```

对任何可行权重 lambda，乘循环不等式后求和，得到

```math
\sum_C\lambda_C\gamma_C
\le\sum_e\left(\sum_{C\ni e}\lambda_C\right)\delta_e
\le\sum_e\delta_e.
```

所以只要找到一个可行 lambda 就给出了可用下端。贪心选取边不重叠三角形只是 lambda_C 取 0 或 1 的一个可行解；最优分数解必定不弱。加入更多循环同样不会减小 P_S。

为了认证这里确实达到**所列线性规划的最优值**，另保存非负边权 y_e，要求

```math
\sum_{e\in C}y_e\ge\gamma_C\quad(C\in S).
```

任意可行 lambda、y 都满足初等弱对偶

```math
\sum_C\gamma_C\lambda_C
\le\sum_C\lambda_C\sum_{e\in C}y_e
\le\sum_e y_e.
```

若二者目标值严格相等，就已证明最优，无需信任求解器的停止标记或使用外部数值优化结果。本专题用 Fraction 有理单纯形法寻找证书；接受器重新构造全部几何系数，分别检查非负性、每条边的容量、每个循环的对偶支付及目标值相等。

因此认证的 P_S 给出对所有相位成立的上界

```math
\boxed{F\le U_{\rm pair}(r)e^{-P_S}
       \le\frac{U_{\rm pair}(r)}{1+P_S}.}
```

第二步仅使用 exp(P_S)>=1+P_S，以保持最终上端为有理数。这里未把 P_S 当作真实最小相位缺额；循环下界本身的松弛可能仍很大。

## 3. 从固定半径扩展到整个有理半径盒

设 r_i 属于 [l_i,u_i]，0<l_i<=u_i<l_(i+1)。对 e=ij、i<j，取

```math
q_e^-=(l_i/u_j)^{L_e},\qquad
\eta_e^-=\frac{4q_e^-}{(1+q_e^-)^2}.
```

因为 q=(r_i/r_j)^{L_e} 属于 (0,1)，且 4q/(1+q)^2 的导数为 4(1-q)/(1+q)^3>0，所以 eta_e>=eta_e^-。将 eta_e^- 代入 gamma_C 定义，便得到对整个半径盒共同成立的 gamma_C^-。使用这些系数重新认证线性规划 P_S^-。

另外，所有乘积项都随半径增加而不减，而 Q>=Q_-=sum m_i l_i^2。因此

```math
U_{\rm box}=\left(\frac n{Q_-}\right)^N
\prod_i m_i^{m_i}u_i^{m_i(m_i-1)+2hm_i}
\prod_{i<j}(u_i^{L_{ij}}+u_j^{L_{ij}})^{2g_{ij}}
```

是整个盒内 U_pair(r) 的上端，从而

```math
\boxed{r_i\in[l_i,u_i]\ \Longrightarrow\
F\le U_{\rm box}e^{-P_S^-}
\le\frac{U_{\rm box}}{1+P_S^-}.}
```

这个连续盒结论来自端点单调性和循环不等式；不依赖取样、不依赖浮点误差，也没有把所有半径的最大值宣称已求出。区间过宽时，分离 Q 与各乘积因子会使上端变弱，需要进一步细分。

## 4. 四正方形环：分数打包严格胜过贪心

人口为 (4,4,4,4)，半径为 (9/10,1,11/10,6/5)，n=16。四个三角形及其精确 gamma 为

|三角形|gamma|
|---|---|
|012|7684768080000/6247243870201|
|013|16796160000/14920250497|
|023|196730062848/175568157161|
|123|3035957760000/2433572506097|

任何两个三角形都有公共边，因此上一算法只选最大的一项，G=gamma_123，约为 1.247531254。令所有四个 lambda 都为 1/2，每条边恰被支付一次，得到

```math
P=\tfrac12(\gamma_{012}+\gamma_{013}+\gamma_{023}+\gamma_{123})
\approx2.361949769>1.89G.
```

用 a=gamma_012、b=gamma_013、c=gamma_023、d=gamma_123，可取精确对偶边权

```math
y_{01}=y_{02}=0,\quad y_{12}=a,\quad
y_{03}=(a+b+c-d)/2,\quad
y_{13}=(b-c+d-a)/2,\quad y_{23}=(c-b+d-a)/2.
```

上述数均非负，各三角形支付恰等于其 gamma，总支付恰为 P。因此这就是四三角形预算的精确最优值。

同一 U_pair 下，新有理上端与旧贪心有理上端之比为 (1+G)/(1+P)，小于 669/1000，约为 0.668520177，即降低超过 33.1%。这是上界本身的改善，不是声称真实最大值下降了这个比例。

把四个半径分别扩展为中心值正负 1/10000 的区间，重新计算 uniform gamma 和 LP，仍有 P_box 约为 2.361383048。**整个半径盒与所有连续相位**的新有理上端，小于原固定中心半径的旧贪心上端的 7/10，精确比值约为 0.699541382。证书不是仅在 16 个半径角点取样后作的外推。

## 5. 二十五点例：四循环胜过最优三角形预算

人口为 (8,6,3,8)，半径为 (4/5,9/10,1,11/10)，n=25。只有三角形 013、023 不相容，它们共享边 03，最优三角形预算约为 0.04497805187。

取循环 0->1->2->3->0，总 lcm 为 24，沿边的整数乘子为

```math
(24/24,24/6,24/24,24/8)=(1,4,1,3),\qquad \sum a_e=9.
```

其中包含一个偶乘子，仍由奇总和触发循环定理。将所有合格三角形和四循环放入 LP 后，最优解将权重 1 全给此四循环，所得 P 约为 0.06485607970，比已是最优的三角形预算高 44.1% 以上。原始与对偶有理向量保存于证书，接受器检查了所有其他循环的对偶支付，未只比较这一条循环与贪心值。

这个例子说明：推广循环种类提供的信息不能完全用原三角形预算替代。它仍只约束此指定人口和半径家族；不把 25 点一般最优者假定为这四条正规环。

## 6. 实际复核与未完成事项

固定证书全部通过精确接受器。另用独立 Gauss-Jordan 实现穷尽小 LP 的全部约束交点，直接复核最优值；在有理平面坐标中，核对四正方形环半径盒的 16 个角点和四组有理旋转，共 64 个十六点构型，每个构型直接相乘 120 个距离平方。

这些有限检查验证实现；连续域定理由第 1 至 3 节证明承担。程序还主动破坏原始权重、对偶支付、几何系数、半径、循环与边的索引、目标值、上端和作用域，确认接受器拒绝伪造输入；全部检查在 python -O 下保留。

实现目前有明确资源范围：1 至 8 条环，非中心人口总和不超过 100、总 lcm 不超过 240、至多 300 个合格循环；超出预算会报错。数学定理不受这些实现范围限制。最大循环长度是证书的一部分，未枚举的更长循环没有被声称已优化。

该方法可接入半径分支定界，再联合[已有完整逐点力余式](../symmetry-breaking/STATIONARITY.md)及完整二阶条件筛选候选。但本轮没有覆盖所有人口、所有半径或所有平面构型，也没有确定一般 M_n、晶格结构或所有点数的最优构型。
