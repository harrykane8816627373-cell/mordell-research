# 连续相位的最优循环打包与半径盒上界

研究资料与项目发起：蒋丰灿（Fengcan Jiang）；推导与精确代码包含 OpenAI Codex 协作。更新：2026-11-05。

本专题把[已有连续相位缺额](../general-structure/README.md)推进为精确分数打包，并加入一般奇加权循环和整个半径区间盒。**所有上界都针对指定正规环人口和半径范围，未求出无约束 M_n。**

每条不相容循环给出正对数缺额 gamma_C。选择非负权 lambda_C，使每条环对的总权重不超过 1，便能将循环缺额相加。保存原始与对偶有理向量、逐项检查可行性和目标值相等，可以认证所列循环预算的最优值 P：

```math
F\le U_{\rm pair}e^{-P}\le U_{\rm pair}/(1+P).
```

这是**有限预算的最优认证**；P 仍可能小于真实相位最小缺额。

|实例|此前预算|本轮认证|
|---|---|---|
|四个正方形环，半径 9/10、1、11/10、6/5|贪心缺额约 1.247531|分数三角形最优缺额约 2.361950，有理上端降低超过 33.1%|
|同上四个半径各扩展正负 1/10000|此前仅有固定半径执行|整个半径盒、全部连续相位的新上端，低于原固定中心贪心上端的 70%|
|人口 8、6、3、8，半径 4/5、9/10、1、11/10|最优三角形缺额约 0.0449781|加入四循环后约 0.0648561，比最优三角形预算高 44.1% 以上|

一般循环的整数乘子 a_e=L_C/L_e 只需总和为奇数。例如二十五点例的乘子为 (1,4,1,3)，因此该改进超出了三角形公式。半径盒采用 eta 的严格端点下界及归一化乘积上界，连续覆盖由解析单调性保证。

从仓库根目录复核固定输入：

```bash
python -B -S -O phase-packing/verify_all.py
```
