## 3. 十点：任何全局最大点的范围进一步收紧

用x=√(9/10)z、Σ|xᵢ|²=9。旧整数见证严格给出Δ(x)>L=(97/80)9⁹。对任何全局最大点的一对，记u=|xᵢ|²、v=|xⱼ|²、t=Re(xᵢconj(xⱼ))、d=u+v−2t。新的[必要域证明](../maximizer-domain/README.md)得到

```math
0\le u,v<15403/10000,\quad t^2\le uv,\quad d>2/5,
\quad9(u+v)+2t<664/25.
```

平方半径上端由1.62收紧至1.5403；剩余八点去重心质量q=9−9(u+v)/8−t/4，由旧严格子集下端5.6提高至5.68。点距条件d>2/5沿用严格子集定理的两点情形。

更强的信息来自交互多项式在原点的一阶导数为零。对子集伸缩的条件多项式P，归一化f=P/P(1)满足单位圆上|f|≤1、f(1)=1、f′(0)=0。圆盘自同构和二阶Schwarz给出

```math
\delta\ge2\frac{1-|f(0)|}{1+|f(0)|}.
```

取δ=5q−28、b=((81u+v+18t)(u+81v+18t))/4096，则0<δ<2时还有

```math
(\delta+2)^2d\,b^8q^{28}\ge(2-\delta)^2L\,7^{21}.
```

点对(3/2,3/2,−1/4)通过新的半径、点距和线性切割，却违反此式，说明非线性条件确有额外排除力。这些是全部全局最大点的必要条件；任意驻点或任意可行构型不必满足。

## 5. 正定核如何接入两点上界

[候选适配核专题](../candidate-kernel/README.md)采用径向向量和角向谐波。令Hₖ(u,v,t)=Re((xᵢconj(xⱼ))ᵏ)，其递推为H₀=1、H₁=t、Hₖ=2tHₖ₋₁−uvHₖ₋₂。对半正定矩块Qₖ，核形如

```math
K(u,v,t)=F(u)^TQ_0F(v)+\sum_{k\ge1}H_k(u,v,t)V_k(u)^TQ_kV_k(v).
```

全体有序点对求和是径向和角向矩的半正定二次型，所以ΣᵢⱼKᵢⱼ≥0。核在候选处取零要求相关候选矩落在Qₖ的零空间内；候选确有非零矩时，不能直接把所有Qₖ设为正定并要求那些矩消失。

质量n−1尺度下令N=n(n−1)/2、b=(B−N)/n，取

```math
p(u)=\frac{nu/2+b-K(u,u,u)/2}{n-1},\qquad h(u,v,t)=p(u)+p(v)-K(u,v,t).
```

利用总质量，精确得到Σᵢ<ⱼhᵢⱼ=B−ΣᵢⱼKᵢⱼ/2≤B。若能在每个全局最大点可能出现的整个点对域上证明h≥log(u+v−2t)，就有logΔ≤B；再匹配候选值及等号条件才能完成锐界。

[一般旋转层定理](../candidate-kernel/RIGIDITY.md)还给出具有刚性零集的核构造：当各正半径层人口为m或2m、存在一个m人口锚定层且m次矩满足非退化条件时，径向矩、逐层非m谐波和m次矩的秩一零空间共同强制构型为候选旋转轨道。它统一适用于10点的2/4/4层、12点的3/3/6层和19点的中心加6/6/6层；所需实际候选矩条件已通过精确区间认证。该定理锁定核罚项的零集，仍需控制整个必要域上的目标值。

原始10、12点SDP系数尚不能完成候选锐界证明。12点出现离散目标差为零，但仍有连续点对违反原始majorant；10点尝试也有失败点对。专题将固定浮点系数解释为精确二进有理数，再以对数的有理下端验证违反。这些反例否定的是无余量核拟合，未否定候选全局最优。下一节保留原系数、增加明确余量并完成连续证明。

## 6. 上一轮十二点：连续覆盖给出非锐全局界

新增[十二点核上界](../twelve-point-kernel-upper/README.md)将原拟合转换为一条真正连续有效、带明确余量的全局证书。令V₁₂为旧12点整数构型在原质量12尺度的精确可达值，C₁₂为已有真实候选的值，现已严格得到

```math
V_{12}<C_{12}\le M_{12}<\frac{23}{20}V_{12},
\qquad\frac{C_{12}}{M_{12}}>\frac{20}{23}\approx86.9565\%.
```

这是全局值的定量包围；没有预设所有最大点具有候选D₃对称，也尚未证明C₁₂=M₁₂。

具体取质量11尺度，令c=21/10000，B=7726135064073933/281474976710656为冻结拟合中的精确二进有理数。所有12个编码Q矩块均通过精确LDL正定检验。旧严格子集定理保证任何全局最大点的点对属于闭必要域

```math
0\le u,v\le121/72,\qquad t^2\le uv,\qquad d=u+v-2t\ge1/3.
```

对同一个原始h，完整精确覆盖证明h+c≥log d。因此核求和接口给质量11下logΔ≤B+66c=B+0.1386。这里成立的是增加余量后的majorant；原始h≥log d仍被既有有理反例否决。

连续证明将h展开为三变量多项式，Bernstein次数19/19/11，共4800个系数。初始变换完全使用Fraction；系数向下量化到2⁻⁴⁰网格，逐次中点细分继续向下取整。对数用切线作上界，切点对数经范围归约、正项级数及严格尾项上端处理。Python无界整数的分栏编码加速这些精确运算；已检查分栏范围，未使用浮点算术决定叶子的接受。

|完整树计数|结果|

|二分节点|18526|

计数满足37053=2×18526+1及16237+2290=18526+1；默认接受器实际重放这棵完整树。交换u、v的剪枝以精确核对的多项式对称性为依据，不引入构型对称假设。

最后设旧整数坐标为pᵢ，P=∏ᵢ<ⱼ|pᵢ−pⱼ|²，D=12Σ|pᵢ|²−|Σpᵢ|²。原质量12尺度V₁₂=144⁶⁶P/D⁶⁶，质量11尺度则为Ṽ₁₂=132⁶⁶P/D⁶⁶。精确对数下端证明

```math
B+66c<\log\left(\frac{23}{20}\widetilde V_{12}\right),
```

故缩放回原质量即得M₁₂<23V₁₂/20。重放真实候选根后，其目标值区间下端又严格超过V₁₂，给出上述候选比例。

连续覆盖也发现原SLSQP违反点搜索漏掉了更低区域：先前约−0.000604仅是一次找到的余量，不是整个必要域的最小值。较小余量的探索有未决区域，不计入完整证明；最终结论只采用已通过的c=21/10000证书。
