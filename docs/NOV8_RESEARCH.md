# 11月8日：四环人口约束、完整候选族排除与高点数局部极值

蒋丰灿（Fengcan Jiang）研究项目，OpenAI Codex协作。承接已推送的11月5日研究版本8b57561。本轮不改写旧冻结证据，在新目录记录进一步定理与实际精确接受。

## 1. 四条正规环的人口不能任意选

[完整逐点力定理](../four-ring-rigidity/THEOREMS.md)允许任意连续相位、两两不同的正半径及可选原点，得到：

- 任意条数的不等人口驻点，至少三条环的人口严格小于最大值。
- 因此四环的不等人口模式只有一个最大人口m，而且m严格小于其余三个人口之和。
- 若其余人口之和不超过2m，必须存在人口重复，或其中最大者等于另两者之和。全部子集和不同会导致两个互相矛盾的力余式系数。
- 三同一异的人口(s,s,s,m)、m≠s，必要条件进一步收紧为m=2s。这个保留比例尚未被认证为存在。

平衡边界(s,s,s,3s)的两个可能系数支均被处理：一支由完整Ward恒等式与三个复向量的加权闭合排除，另一支由virial关系和严格算术几何平均矛盾排除。没有把有重复次数的分支跳过，也没有声称四环人口必须全等。

有限清点覆盖非中心总人口≤100的156636个排序模式，仍保留60个不等人口模式和24个等人口模式；保留表示这些必要条件未排除它们，不表示驻点、局部极大或全局最优存在。

## 2. 非线性角向缺额显著加强

[新角向证书](../phase-deficit-sharp/PROOF.md)保持原人口、半径、循环及打包权重，改为保留正弦和对数的非线性代价。普遍的加权Jensen先严格加强旧二次预算；有理八次正弦下端、三项对数下端与标量对偶进一步给出：

|指定规则环家族|前轮预算|新认证缺额D|
|---|---|---|
|四正方形环，半径9/10、1、11/10、6/5|约2.36195|5.97446865|
|上述四半径各变化±1/10000的完整盒|约2.36138|5.97277165|
|人口8、6、3、8的25点固定环族|约0.0648561|0.1591666|

每条仿射支持都在整个角偏差区间[0,1]通过精确Bernstein覆盖接受，总共291个叶。没有用有限角度取样代替连续覆盖，没有再次将旧分数打包算作新发现。

## 3. 从上界改善到一个完整16点家族的排除

已证F≤U exp(−D)。保留指数的八阶正项E₈(D)=Σₖ₌₀⁸Dᵏ/k!，就有严格有理上端F<U/E₈(D)。用旧整数坐标重算一个真正可行的16点构型值V₁₆，再做准确比较，[家族排除证书](../family-exclusion-nov8/PROOF.md)得到：

```math
\frac{U_{\rm fixed}}{E_8(D_{\rm fixed})V_{16}}
\in(0.04490398721963,0.04490398721964),
```

```math
\frac{U_{\rm box}}{E_8(D_{\rm box})V_{16}}
\in(0.04704991411673,0.04704991411674).
```

两者均小于1/20。因V₁₆≤M₁₆，固定四正方形环的全部相位及上述整个半径扰动盒，都不能包含全局最优构型。这是整个列出候选族的排除，不是M₁₆的全局上界。25点例也通过比较，但其定性排除在旧预算下已经成立，不记为本轮新增排除。

## 4. 把更高下界认证为真实严格局部极大

对11月5日保存的25、35、42、46点改进整数种子，[新的区间证书](../validated-maxima-nov8/PROOF.md)全部证明：存在规范盒半径2⁻⁸⁰内的真实驻点，其完整实Hessian除整体旋转外严格负，因而是质量球面上模旋转的严格局部极大。

这些根的目标值下端还严格超过对应整数种子的值，报告给出相对新旧整数见证的有理区间。结合前轮，现有12个不同点数的严格局部极大轨道及15点一个不稳定驻点的实际证据。唯一性仅限所列旋转切片盒，不是全部驻点分类；严格局部极大不等于全局最优。

## 5. 实际复核与未完成问题

四环专题实际核对19项一般恒等式、4466组平衡系数、29945组子集案例、127个Ward差商和16827组端点余数；一般定理由解析证明承担。角向专题额外核对360项多项式细分恒等式、140项特殊角/对数、80个直接坐标构型并拒绝20种破坏。家族排除重新接受三份角向证书、重算两个整数见证并拒绝10种错误输入；新局部认证固定引用前轮精确整数代码，并重新执行完整根与Hessian检验及7种伪证书拒绝。

正式接受只依赖Python标准库、精确整数和有理数，关键判断在`-O`下保留。所有作用域、输入哈希和实际报告各自保存；协作交叉核验不是外部同行评审或整篇形式化证明。

下一步仍需对保留的加法共振人口做半径、相位及完整Hessian联合分析，并扩展到非规则层。一般n≥10的锐值、全部最优构型、微观晶格与全域覆盖仍未由本轮确定。
