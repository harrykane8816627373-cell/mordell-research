# 十点转折：候选失效不等于已知新最优构型

2026-11-04。坐标来源为 Gueron–Shafrir (1999)；这里按 Ji–Xu–Yu 的 [arXiv:2611.03088v1，命题5.1](https://arxiv.org/pdf/2611.03088v1)重放整数比较。此处没有声称新的十点最优构型。

记 N=n(n−1)/2，中心正多边形的可达值为

~~~math
C_n=(n-1)^{n-1}\left(\frac n{n-1}\right)^N.
~~~

取整数点集（矩形中的正负号独立）

~~~math
W=\{(\pm11183,0),(\pm32765,\pm14669),(\pm12323,\pm31572)\},
\qquad q=\sum_{w\in W}|w|^2=9999608174.
~~~

令 z=√(10/q)W，则 Σ|z|²=10。对45个正整数平方点距直接相乘得到

~~~math
9^{36}\prod_{i<j}|w_i-w_j|^2>q^{45}.
~~~

乘以10⁴⁵/(9³⁶q⁴⁵)，即得 Δ(z)>10⁴⁵/9³⁶=C₁₀，因此 M₁₀>C₁₀。这只是严格可达下界，无需坐标是精确驻点；把印刷小数视作有理数已经足够。

独立复核仅使用 Python 标准库，所有比较在 `-O` 下仍执行：

~~~bash
python -B -S -O scripts/verify_ten_point_transition.py
~~~

程序输出整数质量、45个点距的检查、Δ(z)/C₁₀ 的有理包围及整数差的哈希。

对 n≥11，Ji–Xu–Yu §5.2引用 Gueron–Shafrir 定理1(2)的受约束不稳定方向，故中心正(n−1)边形在任意小邻域内已有更优构型。这里没有重建该外部定理。结合十点整数见证，中心正多边形在所有 n≥10 都不能全局最优。确定真正的最优构型仍需新的全域上界和等号分类，有限搜索、环形参数族的最优值或 Hessian 稳定性均不足以代替它们。
