# 11月5日：从多环相位到完整逐点条件

研究资料与项目发起：蒋丰灿（Fengcan Jiang）；推导、探索、精确程序及交叉审阅包含OpenAI Codex协作。基于2026-11-04已发布版本43f0bd6，八、九点全局证据保持原字节。本轮继续研究一般点数，没有声称确定所有n的锐值。

## 1. 三环公式为什么不能覆盖一般最优者

[三环刚性定理](../ring-rigidity/THEOREMS.md)证明：恰由三个互异正半径上的同心正多边形组成的无碰撞驻点，三个环的点数必须全部相同，允许任意连续相位和可选原点。它从每个点的力方程推出，不只是同步改变各环半径和角度所得的条件。原有“两环必须等人口”在恰有三环时也得到完整等人口障碍。

同时，对任意阶m旋转对称的局部最大点，若非零点分成K个长度m的轨道，另有h∈{0,1}个原点，则

```math
\left\lfloor\frac{m^2}{4}\right\rfloor\le2(n-1+h),\qquad n=Km+h.
```

轨道半径不全相同时必须严格。该不等式来自完整逆平方Laplacian的Fourier主块，控制的是每个点独立移动的Hessian。旋转阶至多按√n尺度增长；它不说明最优者必须具有非平凡旋转对称。

结合三环人口刚性，无中心时每环人口m≥24、有中心时m≥25的三规则环驻点均不可能是局部最大点。等人口也不是充分条件：精确Hermite六、七点构型为三条反足环的真实驻点，但有二阶增益60、105的非径向扰动。

## 2. 连续相位的循环预算如何加强

前轮已经知道，多环对的相互作用未必能同时取到各自最大值。本轮[循环分数预算](../phase-packing/PROOF.md)将缺额写成有理线性规划，并保存精确原始与对偶证书，保证没有重复支付同一条边的缺额。

- 四个正方形环的固定半径为9/10、1、11/10、6/5：最优三角形分数预算约2.36195，旧贪心约1.24753；对应有理上界降低超过33.1%。
- 人口(8,6,3,8)的固定25点环族：一个具有乘子(1,4,1,3)的四循环，比最优三角形预算再提高超过44.1%。
- 四正方形环的每条半径变化±1/10000，整个半径盒与所有连续相位的新上界，仍小于旧固定半径贪心上界的70%。

这些是明确规则环家族的全相位上界，不能提升为全部平面构型的上界。更宽半径盒、更多人口和不规则环仍需额外覆盖。

## 3. 16项更强的整数可达下界

两波自由构型搜索实际执行1455次优化、434320次迭代。新的[整数坐标](../finite-search-nov5/integer_witnesses.json)在以下点数严格超过旧保存见证：

17、18、25、28、31、32、34、35、36、39、42、45、46、47、49、50。

比较重新相乘全部整数平方点距，准确消去重心与归一化因子；见[完整下界证明及增益表](../finite-search-nov5/README.md)。例如17点提高约1.0230%、18点约3.1223%，最大改善为46点的[4.931680542211%,4.931680542212%)。比较对象是旧可达构型，不是未知最优值。

这证明少量起点留下的小梯度构型可能离更高可达值仍有明显差距。它不证明新见证是驻点或全局最优。

## 4. 把近似点认证为真实局部极值

[整数区间验证](../validated-maxima/PROOF.md)在旋转规范y₀=0、x₀>0下，对半径2⁻⁸⁰的实盒检验压缩映射，恢复被省略的力方程，并由完整方程推出中心化和Σ|z|²=n。随后用整个盒上的有理合同与严格Gershgorin界，控制完整实Hessian。

实际接受8个严格局部极大轨道：n=10、11、12、13、14、17、18、19。其中17、18点使用本轮改进种子。另在15点旧候选附近认证一个真实驻点，却找到严格正二阶方向，故其不稳定。整数种子与盒内精确根不同，接受的对象是后者。

每个盒内根局部唯一，只是该旋转切片中的唯一性；未穷尽任何点数的全部驻点。局部极大也不意味着全局最优。

## 5. 实际核验与后续研究

四组正式接受均在Python标准库、`-B -S -O`下通过。三环专题核对16项一般参数恒等式、8255个独立Fourier系数和25736个人口模式；相位专题另核对原始/对偶、独立顶点、直接点距及篡改拒绝。局部认证包含4950项有理端点运算、276个独立复Laplacian条目与5种伪造证书拒绝，并经另一代理独立复跑和审阅。协作审阅不等于外部同行评审或整篇形式化证明。

这些结果给出可继续衔接的路线：先用逐点力排除不可能的规则人口，保留能通过完整稳定性筛选的分支，再用连续相位及半径盒上界排除受限家族，并用严格局部认证区分真正极值与近退化鞍点。一般构型的全域上界、非规则半径层的精确结构、n≥10的锐值及微观结晶仍未解决。
