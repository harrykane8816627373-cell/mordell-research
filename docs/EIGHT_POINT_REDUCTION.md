# 八点当前归约：旧椭圆、零矩分类与新排除集的交集

2026-11-01。研究项目：蒋丰灿（Fengcan Jiang），OpenAI Codex 协作。

**旧椭圆和零矩分类继续作为前置条件。** 局部能量、低阶矩耦合及本轮径向—角向排除继续缩小同一个剩余集合；六个矩门槛不是六个重新打开的独立分类问题。完整排除仍未完成。

## 1. 先统一三个尺度

原归一化是 Σ|z_i|²=8，记 P_k=Σz_i^k。当前八点管域采用 w=√(7/2)z、p_k=Σw_i^k；进一步令 q=w/2、s_k=p_k/2^k。

因此

```math
p_k=(7/2)^{k/2}P_k,\qquad s_k=p_k/2^k.
```

[旧驻点混合矩证明](../stationary-screening/STATIONARY_MOMENTS.md)第5节给任何八点全局最优者的必要椭圆

```math
|P_2|^2+\frac{27}{100}|P_3|^2\lt\frac{64}{49}.
```

它在力1尺度下准确等价于

```math
\boxed{|p_2|^2+\frac{27}{350}|p_3|^2\lt16,}
```

在七次单位根的 q 尺度下等价于

```math
|s_2|^2+\frac{54}{175}|s_3|^2\lt1.
```

同一字母在旧专题的不同章节曾用于不同尺度，不能把原尺度的8/7上端直接当作力1尺度的上端。旧证明中更强的径向项和四次罚项也可保留，简化椭圆不是全部旧约束的替代品。

## 2. 零矩分支已经关闭的部分不重新打开

按照[原有零矩分类及其适用前提](../configuration-bounds/PROOF_STATUS.md)，研究潜在全局最优者时，可以把剩余攻关对象限制到

```math
p_2p_3\ne0,\qquad\text{即 }p_2\ne0\text{ 且 }p_3\ne0.
```

这是两个零矩分支的并集被处理后的补集，不是“二者不同时为零”。驻点、稳定性、目标阈值以及原分类所列依赖仍须保留。

目标是排除**能够挑战候选值的非零矩分支**，不要求证明所有目标值较低的非零矩驻点都不存在。

## 3. 当前待排空的是所有约束的交集

用 E 表示上述力1尺度椭圆，G 表示全部已证的半径、点距、严格真子集及其他必要条件。非候选全局最优者若存在，必须同时满足：

- 八点互异，Σw_i=0，Σ|w_i|²=28；
- 真实逐点力方程及完整逆平方算子范数≤1；
- E、G 以及 p₂p₃≠0；
- 距离乘积 Δ_w≥T=4²⁸7⁷。

[此前代数证明](../algebraic-gap/README.md)把旧 p₂=0 ⇒ p₃=0 整数恒等式齐次化，给出另一条全局必要条件

```math
|p_2|\ge10^{-36}|p_3|.
```

它直接使用旧椭圆、真实力方程和目标阈值，不要求靠近候选。它只排除一条很细的楔形区域，没有证明其余非零矩系统为空。文中还保留了可在更小系数盒重算的目标值—矩联合不等式。

[本轮径向—角向定理](../radial-gap/README.md)进一步要求非候选挑战者在 q=w/2 尺度下满足

```math
E_q=\sum_i|q_i|^2(|q_i|^2-1)^2>1/1200.
```

原上传统一包的门槛是1/35000；本轮扩大到1/1200，并给出该区域内 log(Δ_q/7⁷)≤−E_q/32。此结果从真实点坐标出发，不需要驻点、稳定性或预设半径上界，但继承七点锐界的已披露外部分类依赖和已有局部目标值定理。它不能替代余域中的真实根配对和完整稳定性。

[新能量证明](../eight-point/ENERGY_BASIN.md)进一步要求未排除者满足

```math
d(w)>1/5,\qquad
\max_{k\in\{2,3,4,5,6,8\}}|p_k|/2^k>1/8.
```

最后一个条件展开就是[六个剩余矩条件](../eight-point/OPEN_BRANCHES.md)。每一项都应继续与 **E、G、p₂p₃≠0、代数耦合、E_q>1/1200、逐点力方程、完整稳定性和目标阈值**取交集；旧11个目标盒也继续删去。不能脱离旧椭圆，在整个矩空间重新开始六个无约束搜索。

## 4. 为什么椭圆还不能直接完成全域覆盖

椭圆给 p₂、p₃ 的必要上界；新管域则同时要求六个矩都足够小。尚无证明从椭圆及非零条件就能推出全部六个小量条件，尤其不能直接控制 p₄、p₅、p₆、p₈。

例如仅作为矩数据的集合比较，p₂=p₃=1 满足

```math
1+27/350=377/350\lt16,
```

但不满足新管域要求的 |p₂|≤1/2。这不是实际驻点存在性证明或反例，只说明椭圆本身没有被包含在新管域内。真实力方程与完整稳定性是否进一步把全部可行点压进已排除集合，正是尚需证明的步骤。

因此正确的下一步仍是：在**旧椭圆内的非零矩物理系统**上做全覆盖、消元或严格矛盾证书；不是舍弃旧成果，也不能将已有局部扩张当作这一步已经完成。

## 5. 完整驻点与 Hessian 的等价多项式接口

[本轮联合模型](../joint-closure/README.md)直接在实际 q 坐标上构造8×8 Hermitian 多项式矩阵，其 PSD 在质量7、中心化、Δ>0下，等价于 S₁₆=0与完整实能量 Hessian PSD。该矩阵的饱和零行恢复六条完整 Ward 等式；进一步可写成12个最高8次的实等式及6×6最高14次的 Hermitian PSD 条件。该接口保留真实根结构，能够与本页所有约束联合使用。

已经执行并重放的部分覆盖含60021个节点，但仍有21个开放坐标区域。[覆盖报告](../joint-closure/reports/cover.json)不是整个剩余系统的无解证书。覆盖中的严格子集、半径上界只用于假想全局最优者；不能无条件移用到所有稳定驻点。最新径向剩余门槛是 E_q>1/1200，原先的1/40000已经被加强。
