# 保留非线性角向代价后的严格循环缺额

2026-11-08。蒋丰灿研究项目；推导、精确证书及代码包含 OpenAI Codex 协作。本文加强既有[连续相位缺额](../general-structure/CONTINUOUS_PHASES.md)及[分数循环预算](../phase-packing/PROOF.md)，不改变它们的归属，不作全球优先权声明。

本轮沿用相同人口、半径和打包权重，改进的是**单条循环的角向代价下端**，没有再次把旧分数打包作为新结果。证书对指定正规环家族的全部连续相位成立；一般 n 点最优构型不被假定为多环。本文没有求出精确角向最小值，也没有求出无约束 M_n。

## 1. 精确边代价与奇循环约束

沿用第 i 环人口 m_i>=2、半径 r_i、物理相位 theta_i，并允许 h=0 或 1 个原点。不同环半径严格递增。设 n=h+sum m_i，Q=sum m_i r_i^2，N=n(n-1)/2，归一化距离积 F=(n/Q)^N Delta。对边 e=ij 记

```math
g_e=\gcd(m_i,m_j),\quad L_e=\operatorname{lcm}(m_i,m_j),\quad
\eta_e=\frac{4r_i^{L_e}r_j^{L_e}}{(r_i^{L_e}+r_j^{L_e})^2}\in(0,1).
```

令 epsilon_e 为 L_e(theta_i-theta_j)-pi 在 [-pi,pi] 中的有向代表，x_e=|epsilon_e|/pi 属于 [0,1]。由交叉 resultant，环对相对于其独立最大值的精确对数缺额是

```math
\delta_e=-g_e\log\left(1-\eta_e\sin^2(\pi x_e/2)\right).
```

取简单定向循环 C，L_C=lcm(m_i:i in C)，a_e=L_C/L_e。若 sum a_e 为奇数，则

```math
\sum_{e\in C}a_e\epsilon_e\in\pi(2\mathbb Z+1),
\qquad \sum_{e\in C}a_ex_e\ge1.
```

令 U_pair 为同环、原点项保持准确、各跨环因子独立最大化的归一化乘积。既有恒等式是

```math
\log(U_{\rm pair}/F)=\sum_e\delta_e.
```

以前用 sin(pi x/2)>=x、-log(1-y)>=y 和 Cauchy，得单循环下端

```math
\Gamma_C=\left(\sum_{e\in C}\frac{a_e^2}{g_e\eta_e}\right)^{-1}.
```

这一步同时丢弃了正弦的弯曲和对数的非线性。本轮分别保留这两种余量。

## 2. 一个不需角向搜索的普遍对数加强

设 G_C=sum_(e in C)g_e，A=sum g_e eta_e x_e^2。上述 Cauchy 仍给 A>=Gamma_C。因为 -log(1-y) 为凸函数，且 sin^2(pi x/2)>=x^2，按 g_e/G_C 加权 Jensen 得

```math
\sum_{e\in C}\delta_e
\ge-G_C\log(1-A/G_C)
\ge-G_C\log(1-\Gamma_C/G_C)
>\Gamma_C.
```

所有 eta_e<1，故 A<G_C。又由 Cauchy，sum a_e^2/(g_e eta_e)>(sum a_e)^2/G_C，特别有 0<Gamma_C<G_C。若只需严格有理数，可取任意整数 K>=2，使用

```math
\boxed{\sum_{e\in C}\delta_e\ge
J_{C,K}:=G_C\sum_{k=1}^{K}\frac{(\Gamma_C/G_C)^k}{k}
>\Gamma_C.}
```

本轮固定 K=6。这是通用于所有奇循环的解析加强，不依赖数值寻找相位。它只保留了对数的一部分余量，下面的完整正弦下界还能给出更大的改进。

## 3. 有理正弦与对数下多项式

固定有理数

```math
\pi_- =3141592653589793/10^{15},\qquad
\pi_+ =3141592653589794/10^{15},\qquad
\pi_-<\pi<\pi_+.
```

接受器用 Machin 恒等式 pi=16 atan(1/5)-4 atan(1/239)，以及每个 atan 的 20 项交错级数包围，重新证明这两个端点。恒等式的有理核对为 tan(2 atan(1/5))=5/12、tan(4 atan(1/5))=120/119，再减 atan(1/239) 后正切恰为 1。交错级数还验证 0<4 atan(1/5)-atan(1/239)<1<pi/2，排除正切的周期歧义。这里未把浮点 pi 当作严格输入。

定义八次有理多项式

```math
S(x)=\frac{\pi_-^2x^2}{4}-\frac{\pi_+^4x^4}{48}
     +\frac{\pi_-^6x^6}{1440}-\frac{\pi_+^8x^8}{80640}.
```

**引理。** 在 0<=x<=1 上，0<=S(x)<=sin^2(pi x/2)<=1。

**证明。** 在 0<=t<=pi 上，cos t 的八次交错 Taylor 截断是上端，因而

```math
\sin^2(t/2)\ge t^2/4-t^4/48+t^6/1440-t^8/80640.
```

该截断后的尾项为交错递减项，首个遗漏项对 cos 为负；使用正项的 pi 下端和负项的 pi 上端得到 S。另一方面，因 x^2、x^6<=1，直接丢掉 S/x^2 中的正 x^4 项可得

```math
S(x)\ge x^2\left(\pi_-^2/4-\pi_+^4/48-\pi_+^8/80640\right)\ge0.
```

括号严格为正，由有理比较重算；x=0 时结论显然。

因此，对任何有理 0<eta<1、正整数 g，下面的二十四次有理多项式是完整边代价的全区间下端：

```math
B_{g,\eta}(x)=g\left[\eta S(x)+\frac{(\eta S(x))^2}{2}
                         +\frac{(\eta S(x))^3}{3}\right]
\le-g\log(1-\eta\sin^2(\pi x/2)).
```

这使用 -log(1-y)=sum_(k>=1)y^k/k 的非负尾项；因为 0<=eta S(x)<1，不存在越过对数定义域的问题。这里只取三项，既保持精确接受成本较低，也保留远多于原来的二次代价。

## 4. 单循环的非线性标量对偶

为一个奇循环选择有理 p>=0，并对每条边选择有理 b_e>=0。如果能够证明

```math
B_{g_e,\eta_e}(x)-p a_e x+b_e\ge0
\quad\text{对整个 }x\in[0,1],
```

那么直接求和有

```math
\sum_{e\in C}\delta_e
\ge p\sum_{e\in C}a_ex_e-\sum_{e\in C}b_e
\ge\boxed{D_C:=p-\sum_{e\in C}b_e}.
```

这是由资源条件 sum a_e x_e>=1 导出的全相位对偶下端。不要求边多项式凸，也不要求找到真实相位临界点。p、b_e 的探索可使用浮点标量搜索，但接受完全依赖下一节的有理全区间不等式。本文没有声称保存的 p、b_e 是这个对偶的精确最优解。

## 5. Bernstein 连续覆盖：不是取样接受

对待证多项式 R(x)=sum_(j=0)^d c_j x^j，d=24，使用精确恒等式

```math
R(x)=\sum_{k=0}^d b_k {d\choose k}x^k(1-x)^{d-k},
\qquad b_k=\sum_{j=0}^k c_j\frac{{k\choose j}}{{d\choose j}}.
```

Bernstein 基函数在 [0,1] 非负、总和为 1，所以所有 b_k>=0 就证明整个区间非负。系数含负项时，在 1/2 处用 de Casteljau 精确细分。将根系数清成共同正分母后，所有后续运算只需要整数加法与二进移位；分母改变不会影响符号。

每个叶盒保存从根开始的二进路径。接受器从根多项式重建该路径的所有整数系数，检查叶盒中每个 Bernstein 系数非负，并递归检查每个非叶结点都有两个被覆盖的孩子。缺少叶、重复叶、暗藏未检查后代或不完整区间都会被拒绝。因此验证的是整个 [0,1]，没有用有限取样替代连续覆盖。

所有原始支持线都留有少量有理余量，允许有限细分得到非负系数。报告中的树深与叶数记录实际执行范围；没有声称任何任意输入都能在固定预算内终止。

## 6. 半径盒与原有打包权重

若 r_i 属于互不相交且按半径递增的有理区间 [l_i,u_i]，则对 i<j 取

```math
q_e^-=(l_i/u_j)^{L_e},\qquad
\eta_e^-=4q_e^-/(1+q_e^-)^2\le\eta_e.
```

因为 q 属于 (0,1) 时 4q/(1+q)^2 的导数为正，边代价也随 eta 增加而增加，所以将 eta_e^- 代入上述多项式和支持证书，就对整个半径盒有效。

对若干循环沿用非负权 lambda_C，要求每条边的权重总和不超过 1。于是

```math
\sum_e\delta_e\ge\sum_C\lambda_C D_C=:D.
```

没有额外重复花费同一边。所有权重都由接受器重新核对。本轮四正方形环仍给四个三角形各权 1/2；二十五点例仍仅给原四循环权 1。新的 D 增益完全来自单循环代价。

使用与此前相同的端点乘积上端

```math
U_{\rm box}=\left(\frac n{\sum_i m_i l_i^2}\right)^N
\prod_i m_i^{m_i}u_i^{m_i(m_i-1)+2hm_i}
\prod_{i<j}(u_i^{L_{ij}}+u_j^{L_{ij}})^{2g_{ij}},
```

便得到

```math
\boxed{F\le U_{\rm box}e^{-D}\le U_{\rm box}/(1+D).}
```

本轮比较始终使用同一个 U_box 和同一个最终有理化方式，保证改进来自角向缺额，而不是混淆归一化或改变比较家族。

## 8. 验证范围和研究边界

正式接受仅使用 Python 标准库与精确整数/Fraction，不调用浮点三角函数、数值全局优化器或存储的“成功”标记。三份证书的完整角向覆盖共有 291 个 Bernstein 叶；另独立验证 360 个多项式与子区间参数恒等式、140 个精确特殊角及有理对数检查，并对半径盒 16 个角点与五组有理旋转共 80 个十六点构型直接相乘 120 个平方点距。20 种有意篡改均被拒绝，接受检查在 -O 下保留。

有限坐标检查只验证实现。连续相位和半径盒结论来自第 1 至 6 节的解析证明与完整 Bernstein 覆盖。实现有明确人口、lcm、树深及叶数预算，超限拒绝；数学定理没有这些实现限制。

更高阶正弦或对数下端、更细支持函数、与人口和半径分支定界的联合仍可加强本方法。当前证书不认证角向真实最优值，不覆盖全部人口和半径，也没有证明一般最优者由正规环或某个晶格组成。原问题的 n>=10 全局锐值与全构型分类依然开放于本研究范围。
