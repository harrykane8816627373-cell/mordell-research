# 非线性角向代价：更强的全相位循环缺额

蒋丰灿研究项目；推导与精确代码包含 OpenAI Codex 协作。2026-11-08。

本专题保持[既有分数循环预算](../phase-packing/README.md)的人口、半径和打包权重，保留正弦与对数的非线性余量，严格加强单循环缺额。**结果适用于指定正规环家族的全部连续相位和所列半径盒，未求出一般 M_n 或精确角向最小值。**

|家族|上一最优循环预算|新认证预算|
|---|---|---|
|四正方形环，半径 9/10、1、11/10、6/5|约 2.361949769|5.97446865|
|四个半径各扩展正负 1/10000 的整个盒|约 2.361383048|5.97277165|
|25 点人口 8、6、3、8 的既有四循环|约 0.064856080|0.1591666|

四正方形环的同口径有理上界降低超过 51.7%；25 点固定家族降低超过 8.1%。新预算超过此前预算 2.5 倍、2.5 倍和 2.4 倍；这些倍数描述可认证下界的改进，未声称真实最优能量改变了该倍数。

方法有两个层次：用加权 Jensen 保留对数，可无条件严格加强旧 Gamma；进一步用有理八次正弦下端及三项对数下端，对每条边构造全区间仿射支持。支持不等式通过整数 Bernstein 细分完整覆盖 [0,1]，再由奇循环的加权角偏差至少为 pi 推出更大缺额。没有重新运行或重新包装旧打包 LP。

从仓库根目录接受固定证书：

```bash
python -B -S -O phase-deficit-sharp/verify_all.py
```

仅需 Python 标准库，正式接受没有浮点三角函数或数值优化依赖。三份固定证书有 291 个 Bernstein 叶；独立核对 360 个多项式恒等式、140 个特殊角/对数检查、80 个直接有理坐标十六点构型，并拒绝 20 种输入破坏。详细记录见[实际执行报告](verification_report.json)。
