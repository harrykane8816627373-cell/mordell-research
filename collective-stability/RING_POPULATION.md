# 从同层角向装点和总矩得到更强的全 n 层数界

研究资料与项目发起：**蒋丰灿（Fengcan Jiang）**；本轮推导、程序及核验包含 OpenAI Codex 协作。2026-10-29。

本节联合用户此前已经证明的严格子集间距、任意圆周上的装点限制和总二阶矩。**不要求同一层等角，也不要求构型由正规多边形组成。**

## 1. 普遍结论

在 Σ|z_i|²=n 归一化下，任意全局最大构型相对重心的不同半径数 K 满足

~~~math
\boxed{K>\frac{n}{\pi\sqrt{n-1}}>\frac{\sqrt n}{\pi}\qquad(n\ge2).}
~~~

这把此前适用于全部 n 的常数3/22提高到1/π≈0.3183。证明用到的严格子集矩定理属于用户原有成果；本节不把它重新列为新定理。

该结论只适用于全局最大点，不推广到所有驻点或局部最大点。本专题另有更强的渐近层数结论；不能把渐近起点未知的结论直接替代本节有限 n 保证。

## 2. 同层人口产生一个立方代价

原有[严格真子集矩定理](../finite-n/SUBSET_PROOF.md)给出：n≥3的任意全局最大点，其任意两点满足

~~~math
|z_i-z_j|^2>\frac4{n-1}.
~~~

这是比旧局部稳定性基本间距2n/(n−1)²更强的**全局**必要条件；其推导见[用户一般结构原稿](../earlier-results/general_n_structural.tex)。

一条平方半径为 q、人口为 m≥2 的层上，最小相邻角间隔不超过2π/m，因此某对点的距离满足

~~~math
|z_i-z_j|^2\le4q\sin^2(\pi/m)
\le\frac{4\pi^2q}{m^2}.
~~~

与严格间距联立得 q>m²/[π²(n−1)]。所以每条人口至少2的层，对总二阶矩的贡献严格大于 m³/[π²(n−1)]。

若层人口为 m_1,…,m_K，必须满足

~~~math
\boxed{\sum_{j:m_j\ge2}m_j^3<\pi^2 n(n-1).}
~~~

单点层必须单独保留，不能把m=1也套入同圆相邻点公式；可能存在的原点属于一条单点层。

## 3. 正确处理单点层

设 S 为单点层数。若 K≤2n/3，则至少存在一条多点层，且凸性给出

~~~math
\sum_{m_j\ge2}m_j^3
\ge\frac{(n-S)^3}{(K-S)^2}.
~~~

对于0≤s<K，

~~~math
\frac{d}{ds}\frac{(n-s)^3}{(K-s)^2}
=\frac{(n-s)^2(2n-3K+s)}{(K-s)^3}\ge0.
~~~

因此上述和至少为n³/K²，代入立方预算就得到K>n/[π√(n−1)]。若 K>2n/3，则因π>3、n≥3，同一结论直接成立。n=2的全局最大点为等长反向的一对点，K=1>2/π，单独验证即可。至此覆盖全部 n。

## 4. 保留整数人口，进一步改善有限判定

给定n和K，不必把立方代价只放松成连续量。若有S条单点层，剩余d=K−S层人口至少2、总人口P=n−S。固定S时，最小立方和由人口尽量均衡达到：写P=bd+r，0≤r<d，则

~~~math
C_S=(d-r)b^3+r(b+1)^3.
~~~

这是因为把相差至少2的两个人口各向中间移动1，会严格降低立方和。于是对全部合法S完整取最小值

~~~math
C(n,K)=\min_{\max(0,2K-n)\le S<K} C_S,\qquad C(n,n)=0.
~~~

若 C(n,K)≥π_U² n(n−1)，其中π_U是任意已认证的π上端，就排除所有K层全局最优构型。由于每次把一层拆成两条非空层会降低代价，C(n,K)关于K不增，可以用二分查找最后被排除的K。

实现使用Machin恒等式π=16 arctan(1/5)−4 arctan(1/239)及交错级数，给出纯有理π上下端。恒等式由正切加法验证；相应角在(0,π/2)，避免正切周期歧义。预算不足时拒绝完整计算，不把部分枚举结果宣称为最优。

程序也可直接接受一个人口序列，用同一个预算排除它；这种排除不依赖每层具体半径或角度，也不证明所有未排除人口可实现。
