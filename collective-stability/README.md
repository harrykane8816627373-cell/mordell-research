# 一般 n 构型：更强层数定理、局部能量与多点稳定性

研究资料与项目发起：**蒋丰灿（Fengcan Jiang）**；推导、程序与交叉审阅包含 OpenAI Codex 协作。2026-10-29。承接提交 a4f6cf6485dfab7690213bc99a51b7fd8f4df43d。

本轮得到两条更强的通用层数保证，并补充局部角向和多点联合约束。一般 n 的完整最优构型、八点完整锐值和精确渐近常数 γ 仍未确定。

## 1. 全 n 的层数保证加强到1/π

任一全局最优构型相对重心的不同半径数 K 满足

~~~math
\boxed{K>\frac{n}{\pi\sqrt{n-1}}>\frac{\sqrt n}{\pi}\qquad(n\ge2).}
~~~

此前通用系数为3/22。本节把用户已有的严格子集间距，与同一圆周的角向装点和总二阶矩结合；同一层角度完全任意。单点层单独处理，避免对原点或独立半径上的单点使用不存在的相邻弦。

更细的整数人口预算为

~~~math
\sum_{j:m_j\ge2}m_j^3<\pi^2n(n-1).
~~~

所有整数人口分配的最小代价可完整计算，再给必要层数。该方法在n=1000、10000分别给至少11、32层；与其他既有层数界联合时取较强者，不声称它在所有有限点数都最强。

[证明](RING_POPULATION.md) · [实现](ring_population.py) · [65534个独立整数分拆复核](ring_population_verification.json)

## 2. 渐近层数保证提高到13/30

新方法将径向区间分成128格，隔离每格的内部空隙，同时保留各格共享的总层数预算。127条有理凸切线消去全部未知分配，给任意归一化构型

~~~math
\frac{\delta(z)}n\ge
B-\frac7{100}\frac{K+127}{\sqrt n}-\frac1{4400},\qquad
B=\frac{52147603526844565517847}{1638400000000000000000000}.
~~~

结合此前已注明的线性渐近项与三角试探下界，严格推出

~~~math
\boxed{\liminf_{n\to\infty}\frac{K_n}{\sqrt n}\ge\frac{13}{30}.}
~~~

新常数约0.433333，此前为101/250=0.404。该结论保留渐近量词；没有给出把13/30直接用于每个有限 n 的有效起始阈值。上面的有限式则始终保留127修正，并可输入另行证明的实际缺额预算。

[完整证明与外部输入边界](RADIAL_QUANTIZATION.md) · [有理凸对偶](radial_quantization.py) · [127条固定切线证书](radial_quantization_verification.json)

## 3. 把角向能量局部化到环带

新的分段调和帽函数只测量指定圆盘或环带。不同角向模式正交；同一模式在支撑不交的环带上也可相加。整片平滑圆盘位于单个调和区时，其测量可用中心值精确求出；可能穿越界面的输入会被拒绝。

帽函数与径向缺额可以联合，并给带有角向集中、不抵消条件的局部人口上界。这些条件必须明确证明，不能由人口或径向带单独推断角度。

若全局支撑圆包含帽子的全部支撑，全纯零级矩与帽函数即使同一角向模式也正交，可以额外相加；更高径向次数通常需要完整Gram矩阵。

正文展示一个非空类的排除及与指定旧全局一级角向投影的比较。该类也会被本专题人口预算排除，因此例子用于展示新局部测量接口，不声称所有旧方法都无法处理它。

[证明](LOCAL_ENERGY.md) · [实现](local_energy.py) · [精确复核](local_energy_verification.json)

## 4. 从两点检验推进到多点联合稳定性

对用户原有稳定性算子的饱和投影，取两个不相交点集的交叉块，得到一个可直接接受的正半定矩阵条件。总三点时，它新增一个联合行列式约束；其对角项正好恢复旧两点式。

两个明示的八点坐标邻域都通过旧两点检验，却被新块条件整体排除。其中一个邻域还通过已有的较强全局点距和半径限制。每个原始坐标可在实、虚方向各变化±1/100，再中心化归一化；全部区间由有理数覆盖。

这是原完整稳定性算子的有限压缩，强于所比较的标量条件，不比原完整算子条件更强。通过某个块也不能证明局部或全局最优。
