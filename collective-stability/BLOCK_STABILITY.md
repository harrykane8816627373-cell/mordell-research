# 从饱和稳定性到三点及交叉点集联合约束

研究资料与项目发起：**蒋丰灿（Fengcan Jiang）**；本轮推导、程序及交叉审阅包含 OpenAI Codex 协作。2026-10-29。

原稿已证明的完整二阶算子必要条件是本节输入，不登记为新发现。本节提取只使用不同点之间矩阵元的有限块约束：总三点的联合条件可以排除所有旧局部两点检验都通过的厚区域；一个总六点的交叉块还排除连旧全局点距、半径条件也全部通过的厚区域。**这些压缩条件不比原完整算子条件更强，不给新的无条件锐值。**

## 1. 任意交叉点集的正半定必要条件

设无碰撞归一化构型满足 Σz_i=0、Σ|z_i|²=n。若它是局部最大，令 λ=(n−1)/2，则用户原稿中的复对称稳定性矩阵 B 满足

~~~math
B\mathbf1=0,\qquad Bz=\lambda\overline z,\qquad \|B\|\le\lambda,
\quad B_{ij}=-(z_i-z_j)^{-2}\quad(i\ne j).
~~~

出处与适用条件见[用户修订主稿](../source-review/revised_main.tex)及[此前两点归约](../symmetry-breaking/PAIR_STABILITY.md)。定义

~~~math
P=I-\frac{\mathbf1\mathbf1^*}{n}-\frac{zz^*}{n},
\qquad
C=B-\frac\lambda n\overline z\,\overline{z}^{T}.
~~~

饱和分解给出 `C=overline(P) C P`、`||C||≤λ`。对任意不相交非空点集 I,J，有

~~~math
\boxed{\mathcal K_{I,J}:=
\begin{pmatrix}
\lambda\overline P_{I,I}&C_{I,J}\\
C_{I,J}^*&\lambda P_{J,J}
\end{pmatrix}\succeq0.}
~~~

证明：将 u∈C^I、v∈C^J 嵌入全空间，令 a=||overline(P)u||、b=||Pv||。交叉项的绝对值至多 λab，所以对应二次型至少 `λ(a−b)²≥0`。

不相交假设用于避免 B 的对角元：全部 C_ij 都能直接从所选点计算，不涉及未选点的相互作用之和。P 的分母 n 和归一化必须保留。较大点集的正半定条件包含其所有较小交叉子块条件；但本节没有声称这组不相交子块足以恢复完整算子条件。

它适用于所有局部最大，因此也适用于全局最大；不要求驻点分类、正规环、等半径或反射对称。通过条件不能反推局部或全局最优。

## 2. 总三点：旧两个标量对角之外，必须再保留一个行列式

取 I={i}、J={j,k}，三者互异。记 p_i=P_ii，以及 c_j=C_ij、c_k=C_ik。上一式等价地给出

~~~math
H_{i;jk}:=\lambda^2p_i
\begin{pmatrix}P_{jj}&P_{jk}\\P_{kj}&P_{kk}\end{pmatrix}
-\begin{pmatrix}\overline c_jc_j&\overline c_jc_k\\
\overline c_kc_j&\overline c_kc_k\end{pmatrix}\succeq0.
~~~

因此，除了两个对角非负，还必须有

~~~math
\boxed{H_{jj}H_{kk}\ge
\left|\lambda^2p_iP_{jk}-\overline c_jc_k\right|^2.}
~~~

p_i>0 时由 Schur 补直接得到；p_i=0 时原行范数界强迫 c_j=c_k=0，结论仍成立，无需除以零。

令 a=|z_i|²、b=|z_j|²、s=|z_i−z_j|²，旧两点表达式为

~~~math
T_{ij}=(n-1)\left(s-\frac{2n}{(n-1)^2}\right)
\left[1+\frac{n-1}{2n}(n-1-a-b)s\right]-(a-b)^2.
~~~

精确代数展开得到

~~~math
\boxed{H_{jj}=\frac\lambda{ns^2}T_{ij}.}
~~~

故三个点的新信息确实来自联合行列式，不是把两个旧标量约束重新命名。一般单行对多列 J 的矩阵 `λ²p_i P_JJ−C_iJ* C_iJ` 也必须正半定，实现支持这个接口。

## 3. 一个全部旧局部两点通过、总三点联合失败的厚类

取八个原始有理点

~~~math
u=\{(7,0),(5,6),(0,8),(-4,4),(-7,1),(-3,-6),(1,-8),(4,-3)\}.
~~~

对任何原始点组，统一定义

~~~math
v_i=u_i-\frac18\sum_a u_a,\quad Q=\sum_i|v_i|^2,
\qquad z_i=\sqrt{8/Q}\,v_i.
~~~

这样自动中心化、归一化。本例全部28个旧 T_ij 严格正，全部距离也严格超过旧局部基本下界16/49。取人类编号 `(i,j,k)=(4,3,5)`，即代码零基索引 `(3,2,4)`。两个 H 对角均严格正，但 `det H<0`，约为 −12.289955，仅供展示。

更强地，让上述每个 u_i 的实、虚坐标**分别独立变化 ±1/100**，再作相同中心化、归一化。接受程序用 Fraction 区间运算证明：

- 整个坐标盒内全部28个旧局部两点条件仍严格通过；
- 整盒三点 Schur 行列式的上界严格小于 −5。

因此这是明确非空、有宽度的被排除类，不是依赖浮点舍入的单点反例。该例的旧**全局**间距界 `s>4/(n−1)` 不通过，所以只用它比较旧局部两点约束；不能声称它避开了此前所有全局必要条件。

## 4. 总六点的3+3交叉块：连更强旧点距、半径也通过

取近正八边形的整数点

~~~math
u=\{(70,0),(49,49),(0,70),(-49,49),(-70,0),
(-49,-49),(0,-70),(49,-49)\}.
~~~

它已经中心化，Q=38808，故 z_i=u_i/√4851。全部28个旧两点条件通过，而且

~~~math
\min_{i<j}|z_i-z_j|^2=\frac{2842}{4851}>\frac47,
\qquad
\max_i|z_i|^2=\frac{4900}{4851}<\frac74.
~~~

右侧分别是八点的较强旧全局间距、半径限制；其来源仍属用户原稿及[严格子集证明](../finite-n/SUBSET_PROOF.md)。

取人类编号 `I={1,5,7}`、`J={4,6,8}`，代码零基索引 `I=(0,4,6)`、`J=(3,5,7)`。6×6 Hermitian 块 `K_(I,J)` 有精确负主子式；程序还由有理 LDL 消元提取显式复有理向量 w，使

~~~math
w^*\mathcal K_{I,J}w<-\frac{19}{10}.
~~~

向量、主子式索引和完整有理数见 `block_stability_verification.json`，不以浮点特征值作为证据。

仍让每个原始实、虚坐标独立变化 ±1/100。对**同一固定有理向量 w**作区间二次型估计，整盒均有

~~~math
w^*\mathcal K_{I,J}w<-\frac32.
~~~

与此同时，整盒全部旧 T_ij 仍严格正，且安全区间给出

~~~math
\min_{i<j}|z_i-z_j|^2>\frac{29}{50}>\frac47,
\qquad
\max_i|z_i|^2<\frac{51}{50}<\frac74.
~~~

所以这个非空厚区域由新的交叉块排除，而所列旧两点和全局几何条件均允许。这里是**两个三点集合、总六点**的条件，与上一节真正总三点条件有意区分。仍不声称该类通过原完整算子条件或此前每一个其他全局判据。

## 5. Fraction 接受器与普遍结论的边界

若原始点属于 Q(i√d)，d为正整数，中心化后写成 v，Q=Σ|v|²，则无需引入归一化平方根，直接计算

~~~math
P_{ij}=\delta_{ij}-\frac1n-\frac{v_i\overline v_j}{Q},
\qquad
C_{ij}=-\frac Qn(v_i-v_j)^{-2}
-\frac\lambda Q\overline v_i\overline v_j\quad(i\ne j).
~~~

因此全体主子式和固定二次型都完全有理。Hermitian 矩阵的正半定性用**全部主子式非负**验收；并非只检查顺序主子式。预算在检查前拒绝过大的集合，不把不完整检查登记为通过。零主元退化不影响完整主子式接受；LDL 仅用于可选的负向量提取。

整类证书对有理复坐标盒使用四则运算、平方区间及正距离倒数；中心化均值、Q和尺度依赖全部向外包围。抽样只用于独立检查编码，两个整盒排除结论来自区间覆盖，不来自抽样。

```bash
python -B -S -O collective-stability/verify_block_stability.py
```

实际核验包括：8次独立行列式排列展开；直接构建原完整B并确认范数界的4个稳定例；147个稳定三点压缩；3个稳定交叉块；94次旧标量—新对角恒等式；64个独立区间端点代入；6类非法输入拒绝，以及上述两套完整厚盒证书。稳定例含五点原点加正方形，它是局部最大但非全局最大，故程序没有把通过稳定性误作全局认证。

普遍定理由第1、2节的投影和范数论证证明；有限核验只验证这些明确实例、区间及实现。块条件是可行性必要条件，**不是能量罚项**，不能把负主子式或负二次型数值与径向、角向库仑能量直接相加。没有覆盖完整剩余域就没有新的全局锐值；本节不作全球优先权或整篇形式化验证声明。
