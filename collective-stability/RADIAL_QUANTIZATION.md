# 分区层数预算耦合：把径向层数渐近保证提高到13/30

研究资料与项目发起：**蒋丰灿（Fengcan Jiang）**。推导、精确证书及交叉审阅包含 OpenAI Codex 协作。2026-10-29。

本节建立新的有限分区量化下界。每个径向小区间只由其中的半径层影响内核，不同区间所分配的层数共同受到总层数预算限制。这个耦合保留了此前统一覆盖长度估计所丢失的局部信息。固定128个区间及一组有理切线，得到任意规范构型的显式线性缺额下界，并将全局最优者的已证渐近层数保证从 \(101/250\) 提高到 \(13/30\)。这项提高来自新的分区预算方法，不是对旧平滑参数的小幅调节。

## 1. 结论与适用范围

沿用仓库归一化

```math
M_n=\max_{\sum|z_i|^2=n}\Delta_n(z),\qquad
\Delta_n(z)=\prod_{i<j}|z_i-z_j|^2,\qquad
N=\frac{n(n-1)}2,
```

```math
U_n=n^{n/2}\left(\frac{2n}{n-1}\right)^N e^{-N/2},\qquad
\delta(z)=\log\frac{U_n}{\Delta_n(z)},\qquad
x_i=\sqrt{\frac{n-1}n}z_i.
```

令 K 为这些点相对于指定原点的不同半径数。对任意 n≥2、归一化且无碰撞的构型，固定常数

```math
h=\frac{197}{200},\qquad \lambda=\frac7{100},\qquad
B=\frac{52147603526844565517847}{1638400000000000000000000}
```

给出

```math
\boxed{\displaystyle
\frac{\delta(z)}n\ge
B-\frac7{100}\frac{K+127}{\sqrt n}-\frac1{4400}.}
```

右端可以与0取最大。不需要规则角度、驻点、稳定性或预设最外半径上界。

所以若 \(\delta(z)\le E\) 是一个独立证明的缺额上包，则

```math
\boxed{\displaystyle
K\ge\sqrt n\frac{B-1/4400-E/n}{7/100}-127.}
```

右端再向上取整，可得整数层数必要条件。对全局最优者，可以输入任何已证可达下界 \(L_n\le M_n\) 所给的 \(E\ge\log(U_n/L_n)\)；程序本身不会证明输入下界的有效性。这个有限式没有把127的修正省略。

结合仓库已有的线性渐近项及三角试探界，对任意全局最优构型列，有

```math
\boxed{\displaystyle
\liminf_{n\to\infty}\frac{K_n}{\sqrt n}\ge\frac{13}{30}.}
```

这里半径相对于重心计数；全局最优者的重心已知为零。\(13/30\approx0.433333\)，旧结论为 \(101/250=0.404\)。新的渐近定理没有给出使 \(K_n\ge(13/30)\sqrt n\) 成立的有效有限 n 起始阈值，也没有确定最优构型的各层人口或角度。

## 2. 局部径向内核及层数预算

任取 h>0，令 \(r=h\sqrt{2/n}\)，并定义平滑测度、背景及代价

```math
\mu_h=\frac1n\sum_i\sigma_r(\cdot-x_i),\qquad
\nu_h=\mu_h-\mu_0,\qquad
\psi(h)=\frac{h^2-1}2-\log h.
```

\(\mu_0\) 为半径 \(\sqrt2\) 的均匀圆盘概率。沿用[已有可变平滑分解](../radial-angular/RADIAL_LAYERS.md)：

```math
\delta(z)\ge n^2D(\overline\nu_h)-n\psi(h).
```

上划线表示旋转平均。换用归一化半径 \(u=t/\sqrt2\)，写

```math
G(u)=\mu_h\{|w|\le\sqrt2u\},\qquad
D(\overline\nu_h)=\int_0^\infty
\frac{(G(u)-\min\{u^2,1\})^2}u\,du.
```

这个变换没有额外常数：\(dt/t=du/u\)。每个圆盘的中心半径也作同一变换，圆盘平滑后的径向支撑离中心半径至多

```math
\varepsilon=\frac h{\sqrt n}.
```

取 \([0,1]\) 的任意有限分区。考虑一格 \([a,a+w]\)，只保留开内核

```math
(a+\varepsilon,a+w-\varepsilon).
```

中心半径在这一格外的圆盘，不能进入该开内核；边界相切不影响积分。把分区格约定为左闭右开，最后一格包含最外端点1，以免重复计数。

设这一格有 k 个不同的中心半径。它们对内核的支撑覆盖总长度至多 \(2\varepsilon k\)，补集由至多 k+1 个空隙组成，总空隙长至少

```math
L=(w-2\varepsilon(k+1))_+.
```

这在内核为空时仍成立，右端为0。半径超过1的中心不影响任何格的开内核；不需要假设它们不存在。

## 3. 每格的凸量化代价

在 \((p,q)\subset[0,1]\) 的空隙中，G 是某个常数 c。此前真实权重空隙估计在 u 变量中为

```math
\int_p^q\frac{(c-u^2)^2}u\,du
\ge\frac{(p+q)(q-p)^3}6.
```

这可直接由[半径空隙引理](../radial-angular/RADIAL_LAYERS.md)置 \(t=\sqrt2u\) 得到，或直接积分并使用
\(\log v\ge3(v^2-1)/(v^2+4v+1)\)。由于空隙位于当前格内核，p≥a，所以其贡献至少为 \(a(q-p)^3/3\)。对至多 k+1 个空隙求和，给

```math
D_{\rm core}\ge\frac{aL^3}{3(k+1)^2}.
```

令

```math
y=\frac{k+1}{\sqrt n},\qquad
f_{a,w,h}(y)=\frac{a(w-2hy)_+^3}{3y^2},\qquad y>0.
```

便得到 \(nD_{\rm core}\ge f_{a,w,h}(y)\)。这个函数非负、单调不增且凸。在 \(0<y<w/(2h)\) 上，

```math
f'(y)=\frac a3\left(-\frac{2w^3}{y^3}
+\frac{6hw^2}{y^2}-8h^3\right),\qquad
f''(y)=\frac{2aw^2(w-2hy)}{y^4}\ge0.
```

在其余范围 f=0；一阶导数在衔接点连续为0，因此凸性在整个正半轴成立。a=0 的第一格只给0，可以安全省略。

特别地，若第 j 格的不同半径数为 \(k_j\)，所有格的开内核互不相交，故

```math
\boxed{\displaystyle
\frac{\delta(z)}n\ge
\sum_{j:\,a_j>0}
f_{a_j,w_j,h}\left(\frac{k_j+1}{\sqrt n}\right)-\psi(h).}
```

这也是一个局部层数分配必要条件。各格的人口上限 \(P_j\) 同时是不同半径数上限；由于 f 单调不增，把 \(k_j\) 替成任何已证的上限 \(P_j\) 仍给合法下界。人口数据不能只保留总数，否则会丢失不同格之间的预算信息。

## 4. 用有理切线消去未知的全部分配

现在固定均分 J 格：\(a_j=j/J\)、\(w=1/J\)，使用 j=1,…,J−1 这 J−1 个正左端点格。不同格的层数之和不超过 K，因此

```math
\sum_{j=1}^{J-1}\frac{k_j+1}{\sqrt n}
\le\frac{K+J-1}{\sqrt n}.
```

对任意 z≥0，取切点

```math
y_0=\frac w{2h(1+z)}.
```

直接代入上节导数，得到切线斜率绝对值及截距

```math
\lambda_j=\frac{a_j(2h)^3}3z^2(3+2z),\qquad
b_j=a_jw(2h)^2z^2.
```

凸性说明 \(f_j(y)\ge b_j-\lambda_j y\)。如果每个格都选到有理 z_j，使 \(0\le\lambda_j\le\lambda\)，则对 y>0 有

```math
f_j(y)\ge b_j-\lambda y.
```

因而，设 \(B=\sum_{j=1}^{J-1}b_j\)，不论未知的各格层数如何分配，都有

```math
\boxed{\displaystyle
\frac{\delta(z)}n\ge
B-\lambda\frac{K+J-1}{\sqrt n}-\psi(h).}
```

这是一个完整解析对偶证明；不需要执行所有整数层数分配枚举，也不需要证明某个数值优化器找到了全局最小。

选择 z_j 的接受方式非常简单：给定一个网格分母 S，取满足

```math
z^2(3+2z)\le\frac{3\lambda}{a_j(2h)^3}
```

的最大非负网格点 \(z=m/S\)。左边严格递增，整数二分搜索可以完整找到它。程序同时核对该点满足不等式且下一网格点不满足。即使使用较粗的合法下根，切线证明仍成立；更精细的网格只是提高截距 B。

## 5. 固定证书与13/30的严格比较

取

```math
J=128,\qquad h=197/200,\qquad \lambda=7/100,\qquad S=10^8.
```

对第4节的127个单调三次式分别取最大合法网格点，精确截距和为

```math
B=\frac{52147603526844565517847}{1638400000000000000000000}.
```

全部 z_j 随[验收报告](radial_quantization_verification.json)保存；每个点的合法性、相邻格点以及截距总和均可独立用整数／有理数复算。

平滑代价的简短有理上包为

```math
\psi(197/200)<\frac1{4400}.
```

例如在 y=3/397 处，对 \(\log(200/197)\) 用 atanh 级数4项及显式几何尾项上包，再加 \((h^2-1)/2\)，即可严格验收这个比较。由此得到第1节的有限线性不等式。

已有[线性渐近项及常数证书](../asymptotics/README.md)给全局最优缺额

```math
\frac{\delta_n}n\longrightarrow\gamma_D-\gamma
\le\gamma_D-\gamma_\triangle<\frac1{800}.
```

这里沿用原文的外部重整化能量定理及三角晶格试探下端，并未证明三角晶格在全部允许构型中全局最优。对有限线性不等式重新排列并取下极限，得到

```math
\liminf\frac{K_n}{\sqrt n}
\ge\frac{B-1/4400-1/800}{7/100}
=\frac{78142805542184317242331}{180224000000000000000000}
>\frac{13}{30}.
```

最后一步的完整正余量为

```math
B-\frac7{100}\frac{13}{30}-\frac1{4400}-\frac1{800}
=\frac{960516385870662088951}{54067200000000000000000000}>0.
```

因此本文采用较简洁的 \(\liminf K_n/\sqrt n\ge13/30\) 表述。分区数128、平滑参数与斜率均未宣称最佳；后续可以增加分区、优化分区端点，或联合其他互不重复的能量信息。

## 6. 精确人口接口及实现

[radial_quantization.py](radial_quantization.py) 中：

- `dual_constants` 构造任意均分格数、正有理 h、正有理斜率的合法凸对偶证书；`fixed_layer_certificate` 是本文固定的127条切线。
- `uniform_delta_lower` 给指定层数上限的整类缺额下界；`necessary_layers` 输入另行已证的缺额上包，给带有限修正的整数层数必要条件。
- `allocation_delta_lower` 保留各格不同半径数或点人口的上限，执行第3节的局部量化和。
- `exact_radial_census` 输入库仑尺度的有理平方半径，只比较 \(q_i\) 与 \(2(j/J)^2\)，精确清点各格点人口和不同半径数。它不需要计算平方根，也不推断角度、非空性或最优性。

点人口上限通常比实际不同半径数上限弱，但二者都可以直接作为区域条件。不同半径数必须按指定原点计数；在全局最优问题中取已知为零的重心。改变原点可以改变层数，不能任意混用不同原点的数据。

运行

```bash
python -B -S -O verify_radial_quantization.py
```

验收包含单调三次根的外包方向、凸切线恒等式、局部内核几何、所有4格小层数分配对照、固定127个切点、截距和、短平滑代价、渐近正余量、实际有理人口清点及非法输入拒绝。所有接受判断均用整数和 Fraction，浮点近似不承担证明。

## 7. 联合使用与研究边界

本节控制的是 \(D(\overline\nu_h)\)。它可以与同一 h 下有严格正交性证明的角向或混合矩能量相加，再扣除一次 \(n\psi(h)\)。各格内核互不重叠，已在上述求和中处理；另一个覆盖相同内核的完整径向下界应取最大值，不能重复相加。

新有限式可以与其他已证层数必要条件共同取较强者。全局最优值的渐近缺额只有未知有效阈值的外部定理时，13/30必须保留渐近量词；不能把它标为所有有限 n 都成立的无修正系数。

原圆盘平滑及真实空隙权重来自[已有径向层数证明](../radial-angular/RADIAL_LAYERS.md)，外部渐近来源仍见[渐近专题](../asymptotics/README.md)。新增部分是局部内核隔离、共同层数预算的凸对偶，以及对应纯有理固定证书。本文不作全球优先权声明；协作审阅及程序验收不等于外部同行评审或整篇形式化证明。一般 n 最优构型的完整分类、全八点锐界和精确 γ 仍开放。
