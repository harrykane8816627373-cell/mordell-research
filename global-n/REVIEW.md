# 审阅记录与证明范围

研究资料与项目发起：蒋丰灿。2026-10-27。

- 网格误差由主推导与两份协作推导分别核对，均得到同一二阶抵消式。依赖此前已证的全局力方程、Gaussian二阶条件及严格子集点距；不要求驻点非退化。
- 随机子集四阶方差恒等式、共享边计数、强对数凹性损失及最终指数由另一协作审阅单独检查；相邻严格性由取等条件和实Gram秩证明。
- 实现审阅发现有理平方根向上包围可能在停止条件的精确边界过粗；已将它与另一个合法有理上界 a_n/q 取最小。回归例为 n=9、ε=21/179、q=20。
- 子集删格条件保留明确圆整误差，只用于保证真实最优点附近的网格见证被保留。没有把最优点的原始必要条件直接施加给所有格点。
- 已公开小网格均为完整穷举；1%计划仅为未执行的工作量说明。方差折扣改善普通递推，但当前没有超过圆盘上界的结果。
- 一般 n 闭式、八点完整锐界、一般非零矩分支、精确微观常数及真实边界修正仍未解决。

本审阅来自同一 AI 协作工作流，不是外部同行评审。程序核对有理算术、系数和有限完整枚举；解析量词由证明承担。旧的高阶矩、有限代数性和外部渐近定理没有改作本轮新发现。
