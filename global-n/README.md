# 一般 n：严格跨点数递推、平面方差与有效全局网格

研究资料与项目发起：**蒋丰灿（Fengcan Jiang）**；证明推导、整理及程序核验包含 OpenAI Codex 协作。日期：2026-10-27。

来源更正（2026-10-28）：完整原稿已经包含明确网格、全局误差及相邻严格单调性证明。本专题保留这些旧成果的重述，并整理后续子集方差、替代误差及安全删格。详见[完整源码核对与补充](../source-review/README.md)。**尚未得到一般 n 的简洁全局最大值公式，也未证明八点完整锐界。** 以下证明给出新的结构兼容条件，以及对每个有限 n 有保证的构型和全局包围。

```math
M_n=\max_{\sum_i|z_i|^2=n}\prod_{i\lt j}|z_i-z_j|^2,
\qquad N_n=\frac{n(n-1)}2.
```

## 1. 重述原稿严格递推，并保留后续方差补充

定义标准化最大值

```math
d_n=\frac{n-1}{n}M_n^{1/N_n}.
```

则

```math
\boxed{d_2=d_3=2,\qquad d_n\lt d_{n-1}\quad(n\ge4).}
```

下述相邻严格单调性及其证明已见用户原修订稿，不是2026-10-27首次所得；一般m子集的完整平面方差恒等式另作为补充保留。证明不分类驻点。先将所有 m 点子集的最优值比较相乘，再对内部二阶矩取对数平均。若相邻递推取等，删去任一点后都须仍是对应点数的全局最优构型。两套驻点力方程相减迫使每对点等距，所得实 Gram 矩阵秩为 n−1，与平面秩≤2矛盾。

仅有严格性还不能给出可用折扣。为此，设 S 为均匀随机 m 子集，并记 Q_S 为其内部二阶矩。对任意中心化、总二阶矩 n 的平面构型，有

```math
\boxed{\displaystyle
\operatorname{Var}(Q_S)\ge
\frac{n(m-1)(n-m)(n-m-1)}{m(n-1)^2(n-2)}
\quad(n\ge4,\ 2\le m\le n-2).}
```

[完整英文证明](RECURRENCE_PROOF.md)给出包含 Σ|z|⁴及 |Σz²|² 的精确恒等式。保留对数平均的方差损失，得到

```math
\boxed{\displaystyle
M_n\le M_m^{N_n/N_m}
\left[\frac{n(m-1)}{m(n-1)}\right]^{N_n}
\exp\!\left[-\frac{n(n-m)(n-m-1)}{4m(n-2)L}\right].}
```

可取 L=min{n,2m(n−1)/n,n−(n−m)(n−m−1)/(n−1)}；此前显式子集余量还能进一步减小 L，公式见完整证明。该式严格改善普通子集递推。以已有小点数锐值作比较时，它仍未超过已发表圆盘上界，故不宣称刷新目前的总体上界。

## 2. 原稿网格路线的替代误差与安全筛选

在有限整数方格中穷尽所有 n 点子集，中心化并缩放到总二阶矩 n，取精确有理乘积的最大值 G_n(q)。[完整中文证明](GRID_PROOF.md)明确规定方格边界、目标函数和穷尽范围。

此前力方程抵消圆整的一次项，完整二阶条件控制二次项，严格点距控制对数尾项。令 a_n=ceil√((n−1)/2)，则

```math
\boxed{\displaystyle
G_n(q)\le M_n\le G_n(q)
\exp\!\left(\frac{7n(n-1)}{12q^2}\right)
\qquad(q\ge(n+1)a_n).}
```

G_n(q)单调上升到 M_n，每个网格见证都是实际可达构型。指定正有理相对误差 ε 后，只需预先再令

```math
q^2\ge\frac{7n(n-1)(1+\varepsilon)}{12\varepsilon},
```

便得到完全有理的有限证书 G_n(q)≤M_n≤(1+ε)G_n(q)。这条路线直接给构型，区别于此前系数矩路线；它不替代旧稿已经证明的有限代数选择定理，也没有降低其全部计算复杂度。

旧的严格子集有理余量也被转为含圆整误差的删格条件：真实最优点的最近圆整必定保留，因而不会误删全部最大构型附近的见证。不能直接要求每个归一化格点满足真实最优点的必要条件。
