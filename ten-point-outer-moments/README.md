# 十点最大构型的外点角矩与配对

蒋丰灿研究项目，OpenAI Codex 协作。

在质量 \(\sum_i|x_i|^2=9\) 下，将任一十点全局最大构型的八个外点按逆时针方向排序为 \(x_1,\ldots,x_8\)。四组 \((x_i,x_{i+4})\) 的夹角余弦均严格小于 \(-14273/15625=-0.913472\)，偏离正对径不到 \(24.02^\circ\)。每组的平方点距大于 \(2526381/781250\)，中点平方模小于 \(73/1250\)。配对由圆周顺序给出，适用于每个全局最大构型。[内外半径带](../ten-point-refined-radii/README.md)

## 从分带核得到外点方向矩

令 \(u_i=|x_i|^2\)，\(P_k=\sum_{\rm out}(x_i/|x_i|)^k\)。本证书得到
\[
|P_1|<39/100,\qquad |P_2|<9/10,\qquad
|P_3|<39/40,\qquad |P_4|<37/25 .
\]
另外，对任意方向 \(\omega\) 有联合界
\[
\left|\operatorname{Re}\left(e^{-i\omega}P_1-\frac{11}{100}e^{-3i\omega}P_3\right)\right|
<\frac{377}{1000}.
\]

用已有细化核的记号，令 \(M_k=\sum_i x_i^k(1,u_i-1,\ldots,(u_i-1)^5)^T\)。第 \(k\) 阶 Gram 罚项为 \(G_k=(E_k^T M_k)^*Q_k(E_k^T M_k)\)，其中 \(E_k\) 是已保存的特征变换。核的有序点对总和为各非负 Gram 罚项之和。因为全局最大值至少为见证值 \(V\)，以及唯一内内边的缺额至少为 \(-9/100000\)、其余 44 边各至少为 \(-3/40000\)，有
\[
\sum_k G_k\le 2(B-\log V+9/100000+44\cdot3/40000)<H=\frac{3391}{500000}.
\]
最后一步重新核验 \(B-\log V<10^{-6}\)。[细化分带核与点对缺额](../ten-point-banded-kernel-refined/README.md)

令 \(I(u)\) 为外带指示函数。用五次多项式 \(g_k(u)\) 逼近 \(I(u)u^{-k/2}\)。若 \(g_k\) 在幂基中的系数为 \(E_k y_k+w_k\)，其中 \(w_k^T M_k=0\) 来自 Ward 恒等式，则
\[
\left|\sum_i x_i^k g_k(u_i)\right|^2
\le (y_k^TQ_k^{-1}y_k)\,G_k.
\]
这里一阶使用 \((M_1)_0=(M_1)_1=0\)，二、三阶使用 \((M_2)_1=7(M_2)_0/10\)、\((M_3)_1=3(M_3)_0/5\)。程序对有理解逐项代回 \(Q_k z=y_k\)，并以一维 Bernstein 系数验证
\[
|u^{k/2}g_k(u)-I(u)| < e_{\rm band}+s(u-9/10)
\]
在两带上成立。平方前检查相应量的符号。因 \(\sum_i u_i=9\)，仿射项的斜率贡献抵消，误差和至多为 \(2e_{\rm in}+8e_{\rm out}\)。[固定的四组多项式数据](harmonics.json) · [Ward 恒等式](../stationary-kernel/README.md)

联合界使用两组另选的多项式 \(g_1,g_3\)。设 \(R=\sqrt{u}\)、\(c=\cos(\theta-\omega)\)、\(\lambda=11/100\)，逐点以同一个仿射式控制联合误差
\[
\left|(R g_1(R^2)-I)c
-\lambda(R^3g_3(R^2)-I)(4c^3-3c)\right|
<e_{\rm band}+s(R^2-9/10).
\]
程序在包住各径向区间的有理 \(R\) 区间及 \(c\in[0,1]\) 上，用二维 Bernstein 系数验证误差的两个符号。左侧关于 \(c\) 的绝对值为偶函数，因此覆盖所有方向。对加权矩同时用 \(G_1+G_3<H\)，得到联合上端
\[
2e_{\rm in}+8e_{\rm out}+
\sqrt{H\big(y_1^TQ_1^{-1}y_1+\lambda^2 y_3^TQ_3^{-1}y_3\big)}<377/1000.
\]
[固定的联合多项式数据](odd-projection.json)

## 五方向闭弧的排除

点距 \(d>2/5\) 与外带 \(169/200<u<164/125\) 蕴含外方向两两夹角大于 \(\alpha=\arccos(106/125)\)。程序将所需不等式平方后检查四个角点；差值在半径变量 \(u,v\) 分别凸。[点距证明](../maximizer-domain/README.md)

设 \(\beta=\arccos(26/125)\)，令 \(F(\theta)=\cos\theta-(11/100)\cos3\theta\)。它是偶函数，在 \([-\pi/2,\pi/2]\) 非负且凹，在正半区间递减。这由
\[
F''(\theta)=-\cos\theta\,\frac{397-396\cos^2\theta}{100}
\]
给出，且 \(F(\theta+\pi)=-F(\theta)\)。

若某长 \(2\beta\) 的闭弧包含五个外点方向，旋转后可令它们在 \([-\beta,\beta]\) 内。四个内部间隙至少为 \(\alpha\)。扣去其基值后，剩余长度在内部及两端的六个间隙之间分配，形成一个单纯形。凹函数 \(\sum F\) 的最小值可在顶点取得。第 \(j\) 个顶点有 \(j\) 个点靠左端按间隔 \(\alpha\) 排列，其余 \(5-j\) 个靠右端排列，\(0\le j\le5\)。程序用 \(\cos(\beta-\ell\alpha)\) 的递推和有理平方根包围核对这六个投影和。

其余三个点的投影和至少为 \(-F(0)-2F(\alpha)\)。为证此式，把方向反转后求三点投影和的上界。若存在一条方向的投影非正，上界 \(2F(0)\) 已足够。否则三方向在同一开半圆，最宽的一对相距至少 \(2\alpha\)，由偶性、凹性及递减性，该对的和至多为 \(2F(\alpha)\)。最后一条至多为 \(F(0)\)。

合计八点的投影严格大于 \(377/1000\)，与联合方向界矛盾。故任何长 \(2\beta\) 的闭弧最多容纳四个外方向。用 \(\theta_{i+8}=\theta_i+2\pi\) 延拓排序角度，得到
\[
2\beta<\theta_{i+4}-\theta_i<2\pi-2\beta.
\]
因此四组循环配对的角余弦严格小于 \(\cos(2\beta)\)。设 \(\kappa=14273/15625\)，配对的平方点距大于 \(u+v+2\kappa\sqrt{uv}\ge 2(169/200)(1+\kappa)\)。配对中点平方模小于 \((u+v-2\kappa\sqrt{uv})/4\)。后一函数在两个径向变量上分别凸，接受器用四个角点得出其上界 \(73/1250\)。
