# 十点候选的配对半差与中点局部锐界

采用总平方半径 \(9\) 的坐标。把待比较的十点任意配成五对 \(m_i\pm a_i\)，其中 \(m_i\) 是中点，\(a_i\) 是有向半差。候选的五个代表依次是正实内点、较小矩形的两个右半平面点、较大矩形的两个右半平面点，记为 \(a_i^*\)。允许整体旋转、重排点对和改变代表的符号。[已认证的五变量代数根](../ten-point-contact-geometry/README.md)

若能令 \(\|a-a^*\|_2\le 7/250\)，则有以下两个结论。

- 当 \(\|m\|_2\le 7/40\) 时，距离平方乘积至多为候选值，等号仅在候选的旋转和重排轨道。
- 当 \(\|m\|_2\le 13/100\) 时，任何完整驻点都满足 \(m=0\)，即所配五对均以原点为中点。

[原有配对证书](../ten-point-pair-midpoints/README.md)中的对应半差半径为 \(1/150\)，中点的能量半径为 \(17/100\)。全局锐界还需要覆盖上述范围之外的构型。

## 零中点时的半差变化

令 \(L=\log\Delta-5\sum_i |z_i|^2\)。将半差向量在固定配对和符号下旋至离 \(a^*\) 最近的方向，写成 \(a=a^*+h\)。于是 \(h\perp i a^*\)，内积取实部。置 \(R=7/250\)。

在零中点构型上，\(L\) 的对数项可写为 \(\sum_{(\ell,d,p)}\ell\log|d+p^T h|\)，相差一个与 \(h\) 无关的常数。五个对内项为 \((2,a_i^*,e_i)\)，每组异对 \(i<j\) 有两项 \((4,a_i^*\pm a_j^*,e_i\pm e_j)\)。记 \(\lambda_{d,p}(h)=p^T h/d\)。驻点性消去一次项。二次损失与三次项分别是

\[
Q_A(h)=10\|h\|_2^2+\sum_{(\ell,d,p)}\frac\ell2\operatorname{Re}\lambda_{d,p}(h)^2,
\qquad
C_A(h)=\sum_{(\ell,d,p)}\frac\ell3\operatorname{Re}\lambda_{d,p}(h)^3.
\]

用通过实轴的共轭反射加上各矩形内部的两个代表互换，定义一个保持势且固定 \(a^*\) 的正交对合。令 \(h_+,h_-\) 是其偶、奇分量，\(s=\|h_-\|_2\)。偶、奇分量之间没有二次交叉项。三次项只保留偶偶偶项和偶奇奇项。证书验证

\[
Q_A(h_+)\ge\frac{29}{4}\|h_+\|_2^2,\qquad
Q_A(h_-)\ge\frac{17}{100}s^2,\qquad
|C_A(h)|\le21\|h_+\|_2^3+19s^2\sqrt{Q_A(h_+)}.
\]

奇向界用旋转正交条件。验证器对压缩前的矩阵加上旋转方向投影，以检查整个十维空间上的严格正定性。三次界对第一个变量的每个坐标形成一个对称矩阵 \(T_i\)，使该项写为 \(\sum_i v_i w^T T_i w\)。其 Gram 矩阵 \(G_{ij}=\operatorname{tr}(T_iT_j)\) 给出上界 \(\sqrt{v^TGv}\,\|w\|_2^2\)。偶奇奇项使用 \(19^2Q_A|_+\succ G\)，偶偶偶项使用 \(21^2I\succ G\)。

候选的 \(|a_i^*|>1/3\) 以及异对分母 \(|a_i^*\pm a_j^*|>73/100\)。因此在 \(\|h\|_2\le R\) 上，\(|\lambda_{d,p}(h)|\le3R\)。验证器还检查五维实矩阵

\[
\sum_{(\ell,d,p)}\frac{\ell}{2|d|^4}pp^T\prec99I.
\]

由 \(|p^T h|^2\le2R^2\)，对数的四次及以上项的绝对值之和至多为 \(B_A\|h\|_2^2\)，其中 \(B_A=99R^2/(1-3R)\)。记 \(t=\sqrt{Q_A(h_+)}\)。用 \(s\le R\) 与 \(\|h_+\|_2\le R\)，得到

\[
L(a,0)-L(a^*,0)\le
-\begin{pmatrix}s&t\end{pmatrix}
\begin{pmatrix}17/100-B_A&-19R/2\\-19R/2&1-(21R+B_A)/(29/4)\end{pmatrix}
\binom{s}{t}.
\]

该矩阵的行列式严格大于 \(3/500\)，左上元为正。因此等号强制 \(h=0\)。

## 中点的相对二次损失

在异对 \(i<j\) 上记 \(d=a_i^*\pm a_j^*\)、\(v=h_i\pm h_j\)、\(\eta=m_i-m_j\)。对两个符号分别求和，由四条异对边的乘积得

\[
L(a,m)-L(a,0)=2\sum_{i<j,\pm}\log\left|1-\frac{\eta^2}{(d+v)^2}\right|-10\|m\|_2^2.
\]

令 \(Q_M(m)=10\|m\|_2^2+2\operatorname{Re}\sum(\eta/d)^2\)。验证器证明 \(Q_M(m)>(7/5)\|m\|_2^2\) 对非零 \(m\) 成立，并证明两个加权上界

\[
\sum\frac{|\eta|^2}{|d|^4}\le\frac{13}{2}Q_M(m),
\qquad
\left|4\operatorname{Re}\sum\frac{v\eta^2}{d^3}\right|\le12\|h\|_2 Q_M(m).
\]

第二个上界使用中点槽的加权 Gram 矩阵 \(G_{ij}=\operatorname{tr}(T_iQ_M^{-1}T_jQ_M^{-1})\)。这是矩阵 \(Q_M^{-1/2}T_iQ_M^{-1/2}\) 的 Frobenius Gram 矩阵，因此 \(G\prec12^2I\) 给出所需界。实际计算只用区间逆矩阵与迹，避免求矩阵平方根。

置 \(x=(10/7)R/(73/100)\)、\(\theta=1-x\)、\(\rho=2M^2/(73/100-(10/7)R)^2\)，其中 \(\|m\|_2\le M\)。从倒平方的幂级数可得

\[
\left|(1+w)^{-2}-1+2w\right|\le |w|^2\frac{3-2x}{(1-x)^2}\quad(|w|\le x<1).
\]

因而对数差中的线性项，在 \(-Q_M\) 和上面已界定的三次耦合项之外，余量至多为 \(4R^2(3-2x)(13/2)Q_M/\theta^2\)。设 \(w=\eta^2/(d+v)^2\)，则 \(|w|\le\rho<1\)。对数在 \(-2\operatorname{Re}w\) 之外的余量至多为 \(|w|^2/(1-\rho)\)。由 \(|\eta|^2\le2M^2\) 及 \(|d+v|\ge\theta|d|\)，全部高阶中点余量至多为 \(2M^2(13/2)Q_M/(\theta^4(1-\rho))\)。代入 \(M=7/40\) 后，有理算术验证总相对余量小于 \(39/40\)，故

\[
L(a,m)\le L(a,0)-Q_M(m)/40.
\]

而对 \(L(a,tm)\) 在 \(t=1\) 求导再除以 2，线性项仍为 \(-2\operatorname{Re}w\)，余量上界变为 \(2|w|^2/(1-\rho)\)。将上式中最后一项的系数加倍，并代入 \(M=13/100\)，总相对余量小于 \(199/200\)。非零 \(m\) 的该导数严格为负，与完整驻点性矛盾。

在质量 9 球面上，\(L\) 与 \(\log\Delta\) 相差固定常数。合并半差和中点的损失即得局部结果。

## 复核

在仓库根目录运行以下命令。

```sh
python -B -S -O ten-point-weighted-pair-basin/verify_all.py
```

验证器用标准库重放上游根区间，在向外舍入的区间上构造七个矩阵，以有理下界及精确 \(LDL^T\) 检查正定性。可加 `--export-jacobian PATH` 导出有理下界，供 Jacobian 的 `matrix.inertia.compute` 独立复核。该操作返回四个 \((10,0,0)\) 和三个 \((5,0,0)\)。
