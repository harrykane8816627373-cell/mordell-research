## 完整驻点上的核和

先采用质量11，令 (u_i=|z_i|^2)，

```math
\phi(u)=(1,u-1,(u-1)^2,(u-1)^3,(u-1)^4)^T,
\qquad M_k=\sum_i z_i^k\phi(u_i).
```

完整驻点的 Ward 恒等式给出 (M_1) 的分量0、1为零，并给出 (v_k^TM_k=0) 对 (k=2,3) 成立，其中 (v_2=(-3/4,1,0,0,0)^T)，(v_3=(-2/3,1,0,0,0)^T)。质量恒等式另给 (v_0^TM_0=0)，其中 (v_0=(1/12,1,0,0,0)^T)。这些条件适用于任一完整全局最大点。[Ward 恒等式及完整力条件](../stationary-kernel/README.md)

基核 (K) 的12个有理 Gram 块均通过精确 LDL 分解和原矩阵重构。修正块 (A_1) 的右下3×3块为零，(A_2,A_3,A_0) 各按 (v_ka_k^T+a_kv_k^T) 构造。输入只保存19个 Ward 自由参数及5个质量参数，程序以精确分数重建四块，在各自允许的矩子空间上检查57个基向量双线性值全为零。

记 (H_k(u,v,t)=\operatorname{Re}((z\bar w)^k))，其中 (u=|z|^2)，(v=|w|^2)，(t=\operatorname{Re}(z\bar w))。令

```math
J(z,w)=\sum_{k=0}^3H_k(u,v,t)\phi(u)^T A_k\phi(v),
\qquad K'=K+J.
```

在完整驻点上，(\sum_{i,j}J_{ij}=\sum_{k=0}^3 M_k^*A_kM_k=0)，因此 (\sum_{i,j}K'_{ij}=\sum_{i,j}K_{ij}\ge0)。证明分别使用基核的正半定性和修正的 Ward 抵消。组合矩阵的全空间正定性没有被用于上界。

## 两点比较与连续覆盖

保持 (B=7726135064073933/281474976710656)，令 (b=(B-66)/12)。以组合核重新计算对角项，

```math
p'(u)=\frac{6u+b-K'(u,u,u)/2}{11},
\qquad h'(u,v,t)=p'(u)+p'(v)-K'(u,v,t).
```

质量11给出 (\sum_{i<j}h'_{ij}=B-\tfrac12\sum_{i,j}K'_{ij})。全局最大点是完整驻点，其点对落在闭域

```math
0\le u,v\le121/72,\qquad t^2\le uv,\qquad d=u+v-2t\ge1/3.
```

必要域由严格子集定理推出。区间覆盖使用这整个域，并通过精确的 (u,v) 交换对称减少一半。[必要域推导](../twelve-point-kernel-upper/README.md) · [严格子集定理](../finite-n/SUBSET_PROOF.md)

程序将 (K) 和 (J) 的非对角项及对角项展开成三变量有理多项式。逐项核验交换对称和19、19、11的次数上端，再用8组有理点与独立的双线性核表达式比较。旧算法负责精确 Bernstein 变换、向下中点细分和对数切线上端，每个叶重新检查。最终验证全域
