# 四正规环：最大人口重数、平衡边界与加法共振

2026-11-08。研究资料与项目发起：蒋丰灿（Fengcan Jiang）；推导、整理与精确程序包含OpenAI Codex协作。本专题继续[三环刚性及逐点力方法](../ring-rigidity/THEOREMS.md)，没有假定四环人口必须全等。所有结论均为必要条件或严格排除，不将保留的模式视为存在认证。

## 1. 基本设置和逐点余式

各点权重为1。构型由有限条同心正规多边形组成，各人口至少2、各正半径两两互异，另允许 $h\in\{0,1\}$ 个原点。所有相位任意。驻点满足

```math
\sum_{j\ne i}(z_i-z_j)^{-1}=\kappa\bar z_i,\quad
\kappa Q=n(n-1)/2,\quad Q=\sum_i|z_i|^2.
```

第二式把第一式乘 $z_i$ 后求和即得。正规 $m$ 环的根多项式为 $z^m-D$，$D\ne0$；若其他非零点多项式为 $P_0$，则在此环的全部实际点上，力平衡等价于

```math
z^m-D\ \mid\ zP_0'(z)+C P_0(z),\qquad
C=(m-1)/2+h-\kappa r^2.
```

这是逐点驻点条件，不是只改变整环半径、相位的条件。若部分外部环也有相同人口 $m$，其乘 $z$ 后的力贡献在被测环上为常数 $mD/(D-D_j)$，可以吸收到 $C$。下文的纯余式排除甚至允许这个有效 $C$ 为任意复数。

## 2. 最大人口以下必须有至少三条环

**定理A。** 对上述任意条数的驻点，若人口不全相等，至少有三条环的人口严格小于最大人口 $m$。特别地，四环的不等人口驻点必须只有一条最大人口环。

**证明。** 设有 $r\ge1$ 条人口 $m$ 的环，较小环的条数为 $t>0$。

若 $t=1$，较小人口为 $a<m$、根常数为 $A$。在任一最大环上，吸收其他最大环的常数作用后，所需整除多项式为 $(a+C)z^a-CA$，其次数小于 $m$。两系数为0要求 $C=0$ 和 $C=-a$，矛盾。

若 $t=2$，较小人口为 $a\le b<m$，常数为 $A,B$。外部剩余多项式为 $z^{a+b}-Bz^a-Az^b+AB$。若 $a+b\ne m$，模 $z^m-D$ 的常数系数仅为 $CAB$，最高指数的余数系数仅为 $(a+b+C)D^q$，其中 $q=0$ 或1；两者不能同时为0。若 $a+b=m$ 且 $a\ne b$，两个孤立中间系数要求 $C=-a=-b$，同样不可能。

唯一残留为 $a=b=s$、$m=2s$。两条较小环半径不同，因此 $A+B\ne0$。余式为

```math
R_s=-(s+C)(A+B),\qquad R_0=(2s+C)D+CAB.
```

它迫使 $C=-s$、$D=AB$。如果 $r\ge2$，对每条最大环分别应用此条件，它们的根常数全部等于 $AB$，导致碰撞。

如果 $r=1$，这是三环模式 $(s,s,2s)$。记平方半径为 $u,v,w$，则 $D=AB$ 给 $w^2=uv$。原始、未吸收背景的 $C=-s$ 给 $2\kappa w=4s-1+2h$；总点数 $4s+h$、质量 $s(u+v+2w)$ 与总体关系给 $u+v=2w$，这里使用恒等式 $(4s+h)(4s+h-1)=4s(4s-1+2h)$。于是 $(u-v)^2=0$，半径不再互异。故 $t=1,2$ 均不可能，证毕。

这一定理不限制人口相等的环数，也不声称四条以上人口一定全等。

## 3. 四环的平衡边界也不能驻定

单环的外部非零人口总数若小于 $m$，整除多项式次数不足已给矛盾。四环在等于 $m$ 的边界还可以进一步排除。

**定理B。** 四条不同正半径正规环的驻点，若最大人口唯一，记其他人口为 $a\le b\le c<m$，则必有

```math
m<a+b+c.
```

**证明。** 只须排除 $m=a+b+c$。令外部三个根常数为 $A,B,E$，则

```math
P_0(z)=(z^a-A)(z^b-B)(z^c-E),\qquad \deg P_0=m.
```

若 $P_0(z)=\sum q_ez^e$，整除条件对每个 $0<e<m$ 给 $(e+C)q_e=0$。因此最多只能有一个非零中间系数。

下面用最低、最高中间次数处理**全部加法指数碰合**，不假定所有子集和不同。

- 若 $a<b$，$z^a$ 的系数恰为 $BE\ne0$，$z^{m-a}$ 的系数恰为 $-A\ne0$。后者从唯一最高子集 $b+c$ 来；任何其他子集的和均更小。这仍包括 $b=c$ 以及 $a+b=c$ 的情形。$a$ 与 $m-a$ 是不同的严格中间次数。
- 若 $a=b<c$，$z^a$ 的系数恰为 $E(A+B)$，$z^{m-a}$ 的系数恰为 $-(A+B)$。不同半径保证 $|A|\ne|B|$，所以 $A+B\ne0$。这也包括 $c=2a$，该情形的另一中间系数可能抵消，但上述两项不会抵消。

两种情形都有至少两个非零中间系数，矛盾。唯一需要继续处理的是 $a=b=c=s$、$m=3s$。

令 $t=z^s$、$S_1=A+B+E$、$S_2=AB+AE+BE$、$S_3=ABE$，则

```math
P_0=t^3-S_1t^2+S_2t-S_3.
```

若 $S_1=S_2=0$，其三个 $t$ 根模长相同，三条较小环半径相同，已不满足假设。否则恰有一个中间系数非零，分为以下两支。

### 第一支：$S_1=0$、$S_2\ne0$

完整构型在乘 $e^{2\pi i/s}$ 下不变。记 $p_k=\sum_i z_i^k$。对于 $1\le k<s$，$p_k=0$；而 $p_s=sS_1=0$。把每个完整逐点力方程乘 $z_i^{s+1}$ 后求和，点对合并给

```math
\kappa\sum_i |z_i|^2z_i^s
=\frac12\sum_{j=0}^s\left(p_jp_{s-j}-p_s\right)
=\left(n-\frac{s+1}{2}\right)p_s=0.
```

其中 $p_0=n$，中心点的正次幂均为0。大 $3s$ 环对左侧的贡献为0，因为其 $s$ 次幂之和为0。因此，对三条较小环的平方半径 $u,v,w$，有

```math
A+B+E=0,\qquad uA+vB+wE=0,
\qquad (u,v,w)=(|A|^{2/s},|B|^{2/s},|E|^{2/s}).
```

**三向量引理。** 若三个非零复数 $x,y,z$ 满足 $x+y+z=0$ 及 $|x|^p x+|y|^p y+|z|^p z=0$，其中 $p>0$，则它们模长相等。

若三个向量不共线，把它们视作 $\mathbb R^2$ 中的列向量，关系空间是一维，第二个关系的三个实系数必须相等，故模长相等。若共线，整体旋转、换标号并改符号后可写作 $x=a$、$y=b$、$z=-(a+b)$，$a,b>0$。第二个关系却要求 $a^{p+1}+b^{p+1}=(a+b)^{p+1}$，与 $p+1>1$ 时的严格超可加性矛盾；例如对导数积分即可严格证明。两种情形覆盖全部可能。

应用 $p=2/s$，得到三条较小环半径相同，矛盾。此支的排除使用了完整逐点方程导出的Ward恒等式，不能仅由环半径内的一阶优化替代。

### 第二支：$S_2=0$、$S_1\ne0$

中间系数要求 $C=-2s$，常数系数要求 $D=-2S_3$。记大环平方半径为 $R$，小环平方半径为 $u,v,w$。于是

```math
2\kappa R=7s-1+2h,\qquad
uvw=2^{-2/s}R^3.
```

总点数 $n=6s+h$、质量 $Q=s(u+v+w+3R)$。总体关系和 $(6s+h)(6s+h-1)=6s(6s-1+2h)$ 给

```math
\frac{u+v+w}{3R}=\frac{5s-1+2h}{7s-1+2h}
\le\frac{11}{15}.
```

上界对所有 $s\ge2$、$h\in\{0,1\}$ 成立，因为交叉相乘的差为 $2(s+2-4h)\ge0$。另一方面，算术几何平均不等式给

```math
\frac{u+v+w}{3R}\ge2^{-2/(3s)}\ge2^{-1/3}>\frac{11}{15}.
```

最后的严格比较等价于 $1331/3375<1/2$，完全有理。矛盾，证毕。

因此 $(s,s,s,3s)$ 也被完整排除；不是把有重复指数的这支跳过了。

## 4. 外部次数不超过两倍最大人口时的子集和障碍

**定理C。** 取 $t\ge1$ 条外部正规环，人口为 $a_1,\ldots,a_t$，满足 $2\le a_j<m$、$M=\sum a_j\le2m$。若这 $t$ 个人口的全部 $2^t$ 个子集和两两不同，则不能使 $m$ 环的逐点力同时平衡。其余环自身是否驻定无需检查，相位和半径也无需固定。

**证明。** 外部多项式 $P_0=\prod(z^{a_j}-A_j)$ 的每个子集恰给一个不同次数，且系数是非零的常数单项式。把这些次数按模 $m$ 分组。若某组只有一个次数 $e$，余式系数消失就迫使 $C=-e$。两个孤立次数因此已矛盾。

假设至多有一个孤立次数。若 $M<2m$，每组最多两个次数。次数总数 $2^t$ 为偶数，所以孤立组的数量也必须为偶数，只能为0。全部次数因而成对相差 $m$。于是正系数生成多项式

```math
F(X)=\prod_j(1+X^{a_j})
```

可被 $1+X^m$ 整除。但在 $\zeta=e^{\pi i/m}$ 处，所有 $0<a_j<m$ 保证 $1+\zeta^{a_j}\ne0$，所以 $F(\zeta)\ne0$，矛盾。

若 $M=2m$，次数 $m$ 不可能是子集和，否则其补集也是另一个同和子集。故0模类只有端点0、$2m$，其他类仍最多两个次数。相同偶数论证迫使没有孤立组；除端点一对外，其他对都相差 $m$，所以 $F(\zeta)=2$。但

```math
F(\zeta)=2^t e^{\pi iM/(2m)}\prod_j\cos\frac{\pi a_j}{2m}
=-2^t\prod_j\cos\frac{\pi a_j}{2m}<0,
```

仍矛盾。故总有至少两个孤立次数，不能平衡逐点力，证毕。

**四环人口共振推论。** 四环的不等人口驻点已经必须有唯一最大 $m$。若其他三人口 $a\le b\le c<m$ 满足 $a+b+c\le2m$，则必须满足至少一个加法共振：两个人口相等，或 $a+b=c$。因为对于三个正整数，子集和碰合除了人口重复之外，唯一可能是一个人口等于另两个之和。

这是人口关系的必要条件，不是这些共振分支存在驻点的结论。例如无限族 $(s,2s,4s,5s)$（$s\ge2$）被排除：两个孤立次数为 $3s,4s$，要求同时 $C=-3s$、$C=-4s$。边界例 $(4s,7s,9s,10s)$ 也被排除，且外部总数恰为 $2m$。

## 5. 另一条可显式消元的四环族

**定理D。** 人口 $(a,s,s,2s)$，其中 $2\le a<2s$、$a\ne s$，不可能组成上述驻点。

**证明。** 设两条 $s$ 环根常数为 $A,B$，$S=A+B\ne0$、$P=AB$，$a$ 环常数为 $T$，最大环常数为 $D$。外部多项式为 $(z^{2s}-Sz^s+P)(z^a-T)$。模 $z^{2s}-D$ 后，次数 $0,s,a,(a+s)\bmod2s$ 两两不同，因而对应 $s$ 及 $(a+s)\bmod2s$ 的两个余式系数恰为

```math
R_s=T(s+C)S,\qquad
R_* =-(a+s+C)S D^q,\qquad q=\left\lfloor\frac{a+s}{2s}\right\rfloor\in\{0,1\}.
```

其组合 $D^qR_s+TR_*=-aTSD^q\ne0$，所以不能同时为0，证毕。

这里特意保留 $a=s$，即 $(s,s,s,2s)$；在该分支，余数次数发生碰合，上述消元不适用。

## 6. 三条等人口环加一个异人口环：人口必须加倍

**定理E。** 四条不同正半径正规环的人口若为 $(s,s,s,m)$、$m\ne s$，则驻定的必要条件为 $m=2s$。相位和可选中心仍任意；这不是 $(s,s,s,2s)$ 的存在结论。

**证明。** 若 $m<s$，最大人口 $s$ 以下只有一条环，已被定理A排除。现设 $m>s$，记三个小环根常数的对称和为 $S_1,S_2,S_3$。外部多项式为

```math
P_0(z)=z^{3s}-S_1z^{2s}+S_2z^s-S_3.
```

其端点次数0与 $3s$ 的系数总是非零。若 $m$ 既不整除 $2s$ 也不整除 $3s$，这两个端点在模 $m$ 的余数类都没有其他次数，迫使 $C=0=-3s$，矛盾。因为 $m>s$，可能的整除只有

```math
m\in\{2s,3s/2,3s\}.
```

$m=3s$ 已由定理B排除；$m=2s$ 保留。只需排除整数分支 $s=2q$、$m=3q$，其中 $q\ge1$。

模 $z^{3q}-D$ 的三个余式系数为

```math
R_q=-(4q+C)S_1D,\quad
R_{2q}=(2q+C)S_2,\quad
R_0=(6q+C)D^2-CS_3.
```

若 $S_1,S_2$ 均非零，前两项要求不同的 $C$；若均为0，三个小环根常数模长相同。故恰有一者为0。

若 $S_1=0$，则 $C=-2q$。对完整构型，所有 $1\le k<2q$ 的幂和都为0：各环人口为 $2q$ 或 $3q$，均大于这些次数，分别在每条环上求和就为0。又 $p_{2q}=2qS_1=0$。第3节的完整Ward恒等式现取次数 $2q$，给三个小环常数

```math
A+B+E=0,\qquad |A|^{1/q}A+|B|^{1/q}B+|E|^{1/q}E=0.
```

三向量引理迫使它们模长相等，仍与半径互异矛盾。

若 $S_2=0$，则 $C=-4q$，$R_0=0$ 给 $D^2=-2S_3$。记大环平方半径为 $R$、小环平方半径为 $u,v,w$，则

```math
2\kappa R=11q-1+2h,\qquad uvw=2^{-1/q}R^3.
```

总点数 $9q+h$、质量 $q(2u+2v+2w+3R)$ 的总体关系给

```math
\frac{u+v+w}{3R}=\frac{8q-1+2h}{11q-1+2h}\le\frac34,
```

因为交叉相乘的差为 $q+1-2h\ge0$。算术几何平均却要求该比值至少为 $2^{-1/(3q)}\ge2^{-1/3}>3/4$，其中最后严格比较的立方为 $1/2>27/64$。矛盾，证毕。

这条规则把 $(s,s,s,m)$ 的异人口情形收紧到唯一未排除的比例 $m=2s$；没有把保留比例当作驻点分类的完成。

## 7. 结论边界及验证范围

人口 $(2,2,2,4)$、$(2,2,4,6)$、$(2,4,4,6)$、$(2,4,6,8)$ 仍未被本专题排除，也没有被认证为存在。没有宣称所有四环人口全等，没有完成共振分支的半径、相位与Hessian分类，也没有确定一般点数锐值。

`verify_all.py` 用Python标准库精确重算一般参数的余式消元恒等式、二元中心virial和两种均值界；独立展开三个二项式的最低、最高中间系数，检查所有重复次数；以独立子集掩码检查低次数障碍及 $M=2m$ 边界；核验完整Ward恒等式的逐点差商及等三人口的端点余数。保存的有限四环人口清点明确记录实际范围。所有关键判断均不依赖 `assert`、浮点优化或采样；一般定理由本解析证明承担，有限清点不是其替代。
