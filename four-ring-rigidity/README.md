# 四正规环：人口共振与逐点力的严格排除

研究资料与项目发起：蒋丰灿（Fengcan Jiang）；推导、整理与精确程序包含OpenAI Codex协作。2026-11-08。本专题继续[三环刚性](../ring-rigidity/README.md)，允许任意连续相位、互异正半径及可选中心。

[完整自含证明](THEOREMS.md)给出：

- 任意多环驻点若人口不全等，至少三条环的人口严格小于最大人口。因此，四环不等人口驻点的最大人口必须唯一。
- 四环最大人口 $m$ 还必须**严格小于**其他三个人口之和。平衡族 $(s,s,s,3s)$ 的两支均被完整排除：一支使用完整Ward恒等式与三向量加权闭合，另一支由精确均值界和算术几何平均矛盾排除。
- 若其他人口总和不超过 $2m$，且所有子集和不同，则已经无法使最大环上的全部点平衡。对四环，这强迫较小人口重复，或其中一个等于另外两个之和。
- 额外无限族 $(a,s,s,2s)$（$2\le a<2s$、$a\ne s$）有直接的非零余式组合，也被排除。
- 三条人口 $s$ 的环加一个异人口 $m$ 环，必须满足 $m=2s$；$m=3s/2$ 的潜在支也由完整Ward或严格均值矛盾排除。

这些结论涉及允许每个点独立移动的完整驻点方程，不是仅对环参数作优化。**没有证明所有四环人口全等**；$(2,2,2,4)$ 等共振分支仍保留，保留不代表存在或最优。
