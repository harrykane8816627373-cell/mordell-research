# 从数值候选到真实驻点与完整局部极大性

2026-11-05。蒋丰灿研究项目，OpenAI Codex 协作推导与精确复核。本专题认证局部结果，不声称确定任何 n≥10 的全局最优值。

## 1. 固定尺度与旋转规范

记 N=n(n−1)/2、λ=(n−1)/2，z_i=x_i+iy_i，定义完整实力向量

```math
F_i(z)=\sum_{j\ne i}\frac{z_i-z_j}{|z_i-z_j|^2}-\lambda z_i.
```

这是 L(z)=log Δ(z)−λΣ|z_i|² 的实梯度的一半。选一个非零点并旋转使 y₀=0、x₀>0。删去 y₀ 变量和 F₀ 的虚部方程，得到 d=2n−1 个变量上的 f。不能再额外假设中心化、固定半径或对称性：这些应由完整力平衡推出。

恒等式 Σ_i(x_i F_{iy}−y_i F_{ix})=0 对所有无碰撞构型成立，因为每个点对的内部力平行于其位移，而约束力也平行于位置。在 f=0、y₀=0、x₀>0 时，该恒等式恢复遗漏的 F₀y=0。所以此规范不丢失任何逐点方程。

再对完整方程求和，得 Σz_i=0。与位置作实内积，得 N−λΣ|z_i|²=0，因此 Σ|z_i|²=n。数值种子可以先居中和缩放，但接受阶段没有把这些浮点操作当作证明。

## 2. 完整实 Jacobian

对点对 i,j 令 d=(x_i−x_j,y_i−y_j)、s=|d|²。其 2×2 导数块为

```math
B_{ij}=\frac{I_2}{s}-\frac{2dd^T}{s^2}.
```

完整对称 Jacobian J=DF 的对角块为 Σ_{j≠i}B_ij−λI₂，非对角块为 −B_ij。删去 y₀ 的行列得到 Df。验证程序对一个连续实盒包围全部 s、F、Df 和 Δ，不用中点特征值代表整个盒。

另以独立的复逆平方 Laplacian A 构造检查上述实表示。若 A 的一个复条目为 a+ib，则 −conj(Av) 的对应实块为 ((−a,b),(b,a))；再减 λI 得同一 J。精确有理样本上的每个条目均被重新核对。

## 3. 整数区间压缩认证真实根

证书给出精确二进有理中点 c、半径 r=2⁻⁸⁰ 的闭立方体 X，以及精确二进有理预条件矩阵 C。全部区间运算在 2⁻³⁸⁴ 格上向外舍入：加法精确，乘除对所有端点取整数向下/向上商，平方跨零时保留零下端。除数区间含零时立即拒绝。

程序实际验证：整个 X 无碰撞、x₀>0，且

```math
\|Cf(c)\|_\infty<r/4,\qquad
\sup_{x\in X}\|I-CDf(x)\|_\infty<1/4.
```

映射 T(x)=x−Cf(x) 将 X 送入以 c 为中心、半径小于 r/2 的盒，并在 X 上为压缩映射。Banach 定理给出唯一固定点。由于 CDf 与单位矩阵的距离小于1，CDf 可逆，C 也可逆，故该固定点等价于 f=0。第1节随即恢复完整驻点、中心化及质量 n。

唯一性只针对这个旋转规范盒，不是全部驻点的分类，也不是全局最大点唯一性的证明。

## 4. 完整 Hessian 的负性，而非环族内的负性

对声称局部极大的分支，证书另给精确有理方阵 W。程序对整个 X 验证

```math
G(x)=-W^TDf(x)W,\qquad
G_{ii}(x)-\sum_{j\ne i}|G_{ij}(x)|>0.
```

每个 G 都是实对称严格正定矩阵。该结论本身也迫使 W 可逆，因此 Df 严格负定。W 是从数值 Cholesky 得到的探索输入，但“W 可逆”或“原矩阵正定”均不被当作未经检查的前提；接受程序只检查精确的合同与行和下端。

在真实驻点，旋转协变性给 J(iz)=0，且此核向量的 y₀ 分量为 x₀>0。任意实方向 v 唯一分解为 w+a(iz)，其中 w 的 y₀ 分量为0。因此

```math
v^TJv=w^TJw<0\quad\text{除非 }v\text{ 是整体旋转方向}.
```

故完整 Hessian D²L=2J 只有旋转零方向；其余方向严格负。有限维 Taylor 展开及局部旋转切片给出模旋转的严格局部极大。在 Σ|z|²=n 上 L 与 log Δ 只相差常数，故也得到原约束问题的严格局部极大。没有把同步旋转各环、径向缩放或某个小模式子块的负性替代完整实 Hessian。

## 5. 不稳定分支的接受标准

对于不稳定分支，仍先完整认证真实驻点，再给一个有理规范方向 v，实际验证整个 X 上 vᵀDf(x)v>0。它确实导致约束不稳定性：在真实驻点，由齐次性有 Jz=−2λz。把 v 的径向分量减去，所得球面切向量 w 满足

```math
w^TJw=v^TJv+2\lambda\frac{\langle v,z\rangle^2}{\|z\|^2}>0.
```

因此球面内存在增益方向。中心化或平移方向不能掩盖这个结论；完整 J 已纳入所有点的独立移动。

## 6. 实际结论与范围

本次认证了9个规范盒：n=10、11、12、13、14、17、18、19 的8个严格局部极大轨道，以及 n=15 的一个不稳定驻点轨道。17、18点采用本轮改进的整数种子；其余来自此前保存的自由构型种子。原始整数种子本身不是精确驻点，真正被认证的是盒内唯一根。

特别是15点：旧浮点搜索留下了很小的梯度，进一步 Newton 定位得到的真实根却具有严格正的完整二阶方向。这不撤销旧整数构型作为可达下界的正确性，但说明“小残差”不足以认证局部最大。

每个根的 Δ 值另由盒内所有平方点距相乘给出有理上下端。这些是已认证局部驻点值的包围，不是 M_n 的上界。未证明所列轨道互异于全部其他分支，也未穷尽任何 n≥10 的全部驻点。
