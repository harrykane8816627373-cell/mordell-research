## 1. 驻点闭合：八点得到更紧低阶矩区域

一般n的库仑尺度 x=√((n−1)/n)z，默认平滑半径r²=2/n。写p_k=Σx_i^k。驻点恒等式与准确圆盘平均联合给

~~~math
A_{k,1}=2p_k+\frac1n\sum_{\ell=1}^{k-1}p_\ell p_{k-\ell}.
~~~

代入已有一级混合矩Gram，能量除旧全纯项外还有准确的额外平方。低阶k=2、3的卷积因p₁=0而消失，高阶仍保留非线性相关性。带加权驻点残差的版本可接区间盒，不把近似驻点当成严格驻点。

对任意八点全局最优者，改回**原z尺度** P_k=Σz_i^k，可严格推出

~~~math
\boxed{|P_2|^2+\frac{27}{100}|P_3|^2<\frac{64}{49},
\qquad |P_2|<\frac87.}
~~~

这比本次提供包中保留的单独界20/13更紧，且缩小原联合椭圆。将未知高阶矩在二次型中准确消元，还会留下正的|P₂|⁴和|P₂P₃|²罚项，可继续收紧区域。推导使用已证驻点关系、全局半径及可达八点下界；没有枚举全部驻点，也没有证明P₂=P₃=0。

## 2. 矩校正空洞：从取最大值到准确联合Gram

在库仑x尺度，默认平滑的总二阶矩恰与均匀背景一致。这个零测量与空洞泡函数不正交，因而会强迫补偿能量。若不交平滑空盘的四次半径和为T、支撑平方半径为S，则

~~~math
\delta\ge\frac{n^2T}{16(1-T/S^2)}.
~~~

原独立空洞项仅为n²T/16。进一步加入驻点的零偶极矩和全部已闭合混合模式，得到统一Schur证书；全纯角向项仍可正交相加。完整径向能量不能未经处理再加一次。

一个与当前实际百点下界闭合的例子：圆心x=1、能量空盘半径19073/100000时，旧空洞项约0.827096、二阶矩校正约0.827290，均低于已认证缺额上端0.827847658522；加入驻点偶极后约0.828271，严格排除该空洞类。该例比较所列投影，不声称通过全部其他既有构型条件。

## 3. 含背景边界的覆盖推进到带对数损失的微观尺度

在原z尺度，对n≥64令ε_n=2√(log(8n)/n)。任意全局最优者都有

~~~math
\boxed{\sup_{|u|\le\sqrt2}\min_i|z_i-u|
<\frac6{\sqrt{n-1}}+\sqrt2-\sqrt{2(1-\varepsilon_n)}
=O\!\left(\sqrt{\frac{\log n}n}\right).}
~~~

这条结论覆盖整个闭背景盘，包含边界；只用全局加权插值与严格点距，不需要缺额预算或外部线性渐近项。百万点的严格覆盖上端为0.011649541114。

此前固定内盘仍有更细的常数6/√(n−1)；本轮全背景结论保留√log n损失，未证明边界上的固定微观常数。
