# 从固定内盘到整个闭背景盘：带对数损失的有效微观覆盖

研究资料与项目发起：**蒋丰灿（Fengcan Jiang）**；推导及精确程序包含 OpenAI Codex 协作。2026-10-30。

此前[全局加权插值证明](../distribution-geometry/MICROSCOPIC_COVERING.md)给固定内盘上6/√(n−1)覆盖；[局部空洞能量](../distribution-geometry/LOCAL_POPULATION.md)对整个背景盘只给n⁻¹ᐟ⁴阶。本节让插值适用的内盘随 n 扩张，将含边界的覆盖提高为 O(√(log n/n))。所有距离均为原 z 尺度，Σ|z_i|²=n。

## 1. 全背景定理

令 n≥64，定义

~~~math
\varepsilon_n=2\sqrt{\frac{\log(8n)}n},\qquad
R_n=\sqrt{2(1-\varepsilon_n)}.
~~~

有0<ε_n<1。每个全局最优构型都满足

~~~math
\boxed{\sup_{|u|\le\sqrt2}\min_i|z_i-u|
<\frac6{\sqrt{n-1}}+\sqrt2-R_n.}
~~~

因1−√(1−ε)≤ε，较简明的上端为

~~~math
\frac6{\sqrt{n-1}}+2\sqrt{\frac{2\log(8n)}n}.
~~~

这是闭背景盘上全部圆心同时成立的显式结论，包括 |u|=√2。它保留一个 √log n 损失，**没有证明边界上的固定常数 n⁻¹ᐟ²覆盖，也没有确定边缘排列**。

## 2. 插值与分离输入

仍取 λ=(n−1)/2。此前从全局单点替换、次数n−1的截断指数多项式得到

~~~math
1\le\sum_i e^{-\lambda|z_i-u|^2/2}+n\sqrt\tau+\tau,
\qquad
\tau=\Pr\{\operatorname{Poisson}(\lambda|u|^2)\ge n\}.
~~~

这条不等式对任何 u 成立。其有限多项式余项由级数Cauchy–Schwarz在整个复平面一致控制，未将无限整函数直接放入有限插值式。

用户原有严格点距 >2/√(n−1)又给：若全部 |z_i−u|≥6/√(n−1)，则缩放点互距>1且离圆心≥3，故

~~~math
\sum_i e^{-\lambda|z_i-u|^2/2}
\le8e^{-23/8}<1/2.
~~~

这两项沿用此前自含证明；加权Fekete插值的经典背景参见 Ameur–Ortega-Cerdà [arXiv:1110.0284](https://arxiv.org/abs/1110.0284)。这里的改动是把有限Poisson尾量词推进到随n扩张的内盘。

## 3. 随 n 收缩的边界层

若 |u|≤R_n，则 s=λ|u|²≤n(1−ε_n)。指数Markov界以及对0<ε<1的恒等式/正项界给

~~~math
\tau\le[(1-\varepsilon_n)e^{\varepsilon_n}]^n,
\qquad
-\varepsilon-\log(1-\varepsilon)
=\sum_{k=2}^\infty\frac{\varepsilon^k}k
\ge\varepsilon^2/2.
~~~

因此

~~~math
\tau\le e^{-n\varepsilon_n^2/2}=(8n)^{-2},\qquad
n\sqrt\tau+\tau\le\frac18+\frac1{64n^2}<\frac14.
~~~

若此扩张内盘仍有半径6/√(n−1)空洞，上一节会强迫1<3/4，矛盾。故对所有 |u|≤R_n，原有微观覆盖常数6依然成立。

起点是有效的：log(512)<64/9，故 ε₆₄<2/3；log(8n)/n在n≥64严格递减，所以全部n≥64都有ε_n<1，不需要外部未给出的“大n阈值”。

## 4. 投影圆心而覆盖背景边界

对任意 |u|≤√2，把u径向投影到半径R_n的闭内盘，得到v。此时 |u−v|≤√2−R_n。由上节有某个点满足 |z_i−v|<6/√(n−1)。三角不等式即得第1节。

不要求u、v、某个点共线；只把查询圆心投影，未移动原构型。证明也不使用能量缺额预算或外部线性渐近项。

有限点集的最近点距离是连续函数，在闭背景盘上达到最大值，因此逐圆心的严格界也给第1节上确界的严格界。

## 5. 向外有理实现

[实现](edge_covering.py)以对数上端选择略大的有理ε，以平方根下端选择略小的内盘半径。这样每一步都会扩大最终覆盖上端。默认根网格至少n²，避免固定输出精度掩盖理论速率。

|n|整个闭背景盘的覆盖半径严格上端（向上取整）|
|---:|---:|
|10000|0.108347272667|
|1000000|0.011649541114|
|100000000|0.001240459360|
|1000000000000|0.000013708518|

这些是普遍必要上端，不是实际最优点集覆盖半径的数值。它们与此前固定内盘的更细常数6/√(n−1)分别保留范围。

[精确验收](edge_covering_verification.json)核对独立尾指数、正项级数、起点、多个有限n和向外取整。普遍结论依赖上述证明，未声称全域最优构型、最优覆盖常数、外部同行评审或整篇形式化验证。
