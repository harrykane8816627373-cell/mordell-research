# 角向矩、空洞与有限原子性：库仑缺额的新联合证书

研究资料与项目发起：蒋丰灿（Fengcan Jiang）；本轮推导和程序包含 Codex 协作。2026-10-30。本地研究稿，尚未上传GitHub；不作外部优先权声明。

本稿联合已证明的圆盘库仑分解、严格子集半径界和现有可达下界，得到三个结果：径向与角向缺额可相加；任意位置的空洞可被排除；有限原子性给圆盘上界一个显式正折扣。最后一个折扣随n增长很小，不解决锐值问题。

## 1. 已有输入及记号

令n≥2，N=n(n−1)/2，Σ|zᵢ|²=n，Δ=∏ᵢ<ⱼ|zᵢ−zⱼ|²。已有无条件上界为

```math
U_n=n^{n/2}\left(\frac{2n}{n-1}\right)^N e^{-N/2}.
```

令xᵢ=√((n−1)/n)zᵢ，r=√(2/n)，μ=(1/n)Σσᵣ(·−xᵢ)，μ₀为半径√2圆盘的均匀概率，ν=μ−μ₀。σᵣ为均匀圆盘概率。已有分解给

```math
\delta(z):=\log\frac{U_n}{\Delta(z)}\ge n^2D(\nu),\qquad
D(\nu)=\frac1{2\pi}\int_{\mathbb R^2}|\nabla h|^2,
\quad h=(-\log|\cdot|)*\nu.
```

其径向投影能量恰为

```math
D_0=\frac12\int_0^\infty
\frac{(F_\mu(s)-\min(s/2,1))^2}{s}\,ds.
```

这些输入的完整来源为此前的 `source-review/RADIAL_LAYERS.md`、`configuration-bounds/radial_audit.md`。全局最大者重心为零，严格真子集定理给n≥3时|zᵢ|²<2(n−1)/n；n=2可直接核对非严格版本。

## 2. 角向矩的完整常数与可加性

选R≥√2并满足max|xᵢ|+r≤R，令Sₖ=Σxᵢᵏ。任意有限K都有

```math
\boxed{\quad
\delta(z)\ge n^2D_0+
\sum_{k=1}^{K}\frac{|S_k|^2}{kR^{2k}}.
\quad}                                                    \tag{1}
```

这是任意归一化无碰撞构型的结论；R必须按该构型或该构型类的真实支撑上包选择。只有应用到已知全局最大者时，才能使用其专有半径界。

**证明。** 对k≥1取两个试验函数

```math
\phi_{k,c}(\rho,\theta)=a_k(\rho)\cos k\theta,\quad
\phi_{k,s}(\rho,\theta)=a_k(\rho)\sin k\theta,
\qquad
a_k(\rho)=\begin{cases}\rho^k,&\rho\le R,\\
R^{2k}\rho^{-k},&\rho\ge R.\end{cases}
```

它们连续、具有有限Dirichlet能量。直接积分给每个函数的归一化梯度范数平方为kR²ᵏ：圆盘内、外各贡献kR²ᵏ/2。不同k及正弦/余弦两支相互正交，且都与径向梯度正交。

分部积分给⟨h,φ⟩=(1/(2π))∫∇h·∇φ=∫φdν。由于zᵏ调和，圆盘平均保持其中心值；μ₀的正阶复矩为零。因此两个内积分别为Re(Sₖ/n)、Im(Sₖ/n)。对这些互相正交的方向及完整径向投影应用Bessel不等式，得到(1)。无穷远的边界项消失，因ν总质量为零、φ衰减；也可先截断后取极限。

特别地，角向和不能误加两倍；仅计算圆盘外能量会少掉一半，以上内外计算确定了系数1/k。

所以此前任意认证的径向下界d_rad≤n²D₀，可以直接升级为

```math
\Delta(z)\le U_n\exp\left(-d_{\rm rad}
-\sum_{k=1}^{K}\frac{|S_k|^2}{kR^{2k}}\right).             \tag{2}
```

这与旧方法只取几个上界的最小值不同：此处可相加的理由是能量空间正交性。

## 3. Newton恒等式给无条件的显式正折扣

对每个全局最大者可统一取

```math
R_n=\sqrt2\left(\frac{n-1}{n}+\frac1{\sqrt n}\right),\qquad
T_n=\frac{nR_n^2}{n-1},\qquad
c_n=\frac{(\log2)^2}{\displaystyle\sum_{k=2}^{n}T_n^k/k}>0.
```

Rₙ≥√2，且由严格子集半径界覆盖全部平滑圆盘。于是有全n上界

```math
\boxed{\qquad M_n\le U_n e^{-c_n}<U_n\qquad(n\ge2).\qquad} \tag{3}
```

**证明。** 设yᵢ=xᵢ/Rₙ，sₖ=Σyᵢᵏ，q=max|yᵢ|。由Σ|xᵢ|²=n−1，q²≥(n−1)/(nRₙ²)=1/Tₙ。又s₁=0。令E(t)=∏(1+yᵢt)=Σeⱼtʲ。Newton形式恒等式说明：对j≤n，eⱼ等于

```math
\exp\left(\sum_{k=1}^{n}(-1)^{k-1}s_kt^k/k\right)
```

的tʲ系数。取|y_*|=q并用E(−1/y_*)=0，逐系数三角不等式得到

```math
1\le\sum_{j=1}^n|e_j|q^{-j}
\le\exp\left(\sum_{k=2}^n\frac{|s_k|}{kq^k}\right)-1.
```

这里先比较**有限阶形式系数**，再用非负系数指数级数作上包；没有在多项式零点处代入发散的对数级数。故Cauchy不等式给

```math
(\log2)^2\le
\left(\sum_{k=2}^n\frac{|s_k|^2}{k}\right)
\left(\sum_{k=2}^n\frac{q^{-2k}}{k}\right)
\le\left(\sum_{k=2}^n\frac{|S_k|^2}{kR_n^{2k}}\right)
\sum_{k=2}^n\frac{T_n^k}{k}.
```

代入(1)即得(3)。这是对所有全局最大者统一成立的折扣，故得到无条件Mₙ上界。

若需要纯有理版本，用任意有理R²上包Q_R≥Rₙ²，及log2>2/3，即得

```math
c_n^{\mathbb Q}=
\frac{4}{9\displaystyle\sum_{k=2}^{n}(nQ_R/(n-1))^k/k}>0,
\qquad M_n\le U_ne^{-c_n^{\mathbb Q}}.
```

程序给向外舍入的Q_R和cₙᑫ。这个折扣迅速变小，不改变已知线性渐近系数上端，不是锐值，也不保证优于每个小n的其他旧上界。已有锐界及截断指数等上界仍应一起取最小。

## 4. 角向矩如何排除构型类

设已认证Lₙ≤Mₙ，Bₙ≥log(Uₙ/Lₙ)。若某个全局候选区域的角向项与径向项之和严格大于Bₙ，该区域不含全局最大者。

例如在库仑尺度，假设全部点位于某条过重心的旋转条带|Im(e⁻ⁱᶿxᵢ)|≤w。由于Σ|xᵢ|²=n−1，

```math
|S_2|\ge(n-1-2nw^2)_+,\qquad
\delta(z)\ge\frac{(n-1-2nw^2)_+^2}{2R_n^4}
\quad\hbox{（若它是全局最大者）}.                        \tag{4}
```

n=100时Rₙ²=11881/5000。取w²=1/10，右端为78012500000/141158161，大于已有有效缺额上包1657/12。因此**任何方向、全宽2/√10的该条带都不能容纳全局最大构型**。这是以反证法使用全局半径界的全局候选排除；不能给条带内任意非最优构型擅自套上Rₙ。

一般固定k，由Bₙ=O(n)得到|Sₖ|=O(√n)，故归一化正阶复矩为O(n⁻¹ᐟ²)。对二阶矩，这给平面协方差两个特征值的显式差界。它与旧径向CDF的O(n⁻¹ᐟ³)约束描述不同方向，可同时使用。

### 八点的联合椭圆约束

对八点全局最大者，既有候选C₈=8²⁸/7²¹给

```math
\delta_8\le\log(U_8/C_8)=40\log2-7\log7-14\lt\frac{21}{200}.
```

R₈²<49/16，且xᵢ=√(7/8)zᵢ，故Sₖ=(7/8)ᵏᐟ²pₖ。取这个稍宽但系数简单的半径上包，(1)给

```math
d_{\rm rad}+\sum_{k=2}^{8}\frac{(2/7)^k}{k}|p_k|^2
\lt\frac{21}{200}.
```

特别地

```math
\boxed{|p_2|^2+\frac4{21}|p_3|^2\lt\frac{1029}{400}.}      \tag{6}
```

因此|p₂|≥3/2且|p₃|≥3/2的整块区域不含全局最大者。此判断只用明确解析不等式及有理对数包围，不做驻点数值枚举。

已有局部稳定迹界|p₂|≤20/13（见旧 `work/first2_attack/conic_geometry_20261018.md`）应同时保留。(6)单独投影到p₂轴比旧界弱，**不宣称刷新单独p₂上界**；其新增用途是联合限制p₂与p₃，同时还可保留p₄至p₈及径向罚项。没有据此排除整个p₂p₃≠0分支。

## 5. 任意位置的空洞及多个空洞

若开圆盘B(a,ρ)位于背景圆盘B(0,√2)内，且每个平滑点盘均不进入该开圆盘（充分条件|xᵢ−a|≥r+ρ），取ψ(y)=(ρ²−|y−a|²)₊。直接积分给

```math
\int\psi\,d\nu=-\rho^4/4,\qquad
\frac1{2\pi}\int|\nabla\psi|^2=\rho^4.
```

因此δ≥n²ρ⁴/16。多个互不相交的空盘，其梯度支撑互不相交，所以罚项可相加。更进一步，每个ψ都与第2节的全部角向试验函数正交：其支撑位于R盘内，后者在那里调和，分部积分即给零。于是

```math
\boxed{\delta(z)\ge
\sum_{k=1}^{K}\frac{|S_k|^2}{kR^{2k}}
+\frac{n^2}{16}\sum_j\rho_j^4.}                           \tag{5}
```

**不能再把完整径向能量与这些空洞罚项直接相加**，因为二者通常不正交。安全组合是“角向项+max{径向已证罚项，互不相交空洞罚项}”。

对全局最大者，令η=2(Bₙ/n²)¹ᐟ⁴。若|a|+η<√2，则必有一个xᵢ满足|xᵢ−a|≤r+η。否则可选略大于η且仍处于背景盘内的空盘，与(5)矛盾。由Bₙ=O(n)，任意固定内部紧圆盘上的覆盖半径为O(n⁻¹ᐟ⁴)。这把旧“中心附近至少有一点”推广到所有内部位置，但没有达到预期微观尺度O(n⁻¹ᐟ²)。

## 6. 下一步真正需要解决的环节

1. 将现有径向有理区间盒与p₂、p₃等复矩区间共同传播，用(2)作整盒排除；这针对旧径向方法看不见的角度集中区域。
2. 驻点恒等式可提供混合矩消元，例如Σ|zᵢ|²zᵢ=0、(n−1)Σ|zᵢ|²zᵢ²=(2n−3)p₂。需在同一盒中同时保留径向与角向相关性，分别取范围会损失强度。
3. 全部p₂p₃≠0分支尚未排除：这些矩可以接近零，仅靠它们非零不能给统一正缺额。Newton项解决了“所有前n阶矩一起消失”的障碍，但所得小折扣不足以填满八点锐界缺口。
4. 上界(3)的薄弱处是把每个系数都取绝对值以及只用最大半径的平均下界。可进一步研究在驻点/稳定矩阵约束下，截断角向能量的严格最小值；这比继续调整构造数值更直接地朝全局上界推进。
