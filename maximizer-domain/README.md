取x=√(9/10)z，Σ|x|²=9。旧整数见证准确给出Δ(x)>L=(97/80)9⁹。每个全局最大点居中，任一对的u=|xᵢ|²、v=|xⱼ|²、t=Re(xᵢconj(xⱼ))必须满足

```math
0\le u,v<15403/10000,\quad t^2\le uv,\quad d=u+v-2t>2/5,
\quad 9(u+v)+2t<664/25.
```

此外，令

```math
q=9-9(u+v)/8-t/4,\quad\delta=5q-28,\qquad
b=\frac{(81u+v+18t)(u+81v+18t)}{4096}.
```

在0<δ<2时还有非线性必要式

```math
(\delta+2)^2d\,b^8q^{28}\ge(2-\delta)^2L\,7^{21}.
```

q是剩余八点去重心后的总平方模，已证q>142/25=5.68；旧严格子集仅给q>28/5=5.6。点半径旧上端81/50=1.62也收紧为1.5403。点对(3/2,3/2,−1/4)通过新半径、点距和线性约束，却违反非线性式，因此新条件并不重复。

点距d>2/5沿用[严格子集定理](../finite-n/SUBSET_PROOF.md)的两点情形：质量10时两点去重心质量d_z/2>2/9，再乘缩放因子9/10即得d>2/5。

## 1. 保留交互多项式的二阶Schwarz信息

在质量9尺度，最大点也全局最大化Δ(x)exp(−5Σ|x|²)。大小m子集围绕自身重心a伸缩t时，其条件目标为|tᵏP(t)|²exp(−5Qₛ|t|²)，k=m(m−1)/2。令f=P/P(1)。全局性给f(1)=1、单位圆上|f|≤1，驻点给f′(1)=δ=5Qₛ−k。子集偏移之和为零，直接展开各外点对应的m个交互因子，得到P′(0)=0，所以f′(0)=0。

置A=f(0)。非恒定性保证|A|<1。圆盘自同构g=(f−A)/(1−conj(A)f)在0有至少二阶零，因此g(t)=t²h(t)、|h|≤1。沿半径在t=1求导，得到Re(h′(1)/h(1))≥0，从而

```math
\delta\ge2\frac{|1-A|^2}{1-|A|^2}\ge2\frac{1-|A|}{1+|A|}.
```

因此当0<δ<2时，|P(1)|²≤((δ+2)/(2−δ))²|P(0)|²。已有严格子集定理同时给δ>0；相关自含来源见[严格子集证明](../finite-n/SUBSET_PROOF.md)。

## 2. 删除一个点：半径上端

删除平方半径u的点后，九点去重心质量q=9−10u/9；|P(0)|²=(100u/81)⁹。使用[九点锐界](../nine-point-global/PROOF.md)，在δ=5q−36∈(0,2)时，

```math
\Delta(x)\le F_9(u):=\frac{q^{36}}{8^{28}}
\left(\frac{100u}{81}\right)^9\left(\frac{\delta+2}{2-\delta}\right)^2.
```

旧严格子集界给u<81/50。若u≥15403/10000，则δ∈(0,2)。F₉在此区间严格递减：其对数导数小于9/u−100/9<0，其中用了1/(δ+2)+1/(2−δ)≥1。端点的准确有理计算给F₉(15403/10000)<L（比值约0.999673779），与全局最大值≥L矛盾，故半径界成立。

## 3. 删除两点：非线性必要式与补集质量

八点子集重心为−(xᵢ+xⱼ)/8，质量q如上。两个外点到该重心的平方距离乘积恰为b，故|P(0)|²=b⁸。使用[八点锐界](../eight-point-global/PROOF_BRIDGE.md)，其内部距离积≤q²⁸/7²¹；外部两点距离贡献为d。二阶Schwarz即给上述非线性必要式。

下面不预设u,v的大小，直接从这个必要式推出q>142/25。若q≤142/25，则旧子集界q>28/5保证0<δ≤2/5。置r=72−8q、s=u+v，则9s+2t=r。由|t|≤s/2，r/10≤s≤r/8。于是d=10s−r∈[0,r/4]，且

```math
b\le(41s+18t)^2/4096=(5r-4d)^2/4096,
\quad db^8\le\frac{5r}{68}\left(\frac{80r}{17}\right)^{16}/2^{96}.
```

最后一步对d(5r−4d)¹⁶求导，其唯一内点最大值在d=5r/68。代回得到只依赖q的上端F₈(q)。在q∈(28/5,142/25]，其对数导数为

```math
28/q-136/(72-8q)+10/(\delta+2)+10/(2-\delta)>0.
```

后面三项已有下端55/6−136/(664/25)>0。故F₈递增，而准确计算F₈(142/25)<L（比值约0.992495406），矛盾。将q>142/25换元即得9(u+v)+2t<664/25。
