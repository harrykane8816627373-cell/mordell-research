# 一般 n 构型：规则分量障碍、两点联合约束与自由构型改进

研究资料与项目发起：**蒋丰灿（Fengcan Jiang）**；本轮推导、程序及整理包含 OpenAI Codex 协作。2026-10-29。承接 f0ef6c7048fa3ddcf0181972c7c8fe3994c6030d。

本轮从“规则环是否真的满足完整力平衡”切入，同时放开每个点的位置。得到两条一般 n 的必要条件、可量化的余式证书，以及91项严格可达下界改善。**没有确定一般 n 的最优构型或全局锐值。**

## 本轮证明与核验

|结果|结论与边界|入口|
|---|---|---|
|正规分量人口障碍|若驻点含一个以重心为中心的正 m 边形，且另有 M>0 个非中心点，则 m≤M；其余点可以任意分布。M=m 时还有稀疏多项式必要形式|[证明](STATIONARITY.md)|
|完整驻点余式与定量缺口|上一轮99个所选规则候选中91个非驻点；23个人口模式的全部半径、连续相位均被人口定理排除。非零余式给严格改进空间 Γ>0|[算法](stationarity.py)、[证书](stationarity_verification.json)|
|点距—半径差联合约束|去掉稳定性算子中已饱和的尺度方向，得到适用于所有局部最大点的两点标量式，并排除一个非空八点厚区域|[证明](PAIR_STABILITY.md)、[整盒证书](pair_stability_verification.json)|
|自由点移动的整数见证|10≤n≤100全部91项超过旧完整包络；27点至少提高104.12%，100点至少提高35.12%。10、11、12点只提高极小量|[结果与坐标](SEARCH_RESULTS.md)、[整数见证](integer_witnesses.json)|
|新下界反馈到任意全局最优者|39≤n≤42至少3层；80≤n≤85至少4层。没有提高一般 n 的层数渐近常数|[逐项严格预算与层数](witness_verification.json)|

主两点式采用 Σ|z_i|²=n、a=|z_i|²、b=|z_j|²、s=|z_i−z_j|²：

~~~math
s_0=\frac{2n}{(n-1)^2},\qquad
(a-b)^2\le(n-1)(s-s_0)
\left[1+\frac{(n-1)(n-1-a-b)}{2n}s\right].
~~~

它是二阶稳定性的必要条件，比仅保留 s≥s_0 更细；不能与库仑缺额罚项直接相加。

## 复现

从仓库根目录或[离线包](mordell-symmetry-breaking-2026-10-29.zip)解压根目录运行：

~~~bash
python -B -S -O symmetry-breaking/verify_all.py
~~~

接受流程只需 Python 标准库，校验固定输入，复制到临时目录，重跑三个独立入口并比较确定性报告：

1. 多项式余式、直接坐标力、缩放不变性和量化上升。
2. 稳定性投影的复数/实代数展开及整个有理盒排除。
3. 所有整数点乘积、全部此前下界、严格对数包围及必要层数。

[统一报告](verification_report.json) · [字节清单](source_manifest.json) · [来源与计算边界](PROVENANCE.json)。

可选的重新探索需要 NumPy，绘图需要 Matplotlib；它们不属于数学接受流程。重新探索可能因平台浮点差异选到不同候选，只有重新通过整数接受的候选才形成可达下界。当前公开整数见证可以在无这些库的环境重放。
