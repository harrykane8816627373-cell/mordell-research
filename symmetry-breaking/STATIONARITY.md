# 规则分量人口障碍、稀疏多项式与完整驻点余式

研究资料与项目发起：蒋丰灿（Fengcan Jiang）；本轮推导与代码包含 OpenAI Codex 协作。2026-10-29。承接提交 f0ef6c7048fa3ddcf0181972c7c8fe3994c6030d。

这里延续用户原稿的力平衡和多项式方法。原稿已证明**两条人口不同的正规环不能驻定**，见[原文对应命题](../source-review/revised_main.tex)。下面把一条正规环之外的点放宽为任意位置，并把解析必要条件转成精确余式证书；不把旧两环定理记作本轮新发现。

## 1. 一条正规环之外必须有足够多的非中心点

令构型中心为原点，归一化前二阶矩为 Q，N=n(n−1)/2，κ=N/Q。无碰撞驻点满足

~~~math
\sum_{j\ne i}\frac1{z_i-z_j}=\kappa\overline z_i.
~~~

假设其中 m≥2 个点组成以原点为中心的正 m 边形，其根多项式为 z^m−a，a≠0，平方半径为 b。另有 h∈{0,1} 个原点，以及 M=n−m−h 个**任意非零点**，它们不要求共圆或规则。令这些点的首一根多项式为 Q_0(z)，所以 deg Q_0=M，Q_0(0)≠0。

在正规环的每个根处，乘以 z 的驻点方程为

~~~math
\frac{m-1}{2}+h+\frac{zQ_0'(z)}{Q_0(z)}
  =\kappa b.
~~~

因此 z^m−a 整除

~~~math
H(z)=zQ_0'(z)+C Q_0(z),\qquad
C=\frac{m-1}{2}+h-\kappa b.
~~~

若 0<M<m，则 deg H≤M<m，迫使 H≡0。但常数项为 C Q_0(0)，故 C=0；最高项又是 M z^M，矛盾。于是

~~~math
\boxed{M=0\quad\text{或}\quad m\le M.}
~~~

这对任意驻点成立，因此也对全部局部、全局最大点成立。它不要求正规环位于最外侧。M=0 的单环及中心单环是必须保留的例外。条件 m≤M 只是必要条件，不保证存在驻点。

直接推论：含至少两条非零正规环的驻点，每条环人口均不超过非中心总人口的一半；两环情形恢复已有等人口结论。三环及更多环中，若某环占多数，该人口模式的**所有半径和连续相位**均被排除。

## 2. 人口恰好平衡时，剩余点多项式必须稀疏

若 M=m，写 Q_0(z)=z^m+Σ_{k=0}^{m−1}q_k z^k，则余式消失等价于

~~~math
(k+C)q_k=0\quad(1\le k<m),\qquad
(m+C)a+Cq_0=0.
~~~

必有 C≠0,−m。若 C 不属于 {−1,…,−(m−1)}，则 Q_0 只能是二项式 z^m+q_0。若 C=−k，则

~~~math
\boxed{Q_0(z)=z^m+q_kz^k+\frac{m-k}{k}a.}
~~~

这只是正规环一侧力平衡的必要形式；还须检查剩余点自身的方程、无碰撞与二阶条件。它提供有限的稀疏多项式分支，不能直接宣称完成平衡人口的分类。

## 3. 多环的完整余式检验

对于 h 个原点和 K 条正规环，设第 i 环为 z^{m_i}−c_i 的根，平方半径 b_i，所有半径严格递增。定义

~~~math
Q_i(z)=\prod_{j\ne i}(z^{m_j}-c_j),\quad
C_i=\frac{m_i-1}{2}+h-\kappa b_i,\quad
H_i(z)=zQ_i'(z)+C_iQ_i(z).
~~~

整个构型驻定，当且仅当每个 H_i 模 z^{m_i}−c_i 的余式为零。若存在原点，其力平衡自动成立，因为每条 m_j≥2 的正规环逆根和为零。这里检验的是**允许各个点独立移动的完整驻点条件**，不只是整体旋转或同步改变环半径的条件。

实现限制 m_i 为偶数、b_i 为正有理数、c_i=ε_i b_i^{m_i/2}，ε_i∈{−1,1}，因此所有系数均为有理数。一般复相位的上述解析准则仍成立，但没有在本实现中对全部相位做代数消元。

## 4. 非零余式给出定量的改进空间

记余式为 T_i(z)=Σ_{k=0}^{m_i−1}t_{ik}z^k。正规环上的离散正交性给

~~~math
\sum_{z^{m_i}=c_i}|T_i(z)|^2
  =m_i\sum_k|t_{ik}|^2b_i^k.
~~~

完整力残差为 r_z=overline(Σ_{w≠z}1/(z−w))−κz。在环上有 |r_z|=|H_i(z)|/(|zQ_i(z)|)，而

~~~math
|zQ_i(z)|^2\le
b_i\prod_{j\ne i}(b_i^{m_j/2}+b_j^{m_j/2})^2.
~~~

故其平方范数 R=Σ|r_z|² 满足显式有理下界

~~~math
R\ge R_0:=
\sum_i
\frac{m_i\sum_k|t_{ik}|^2b_i^k}
{b_i\prod_{j\ne i}(b_i^{m_j/2}+b_j^{m_j/2})^2}.
~~~

若某个余式非零，则 R_0>0。另一个无需开根的点距平方下界为

~~~math
d_0=\min\left\{
\frac{16b_i}{m_i^2},\
\frac{(b_j-b_i)^2}{2(b_i+b_j)}\ (i<j),\
b_i\ \text{若有原点}
\right\}>0.
~~~

同环项用 sin(π/m)≥2/m，跨环项用平方根的三角不等式。由[已有显式残差上升](../configuration-bounds/ascent_audit.md)，可进一步得到

~~~math
\boxed{
\log M_n-\log F(z)\ge
\Gamma:=\frac{R_0}{2n^2/d_0+\kappa},\qquad
F(z)=\left(\frac nQ\right)^N\Delta(z).}
~~~

证明该简化分母：Σr_i=0，所以 A=Σ_{i<j}|(r_i−r_j)/(z_i−z_j)|²≤nR/d_0；R≤n(n−1)²/d_0，而 C=max|(r_i−r_j)/(z_i−z_j)|≤√(2R/d_0)≤n(n−1)/d_0。原步长的增益 R²/[(2A+κR)+2CR] 因而至少为 R/(2n²/d_0+κ)≥Γ。归一化后的上升构型确实可达，无需把浮点导数当作证据。

Γ>0 时也得到严格的存在性下界 M_n>F(z)(1+Γ)。这是**当前构型距离全局最优至少还有多少**的下界，绝非全局误差上界，也不主张 Γ 很大。Q R_0 与 Γ 均在统一缩放下不变。

## 5. 本次完整执行范围

对上一轮 DP 选出的 2≤n≤100 共99个固定人口、半径、符号候选，精确检验显示：

- 恰有91个不满足完整驻点条件，余式及 Γ 均有精确证书。
- 通过驻点检验的点数恰为 2,3,4,5,6,7,9,11。通过不等于最优；n=11 的中心正十边形已由原稿判为不稳定。
- 其中23个人口模式被第1节定理整体排除，甚至不需要固定半径或相位。

n=8 的被检 DP 候选是两环构型，不是仓库保留的更强“原点加正七边形”候选；不能据此声称排除八点目标等号构型。
