# 对径投影的四次能量误差

采用质量九。取内点一对和按外角序相隔四位的四对外点，写作 \(m_i\pm a_i\)（\(i=0,\ldots,4\)）。令 \(M=\|m\|_2,\ \delta=2M^2/9\)，并把全部中点归零后重新归一到质量九，得到对径构型 \(A=\{\pm b_i\}\)，其中 \(b_i=a_i/\sqrt{1-\delta}\)。对于任一全局最大构型 \(Z\)，有
\[
0\le \log\Delta(Z)-\log\Delta(A)\le 150 M^4.
\]
当 \(M\le1/30\) 时，系数 \(150\) 可以换为 \(74\)。这个结论适用于所有最大构型。它把对径投影的能量误差控制到四次阶，并同时给出投影力的二次阶误差。

## 统一分离与角隙控制

下文对所有 \(i<j\) 和两个符号使用 \(d=a_i\pm a_j,\ \eta=m_i-m_j\)。[径向带](../ten-point-angular-radii/README.md)、[内边界](../ten-point-inner-edge/README.md)及[外点配对](../ten-point-tight-pairing/README.md)给出 \(0.9359<|a_i|<1.128\)（外对），\(|a_0|<0.3641\)。内外对因此有 \(|d|>4/7\)。

记两相邻外角的允许范围为 \((\alpha,\beta)=(\arccos(39/50),\arccos(59/100))\)。对一对外点，把第二个取反，再取两向量的半和。其辐角偏离两辐角均值的量，是斜率绝对值至多
\[
\frac{1.128-.943}{1.128+.943}\cdot\frac1{\sqrt{63}}
\]
的反正切。这里 \(1/\sqrt{63}\) 来自配对方向偏差的一半。复核器检查该夹角小于 \(0.012\) 弧度。按角序延拓至下一半周后，均值辐角的相邻间隙是两条原间隙的平均值。故对径投影的相邻间隙属于 \((\alpha-.024,\beta+.024)\)。所有外外夹角的最小圆周距离至少为 \(\alpha-.024\)，其余弦小于 \(.78+.024\)。这也给出 \(|d|>4/7\)。

小中点时可以进一步保留实际二次误差。对一对外点，辐角均值与 \(\arg a_i\) 之差等于 \(\tfrac12\arg(1-(m_i/a_i)^2)\)。其绝对值至多为 \(|m_i|^2/[2(|a_i|^2-|m_i|^2)]\)。把相邻两对的这两个界相加，就得到对应投影外角间隙的误差。归一后的外平方半径则由
\[
|b_i|^2=\bigl((|m_i+a_i|^2+|m_i-a_i|^2)/2-|m_i|^2\bigr)/(1-\delta)
\]
直接包围。

[内点中点界](../ten-point-inner-midpoint/README.md)和[外点配对](../ten-point-tight-pairing/README.md)给出 \(|m_0|<.087,\ |m_i|<.172\)（外对），故 \(|\eta|<43/125\)。于是每个 \(v=\eta^2/d^2\) 均满足 \(|v|<3/8\)。

## 用驻点性消去二次能量项

置 \(L=\log\Delta-5\sum |z|^2\)。任一质量九最大构型都是 \(L\) 的驻点及全局最大点。对所有点保持 \(a\) 不动，考虑中点 \(tm\)，则
\[
L(a,tm)-L(a,0)=2\sum_{i<j,\pm}\log|1-t^2v|-10t^2M^2.
\]
在 \(t=1\) 求导得 \(\sum\Re(v/(1-v))=-5M^2\)。代回能量差得到
\[
L(a,m)-L(a,0)=2\Re\sum_{i<j,\pm}\bigl(\log(1-v)+v/(1-v)\bigr).
\]
右侧每条边的级数从 \(v^2\) 开始。若 \(|v|\le\rho<1\)，则其绝对值至多为 \(|v|^2(1+\rho)/(1-\rho)\)，因为 \(v^2\) 的系数为一，更高次系数至多为二。居中给 \(\sum_i m_i=0\)，故 \(|m_i|^2\le(4/5)M^2\)。写 \(t_{ij}=\Re(m_i\bar m_j)\)，展开四次差分得到
\[
\sum_{i<j}|m_i-m_j|^4=5\sum_i |m_i|^4+M^4+2\sum_{i,j}t_{ij}^2\le7M^4.
\]
最后一步用 \(\sum_i|m_i|^4\le(4/5)M^4\) 和 \(\sum_{i,j}t_{ij}^2\le M^4\)。又因 \(|a_i-a_j|^2+|a_i+a_j|^2=2(|a_i|^2+|a_j|^2)\)，两个符号中至少有一个对应的 \(|d|>99/100\)。对这两个符号分别用 \(4/7,99/100\) 作长度下界，并分别取 \(\rho\le(43/125)^2/|d|^2\) 或 \(\rho\le2M^2/|d|^2\)，便得到所列两个系数。归一化将 \(L(a,0)\) 增加 \(45[-\log(1-\delta)-\delta]\ge0\)，所以同一上界适用于质量九的投影 \(A\)。

## 投影的力残差

对平方像 \(b_i^2=\widehat r_i e^{i\theta_i}\)，令 \(g_{s_i},g_{\theta_i}\) 分别为 \(L(A)\) 在 \(s_i=\log\widehat r_i,\theta_i\) 的导数。对于全局最大构型，
\[
\left|(g_{s_i}+10\delta\widehat r_i)+\mathrm i\,g_{\theta_i}\right|
\ \le\ 38\bigl(5|m_i|^2+M^2\bigr).
\]
比较 \(L(a,m)\) 与 \(L(a,0)\)。保持 \(m\) 固定时，\(a_i\) 对平方像的对数半径和辐角的导数分别为 \(a_i/2\) 和 \(\mathrm i\,a_i/2\)。单条修正项 \(2\log|1-v|\) 的这两个导数合成一个复数，模长至多为 \(2|a_i||\eta|^2/[|d|(|d|^2-|\eta|^2)]\)。每对有两条这样的项。完整驻点性消去 \(L(a,m)\) 的两项导数，且 \(\sum_j|m_i-m_j|^2=5|m_i|^2+M^2\)。归一化只改变惩罚项的径向梯度，改变量为 \(-10\delta\widehat r_i\)。当中点较小时，系数 \(38\) 也可换为 \(4(1.128)/[(4/7)((4/7)^2-2M^2)]\)，只要分母为正。

## 中点方向的六次必要条件

定义投影处的二次型 \(Q_a(m)=10M^2+2\Re\sum v\)，仍令 \(v=\eta^2/d^2\)。将中点乘以 \(\sqrt{t}\)，在 \(t=1\) 取二阶导数。局部极大要求
\[
\Re\sum\frac{v^2}{(1-v)^2}\ge0.
\]
一阶力方程给 \(Q_a(m)=-2\Re\sum v^2/(1-v)\)。由于 \(v^2/(1-v)=v^2/(1-v)^2-v^3/(1-v)^2\)，得到
\[
Q_a(m)\le 2\sum_{i<j,\pm}\frac{|\eta|^6}{|d|^2(|d|^2-|\eta|^2)^2}.
\]
同一对的两项分别取 \(|d|\) 的短边下界 \(4/7\) 和长边下界 \(99/100\)。结合 \(\sum_{i<j}|\eta|^6\le2M^2\sum_{i<j}|\eta|^4\le14M^6\)，得全域 \(Q_a(m)\le2017M^6\)。当 \(M\le1/30\) 时，系数降为 \(846\)。这使中点非零的构型必须满足一个六次量级的二次型上界，可直接用于中点方向的区间排除。
