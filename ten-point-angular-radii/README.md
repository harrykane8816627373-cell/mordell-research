# 十点全局最大构型的逐点径向范围

取总平方半径为 9。任一全局最大构型有两个内点，平方半径严格落在 \((0.084,0.159)\)，八个外点的平方半径严格落在 \((0.89,1.271)\)。此前认证的两个区间为 \((0.074,0.172)\) 和 \((0.845,1.312)\)。[此前的逐点证书](../ten-point-refined-radii/README.md)

## 角序分组与 Ward 方程逐行求和

对标记点 \(z_i\) 的九条边，记 \(u=|z_i|^2\)、\(v=|z_j|^2\)、\(t=\operatorname{Re}(z_i\bar z_j)\)、\(d=u+v-2t\)。用质量守恒、质心、标记点径向力和前三阶 [Ward 条件](../stationary-kernel/README.md)得到六项逐行零和函数。

\[
\begin{gathered}
v-1+u/9,\quad t+u/9,\quad (u-t)/d-5u/9,\quad vt+u^2/9,\\
(v-17/10)(2t^2-uv)+(u-17/10)u^2/9,\\
(v-8/5)(4t^3-3uvt)+(u-8/5)u^3/9.
\end{gathered}
\]

例如，第四项来自 \(\sum_j |z_j|^2 z_j=0\)，乘以 \(\bar z_i\) 后取实部，再将对角项均分到九条边。后二项分别乘以 \(\bar z_i^2,\bar z_i^3\) 作同样处理。

标记内点有一条内内边和八条内外边。标记外点有两条内外边和七条外外边，外点循环间隔 1、2、3、4 的边数为 2、2、2、1。对每个标记平方半径小区间，取同一组六个有理乘子。令 \(G=h-\log d\)，其中 \(h\) 是[曲率核](../ten-point-curved-kernel/README.md)。每个邻点类别有一个有理下界 \(c_j\)。程序在整个标记区间与相应邻点域上验证 \(G\) 减去六个加权行项的和至少为 \(c_j\)。因行项精确抵消，九条边的缺额和至少是各 \(c_j\) 乘以类别重数之和。

余下 36 条边使用[角序分区上界](../ten-point-angular-upper/README.md)的下界。由类别重数，其补偿分别为 0.0017572 和 0.0017569。程序从候选根证书重算 \(B-\log C_{10}^{(9)}\) 的有理上端。每段标记区间的严格行下界都超过补偿与此上端之和。因此四个被排除闭区间均不含任何全局最大构型的平方半径。

## 内点半差长度的单变量凹性

固定两个内点的中点 \(m\) 和连线方向 \(e\)，以及全部外点。令 \(w\) 为内点有向半差长度的平方，两内点写作 \(m\pm\sqrt w\,e\)。对外点 \(z_j\) 写 \(p_j=\bar e(z_j-m)\)。在质量 9 时，完整最大构型同时最大化 \(L=\log\Delta-5\sum|z_i|^2\)。沿固定数据的切片，依赖 \(w\) 的项为

\[
F(w)=\log(4w)+2\sum_{j=1}^8\log|p_j^2-w|-10w.
\]

在既有内边范围 \(41/400\le w\le W=11/80\) 内，令 \(M=239/2000\)，于是 \(|m|\le M\)。可用 \(g(u)=(\sqrt{u}-M)^2-W\) 作 \(|p_j^2-w|\) 的严格正下界。函数 \(g(u)^{-2}\) 在新外带上凸，因为其二阶导数符号由 \(3g'^2-g''g>0\) 决定。用两端的有理上界构造割线，结合外点平方半径和至少 \(9-2(W+M^2)\)，得

\[
F''(w)\le-1/W^2+2\sum_{j=1}^8 g(|z_j|^2)^{-2}<-15.
\]

固定这些数据时，内点半差长度至多有一个驻值。对参考值 \(w_0\)，切片上界为 \(F(w_0)+F'(w_0)^2/30\)。这给出一个可独立使用的消元步骤。它与外角凹性各自固定其余参数。
