# 严格子集条件与共同质量、重心预算

本文保留19dbbd3阶段的计数与证明；最新进展见[11月4日续算](NOV4_PROGRESS.md)。

2026-11-02。蒋丰灿（Fengcan Jiang）研究项目；OpenAI Codex 协作。

本次把[已有严格子集定理](../finite-n/SUBSET_PROOF.md)中的点距和改写为共享二阶矩与子集重心，加入逐点范数传播，并按上轮30个开放盒逐一核算完整闭合。所有算术使用同一组13个实际坐标，第八点准确由中心化闭合。

## 1. 保留子集共有的变量

在质量7、中心化的八点全局最优者上，对任意2≤m≤7的真子集 S，已有结论为

~~~math
W_S:=\sum_{i<j,\ i,j\in S}|q_i-q_j|^2
>\frac{m^2(m-1)}8.
~~~

准确恒等式

~~~math
W_S=m\sum_{i\in S}|q_i|^2-
\left|\sum_{i\in S}q_i\right|^2
~~~

允许使用共同质量 Σ|q|²=7，而无需把每条边的最大值独立相加。设各点平方范数的有效区间为 [lᵢ,uᵢ]，子集重心和的模方下界为 c_S，则

~~~math
W_S\le U_S:=
m\min\left\{\sum_{i\in S}u_i,
7-\sum_{j\notin S}l_j\right\}-c_S.
~~~

若 U_S 不大于严格阈值，整盒无解。子集和同时由十三变量的准确线性式、直接的点包围域之和，以及补集和的负值包围；这三者取交。

对每个 m 检查全部子集，共246类。该条件属于全局最优者归约，不能移用于一般稳定驻点；实现包含明确的作用域检查。

## 2. 传播给每一个点

由严格下界可得

~~~math
\sum_{i\in S}|q_i|^2>
\frac{m(m-1)}8+\frac{c_S}{m}=:L_S.
~~~

因此对 i∈S、j∉S，分别有保解收缩

~~~math
|q_i|^2\ge L_S-\sum_{k\in S\setminus\{i\}}u_k,
\qquad
|q_j|^2\le7-L_S-\sum_{k\notin S,\ k\ne j}l_k.
~~~

实现将 L_S 向下取整后用于非严格区间收缩，保留所有满足原严格不等式的真实点。随后利用 |xᵢ|²+|yᵢ|² 的新上下界收缩两个坐标，再传播准确重心条件。全局半径界与共同质量也同时保留。

[实现](subset_budget.py)在整数网格上完成这些步骤；[联合接口](subset_force.py)再接入原真实力、复余项、Newton必要像、旧椭圆、目标值和完整Hessian必要条件。一次与两次组合分别标记 `joint_force_subset_fast`、`joint_force_subset`，每个旧节点按原版本重放。

## 3. 连续域的严格加强例

四个点分别落在实、虚部均为 [−2/5,2/5] 的小方盒时，独立地相加六条边的平方距离上界给

~~~math
6\cdot\frac{32}{25}=\frac{192}{25}>6,
~~~

尚不能直接否定四点严格子集阈值。共同范数预算却给

~~~math
W_S\le4\cdot4\cdot\frac8{25}=\frac{128}{25}<6.
~~~

因此整个连续四点内区被排除。这是共享变量的整盒结论，不依赖在盒内采样。一般地，对2≤m≤7，若 m 点同处某个半径平方不大于 (m−1)/8 的圆盘，平移上面的恒等式即可排除它们属于全局最优者。

独立检查还用有理直角三角形给出 W_S=9/4 的准确边界盒，确认严格阈值的等号也被拒绝。

## 5. 复现

默认完整重放祖先及当前全部算术：

~~~bash
python -B -S -O joint-refinement/verify_force.py
~~~

仅当8be9f91的固定证明此前已经验收，且61个旧算术输入逐字节不变时，可复用该前缀：

~~~bash
python -B -S -O joint-refinement/verify_force.py --accepted-prefix-already-replayed
~~~

该模式仍从固定输入临时副本核算全部新增步骤，并在[执行记录](reports/force_execution.json)中标明实际范围。完整排空要求所有当前开放叶为0。

继续搜索时，可用 `propose_edge.py --leaves ... --narrow-first` 明确选择已有开放叶。该生成器的搜索结果与独立验收分开记录；[新的119/80半径界](TARGET_RADIUS.md)另以独立节点版本使用。
