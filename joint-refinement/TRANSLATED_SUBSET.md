# 固定有理平移中心的严格子集预算

2026-11-04。蒋丰灿（Fengcan Jiang）研究项目；OpenAI Codex 协作。

本页保留已有全局最优者严格子集条件，不增加新的外部定理。对任意真子集
S、m=|S|，以及任意固定复数 c，准确有

~~~math
W_S:=\sum_{i<j\in S}|q_i-q_j|^2
=m\sum_{i\in S}|q_i-c|^2
-\left|\sum_{i\in S}q_i-mc\right|^2
>\frac{m^2(m-1)}8.
~~~

最后的严格不等式沿用[既有全局子集定理](../finite-n/SUBSET_PROOF.md)。
平移恒等式本身没有全局性要求；使用严格阈值排除时必须处于全局最优者归约。

对一个连续坐标盒，先为该子集固定 c：分别将各点区间中点的平均值向下取整到
同一整数网格。此后 c 不随盒内实际点改变。各项 |qᵢ−c|² 取向外上界，
子集和同时由准确十三变量线性式、直接点区间相加、补集负和三者取交，
再对其减去 mc 的模方取向外下界。于是得到严格有效的 W_S 上界 U_S。
若 U_S≤m²(m−1)/8，整个连续盒无解；等号也必须排除。

平移改变的是区间估计的宽度，不改变待证的实际点距和。特别是若子集集中在
离原点较远的小盒中，先平移再估计可避免把共同偏移计成彼此独立的范数误差。

例如三个点各自处于以 −1/2−i/2 为中心、实虚半宽均为1/3的方盒内。
独立相加三条边的平方距离上界为8/3，大于严格阈值9/4；以原点展开的
独立范数与重心下界也不足以排除。选择该共同中心却直接给

~~~math
W_S\le3\cdot3\cdot2(1/3)^2=2<9/4.
~~~

这是对整盒的结论，不依靠采样。向下取整中心造成的微小网格偏差由同一向外
算术包含，实际脚本仍严格拒绝该连续例。

其存活返回值 aux[0] 为已收缩的八个实际点区间，aux[1] 为距离区间。

`translated_subset_budget`；若三份重心包围的交集已空，理由为
`translated_subset_geometry`。原有内核及其接受语义不变。
