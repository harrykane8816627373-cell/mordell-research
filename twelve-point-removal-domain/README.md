# 十二点全局最大构型的删点必要域

取质量11。每个全局最大点的平方半径 (u) 满足 (u<81/50)。删除任意两点后，余下十点的去重心质量 (q) 满足 (q>7573/1000)。这两条将旧端点 (121/72) 和 (15/2) 分别收紧，并与既有九点子集约束互补。

对任意两点记 (u=|z|^2,v=|w|^2,t=\operatorname{Re}(z\overline w))。第二个结论等价于 (11(u+v)+2t<3427/100)。另有更强的非线性两点条件。

## 输入和统一估计

设 (L) 为旧整数十二点见证在质量11的准确可达值。原有限圆盘上界给任意 (m) 点、去重心质量 (q) 的距离积上界

\[
U_m(q)=m^{m/2}\left(\frac{2q}{m-1}\right)^{m(m-1)/2}e^{-m(m-1)/4}.
\]

这里取 (U_{11}(q)<C_{11}q^{55}) 和 (U_{10}(q)<C_{10}q^{45})，其中

\[
E(x)=\sum_{j=0}^{100}\frac{x^j}{j!},\qquad
C_{11}=\frac{11^5(33166248/10^7)(1/5)^{55}}{E(55/2)},\quad
C_{10}=\frac{10^5(2/9)^{45}}{E(45/2)}.
\]

正项指数级数及 ((33166248/10^7)^2>11) 保证两个有理上界。有限圆盘上界见 `asymptotics/proof.tex` 的定理 `thm:finite`。

对任一待伸缩子集 (S)，记 (k=|S|(|S|-1)/2\)、去重心质量为 (q)，并令 (delta=6q-k)。既有二阶 Schwarz 条件给出

\[
|P(1)|^2\le \left(\frac{\delta+2}{2-\delta}\right)^2|P(0)|^2\qquad(0<\delta<2),
\]

其中 (P) 是子集绕自身重心作复伸缩的交互多项式。它来自完整最大性及 (P'(0)=0)，见 `maximizer-domain/README.md`。质量11时齐次指数目标为 (Delta e^{-6Q})。旧严格子集界给 (delta>0)，见 `finite-n/SUBSET_PROOF.md`。

## 删一个点

全局最大构型居中。删除平方半径 (u) 的点，余下十一点质量为 (q=11-12u/11)，交互常数项平方为 ((144u/121)^{11})。旧子集界给 (q>55/6) 及 (u<121/72)。若 (u\ge81/50)，则 (0<\delta=6q-55<2)，从而

\[
\Delta\le F_{11}(u)=C_{11}q^{55}(144u/121)^{11}
\left(\frac{\delta+2}{2-\delta}\right)^2.
\]

该区间上 ((\log F_{11})'<11/u-144/11<0)。这里 (55q'/q<0)，且 (1/(\delta+2)+1/(2-\delta)\ge1)。准确端点计算给 (F_{11}(81/50)/L<997/1000)，与全局最大性矛盾。

## 删两个点

令 (a=-(z+w)/10) 为余下十点重心，并记

\[
q=11-\frac{11}{10}(u+v)-\frac t5,\quad
d=u+v-2t,\quad
b=\frac{(121u+v+22t)(u+121v+22t)}{10000},\quad \delta=6q-45.
\]

这里 (b=|z-a|^2|w-a|^2)。交互常数项平方等于 (b^{10})。因此 (0<\delta<2) 时，任何全局最大点必须满足

\[
\boxed{\ (\delta+2)^2 C_{10}q^{45}d\,b^{10}\ge(2-\delta)^2 L.\ }
\]

令 (R=11-q)，外部二点去重心质量为 (s=d/2)。重心分解给 (0\le s\le R) 及 ( |z-a|^2+|w-a|^2=(6R-s)/5)。故 (d b^{10}\le 2s((6R-s)/10)^{20}\le (4R/7)^{21})。最后一步将 (s(6R-s)^{20}) 对 (s) 求导，导数为 ((6R-s)^{19}(6R-21s))。唯一内点最大在 (s=2R/7)，代回即得。

在待排除的 (15/2<q\le7573/1000) 内，(0<\delta<2)，且

\[
\Delta\le F_{10}(q)=C_{10}q^{45}(4(11-q)/7)^{21}
\left(\frac{\delta+2}{2-\delta}\right)^2.
\]

对数导数至少为 (45/q-21/(11-q)+12>0)，而 (F_{10}(7573/1000)/L<992/1000)。这排除全部待排除区间，给出 (q>7573/1000)。

## 精确复核和剪枝

从仓库根目录执行 `python -B -S -O twelve-point-removal-domain/verify_all.py`。核验器重算旧见证、两个严格端点、有理导数条件及展开系数。对全部66个旧见证点对重算新必要条件。点对 ((8/5,8/5,-1/2)) 及每个变量独立变化 (\pm1/1000) 的整个闭盒通过新半径、点距、物理性和线性补集条件，却被非线性式排除。`pair_box_excluded` 提供可直接接入有理两点覆盖的充分剪枝函数。这个例子是变量域的一块，并未要求它能完成为一个十二点构型。

默认运行比较新算出的报告与保存记录。Python 调用者可使用 `verify_single_radius(V11)` 独立重算半径证书，参数必须等于本目录固定的质量11见证值。
