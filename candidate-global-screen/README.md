## 保存的1000次搜索

每个n有100个起点：5个已有构型/螺旋锚点、30个已有候选扰动、30个圆盘样本、20个高斯样本、10个增删点延拓、5个其他螺旋。随机种子为2026110800+n，每次最多500步，使用仓库既有无对称约束优化器。筛选条件为保存的梯度最大分量小于10⁻⁵。完整记录在`data/n10.json`至`data/n19.json`。

除15点外，保存的最佳log值与固定候选的增量不超过6.2×10⁻¹³，属于这里的浮点精度尺度；没有因此宣称构型完全相同。15点有约4.88×10⁻⁹的增量。已证明“不稳定”的对象是旧微小盒内的真实驻点，**不能把该结论自动套到这次略有改进的数值点**；新点是否靠近另一个局部最大仍待真实根及完整Hessian认证。

16点的高复现率和较大已观察差值值得继续定位；它尚未获得与10、12、19点相同的真实根认证，故没有仅凭搜索频率把它排为首选。`geometry_report.json`中的特征值、半径分层和矩残差都是浮点诊断，其范围与后面的精确对称证书分开。

## 候选自身的精确对称

|n|已证二面体群|群阶|精确半径层人口|O(2)点对三元组类型数|
|---|---|---:|---|---:|
|10|D₂|4|2、4、4|15|
|12|D₃|6|3、3、6|14|
|19|D₆|12|1、6、6、6|22|

这里Dₖ采用阶为2k的约定。点对三元组是(u,v,t)=(|zᵢ|²,|zⱼ|²,Re(zᵢconj(zⱼ)))，半径按大小排序；类型数不是纯距离类型数。该三元组在整体反射下也不变，故是O(2)分类，不是完整的SO(2)轨道分类。原数值探索记录中保留的`SO2_pair_contact_types_at_tolerance_1e_8`字段也仅计这类三元组；精确报告采用更准确的`O2_pair_contact_types_exact`名称。19点旋转固定的单点严格为原点。

`verify_symmetry.py`先重放既有完整力方程的压缩证书，取得旋转规范y₀=0、x₀>0中的唯一真实根z*。若压缩映射T的中点残差上端为η、整盒收缩常数上端为q<1，则真实根位于中点的η/(1−q)邻域。该更小邻域用于变换包围，避免用原大盒的宽度误差推断对称。

对保存的旋转置换τ，把置换后的点重新整体旋转，使第一个点回到正实轴；对反射置换ψ，另施共轭后同样规范化。旋转、重排和共轭均保持完整力方程。程序使用整数区间及整数平方根包围两种规范化变换，并严格验证它们都进入原唯一根盒，故变换后的真实根就是z*。τ的精确置换阶为k、ψ为二阶，且ψτψ=τ⁻¹，生成2k个不同置换。根无碰撞，因而对应平面旋转的阶也恰为k；这证明候选具有所列精确二面体群作用。

随后计算该群的点轨道和无序点对轨道；不相交的有理半径区间证明不同点轨道对应不同半径层，不相交的三元组区间证明不同点对轨道不是额外重合的接触类型。对任意径向权重w，旋转不变性立即给

```math
\sum_i w(|z_i^*|^2)(z_i^*)^j=0\qquad(k\nmid j).
```

这些消失矩只属于已经认证的候选根。未知全局最大点尚未被证明对称；构造全局核函数时不能把这些等式当作所有待排除构型的前提。

10点另核验了后续矩形刚性所需的非退化条件。以内层某点w为实轴，二面体群中的一条反射固定w，因此各层二阶复矩严格为实数。内层矩为2a₀（a₀为该层平方半径）。对两个四点外层，整数区间直接包围

```math
c_r=\frac{\sum_{i\in r}\big((x_i^2-y_i^2)(\Re(w)^2-\Im(w)^2)
          +4x_iy_i\Re(w)\Im(w)\big)}{|w|^2}
```

并证明0<|cᵣ|<4aᵣ。由中心对称和等半径，每个四点外层本来就是两个反向点对；这两个严格不等式分别排除二阶矩为零的方形端点及共线重合端点，可用于核函数等号条件的矩形刚性分析。报告保留全部有理区间；此处采用质量10尺度，按统一缩放转到质量9不改变这些非退化性质。

12点也保存了相应的三阶矩非退化证书。取最内三点层的一点w，程序在已认证D₃群中找出固定w的反射；其轴是w所在直线，所以各半径层在此规范下的三阶复矩都是实数。为免平方根，直接用整数区间复乘包围

```math
C_r=\operatorname{Re}\sum_{i\in r}(z_i\overline w)^3.
```

两个三点层由三阶旋转自动为正三角形，其矩模平方准确为9(aᵣa₀)³，故非零（a₀=|w|²）。程序也直接验证三个Cᵣ的区间均不含零。六点外层另满足严格式0<Cᵣ²<36(aᵣa₀)³，排除其三阶矩为零及两个正三角形重合的端点。它支持外层两组三角形的核零集刚性分析；此处采用质量12尺度。

19点的三个非零半径层各有六点，已认证六阶旋转使它们分别严格为正六边形。类似选一层点w及固定w的D₆反射，得到各正半径层的六阶矩在w轴规范下为实且非零；未除以|w|⁶的矩模平方准确为36(aᵣa₀)⁶，程序同时给出不含零的有理区间。以上结构均是候选自身的严格性质，仍未对未知全局最大点施加对称假设。

## 复核与依赖

从仓库根目录执行：

```bash
python -B -S -O candidate-global-screen/verify_all.py
```

该接受器仅用Python标准库：验证固定输入和原搜索来源哈希，复算1000条保存记录的聚类、分层频率、次高差值及最佳增量，并用独立标准库浮点计算交叉检查固定候选log值。**这部分没有重新搜索，也不把浮点计算变为区间证明。**它随后独立运行精确对称接受器，重新认证三个真实根及上述群作用，最后要求完整结果与保存报告一致。所有接受检查在`-O`下仍执行。

`search.py`和`geometry.py`是可选探索程序，需NumPy；正式接受器不导入它们。完整源文件、数据和上游依赖由`source_manifest.json`绑定，报告见`verification_report.json`。
