# 十二点锐核的精确接触与局部不等式

2026-11-09。蒋丰灿研究项目，OpenAI Codex 协作。本文在质量11的真实 \(D_3\) 候选上，构造了恰好接触 \(\log |z-w|^2\) 的两点函数。十四类点对全部精确取等。十三个内点有正定缺额 Hessian，唯一的 Gram 边界点有正定切向 Hessian 和严格正的向内导数。十二个基础 Gram 块均严格正定，候选的核和为零。外带内还存在一组严格负缺额的有理点对，因此这一构造目前给出接触邻域内的锐两点不等式。

## 系数域和候选零条件

沿用两点函数 \(h=p(u)+p(v)-K'(u,v,t)\) 及对角修正，写 \(G=h-\log d\)，其中 \(d=u+v-2t\)。这次取 \(B=\log\Delta(z^*)\)，\(z^*\) 为已认证的真实候选。候选是有理多项式方程组的孤立实根，规范坐标为实代数数。若 \(h\) 的非常数系数全为代数数，即使其常数项允许含 \(B\)，任意两个候选点对之间的 \(h\) 值之差仍是代数数。两个不同候选距离平方的比是正代数数且异于1。由 Hermite–Lindemann 定理，其对数为超越数，因此需要把各类候选点距的对数引入系数。 [候选与精确群作用](../candidate-global-screen/README.md) · [原 Ward 核求和](../twelve-point-ward-upper/README.md)

径向特征用精确候选半径节点和矩均值。对 \(k=3,6,9\)，记 \(m_k\) 为候选在基底 \(\phi_j(u)=(u-1)^j\) 的矩向量，使用四个特征 \(\phi_j-(m_k)_j/(m_k)_0\)，\(j=1,\ldots,4\)。固定内三角形的反射轴后这些比值为实数，区间重放验证三个分母异于零。非三倍数的谐波矩由旋转自动为零。于是每个基础块的候选矩为零，且其核和的导数也为零。

Ward 修正沿用四个低阶块，另取 \(a_0^TM_0^*=a_3^TM_3^*=0\)。因为 \(v_k^TM_k^*=0\)，这使 \(A_0M_0^*=A_3M_3^*=0\)，从而在完整构型空间的一阶导数也消失。其余两个块的候选矩 \(M_1^*,M_2^*\) 自身为零。该空间含165个对称 Gram 条目和22个 Ward 参数。

这两个附加条件也由锐接触的一阶等号所要求。写内、中三角形分别为 \(a\omega^j,-b\omega^j\)，外带为 \((c\pm id_0)\omega^j\)，\(\omega=e^{2\pi i/3}\)。沿 \((\delta a,\delta b)=(b,-a)\) 有 \(dQ=0\)，而三阶 Ward 矩 \(F_3=\sum_i (|z_i|^2-5/3)z_i^3\) 的导数为

~~~math
15ab\big[a(a^2-1)+b(b^2-1)\big]<0.
~~~

严格号来自已认证的 \(a^2\in(0.17,0.18)\)、\(b^2\in(1.07,1.09)\)。点对缺额求和的一阶条件先迫使 \(a_3^TM_3^*=0\)，再用改变总质量的一阶方向迫使 \(a_0^TM_0^*=0\)。在候选附近，点对域的半径与距离端点均有严格余量，实际点坐标变分自动保持 Gram 条件。

## 接触方程的秩与精确回代

十四个值条件、十三个内点的39个导数条件和一个边界点的两个切向条件中，有六个同半径内点的 \(u,v\) 导数重复。合并后，接触矩阵为 \(49\times187\)。它有以下五条独立行关系。

- 对值条件按点对轨道的重数求和。候选总核和为零，故任一参数方向的加权和为零。右端同样满足，因 \(B=\sum_{i<j}\log d_{ij}^*\)。
- 对 \(D_3\) 参数 \(a,b,c,d_0\) 作四个独立的一阶变分。各参数方向的总核和导数为零，右端的总导数也为零，因为候选完整力给 \(d\log\Delta=6\,dQ\)。四条关系独立。取三个半径 \(a^2,b^2,c^2+d_0^2\) 和一类内外点对的 \(t=ac\)，它们对这四个参数的微分独立，因 \(a,b,d_0>0\)。若四条加权切向关系的组合为零，则每类点对的对应三元组微分均为零，故该变分为零。

因此秩至多44。整数区间高斯消元逐个验证一个44阶子式非奇异，证明秩恰为44。保存的数值解只指定回代的起点。把选定44个系数加上该子式给出的精确改正，即满足选定方程。五条相容关系将精确等号延伸到其余方程。程序同时检查所有行的区间残差包含零。 [固定子式](minor.json) · [数值起点](seed.json)

## 局部不等式和补集

把精确系数表示为上述线性系统的解，并用384位整数区间包含它。对候选距离用正项对数级数包围，区间 LDL 验证全部基础 Gram 块。对十三个内部接触点，\(G=0\)、梯度为零且完整 Hessian 正定。对唯一的反向共线点对，在 \(t=-\sqrt{uv}\) 面上验证 \(G\) 的切向梯度为零及切向 Hessian 正定，同时验证 \(tG_t<0\)。由连续性与 Taylor 定理，各接触点都有相对开邻域，\(G\) 在其中非负并仅在接触点为零。

程序还用同一精确系数在有理点对 \((941/1000,1419/1000,-979/1000)\) 验证 \(G<-1/4000\)。该点严格位于外外带，满足 Gram、最小距离和删二点线性条件。它把余下的证书任务具体化为在保留精确接触和局部曲率的仿射解空间里重新拟合，并覆盖接触邻域之外的必要域。 [半径分带](../twelve-point-ward-radii/README.md) · [删点必要域](../twelve-point-removal-domain/README.md)
