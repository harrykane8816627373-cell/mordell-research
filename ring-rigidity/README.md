# 三环人口刚性与旋转对称阶的Hessian上限

研究资料与项目发起：蒋丰灿（Fengcan Jiang）；推导、整理与精确程序包含OpenAI Codex协作。2026-11-05。

本专题把[已有逐点力余式方法](../symmetry-breaking/STATIONARITY.md)推进到两个不依赖预设相位的结构结论。它们使用**每个点独立移动的完整驻点及二阶条件**，不是只优化多环半径和整体角度。

- **三环人口刚性：** 恰由三条同心正规多边形、互异正半径及至多一个中心点组成的无碰撞驻点，三个人口必须完全相等。原有“最大环不超过其他环总人口”在这里加强为全部相等，覆盖任意连续相位。
- **旋转阶上限：** 任意无碰撞驻点若在阶数 $m\ge2$ 的旋转下不变，非零点分成 $K$ 个轨道，另有 $h\in\{0,1\}$ 个中心点，则成为局部最大点的必要条件为

```math
\left\lfloor\frac{m^2}{4}\right\rfloor\le2(n-1+h),\qquad n=Km+h.
```

这里不同轨道可以位于同一圆周，不要求“一个轨道就是一个半径层”。若至少两条轨道半径不同，不等号还必须严格。违反条件给出完整Hessian的不稳定性及显式正的二阶间隙。

对三条互异半径的正规环，先由第一条结论知道它们人口均为 $m$，再由第二条结论得到：无中心时 $m\ge24$、有中心时 $m\ge25$ 均不可能是局部最大点。对固定轨道数的一般结论是：无中心 $m\ge8K$ 必不稳定；有中心且 $K\ge2$ 时 $m\ge8K+1$ 必不稳定。单轨道情形恢复已知的正 $m$ 边形 $m\ge8$、中心正 $m$ 边形 $m\ge10$ 的失稳阈值；这些单环阈值属于已有成果。

人口相等并不保证驻定或局部最优。精确Hermite六点、七点构型给出三条人口均为2的真实驻点，但一个打破正规环结构的切向扰动产生严格正二阶变分60、105，故二者都不稳定。

在仓库根目录运行：

```powershell
python -B -S -O ring-rigidity/verify_all.py
```

程序只用Python标准库，关键判断不使用可被 `-O` 跳过的断言。独立验证包括一般参数的多项式消元恒等式、全部非单位根的有理迹运算、总非中心人口不超过100的三环余式分组、Hermite真实驻点及非径向Hessian方向。有限人口清点不代替一般定理的解析证明。默认命令不修改证书；`--record-report` 用于保存新的实际执行报告。

这些结论给出一般点数最优构型的必要结构：精确的高阶旋转对称与固定少量规则层会受到完整Hessian限制。没有确定一般 $n$ 的锐值、最佳晶格或所有等人口三环的驻点分类，也不把未排除的人口列作存在或最优认证。没有全球优先权或整篇形式化证明声明。
