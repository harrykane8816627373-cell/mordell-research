# 全部连续相位下的三环刚性与完整Hessian障碍

2026-11-05。本专题承接蒋丰灿项目的完整力平衡、根多项式余式及二阶收缩条件，证明均自包含。多边形涡旋相对平衡有长期文献，例如Celli、Lacomba、Pérez-Chavela的 [On polygonal relative equilibria in the N-vortex problem](https://arxiv.org/abs/0811.1785)。这里不借用外部多环分类，也不作全球优先权声明。

## 1. 设置与已有输入

目标为 $\Delta(z)=\prod_{i<j}|z_i-z_j|^2$，质量 $Q=\sum|z_i|^2>0$，总点数 $n$。任何无碰撞物理驻点满足

```math
\sum_{j\ne i}\frac1{z_i-z_j}=\kappa\bar z_i,\qquad
\kappa Q=\frac{n(n-1)}2.
```

本文各点权重均为1。所有圆和旋转均以原点为中心。中心点数 $h$ 只能为0或1；非零正规环人口至少2。它们自动中心化，不同半径上的点不会碰撞。

已知的[单环人口障碍与余式准则](../symmetry-breaking/STATIONARITY.md)是：对一条人口 $m$、根常数 $D\ne0$、半径 $r$ 的正规环 $z^m=D$，其余非零点根多项式为 $P_0$，令

```math
C=\frac{m-1}{2}+h-\kappa r^2.
```

逐点驻点方程等价于 $z^m-D$ 整除 $zP_0'(z)+CP_0(z)$。这是对环上**全部实际点**施加的条件；没有把多环参数空间的一阶条件当作完整驻点。

## 2. 三环人口必须完全相等

**定理1。** 恰由三条同心正规多边形、三个互异正半径及可选的一个原点组成的无碰撞驻点，其三个人口必须相等。相位为任意复单位数，不限于对齐、交错或实二项式常数。

**证明。** 按人口排序为 $a\le b\le m$。所有根常数非零。

**恰有两个最大人口。** 若 $a<m=b$，在其中一条 $m$ 环上，另一条 $m$ 环的作用乘以 $z$ 后是常数。剩下的 $a$ 环贡献为 $az^a/(z^a-A)$，其中 $A\ne0$。映射 $t\mapsto at/(t-A)$ 在非极点处单射，因而 $z^a$ 必须在全部 $m$ 个根上相同，即 $m\mid a$，与 $0<a<m$ 矛盾。

同一论证有精确多项式证书。令被测试环常数为 $X$、另一大环常数为 $Y$、小环常数为 $A$，则余式在 $z^a$ 和常数项的系数为

```math
R_a=(a+m+C)X-(a+C)Y,\qquad
R_0=A\{CY-(m+C)X\}.
```

它们满足 $AR_a+R_0=aA(X-Y)$。两个 $m$ 环无碰撞保证 $X\ne Y$，右侧非零，所以两系数不可能同时消失。

**唯一最大人口。** 现设 $a\le b<m$。在 $m$ 环上，外部多项式为

```math
P_0(z)=(z^a-A)(z^b-B)
=z^{a+b}-Bz^a-Az^b+AB.
```

若 $a+b\ne m$，则在模 $z^m-D$ 的余式中，常数项只有 $CAB$，因为 $0<a,b<m$ 且 $0<a+b<2m$。最高项落在 $(a+b)\bmod m$，与其余三个指数均不同，其系数为 $(a+b+C)D^q$，其中 $q\in\{0,1\}$。常数项消失迫使 $C=0$，最高项却非零，矛盾。这也覆盖 $a=b$ 时两个中间项合并或抵消的情形。

若 $a+b=m$ 且 $a\ne b$，两个中间指数分别孤立，故 $-(a+C)B=0$ 和 $-(b+C)A=0$，同样矛盾。

仅剩 $a=b$、$m=2a$。中间系数和常数系数为

```math
R_a=-(a+C)(A+B),\qquad R_0=(2a+C)D+CAB.
```

两条 $a$ 环半径互异，故 $|A|\ne|B|$，尤其 $A+B\ne0$。所以 $C=-a$、$D=AB$，并有

```math
\kappa r_D^2=\frac{4a-1+2h}{2}.
```

记三条平方半径为 $u,v,w$，其中 $w=r_D^2$。由 $D=AB$ 的模长得 $w^2=uv$。总点数 $n=4a+h$、质量 $Q=a(u+v+2w)$。由于 $h\in\{0,1\}$，

```math
n(n-1)=4a(4a-1+2h).
```

结合总体virial关系和上式，得 $u+v=2w$。于是 $(u-v)^2=(u+v)^2-4uv=0$，进一步 $u=v=w$，与半径互异矛盾。故唯一最大人口也不可能存在。唯一剩下的人口模式是 $a=b=m$，证毕。

**范围。** 不同半径不可删除：例如一个正多边形在同一圆上可能被拆成多条小正规多边形。定理不声称等人口三环一定存在驻点，更不声称驻点是极值。它不排除四条及更多正规环的人口不等模式。

**与旧成果的关系。** 原稿已证明两环人口相等，旧专题只对任意多环给出“最大人口不超过其余非中心人口”。本定理完成三环的严格人口障碍。旧 `earlier-results/general_n_notes.tex` 中的 $2+2+4$ 三层分析允许四点组是一般矩形，并有专门的八点值比较；这里限制该组为正规多边形，却对任意人口、任意尺度、中心与全部连续相位给出直接不驻定结论，两者的范围不同。

## 3. 任意旋转对称阶的完整Hessian上限

**定理2。** 设一个无碰撞驻点在 $z\mapsto\omega z$ 下不变，$\omega=e^{2\pi i/m}$、$m\ge2$。全部非零点分成 $K\ge1$ 个长度为 $m$ 的轨道，另有 $h\in\{0,1\}$ 个原点，故 $n=Km+h$。如果它是约束球面上的局部最大点，则

```math
\left\lfloor\frac{m^2}{4}\right\rfloor\le2(Km-1+2h)=2(n-1+h).
```

若至少两个轨道半径不同，不等号必须严格。不同轨道可以处于同一圆周；本定理不要求只有 $K$ 条半径层。

**证明。** 定义完整复对称逆平方Laplacian $A$：$A_{ij}=-(z_i-z_j)^{-2}$，对角元使行和为0。驻点满足 $Az=\kappa\bar z$。$\log\Delta-\kappa Q$ 的实Hessian二次型为

```math
\mathcal H(v)=-2\operatorname{Re}(v^TAv)-2\kappa\|v\|^2.
```

它在球面切空间上非正；径向与切空间对此二次型正交，且径向值为负，所以它在整个实空间非正。分别测试 $v$、$iv$，或使用对应实对称块矩阵，得到必要收缩 $\|A\|\le\kappa$。不要求二阶非退化。

取任一长度 $m$ 的轨道 $z_j=r\alpha\omega^j$，其中 $|\alpha|=1$，记完整 $A$ 限制在这些坐标上的主子块为 $B$。对角元包含**所有外部点**的作用。因为外部点集同样在乘以 $\omega$ 下不变，外部对角贡献恰有 $E/z_j^2$ 的形式，其中 $E$ 是某个复常数；不要求它为实数。

在该轨道的正交Fourier基 $f_k=(1,\omega^k,\ldots,\omega^{(m-1)k})/\sqrt m$ 上，直接求和给出

```math
Bf_k=\frac{\alpha^{-2}}{r^2}(E+c_k)f_{k-2},\qquad
c_k=\frac{(k-2)(k-m)}2,\quad 1\le k\le m.
```

$k=m$ 是常向量模式。这里 $c_k=\sum_{\ell=1}^{m-1}(1-\omega^{k\ell})/(1-\omega^\ell)^2$。可由 $c_1=(m-1)/2$、$c_{k+1}-c_k=k-(m+1)/2$ 得到上述闭式。映射 $k\mapsto k-2$ 只是基的置换，所以 $B$ 的奇异值正是 $|E+c_k|/r^2$。

实数 $c_k$ 的最大值与最小值相差

```math
\max_k c_k-\min_k c_k=\frac12\left\lfloor\frac{m^2}{4}\right\rfloor.
```

不论未知复数 $E$ 如何，由复平面的三角不等式，端点至少一个满足 $|E+c_k|\ge(\max c-\min c)/2$。因此主子块与完整矩阵的算子范数满足

```math
\|A\|\ge\|B\|\ge\frac{\lfloor m^2/4\rfloor}{4r^2}.
```

取最小轨道半径，$r_{\min}^2\le Q/(Km)$；若轨道半径不全相等，则严格小于平均值。由 $\kappa Q=n(n-1)/2$，得

```math
\frac{\|A\|}{\kappa}\ge
\Lambda:=\frac{Km\lfloor m^2/4\rfloor}{2n(n-1)}
=\frac{\lfloor m^2/4\rfloor}{2(Km-1+2h)}.
```

结合 $\|A\|\le\kappa$ 即得结论，证毕。

**定量不稳定性。** 若 $\Lambda>1$，完整实Hessian有正方向，最大切向Rayleigh商至少为 $2\kappa(\Lambda-1)>0$。理由是实对称表示的谱为 $\pm\sigma_j(A)$，故全空间最大值为 $2(\|A\|-\kappa)$；投影掉负的径向分量只会增大二次型并减小范数。因此这是一条允许各点独立移动的失稳结论。它不只是在多环参数空间内找到负曲率。

## 4. 精确阈值及三环推论

由定理2的整数条件，固定 $K$ 时：

- 无中心：$m\ge8K$ 均严格不稳定。
- 有中心、$K\ge2$：$m\ge8K+1$ 均严格不稳定。
- 有中心、$K=1$：$m\ge10$ 均严格不稳定。

例如无中心在 $m=8K$ 两侧之差为2，$m=8K-1$ 时为 $2-2K\le0$。有中心在 $m=8K+1$ 时差为 $2K-2$，$m=8K$ 时为 $-2$；单轨道需单独保留 $m=9$ 的等号。随后每跨两阶，此差增加 $m+1-4K>0$。这些算术推论均有精确多项式证书。

对三条互异半径正规环，定理1首先强迫人口为 $(m,m,m)$，所以它具有阶 $m$ 的旋转对称。于是无中心时 $m\ge24$、有中心时 $m\ge25$ 不可能是局部最大点。特别地，三正规环不能作为任意一般点数的统一最优构型公式。

一般旋转阶只按 $O(\sqrt n)$ 增长。等人口规则轨道的数目则至少按 $\sqrt{n/8}$ 的尺度增长。这是局部最大点的必要条件；不能据此认定真实最优者具有某个旋转群、晶格或精确正规层。

## 5. 等人口真实驻点仍可被非径向扰动破坏

三环人口相等的限制不是空洞的，但也远非充分条件。考虑单首一Hermite多项式

```math
P_6(X)=X^6-\frac{15}{2}X^4+\frac{45}{4}X^2-\frac{15}{8},
```

```math
P_7(X)=X^7-\frac{21}{2}X^5+\frac{105}{4}X^3-\frac{105}{8}X.
```

它们分别满足 $P_n''-2XP_n'+2nP_n=0$。$P_n/X^h$ 是 $X^2$ 的三次多项式，三个平方半径根分别落在

```math
n=6:\ (0,1/4),(1/4,2),(2,8);\qquad
n=7:\ (0,1),(1,3),(3,8).
```

各端点的精确符号相反，三次次数保证恰有三个不同正根。因此根集组成三条不同半径的正规二边形，$n=7$ 时另含原点。对所有实根，微分方程给 $P_n''(z_i)/(2P_n'(z_i))=z_i=\bar z_i$，所以完整逐点驻点方程精确成立，$\kappa=1$、$Q=n(n-1)/2$。

然而对任一这样的实驻点，$A(z^2)=2z^2-(n-1)1$。令实向量 $w_i=z_i^2-(n-1)/2$，则 $Aw=2w$、$\sum w_i=0$。取 $v=iw$，它与径向实向量正交，且保持一阶重心，因此是合法的全空间切向扰动。二阶变分为

```math
\mathcal H(iw)=2\|w\|^2>0.
```

Newton恒等式精确给出 $\|w\|^2=30$、$105/2$，对应二阶变分60、105。该扰动不保持每个反足点对为一条正规环，恰好说明“环参数内优化”与“全部点独立移动”之间存在实质区别。

## 6. 可复核范围

`verify_all.py` 只用有理数和整数：独立展开一般参数的余式消元恒等式、二元中心virial恒等式、Fourier递推及奇偶范围式；在 $2\le m\le128$ 用有理商环中 $(1-\omega)^{-1}$ 的精确表示，重算全部非单位根的迹；对非中心总人口不超过100的所有排序三环人口检查余式分组；对Hermite构型核验微分方程、三个正根隔离、Newton矩及正Hessian方向。

这些有限检查及源哈希记录实现和证书的实际范围。一般人口分类和一般旋转阶不等式由上文解析证明承担，不由有限目录替代。程序没有搜索一般最优构型，也没有确定等人口三环的全部驻点、稳定点或全局锐值。
