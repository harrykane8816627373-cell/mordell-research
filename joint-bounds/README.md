研究资料与项目发起：**蒋丰灿（Fengcan Jiang）**；推导、精确程序及交叉审阅包含 OpenAI Codex 协作。2026-10-28。基于仓库提交 `83d50bfb0685c088431955c9bfd1e67652331f77` 的补充研究。

本轮取得一个严格但数值较小的无条件全 n 上界改善、一个全 n 多环家族的统一下界改善，以及能把径向限制和一般非零复矩一起使用的排除接口。**八点完整锐界、一般 n 的简洁锐值公式及精确线性常数 γ 仍然开放。**

```math
M_n=\max_{\sum|z_i|^2=n}\prod_{i<j}|z_i-z_j|^2,
\quad N=\frac{n(n-1)}2,\quad
U_n=n^{n/2}\left(\frac{2n}{n-1}\right)^N e^{-N/2}.
```

## 1. 全部有限 n 的圆盘上界有显式正修正

令

```math
B_n=\left(1+\sqrt{\frac2{n-1}}\right)^2,
\qquad c_n=\frac{(\log2)^2}{\sum_{k=2}^n B_n^k/k}.
```

则对每个 n≥2，

```math
\boxed{M_n\le U_ne^{-c_n}<U_n.}
```

证明用旋转平均分离径向、角向 Dirichlet 能，再由有限 Newton 恒等式强制至少一个非零复幂和。无需任何未完成的驻点分类。n=8 时 c₈约为0.0020601107；代码给向下包围的正有理修正。此处只证明比指定的圆盘界严格更强，小 n 已有专门锐界仍然远强于它；cₙ趋零，不改变 γ。

[完整证明](ANGULAR_PROOF.md) · [有理实现](angular_bounds.py) · [验证报告](angular_verification.json)

## 2. 径向与非零复矩可以一起排除构型

取 x=√((n−1)/n)z，r=√(2/n)，R≥max|xᵢ|+r。令 ν 为平滑经验测度减均匀平衡圆盘，ν̄为旋转平均。对任何归一化无碰撞构型及有限 d，

```math
\boxed{\log\frac{U_n}{\Delta_n(z)}
\ge n^2D(\bar\nu)+\sum_{k=1}^d\frac{|p_k(x)|^2}{kR^{2k}},
\qquad p_k(x)=\sum_i x_i^k.}
```

既有径向人口、空洞和有理单元下界均可代入第一项。两部分正交，所以罚项可相加。若其和超过由可达下界 Lₙ得到的 log(Uₙ/Lₙ) 上端，整个指定构型类均被排除；无需预设规则角度。

例如八点库仑平方半径为{0,1,1,1,1,1,1,1}的类包含原点加正七边形，故仅凭径向数据不能排除它。再加 |p₂(x)|²≥2，则角向罚项至少16/81，大于候选构型给出的全局缺额预算0.104517，因而该子类不含全局最优者。正文给出其中 p₂p₃≠0 的非空例。这个例子没有覆盖所有八点非零矩分支。

## 3. 原多环家族对所有 n≥13 都可统一提高超过10%

保留原稿人口(6j)及其余半径参数，只把最内六点环的平方半径参数 b₁=6 改为21/4，再中心化、归一化。对**任意连续环旋转**，

```math
\log(\Delta'_n/\Delta_n)>\frac1{10},\qquad
\boxed{\Delta'_n>\frac{11}{10}\Delta_n\quad(n\ge13).}
```

n≥24由统一解析估计证明；13≤n≤23的11项由明确有理式补齐。随后在新固定半径处精确优化全部正负相位。在13≤n≤100的88项比较中，相对此前完整已存包络提高45项，n=91至少提高24.83%。比较保留了旧多环、格点、矩项、保存整数构型、旧相位及n≤30所有已公开一步上升见证；并非只与较弱旧相位比较。

这是可达下界和规定家族的改善，不是全连续相位、半径或平面原问题的全局最优。单个内环的对数增益为O(1)，不改变原多环线性渐近系数。

## 4. 用完整两矩信息加强子集递推

若正随机变量满足EX=μ、X≤L、VarX≥v、0<v<μ(L−μ)，设

```math
a=\mu-\frac{v}{L-\mu},\quad
p=\frac{(L-\mu)^2}{(L-\mu)^2+v},\qquad
\mathbb E\log X\le p\log a+(1-p)\log L.
```

这是这些信息下的精确上包。代入已有子集均值、方差和半径约束，严格加强上一轮统一二次Jensen损失。4≤n≤30、已知2≤m≤7共147组对比全部改善旧递推；**这147组新递推仍高于圆盘界**，所以这部分没有刷新当前整体上包络。六七点锐值输入保留原有外部分类依赖。
