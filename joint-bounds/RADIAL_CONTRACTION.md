# 原多环构造的全 n 径向改善：统一超过 10%

研究资料与项目发起：蒋丰灿（Fengcan Jiang）；本次推导与代码包含 OpenAI Codex 协作。2026-10-28。

沿用原稿多环人口与平方半径参数

```math
n_0=3k(k+1),\qquad r=n-n_0,\qquad
(m_j,b_j)=(6j,6j^2)\quad(1\le j\le k),
```

若 r>0，再加外环 `(r,n+n_0)`。原平方半径为 b_j/n；等价地，先用平方半径 b_j，再中心化并将总二阶矩归一化为 n。每个环允许**任意连续旋转**，不是只允许正负相位。

**定理。** 对每个 n≥13，将最内六点环的参数 b_1=6 改为 21/4，保留其余参数与全部环的旋转，再中心化、归一化。设变化前后距离平方乘积为 Δ、Δ′，则

```math
\log(\Delta'/\Delta)>\frac1{10},\qquad
\boxed{\Delta'>\frac{11}{10}\Delta.}
```

这是对原固定半径多环**整类**的严格改进，不识别原平面问题的全局最优。只改变一个六点内环，因此改进的对数保持 O(1)，不改变既有线性渐近系数 γ_pol。

## 1. 任意相位下的交叉项

记 t=7/8。最内六点环与人口 m、参数 b>6 的另一环之间，设 g=gcd(6,m)、p=3m/g、a=(6/b)^p、τ=t^p。Resultant 给出交叉乘积之比

```math
\left(\frac{|1-\tau a e^{i\phi}|^2}{|1-ae^{i\phi}|^2}\right)^g.
```

由于 0<a<1、0<τ<1，将分式看作 x=cosφ 的函数，其导数符号等于

```math
(1-\tau)(1-\tau a^2)>0.
```

所以该交叉比值至少是 `((1+τa)/(1+a))^(2g)`，其对数至少为 −2g a，使用 `log(1+a)≤a`。这些逐对最坏相位未必能同时达到；取其乘积仍是有效下界。

最内环内部的乘积比值恰为 t^15。只有可能的人口一外环对重心有贡献，因此中心化前后的二阶矩满足

```math
Q=n^2-\mathbf1_{r=1}\frac{n+n_0}{n}\le n^2,
\qquad Q'=Q-\frac92.
```

令 N=n(n−1)/2，归一化带来的对数增益为

```math
N\log\frac Q{Q-9/2}\ge \frac{9N}{2Q}
\ge\frac94\frac{n-1}{n}.
```

此处 Q 采用平方半径 b_j 的尺度；不可遗漏单点环的中心化修正。

## 2. 全部完整环与余数外环的损失

对完整环 j≥2，有 g=6、p=3j、a=j^(−6j)。所有这些交叉项的对数损失不超过

```math
12\sum_{j\ge2}j^{-6j}\le
12\sum_{j\ge2}2^{-6j}=\frac1{336}.
```

对余数外环，n≥24 时若 r≥6，则 b=n+n_0≥42、g≤6、p≥3，故损失至多 `12(6/42)^3=12/343`。若 1≤r≤5，则 g≤3、b≥37，因此损失至多 `6(6/37)^3<12/343`。没有余数环时此项为零。这里对所有 n≥24 都适用，不需要实际枚举其环数。

由 `−log(1−x)≤x+x²/(2(1−x))`，取 x=1/8 得

```math
15\log(7/8)\ge-\frac{225}{112}.
```

因此，对每个 n≥24 和任意连续相位，

```math
\log\frac{\Delta'}\Delta\ge
\frac94\frac{n-1}{n}-\frac{225}{112}-\frac1{336}-\frac{12}{343}
\ge\frac{3601}{32928}>\frac1{10}.
```

## 3. 仅 11 个小 n 的精确补齐

对 13≤n≤23，逐对最坏交叉比的乘积是明确正有理数

```math
G_n=t^{15}\left(\frac Q{Q-9/2}\right)^N
\prod_{(m,b)\ne(6,6)}
\left(\frac{b^p+(6t)^p}{b^p+6^p}\right)^{2\gcd(6,m)},
\quad p=\frac{3m}{\gcd(6,m)}.
```

接受程序以整数交叉相乘核对这 11 项均有 `G_n>21/19`。对 x≥1，积分或幂级数给出

```math
\log x\ge\frac{2(x-1)}{x+1},
```

故 `log G_n>1/10`。最小的所检有理下界在 n=13，约为 1.10749908699；十进数只作展示，验收比较不使用浮点数。最后 `exp(1/10)>1+1/10` 完成全 n 定理。

## 4. 新的精确可达下界和适用边界

在新参数处重新调用已有正负相位图分解，可精确求得该**新固定半径**正负家族的最大乘积 P_n^contract。将原最佳符号原样保留已给出上述严格改善，因此

```math
M_n\ge P_n^{\rm contract}>\frac{11}{10}P_n^{\rm graph}
\qquad(n\ge13).
```

对于正负相位，所有交叉 L=lcm(m_i,m_j) 都为偶数，乘积可完全用有理数计算。对一般正有理参数 b_i，记

```math
Q=\sum_i m_i b_i-\frac1n\sum_{m_i=1}b_i,
\qquad
D=\prod_i m_i^{m_i}b_i^{m_i(m_i-1)/2}
\prod_{i<j}\left|
s_j^{m_i/g}b_j^{L/2}-s_i^{m_j/g}b_i^{L/2}
\right|^{2g}.
```

则中心化且归一化的值恰为 `(n/Q)^N D`。公式只支持至多一个单点环；本多环数据满足该条件。实际点为对应正规多边形的根，不要求这些点本身是有理坐标。

`phase_search.py` 实现此公式与全符号图枚举，`verify_phase_search.py` 独立核对小点数的全部符号，并与**此前完整包络**取最大：原多环、方格、三角格、旧扰动、保存整数构型、已公开矩项、十二点双六环、旧相位，以及 n≤30 已实际公开的一步有理上升见证。仅胜过旧相位而未胜过该完整包络的项，不登记为新的最佳已存下界。

这里没有声称全部连续相位或半径的最优，没有刷新无条件圆盘上界 U_n，也没有得到新的未知点数全局锐值。一般连续相位只参与统一增益定理；程序枚举最优的范围仍是新固定半径的正负相位。
