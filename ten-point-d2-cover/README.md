# 十点全局最大构型的条件对称分类

设 \(Z\) 是质点平方模和为 9 时的十点全局最大构型。如果 \(Z\) 具有 \(D_2\) 对称，则它在整体旋转和点重排下等于[已认证的两矩形候选](../ten-point-contact-geometry/README.md)。这把十点全局锐界归结为证明任一全局最大构型具有该对称性。

## 两种轨道分解

全局最大构型必有[两个内点和八个外点](../ten-point-refined-radii/README.md)，所有平方点距严格大于 \(2/5\)，而[内点对的平方点距](../ten-point-conditioned-inner/README.md)属于 \((41/100,11/20)\)。半转互换两个内点。反射保持这对内点，因此内点轴是两条反射轴之一。旋转使其成为实轴，两个内点为 \(\pm\sqrt a\)，其中 \(a\in(41/400,11/80)\)。

外点的模介于 \(9/10\) 和 \(23/20\) 之间。同一射线上的两个外点平方点距至多 \(1/16\)，故每条反射轴至多有一对外点。轴外的点按四点轨道成矩形，所以八个外点有两种方式组成，两个矩形或一个矩形和两条轴上各一个反向点对。在平方映射 \(w=z^2\) 下，把内点对记为单根 \(a\)，把模平方为 \(r\) 的矩形记为二次因子 \(w^2-2xw+r^2\)。矩形的两个坐标半轴平方为 \((r\pm x)/2\)，对应边的平方点距给出 \(r\pm x>1/5\)。在双矩形分支按半径排序为 \(b<c\)，已有的[外带平方半径跨度](../ten-point-radial-dispersion/README.md)给出 \(c-b>1/100\)。

## 三变量区间检验

五个平方像记作 \(w_i\)，设 \(r_i=|w_i|\)，以 \(S_k=\sum_i w_i^k\)、\(T_k=\sum_i r_i w_i^k\) 表示幂和。在完整驻点上，按对径点配对并展开差商得

\[
  2\sum_{j=0}^k S_j S_{k-j}-(2k+1)S_k-10T_k=0,
  \qquad k=0,1,2,3,4.
\]

双矩形分支记其二次因子参数为 \((b,x),(c,y)\)。第零条给出 \(c=9/4-a/2-b\)，第一条给出

\[
  y=\frac{-(17-10a)a/2-(17-10b)x}{17-10c}.
\]

单矩形分支在实轴、虚轴上分别有外点对，平方像分别为 \(b,-c\)。记矩形的参数为 \((r,x)\)，则

\[
  c=9/2-a-b-2r,\qquad
  x=\frac{-(17-10a)a-(17-10b)b+(17-10c)c}{2(17-10r)}.
\]

两式的分母均由外带严格控制。对余下三变量进行精确二分。每个盒可以通过半径、分离等必要条件剪掉，也可以用后三条方程或实平方像逐点力的区间残差排除。逐点力在实根 \(w\) 处为

\[
\tfrac12-5|w|+2w\sum_{v\ne w}(w-v)^{-1}.
\]

二次因子对末项之和的贡献为 \(2(w-x)/((w-x)^2+r^2-x^2)\)，其中分母严格大于 \(1/25\)。

设 \(P(w)=\prod_i(w-w_i)\)。对径点对的乘积为 \(4^5\prod_i r_i\)，两组对径点之间的四条边贡献 \(|w_i-w_j|^4\)，故完整距离积为 \(4^5(\prod_i r_i)\operatorname{Disc}(P)^2\)。接受器用因子的判别式和两两结式计算其有理区间。如果区间上端低于 \(469765409\)，则该盒不可能含最大点。程序从已认证的候选根独立验证候选距离积严格高于这个阈值。

双矩形分支覆盖 422,161 个节点。余下的 2,193 个叶盒满足 \(\|a_{\rm pairs}-a_{\rm pairs}^*\|_2\le7/250\)，其中 \(a_{\rm pairs}\) 是五个点对的有向半差。全部中点为零，[加权 Taylor 局部锐界](../ten-point-weighted-pair-basin/README.md)因此给出距离积至多为候选值，取等仅在候选轨道。单矩形分支覆盖 201,037 个节点，所有叶盒均已排除。
