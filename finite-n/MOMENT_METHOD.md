# 一般有限点数的精确有理下界与停止准则

以下把已有稿件中的系数矩方法整理为可计算和复核的有限点数结论，并加入有理加权平均的改善。原稿已经包含球面矩公式、矩比下界及其收敛性；这里不把这些内容作为新发现。

## 1. 精确矩公式

对整数 n ≥ 2，记：

```math
N=\frac{n(n-1)}2,\qquad
V_n(z)=\prod_{i\lt j}(z_j-z_i),\qquad F(z)=|V_n(z)|^2,
\qquad M_n=\max_{\sum_i|z_i|^2=n}F(z).
```

平移到重心并重新缩放可知，最大值在复超平面 H 内取得：

```math
H=\left\{z\in\mathbb C^n:\sum_i z_i=0\right\}.
```

展开整数系数多项式，在所有同类项合并后定义：

```math
V_n(z)^k=\sum_{|\alpha|=kN}c_{k,\alpha}z^\alpha,
\qquad
J_{n,k}=\sum_{|\alpha|=kN}c_{k,\alpha}^{\,2}\prod_{i=1}^n\alpha_i!,
\qquad J_{n,0}=1.
```

令 μ_k 是 H 内半径 √n 的球面上 F 的 k 次方的均匀平均。则：

```math
\boxed{\displaystyle
\mu_k=\frac{n^{kN}(n-2)!\,J_{n,k}}{(kN+n-2)!}.}
```

证明：独立标准复高斯的单项式正交关系给出 F 的 k 次方的高斯平均 J_{n,k}。正交分解出重心坐标后，V_n 因平移不变而不依赖该坐标。剩余标准复高斯的复维数为 n−1，其半径平方服从形状参数 n−1 的 Gamma 分布；半径与方向独立。V_n 的齐次次数为 N，径向积分即得公式。特别地：

```math
J_{n,1}=n!\prod_{j=0}^{n-1}j!,\qquad
\mu_1=\frac{n!(n-2)!\,n^N\prod_{j=0}^{n-1}j!}{(N+n-2)!}.
```

这正是已有的中心化高斯平均下界。

## 2. 单调递增的有理下界

对每个整数 k ≥ 0 定义：

```math
\boxed{\displaystyle
B_{n,k}=\frac{\mu_{k+1}}{\mu_k}
=n^N\frac{J_{n,k+1}}{J_{n,k}}
       \frac{(kN+n-2)!}{((k+1)N+n-2)!}.}
```

它们都是正有理数，并满足：

```math
B_{n,k}\le M_n,\qquad
B_{n,k+1}\ge B_{n,k},\qquad
\lim_{k\to\infty}B_{n,k}=M_n.
```

下界是以 F 的 k 次方为权重的平均值不超过最大值；单调性由柯西–施瓦茨不等式得到：

```math
\mu_{k+2}\mu_k\ge\mu_{k+1}^2.
```

当 n ≥ 3 时，球面上同时存在碰撞构型和互异构型，F 是非恒定的连续函数。其分布的支集是完整区间 [0,M_n]，每个正值开区间都有正球面测度，故加权后的方差严格为正。因而全部矩比严格递增，且严格小于 M_n。最大值附近的集合具有正球面测度，所以 μ_k 的 k 次方根趋于 M_n；矩比单调性给出相同极限。

当 n=2 时，中心化球面上的 F 恒等于 4，所有矩比都精确等于 M_2=4，无需更高阶计算。

## 3. 只用前三个矩的显式改善

以下设 n ≥ 3，并记：

```math
A=\mu_1\mu_3-\mu_2^2\gt 0,\qquad
B=\mu_3-\mu_1\mu_2\gt 0,\qquad a=\frac AB.
```

A 的严格正性来自矩的严格对数凸性。B 是 F 与 F 的平方的协方差：取独立同分布的 F、F′，有：

```math
B=\frac12\mathbb E\big[(F-F')^2(F+F')\big]\gt 0.
```

以非负权重 (F−a) 的平方求平均，得到有限有理下界：

```math
\boxed{\displaystyle
R_n=\frac{\mu_3-2a\mu_2+a^2\mu_1}
             {\mu_2-2a\mu_1+a^2}\le M_n.}
```

分母是 (F−a) 的平方的平均，严格为正。该下界严格改善由相同三个矩给出的最高矩比：

```math
R_n-\frac{\mu_3}{\mu_2}
=\frac{a(2A-aB)}
       {\mu_2(\mu_2-2a\mu_1+a^2)}
=\frac{A^2}
       {B\mu_2(\mu_2-2a\mu_1+a^2)}\gt 0.
```

因此，对每个 n ≥ 3，三个有限整数系数和 J_{n,1}、J_{n,2}、J_{n,3} 就给出无需极限过程的有理下界 R_n。计算规模会随 n 增长；有限公式不表示计算成本很低。

还可以与已有显式构型取最大值。单位正 n 边形给出 n 的 n 次方；原点加正 n−1 边形、缩放至总二阶矩 n，给出：

```math
C_n=\frac{n^N}{(n-1)^{(n-1)(n-2)/2}}.
```

所以适用于每个有限 n ≥ 3 的合并下界为：

```math
\boxed{\displaystyle M_n\ge\max\{n^n,\ C_n,\ R_n\}.}
```

各项分别来自明确构型或精确平均，不需要假设最优构型具有多边形对称性。

## 4. 使用更多矩的有理加权下界

仍设 n ≥ 3。对任意非零实系数多项式 q，都有：

```math
\frac{\mathbb E[Fq(F)^2]}{\mathbb E[q(F)^2]}\le M_n.
```

若 q 的系数是有理数，这就是由有限个 μ_k 组成的有理证书。令：

```math
H_0=(\mu_{i+j})_{i,j=0}^m,\qquad
H_1=(\mu_{i+j+1})_{i,j=0}^m.
```

当 n ≥ 3 时，H_0 正定，最大广义特征值等于这些加权下界的上确界。该值随 m 单调增加并趋于 M_n；当 m ≥ 1 时，它严格大于 B_{n,2m}。因为若 q(t)=t 的 m 次方已经最优，沿 t 的 m−1 次方方向的驻点条件会迫使相邻两个矩比相等，与严格性矛盾。需要有理证书时，可选取有理向量并精确计算商值。

这是把通常的 Rayleigh 商方法应用到已有系数矩，不涉及新的最优构型分类。

## 5. 只需整数比较的停止准则

已有稿件的齐次多项式求值界给出：

```math
M_n^\ell\le D_{n,\ell}\mu_\ell,\qquad
D_{n,\ell}=\binom{\ell N+n-2}{n-2}.
```

结合矩比单调性，在 ℓ=k+1 时有：

```math
B_{n,k}\le M_n\le D_{n,k+1}^{1/(k+1)}B_{n,k}.
```

给定相对误差 ε=a/b>0，其中 a、b 是正整数。只要验证以下精确整数不等式：

```math
D_{n,k+1}\,b^{k+1}\le(a+b)^{k+1},
```

就得到完全有理的有限包围区间：

```math
\boxed{\displaystyle B_{n,k}\le M_n\le(1+\varepsilon)B_{n,k}.}
```

固定 n 时，D 的增长是关于 k 的多项式，而容许因子的增长是指数式，因此停止条件最终一定成立。这是数学上明确的终止证书；高阶整数系数展开仍可能昂贵。

## 6. 三点的独立闭式核对

对 n=3，正交中心化坐标可把 Vandermonde 写成 u(u 的平方−3v 的平方) 除以 √2，差一个无关符号。因此：

```math
J_{3,k}=2^{-k}\sum_{j=0}^k
\binom{k}{j}^{\!2}9^j(3k-2j)!(2j)!.
```

由此精确算得：

```math
\mu_1=\frac{27}2,\qquad
\mu_2=\frac{8019}{35},\qquad
\mu_3=\frac{610173}{140},
```

```math
B_{3,2}=\frac{837}{44},\qquad
a=\frac{351}{70},\qquad
R_3=\frac{32265}{1598}\gt \frac{837}{44}.
```

例如另外选取 q(F)=F−7，就有：

```math
M_3\ge\frac{253719}{12476}\gt 20.
```

这些是矩方法的独立核对，并未替代已有锐值 M_3=27。合并下界中的正三角形项已经精确达到 27。
