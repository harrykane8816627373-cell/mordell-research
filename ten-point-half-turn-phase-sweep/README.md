# 半转分支按相对外角覆盖整周

取质量九。假设最大构型具有半转对称，将五个反向点对平方，旋转使内像在正实轴上。按角序写四个外像的辐角 \(\theta_1,\ldots,\theta_4\)，并用表中给定的方向向量 \(\theta^*\) 作参照。对适当的循环匹配，要求 \(\theta_j-\theta_1\) 与 \(\theta_j^*-\theta_1^*\) 在圆周上的差至多为下表容差，\(j=2,3,4\)。

| 相对外角参照 | 容差（平方像弧度） | 相位单元 | 结论 |
|---|---:|---:|---|
| 两矩形候选 | \(3/5000\) | 118 | 最大点属于候选轨道 |
| 近优鞍点 | \(3/250\) | 180 | 排除全局最大点 |
| 正方形的四个方向 | \(3/125\) | 252 | 排除全局最大点 |

外层的共同相位 \(\phi=\theta_1-\theta_1^*\) 可取整周。五个半径均允许取全局必要域。三组条件均只约束四角空间中的三个相对角。

## 用固定半径的参考上界覆盖相位

写 \(\phi=2\arctan p,\ -1\le p\le1\)。每格取中点相位及五个有理参考半径 \(r_i\)，检查它们属于[严格凹的径向域](../ten-point-half-turn-radial-concavity/README.md)且 \(\sum_i r_i=9/2\)。如果格内所有角都已落入[两组纯角度邻域](../ten-point-half-turn-angle-neighborhoods/README.md)，直接调用相应判据。

其余单元使用以下能量比较。记参考处的平方像点距为 \(D_{ij}\)。边能量为 \(2\log D_{ij}\)。其角差导数为 \(4r_i r_j\sin(\theta_i-\theta_j)/D_{ij}\)。对能保证该边角向凹的整段用切线上界，否则用 \(\log x\le x-1\) 和余弦的二阶余项，得到线性项加 \(2r_i r_j(\delta_i-\delta_j)^2/D_{ij}\)。四个外点的共同相位导数先求和后取模，外外边的共同相位完全消去。其余变化由三个相对角容差与切参数单元宽度控制。这给出在固定参考半径、实际角度下的对数距离积上界。

再包围实际角度和参考半径处对五个对数半径的梯度，使用分量
\[
9-10r_i+2\sum_{j\ne i}\frac{r_i^2-r_j^2}{D_{ij}} .
\]
已证径向刚度 \(1/4\) 允许将上述对数上界加上两倍梯度平方范数，从而覆盖全部可能的真实半径。两者都为质量九，能量的质量惩罚抵消。指数的有理上界将结果转换回距离积，与候选值的严格有理下端比较。每格都验收，并检查整周无间隙。
