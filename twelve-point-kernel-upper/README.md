# 十二点：由正半定核证明的全局近似界

2026-11-08。蒋丰灿（Fengcan Jiang）研究项目，OpenAI Codex协作。令M₁₂为质量12约束下的全局最大距离平方乘积，V₁₂为[此前保存的12点整数构型](../symmetry-breaking/integer_witnesses.json)居中并归一化后的可达值。本目录严格证明

```math
V_{12}<\Delta(x_{12}^*)\le M_{12}<\frac{23}{20}V_{12}.
```

x₁₂*是[此前已认证的真实12点候选根](../validated-maxima/README.md)。因而该候选及旧整数见证的目标值均严格超过全局最大值的20/23，约86.9565%。这是全局量化上界，**尚未证明M₁₂等于候选值，也未分类全部最大点**。

完整正式重放仅需Python标准库，约30秒；不依赖浮点SDP、NumPy或SciPy：

```bash
python -B -S -O twelve-point-kernel-upper/verify_all.py
```

默认实际重算全部连续覆盖、正定矩块、整数下界与真实根，不复用零未决报告。[实际报告](verification_report.json)、[固定树](cover.txt)与[输入哈希](source_manifest.json)一起保存。统一入口也默认执行此完整重放。

## 1. 所有全局最大点的必要点对域

先改用质量11，写x=√(11/12)z；这使距离积乘(11/12)⁶⁶，但上下界的比值不变。全局最大点居中：否则平移至重心再放大恢复总质量会严格增大全部距离积。

对任意点对置u=|xᵢ|²、v=|xⱼ|²、t=Re(xᵢconj(xⱼ))、d=u+v−2t。[严格子集定理](../finite-n/SUBSET_PROOF.md)给

```math
0\le u,v<121/72,\qquad t^2\le uv,\qquad d>1/3.
```

具体地，两点子集的去重心质量为d/2；质量12时严格大于2/11，缩放后得到d>1/3。删去一点后，剩余11点的去重心质量为11−12u/11，严格大于55/6，所以u<121/72。

正式程序覆盖更大的闭域0≤u,v≤121/72、t²≤uv、d≥1/3。以U=121/72，初始盒为[0,U]²×[−U,U]。没有假定未知最大点具有D₃、同心层或任何反射对称。

## 2. 精确核与带余量的两点上界

使用[冻结的12点系数](../candidate-kernel/data/n12_exact_interpretation.json)。每个十六进二进浮点字面量都解释为一个**精确二进有理数**，这些数直接定义径向多项式向量及实对称矩阵Qₖ。其发现来自数值拟合；正式证明仅使用固定有理系数。

令H₀=1、H₁=t、Hₖ=2tHₖ₋₁−uvHₖ₋₂。取

```math
K(u,v,t)=F(u)^TQ_0F(v)+\sum_{k=1}^{11}H_k(u,v,t)V_k(u)^TQ_kV_k(v).
```

程序对全部12个Q块重算精确LDL分解，逐项重构并证明全部主元严格为正。因此K为正半定核，ΣᵢⱼKᵢⱼ≥0。特征的节点和矩中心无需等于真实候选的精确参数；正半定性和下面的有理比较已足够。

设B为系数文件内字段B所指的精确有理数，b=(B−66)/12。定义

```math
p(u)=\frac{6u+b-K(u,u,u)/2}{11},\qquad
h(u,v,t)=p(u)+p(v)-K(u,v,t).
```

质量11给Σᵢ<ⱼhᵢⱼ=B−ΣᵢⱼKᵢⱼ/2≤B。原始h不是连续majorant，[精确反例](../candidate-kernel/README.md)仍然保留。本轮实际证明的是

```math
h(u,v,t)+c\ge\log d,\qquad c=21/10000,
```

在第1节的整个必要域成立。因此对全局最大点

```math
\log M_{12}^{(11)}\le B+66c=B+693/5000.
```

M₁₂⁽¹¹⁾表示质量11尺度。这个上端没有将B误认成精确候选的对数。

## 3. 完整连续覆盖如何认证

[verify_cover.py](verify_cover.py)从精确特征和Q重建h的三变量幂基多项式；用Hₖ(u,u,u)=uᵏ加入对角修正。各轴次数至多19、19、11，转换为初始盒上的20×20×12个精确Bernstein系数。4个独立有理点评估还与原核表达式逐项相等；这项交叉核对辅助检查实现，完整证明仍由精确转换公式和全覆盖承担。

以S=2⁴⁰，对每个初始系数β存floor(Sβ)，再加偏置2⁶⁰。这些整数为系数的严格下包围；每次二分使用逐坐标de Casteljau的向下取整中点，所以在所有子盒仍保持下包围。Bernstein基非负且和为1，全部系数的下界遂给整个盒的函数下界。

为了保留h与d的相关性，每个叶选择正有理a，并用对数切线

```math
\log d\le\log a+(d-a)/a\qquad(d>0).
```

log a通过2的幂缩放到[1,2]，用18项atanh级数和严格几何尾上端包围；负缩放指数时相应使用log2下端。切线为仿射函数，其Bernstein系数就是对应控制网格上的值。程序对阈值全部向上取整，逐系数认证h+c至少等于这条切线，即证明整个叶上的两点不等式。

覆盖树只指定分裂轴或叶类型。正式重放重新检查每一个叶；它不是以数值取样判真。可剪除的盒只有三类：全部u>v（h已精确认证对称，可以交换u/v）；最小|t|²大于u、v上端乘积；d的整盒上端小于1/3。其余盒必须由上述连续不等式接受，或继续二分。

实际重放：37053个节点、18526次二分、16237个不等式叶、2290个域外叶、0未决，最大深度34；节点数=2×二分数+1，终端叶数=二分数+1，并检查动作消耗完毕时栈为空。树哈希只绑定输入，完整重放而非哈希核对承担连续证明。

程序用Python无界大整数的64位数位并行保存系数，未使用机器整数或浮点界。初始偏置系数全部位于[0,2⁶²)，中点凸组合保持此范围；两数位求和小于2⁶³，不向相邻数位进位。右移平均后掩去跨数位奇数位，恰为各自的floor平均。比较时加2⁶³哨兵位，阈值也逐盒认证在[0,2⁶²)，所以减法没有跨位借位；哨兵同时留下当且仅当每个系数超过阈值。标量整数自检另外核对全部三个分裂轴。这种实现只压缩整数运算，没有放松任何接受不等式。

## 4. 与真正可达值的精确比较

旧整数点为qᵢ=(aᵢ,bᵢ)，记

```math
D=12\sum_i(a_i^2+b_i^2)-(\sum_i a_i)^2-(\sum_i b_i)^2,\qquad
P=\prod_{i<j}((a_i-a_j)^2+(b_i-b_j)^2).
```

居中并归一化给V₁₂⁽¹¹⁾=132⁶⁶P/D⁶⁶、V₁₂=144⁶⁶P/D⁶⁶，均为正有理数。对x=(23/20)V₁₂⁽¹¹⁾，将x=2ᵏw、1≤w<2；向下舍入w至64位二进有理数，再用80个正atanh项给log x的严格下端。程序精确证得

```math
\log\!\left(\frac{23}{20}V_{12}^{(11)}\right)-(B+66c)>1/1000.
```

故M₁₂⁽¹¹⁾<(23/20)V₁₂⁽¹¹⁾，缩放回质量12即得全局界。同时重放既有12点真实根证书，验证其Δ区间下端严格超过V₁₂。因此真实候选也具有同一个20/23的全局比例保证。
