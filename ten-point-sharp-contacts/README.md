# 十点分角类核的精确接触与零补偿证书

采用总平方半径 9。令 $z^*$ 为[两矩形候选](../ten-point-contact-geometry/README.md)，$B=\log\Delta(z^*)$。本构造给出在 15 类候选点对上取等的两点函数 $h$。12 个谐波 Gram 块及两个二阶变分块均严格正定。15 个局部盒和三个完整点对域均满足 $h\ge\log d$，其中 $d=|z_i-z_j|^2$。已完成的三类是内内以及循环相隔两位、四位的外点对。全局锐界还缺内外类及循环相隔一位、三位的外点对的剩余域。

## 从角序得到精确的逐点行修正

由[逐点径向界](../ten-point-angular-radii/README.md)，两个内点的平方半径在 $I=(21/250,159/1000)$，八个外点在 $O=(89/100,1271/1000)$。令 $\theta_{i+8}=\theta_i+2\pi$。[相邻角界](../ten-point-outer-gap/README.md)给出

\[
\alpha<\theta_{i+1}-\theta_i<\beta,
\qquad \alpha=\arccos(39/50),\quad \beta=\arccos(59/100)<\pi/3.
\]

因此外点相隔 $k=1,2,3$ 位的短弧属于 $(k\alpha,k\beta)$。第四类沿用[近对径配对界](../ten-point-tight-pairing/README.md)。四类的余弦区间互不相交。对任一外点，每类精确有 $2,2,2,1$ 个邻点。记 $E_k$ 为第 $k$ 类无序边，$u_i=|z_i|^2$。任意单变量函数 $f$ 都满足

\[
\sum_{ij\in E_k}[f(u_i)+f(u_j)]
-2\sum_{ij\in E_4}[f(u_i)+f(u_j)]=0,\qquad k=1,2,3.
\]

取外带归一坐标上的前三个 Chebyshev 多项式，得到九个新的零和方向，允许同一个核在各角类有不同的径向补偿。检验只用由角度得到的类标。对候选，区间验证了四类精确人口 $8,8,8,4$。所有外点对的无向角至少为 $\alpha$，而非相邻角至少为 $2\alpha>\beta$。所以候选的八条第一类边恰是相邻边，类标与真实循环次序一致，并在候选的小扰动中保持。

## 核的求和与等号

记 $u=|z|^2,v=|w|^2,t=\Re(z\bar w)$，$d=u+v-2t$。基础核用 $H_k=\Re((z\bar w)^k)$，$H_0=1,H_1=t,H_{k+1}=2tH_k-uvH_{k-1}$。在两条半径带各使用次数至多二的三个特征。每个偶数阶去掉一个非零候选矩方向，每个奇数阶保留全部特征。设 $K$ 是相应 12 个严格正定 Gram 块的和。按对角修正构造两点函数的基础部分

\[
 h_0=\frac{B}{45}-1+\frac59(u+v)-K(z,w)-\frac{K(z,z)+K(w,w)}{18}.
\]

因此 \(\sum_{i<j} h_{0,ij}=B-\tfrac12\sum_{i,j}K_{ij}\)。在最大构型上，Ward 恒等式、带人口、质量、逐点径向力及上述角类行的修正总和为零。[完整力恒等式](../stationary-kernel/README.md) · [已有分带修正](../ten-point-curved-kernel/README.md)

二阶项使用径向位移 $\xi_i=g(u_i)z_i$ 及 $i\xi_i$。对这里的两块，$g$ 取各带二次特征乘以在该带候选节点消失的多项式。若

\[
N_g=\frac59(ug(u)^2+vg(v)^2),\quad
T_g=\frac{[g(u)(u-t)+g(v)(v-t)]^2-(g(u)-g(v))^2(uv-t^2)}{d^2},
\]

则无约束对数能量 \(\log\Delta-5\sum_i u_i\) 的二阶极大必要条件给出 \(\sum_{i<j}(N_g\pm T_g)\ge0\)。将其极化后用两个正定矩阵组合，从 $h_0$ 减去所得修正。由于 $g$ 在三个候选节点都为零，这些修正在候选处的值和一阶导数均为零。最后加入权重为 $2^{-40}$ 的一维径向 Gram 块，特征为 $q(u)^2=[(u-a)(u-b)(u-c)]^2$。总和仍满足 \(\sum_{i<j}h_{ij}\le B\)。

一旦所有点对都有 $h\ge\log d$，取等先迫使 \(\sum_i q(u_i)^2=0\)，再由质量锁定人口 \((2,4,4)\)。一阶特征的零矩可逐层提取 \(\sum z_i=0\)，因为外带的线性多项式能分别取出 $b,c$。二阶矩向量必须是候选向量的一个复倍数。内点对确定该倍数的模，整体旋转后固定它。四点层的根多项式为偶函数，每层两个平方像的公共模长与非零和唯一确定这两个像。这就是[十点等号刚性](../ten-point-contact-geometry/README.md#三个罚项在完整驻点上恢复等号构型)所需的条件。

## 在实际候选上精确校正

50 条接触方程包括 15 条值等式和 35 条一阶等式。六条独立相容关系来自将值按点对重数相加，以及沿五个候选族变量 $a,b,c,x,y$ 对总和求导。在候选处，Gram 罚项与二阶项的一阶变化为零。质量与二阶 Ward 项的另一因子也是候选零矩。逐行力修正的乘子在候选半径上消失，故其全和在驻点处的一阶变化为零。候选满足完整力，所以右端对数满足同样的六条关系。

从 312 个种子系数中选取 44 阶子式，使用 $2^{-384}$ 向外舍入校正这些系数。对剩余六行，精确性来自上述相容关系。程序另外核对全部残差区间包含零。基础 Gram 与二阶块使用区间 LDL 验证。内点接触用 $h-\log d$ 在盒内的正定 Hessian。三个对径类接触用 $t=-\sqrt{uv}$ 面上的正定切向 Hessian，以及整个盒上严格正的向内导数。这样得到十五个正半径接触盒。

## 整个内内类的零补偿覆盖

令 $G=h-\log d$，$R=d^2h$。以多项式 $d R_t+4R+2d^2=d^3 G_t$ 检验 $G_t\ge0$。任一允许内边投影至 $t=-\sqrt{uv}$ 后，平方距离从原先的 $d\in(43/100,53/100)$ 至多增加 $2(1-87/100)\sqrt{uv}$。沿整段投影仍有 $t\le-(87/100)\sqrt{uv}$。在扩大后的三维域验证 $G_t\ge0$。[严格内边界](../ten-point-inner-edge/README.md)

在 Gram 面令 $u=p^2,v=q^2,t=-pq$，于是 $d=(p+q)^2$。只需在二维域上验证 $R(p^2,q^2,-pq)\ge 2s^4\log s$，其中 $s=p+q$。在每个矩形的 $s$ 上端 $a$ 处取二阶 Taylor 上界，因为 $\frac{d^3}{ds^3}(2s^4\log s)=s(48\log s+52)>0$ 于 $s>1/2$。将 $\log a$ 换成有理上端是安全的，因为其系数是正的 $2a^2(6s^2-8as+3a^2)$。两棵覆盖树合计 506 个节点，均无未决。 [内边覆盖报告](inner_cover_report.json)

## 循环相隔两位的外点对

两个相邻外角相加，得到该类的余弦区间 $[-1519/5000,271/1250]$。在正、负点积上分别构造有理根盒。验收器对 $R=d^2h$ 作 Bernstein 细分，逐盒检验 Gram 条件、半径排序、余弦界以及 $d\ge2/5$。保留的盒使用接触邻域或下面的二阶对数上界。两棵树分别访问 2,531 和 3,333 个节点，均无未决。 [相隔两位的覆盖报告](outer_step_two_cover_report.json)

## 整个近对径外类的零补偿覆盖

对循环相隔四位的外点对，排序后写 $p=\sqrt u\le q=\sqrt v$，取 $x=p+q$、$y=q-p$、$e=t+pq$。Gram 边界变为 $e=0$。已证余弦上界 $-31/32$ 给出 $0\le e\le pq/32$，而 $d=x^2-2e$ 与 $y$ 无关。两个候选接触在 $(x,y,e)=(2\sqrt b,0,0)$ 和 $(2\sqrt c,0,0)$。[近对径必要界](../ten-point-tight-pairing/README.md)

令 $P$ 是换坐标后的 $R$。由于内积和核在交换两外点时不变，$P$ 在 $y$ 中为偶多项式。记 $A(x)=P(x,0,0)-2x^4\log x$，则两个接触的确切值和切向一阶等式分别给出 $A=A'=0$。在两个坐标盒内，程序用中心展开证明 $A''>0$，用 Bernstein 系数证明 $(P(x,y,0)-P(x,0,0))/y^2\ge0$ 的多项式延拓非负，并证明 $dP_e+4P+2d^2=d^3G_e\ge0$。先沿 $y=0,e=0$ 用严格凸性，再增加 $y$ 和 $e$，得整个接触盒的零补偿。

补集用三维 Bernstein 细分。对每个盒令 $a=\max d$，用 $(d^2\log d)'''=2/d>0$ 得到 $d^2\log d\le(\log a+3/2)d^2-2ad+a^2/2$。将 $d=x^2-2e$ 代入，右侧只依赖两个拆分坐标。共访问 853 个节点。每个叶盒由点对必要条件、接触盒或这个对数上界结案，未决为零。 [近对径外类覆盖报告](outer_antipodal_cover_report.json)

上一版核在第一外外类的有理点 $(u,v,t)=(119/100,119/100,3511/5000)$ 上有 $G<-1/40000$。这一点已加入系数搜索。新核在同一点严格满足 $G>1/250000$，复核器用校正后的精确系数核验该不等式。

## 复现

```text
python -B -S -O ten-point-sharp-contacts/verify_all.py
python -B -S -O ten-point-sharp-contacts/cover.py
python -B -S -O ten-point-sharp-contacts/cover.py --outer-step-two
python -B -S -O ten-point-sharp-contacts/antipodal.py
```

程序仅使用 Python 标准库。四条命令分别重放精确接触及有理点、内内类及两个外外类。`cover.py --explore 1 2 4` 可尝试余下三类，允许出现未决盒。浮点半正定搜索只提供系数种子。确定候选矩、校正接触及正性判定均重新进行有理区间计算。 [固定输入](source_manifest.json) · [复核报告](verification_report.json)
