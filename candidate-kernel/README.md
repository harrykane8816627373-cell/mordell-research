# 候选适配的正半定核：精确接口、零集刚性与两次失败证书

2026-11-08，蒋丰灿研究项目，OpenAI Codex协作。本目录把已有矩方法与正半定核接到候选构型，而不预设未知最大点的对称性。**本轮没有得到连续全域有效的候选锐界核。** 两份浮点SDP拟合均被精确有理点对否决，包括一次离散目标差为零的12点拟合。

## 1. 从正半定核到候选上界的准确接口

统一取n个复点、质量m=n−1，记u=|x|²、v=|y|²、t=Re(x conj(y))、d=u+v−2t。定义实多项式

```math
H_0=1,\quad H_1=t,\quad H_k=2tH_{k-1}-uvH_{k-2}
       =\operatorname{Re}((x\bar y)^k).
```

任取实径向多项式向量F、Vₖ及实对称正半定矩阵Qₖ，构造

```math
K(u,v,t)=F(u)^TQ_0F(v)+\sum_{k=1}^sH_k(u,v,t)V_k(u)^TQ_kV_k(v).
```

其全体有序点对和为非负矩平方和：

```math
\sum_{i,j}K_{ij}
=\Big\|\sum_iF(u_i)\Big\|_{Q_0}^2
+\sum_{k=1}^s\Big\|\sum_i x_i^kV_k(u_i)\Big\|_{Q_k}^2\ge0.
```

复向量范数在实部、虚部分别计算。令N=n(n−1)/2、b=(B−N)/n，并定义

```math
p(u)=\frac{nu/2+b-K(u,u,u)/2}{n-1},\qquad h(u,v,t)=p(u)+p(v)-K(u,v,t).
```

利用Σuᵢ=n−1，精确得到

```math
\sum_{i<j}h(u_i,u_j,t_{ij})=B-\frac12\sum_{i,j}K_{ij}\le B.
```

所以，只要在包含**每个全局最大点的全部点对**的必要域D上严格证明h≥log d，就有全局logΔ≤B。无需D包含所有可行构型；但必须先证明所有最大点均在D内。当前10点可用[强化必要域](../maximizer-domain/README.md)。

要取B=logΔ(x*)并在候选取等号，还必须同时满足：所有候选接触点h=log d；候选矩向量落在对应Qₖ的核内。遗漏对角修正，或给有非零候选矩的原始特征强行配正定矩阵，都会破坏这条接口。这里需要的是**正半定核**，非零矩方向通常必须保留零特征值。

## 2. 怎样让核的零集锁住10点候选

[精确对称证书](../candidate-global-screen/README.md)认证实际10点根有D₂对称、三个不同半径层，人口2、4、4。以下构造的参数均指这个实际根的精确参数，非浮点近似。缩放至质量9，并将最内层点对旋至实轴。设三个平方半径为a₀、a₁、a₂，T₂*=Σuᵢ²，q(u)=∏ᵣ(u−aᵣ)，ℓᵣ为三个节点上的Lagrange基。

取Q₀正定、F=(u−9/10, u²−T₂*/10, q(u)²)。若ΣK=0，则ΣF=0；特别是Σq(uᵢ)²=0，故每个uᵢ必须等于某个aᵣ。总人口、Σu和Σu²组成可逆Vandermonde系统，唯一确定人口为2、4、4。

在k=1、3取Vₖ=(ℓ₀,ℓ₁,ℓ₂)及正定Qₖ。这迫使每层p₁=p₃=0。两点层因此为一对对径点；四点层的Newton恒等式给e₁=e₃=0，根多项式为偶函数，故各为两对对径点。同半径的两对对径点构成中心矩形。

设候选各层二次矩c=(c₀,c₁,c₂)为实向量，其中c₀=2a₀，外层cᵣ≠0且|cᵣ|<4aᵣ；这些非退化关系已由[实际根的精确区间报告](../candidate-global-screen/symmetry_report.json)认证（报告采用质量10，同次缩放保留严格不等式）。在k=2取V₂=(ℓ₀,ℓ₁,ℓ₂)，

```math
Q_2=\|c\|^2I-cc^T\succeq0,\qquad
M^*Q_2M=\sum_{r<s}|c_rM_s-c_sM_r|^2.
```

核的零条件给实际层二次矩M=αc。内层对径点使|α|=1；再整体旋转令α=1。对外层，两个模长均为aᵣ的复数x²、y²之和已固定且非零，因此该无序对唯一；取各自正负平方根就固定矩形。于是所有这些矩平方和同时为零的质量9构型，恰为候选的旋转、重排轨道。

这给出一个**具有候选刚性零集的正半定核架构**。它尚不提供h≥log d；后者是待解决的关键不等式。即使零集刚性成立，也不能跳过这个步骤直接宣称候选全局最优。

这一构造已推广为[一般旋转层刚性定理](RIGIDITY.md)：正半径层人口为m或2m，至少有一个m人口层，且2m层的m次矩非退化时，可以用有限多项式正半定核把零集精确锁成候选轨道。取m=2、3、6，分别适用于10、12、19点；后两者所需的三阶、六阶矩结构也已由[实际根区间](../candidate-global-screen/symmetry_report.json)认证。一般Cₘ候选可用复Hermitian块；共同Dₘ反射使它化为当前实三变量核。

[精确接受器](verify_all.py)用另一组完全有理的D₂构型检验全部代数接口：最内层±3/10，另两层为±9/10±(9/20)i、±3/10±(21/20)i。其质量恰为9，平方半径9/100、81/80、477/400。程序逐项验证ΣK等于矩平方和、上述Q₂恒等式及Σh=B−ΣK/2；将一层乘(3+4i)/5后，核罚项严格变正。这组有理数是接口测试，未冒充真实最优候选。

为排除“只是浮点误差”的解释，将每个存储的二进浮点系数视为精确二进有理数，完整冻结为[10点多项式](data/n10_exact_interpretation.json)和[12点多项式](data/n12_exact_interpretation.json)。标准库接受器对以下严格位于相应必要域内的有理点对重算h：

10点反例还通过新的非线性Schwarz必要条件。log d使用正项级数2Σⱼ₌₀¹¹⁹a²ʲ⁺¹/(2j+1)的严格下端，a=(d−1)/(d+1)∈(0,1)，所有比较均为精确有理数。这证明**这两份已存储核拟合不是连续有效的上界**；它没有否定候选的全局最优性，也没有证明整个核架构不可能成功。

另外，[精确矩块检查](verify_psd.py)已证明12点原始拟合的12块Q全部正定，使用有理LDL分解、严格正主元和逐项重构，不依赖浮点特征值。10点的10块统一加2⁻²²I后也全部正定；一维精确Bernstein界和|Hₖ|≤Uᵏ给整个物理径向域u,v≤1.5403上的修正代价|Δh|<231/10⁶，总和预算45|Δh|<0.0104。原10点反例因此仍有log d−h修复>1769/10⁶。正定性可以严格修复，连续majorant仍须单独证明。
