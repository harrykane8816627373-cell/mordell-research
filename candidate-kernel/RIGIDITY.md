# 人口为m或2m的旋转层：具有刚性零集的正半定核

2026-11-08。蒋丰灿（Fengcan Jiang）研究项目，OpenAI Codex协作。本文给出一般解析定理，并说明怎样用于10、12、19点的已认证候选。它不预设未知全局最大点的对称性，也不提供尚未证明的两点majorant。

## 1. 定理的假设和结论

固定整数m≥2及一个无碰撞候选构型x*，点数为n、总质量为n−1。它有s条正半径层，平方半径为互不相同的a₁,…,aₛ>0；每层人口Nᵣ∈{m,2m}，并可选地有一个原点，人口h∈{0,1}。至少一条正半径层的人口为m。候选在乘e²πⁱᐟᵐ后不变，即具有Cₘ旋转对称，因此人口为m的层是一条正m边形，人口为2m的层是两条同半径正m边形的并。

定义候选各正半径层的m次矩

```math
c_r=\sum_{x_i^*:\,|x_i^*|^2=a_r}(x_i^*)^m,
\qquad A_r=a_r^{m/2}.
```

人口为m时自动有|cᵣ|=mAᵣ>0。对每条人口为2m的层，另要求

```math
0<|c_r|<2mA_r.
```

上端严格性排除两条正m边形重合；下端排除具有额外自由相位的零m次矩层。主版本再假设选定整体旋转后，所有cᵣ都为实数。具有共同Dₘ反射对称的候选满足这个实数条件，证明见第5节。第6节给出无共同反射假设的复Hermitian推广。

**定理。** 在这些假设下，存在一个有限多项式正半定核K，使质量n−1的任意n点构型x都满足

```math
\sum_{i,j}K(x_i,x_j)\ge0,
```

且等号当且仅当x是x*的整体旋转、点重排。未知构型x无需预先具有旋转、反射、同心层或无碰撞性质；这些几何性质由核的零条件推出。

这里“正半定”指核的任意有限Gram矩阵正半定。结论不要求每个矩块正定；m次矩块必须保留候选矩方向的零空间。定理只描述核罚项的零集，并未声称距离积在这个零集之外较小。

## 2. 构造：径向节点、逐层谐波和共同相位

将可选节点0和全部正节点合在集合𝒜中，令R=s+h。记

```math
q(u)=\prod_{a\in\mathcal A}(u-a),\qquad
T_j^*=\sum_{i=1}^n|x_i^*|^{2j}.
```

取实多项式向量

```math
F(u)=\big(u-T_1^*/n,\ u^2-T_2^*/n,\ldots,
u^{R-1}-T_{R-1}^*/n,\ q(u)^2\big)^T.
```

当R=1时，前面的矩坐标为空，仅保留q²。取任意实对称正定矩阵Q₀，例如单位矩阵。

对每个正节点aᵣ，令ℓᵣ为整个节点集合𝒜上的Lagrange多项式，即ℓᵣ(aᵣ)=1、在其余节点为0，置

```math
V(u)=(\ell_1(u),\ldots,\ell_s(u))^T.
```

不需要给原点单独设置角向坐标，因为正次数谐波在那里自动为零。对1≤k≤2m−1、k≠m，取Qₖ=Iₛ；对k=m取

```math
Q_m=\|c\|^2I_s-cc^T,\qquad c=(c_1,\ldots,c_s)^T\in\mathbb R^s.
```

由实Cauchy–Schwarz，Qₘ正半定。由于至少有一个m人口层，c≠0，故ker Qₘ恰为c的复线性张成；s=1时Qₘ=0，亦符合这个表述。对任意复向量M，精确恒等式为

```math
M^*Q_mM=\sum_{r<t}|c_rM_t-c_tM_r|^2.
```

对任意复点x、y，设u=|x|²、v=|y|²、t=Re(x conj(y))。用H₀=1、H₁=t、Hₖ=2tHₖ₋₁−uvHₖ₋₂，定义

```math
K(x,y)=F(u)^TQ_0F(v)
       +\sum_{k=1}^{2m-1}H_k(u,v,t)V(u)^TQ_kV(v).
```

所有多项式系数由候选的精确参数确定；无需它们是有理数。系数的区间发现、整数证书和连续不等式验证是另一个问题。

任意有限点集及实权重wᵢ都满足

```math
\sum_{i,j}w_iw_jK(x_i,x_j)
=\Big\|\sum_iw_iF(u_i)\Big\|_{Q_0}^2
+\sum_{k=1}^{2m-1}
 \Big\|\sum_iw_ix_i^kV(u_i)\Big\|_{Q_k}^2\ge0.
```

复向量的Q范数按实部和虚部分别计算。这个恒等式同时证明核正半定及全体有序点对和非负。

候选处ΣF=0，且每层所有非m倍数的谐波都为零。在本构造的1,…,2m−1中，只有m是m的倍数；对应向量恰为c，Qₘc=0。因此候选确实使ΣᵢⱼKᵢⱼ=0。

## 3. 零条件首先恢复半径、人口及正多边形层

设任意n点构型使有序核和为零。每个矩块贡献非负，所以各项分别为零。

Q₀正定给ΣF=0。最后一个坐标是Σq(uᵢ)²=0；每个uᵢ都是非负实数，故每个q(uᵢ)=0，全部平方半径都属于𝒜。令各节点人口为νₐ。其总人口和前R−1阶径向矩满足

```math
\sum_{a\in\mathcal A}\nu_a=n,
\qquad\sum_{a\in\mathcal A}\nu_aa^j=T_j^*
\quad(1\le j\le R-1).
```

节点互异，Vandermonde矩阵可逆；唯一解就是候选人口。因而每条正层人口为指定的m或2m，原点人口恰为h。没有将整数人口或预设层结构当作待测构型的额外假设。

此时Lagrange坐标精确抽取各层。对每条正半径层，Qₖ=I迫使

```math
p_{r,k}:=\sum_{i:\,u_i=a_r}x_i^k=0,
\qquad1\le k\le2m-1,\quad k\ne m.
```

以下只用这些幂和、Newton恒等式及同半径性质。

若某层人口为m，前m−1个幂和为零，Newton恒等式给e₁=⋯=eₘ₋₁=0。该层的单首根多项式为zᵐ+B，且B≠0，因为半径为正。根恰为一条正m边形，均无重根。

若人口为2m，先有e₁=⋯=eₘ₋₁=0，eₘ可非零。对m<j<2m，Newton递推中的非零幂和只可能是pₘ，其系数eⱼ₋ₘ已为零，因此eⱼ=0。根多项式必为

```math
P(z)=z^{2m}+Az^m+B.
```

写作(zᵐ−w₁)(zᵐ−w₂)，每个wⱼ都满足|wⱼ|=Aᵣ=aᵣᵐᐟ²，因为所有z根位于半径√aᵣ的圆上。该层因此是两条正m边形的并，暂时允许两条重合。其m次矩为

```math
p_{r,m}=m(w_1+w_2).
```

这些推导没有先假设待测层具有Cₘ对称；旋转层结构已经由零矩条件产生。

## 4. m次矩的秩一零空间恢复所有相对相位

令M=(p₁,ₘ,…,pₛ,ₘ)ᵀ。Qₘ的零条件给

```math
M=\alpha c\qquad(\alpha\in\mathbb C).
```

选一个人口为m的锚定层。第3节已证明该层为正m边形，所以|Mᵣ|=mAᵣ=|cᵣ|；因此|α|=1。选一个整体旋转ρ，使ρᵐα=1；旋转后每层m次矩都恰为cᵣ。存在m个这样的ρ，它们相差Cₘ旋转，均属于允许的整体旋转与重排。

对人口为m的层，所有点的m次幂都是同一个数w=cᵣ/m。取其全部m次根即唯一确定该层。

对人口为2m的层，w₁、w₂的共同模长Aᵣ已知，和S=cᵣ/m已知。假设保证0<|S|<2Aᵣ。两个模长相同的复数在和非零时，其无序对由这个和唯一确定：

```math
\{w_1,w_2\}=
\left\{\frac S2\pm i\frac S{|S|}
\sqrt{A_r^2-\frac{|S|^2}{4}}\right\}.
```

分别取w₁、w₂的全部m次根，就唯一恢复该层。严格上端保证w₁≠w₂，故没有重合点。以上恢复结果与候选层完全相同；可选原点也已由人口条件固定。于是待测构型是候选整体旋转后的重排，定理得证。

非退化条件不能随意删去：若某个2m层cᵣ=0，则S=0，只能得到w₂=−w₁，其共同相位仍可连续变化；当前矩架构不能把该层相位锁到锚定层。若完全没有m人口层，秩一条件也不再由本证明强制|α|=1。本文不声称这些缺失情形没有其他刚性核。

## 5. 10、12、19点的具体接口

共同Dₘ对称保证可把某条反射轴旋至实轴，此时每层的m次矩在共轭下不变，因而cᵣ∈ℝ。某个人口m层提供锚；其相位可以有正负符号，证明只需要|cᵣ|=mAᵣ。

|候选|m及正层人口|R及原点|所用非m谐波|已认证的非退化条件|
|---|---|---|---|---|
|10点|m=2；2、4、4|R=3，无原点|1、3|两条4人口层的cᵣ非零，模长严格小于4aᵣ|
|12点|m=3；3、3、6|R=3，无原点|1、2、4、5|6人口层的cᵣ非零，模长严格小于6aᵣ³ᐟ²|
|19点|m=6；6、6、6|R=4，另有一个原点|1、2、3、4、5、7、8、9、10、11|全为m人口层，cᵣ模长为6aᵣ³，自动非零，无2m层条件|

19点的额外高谐波并非必要；逐层1至5次矩加6次矩秩一块已经足够，统一取至11次不会排除候选。

上述人口、真实根的精确D₂/D₃/D₆对称及半径分离由[候选专题](../candidate-global-screen/README.md)认证。10、12点2m层所需的额外非退化比较，以及19点各正层的六次矩结构，已由[精确根区间报告](../candidate-global-screen/symmetry_report.json)实际认证。报告在质量n尺度计算轴向加权矩；除以锚点模长的相应幂并整体缩放至质量n−1，保留这些齐次严格不等式，因而直接满足本定理假设。参数须使用相应真实根的精确值，不能用近似节点而继续宣称零集完全相同。

## 6. 只有Cₘ时的复Hermitian版本

一般Cₘ候选不必有共同反射轴，也不必能使所有cᵣ同时为实。前面的零集证明仍然成立，只需允许复Hermitian正半定块

```math
Q_m=\|c\|^2I_s-cc^*,\qquad
K_m(x,y)=\operatorname{Re}
\left((\bar x y)^mV(|x|^2)^TQ_mV(|y|^2)\right).
```

其有序点对和为M*QₘM，矩平方恒等式改写为Σᵣ<ₜ|cᵣMₜ−cₜMᵣ|²，零空间仍为spanℂ{c}。径向、其他谐波、锚定层及相位恢复步骤完全不变。因此它给出一般Cₘ层、人口m或2m、带上述非退化条件的刚性正半定核。

这个复版本的核通常还依赖点对的有向角信息，未必只由(u,v,t)三变量决定。对当前Dₘ候选，c实、Qₘ实，恰回到第2节的Hₘ(u,v,t)实三变量核，所以可直接接入仓库当前的两点核接口。

## 7. 与全局锐界之间仍缺什么

具有刚性零集意味着核罚项为零时，几何已被锁定；它不保证核罚项的大小足以控制距离乘积。质量n−1尺度下，[核求和接口](README.md)给Σᵢ<ⱼhᵢⱼ=B−ΣᵢⱼKᵢⱼ/2。只有进一步在包含所有全局最大点点对的连续必要域上证明h≥log|x−y|²，并匹配候选接触值，才能推出全局锐界与等号。

另一种可接合方式是证明核罚项和目标缺额迫使全部最大点进入[已认证局部上界区域](../candidate-basin/README.md)。当前两条路线的全域或补集排除仍未完成。本文也不将刚性构造、有限有理例子、候选对称或数值SDP的离散成功记为全局证明。
