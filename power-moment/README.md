# 一般n的幂和结构与八点已认证局部排除

研究资料与项目发起：**蒋丰灿（Fengcan Jiang）**；推导与精确程序包含 OpenAI Codex 协作。2026-10-31，承接daf4dff4803fd2d3521e7f188fba069c19ad01c6。

本轮按用户要求转攻p_k，不再调整层数系数。**八点剩余区域的全部排空尚未完成，不能宣布八点锐界已证。** 已完成的是一般n的有限幂和闭合、一个明确的全矩局部刚性定理，以及11个完整幂和盒的严格目标值排除。

## 1. 一般n：高阶p_k不能作为独立变量

首n个幂和通过Newton恒等式决定根多项式，进而递推所有高阶矩。特别地，全部乘积恰为

~~~math
\Delta=\left|\det[p_{a+b}]_{a,b=0}^{n-1}\right|.
~~~

这个**全纯Hankel矩阵不是Hermitian矩阵**，取的是行列式模。将p_(n+1),…,p_(2n−2)准确消元，可以直接在p₂,…,p_n整个复区间盒上给目标值上端，不再只比较若干|p_k|²罚项。

另证明：n≥4时，若真实归一化驻点满足p₂=…=p_(n−2)=0，则只能是正n边形或原点加正(n−1)边形；n≥11时两者都不可能局部最大。因此一般n的最优者不能无条件要求全部低阶幂和消失。有限幂和还精确识别循环旋转对称性。[一般n证明](GENERAL_POWERS.md)

## 2. 八点：候选附近的非零矩驻点被整体排除

本节p_k采用**力常数1**的w=√(7/2)z尺度，Σ|w_i|²=28。候选根多项式为X⁸−128X，其p₇=896，其余p₁,…,p₆,p₈均为0。

**定理。** 若某个真实八点驻点在适当整体旋转后满足

~~~math
|p_2|,\ldots,|p_6|,|p_8|\le1/10,
\qquad |p_7-896|\le1/10,
~~~

则它必是原点加半径2的正七边形，允许旋转和重排。尤其该完整邻域中的p₂p₃≠0驻点分支为空。

证明使用精确完整稳定谱、旋转切片上的严格凸性、Newton系数误差传播和八个Rouché根盘。它不是从数值优化或小残差推断驻点。[完整局部刚性证明](LOCAL_RIGIDITY.md)

## 3. 已排除的11个非零矩盒与尚缺的覆盖

[regions_verification.json](regions_verification.json)记录11个独立复矩区间盒，均有p₂p₃≠0，整个盒满足Δ_w<4²⁸7⁷，故不能包含挑战候选值的八点构型。每盒附真实中心化、归一化点集证明非空，但这些有理点集不被声称是精确驻点。

数值Newton仅用于选盒；最终接受完全不依赖NumPy、SciPy、SymPy、优化器或数值驻点完整性。部分远端种子也会被旧子集或点距条件排除，没有声称这11盒胜过全部旧条件。

另有一个非零p₂、p₃的实际归一化见证，处于局部刚性邻域内，且通过246个既有非平凡严格子集条件及旧低阶矩椭圆。局部刚性证明它不能是驻点；这说明不能把低阶必要条件通过误当成驻点存在。

**尚缺的关键一步：** 未证明全部“真实驻点＋完整稳定性＋目标阈值＋p₂p₃≠0”的可行域都落在上述局部邻域与11盒的并集中。明确剩余系统、覆盖清单与未证事项见[COVERAGE_STATUS.md](COVERAGE_STATUS.md)。验证报告固定`full_eight_point_exclusion_proved=false`。
