# 八点剩余区域：已关闭部分与未完成部分

2026-10-31。研究资料与项目发起：蒋丰灿（Fengcan Jiang）；OpenAI Codex协作。

**用户要求的“把八点剩余区域排除掉”尚未全部完成。** 本页明确区分局部证明、有限盒排除与完整覆盖，防止将部分进展表述成八点锐界。

## 1. 完整剩余系统

在力1尺度，任何挑战候选的全局最优者必须同时满足：

1. 八点互异，Σw_i=0、Σ|w_i|²=28。
2. 真实逐点力方程Σ_(j≠i)(w_i−w_j)⁻¹=bar(w_i)。
3. 完整逆平方算子||B||≤1。
4. 所有既有严格子集、半径、点距及矩约束。
5. Δ_w≥4²⁸7⁷。
6. p₂p₃≠0；零矩分支的使用仍保留[原有分类与依赖](../configuration-bounds/PROOF_STATUS.md)。

条件2不能替换成某个小残差或少量Ward式；条件3不能替换成几个低阶标量切割。剩余构型没有非平凡循环旋转对称，不能预设规则多环、中心对称或镜面对称。

## 2. 本轮真正关闭的集合

- **局部全矩集合U**：适当旋转后，|p₂|,…,|p₆|,|p₈|≤1/10及|p₇−896|≤1/10。局部刚性定理与条件2使其中p₂p₃≠0分支为空。
- **11个复矩盒R₁,…,R₁₁**：全部第一至第八幂和区间逐项记录于[region_inputs.json](region_inputs.json)。高阶p₉,…,p₁₄由Newton闭合。每盒整个目标上端严格小于候选阈值，故由条件5排除。
- 所有上述集合的整体旋转、重排也一并关闭。

每盒均有严格归一化点集证明非空。它们来自1200次浮点Newton起点探索，最后有968次数值收敛；这些数字不提供全体驻点个数或全覆盖保证。种子被转成文字有理数据后，最终验证不再运行数值求根。

部分远端种子违反旧子集或点距条件；本轮没有把它们写成“通过全部旧方法”的新难例。另一个候选附近见证通过246个严格子集条件及旧低阶椭圆，并具有非零p₂、p₃；它由局部刚性被严格判定为非驻点，不是全局反例。

## 3. 尚未完成的逻辑步骤

没有证明条件1—6定义的整个集合包含于U∪R₁∪…∪R₁₁。等价地，尚未对其补集完成分支覆盖、临界值消元或符号半正定矛盾证书。

因此本轮没有证明M₈=8²⁸/7²¹，没有证明所有p₂p₃≠0真实驻点都不存在，也没有把找到的有限个数值形状当作完整物理分类。这个缺口是本次明确保留的任务缺口，不是用更多检查次数能自动弥补的量词缺口。

原稿中的[有限幂稳定矩阵和代数刻画](../source-review/revised_main.tex)继续有效；此前八点根自由系数路线已经提出完整共轭配对与关键值消元，不能把重新写一个等价系统算成已排空。下一次完整证明必须提供上述补集的实际穷尽证据。

## 4. 文献核对的范围

检索到的[Aref等人的点涡综述](https://fluid.dtu.dk/-/media/5817c2eec5164d38850d5b51eda22d17.pdf)讨论八点数值相对平衡目录，包括非对称构型。这种数值目录没有在本轮被当成完整分类输入。本文所有新接受依赖明确的解析证明及标准库精确算术；未引入新的外部分类定理。
