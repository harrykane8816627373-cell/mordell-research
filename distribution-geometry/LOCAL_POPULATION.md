# 任意位置的点分布：局部 Gauss 能量、人口区间与全背景覆盖

研究资料与项目发起：**蒋丰灿（Fengcan Jiang）**。推导、精确证书及交叉审阅包含 OpenAI Codex 协作。2026-10-30。

此前径向CDF和中心空洞约束主要围绕重心使用。本节将能量局部化到任意圆心：得到平移圆盘和环带的人口必要区间、多个不交空洞的可加罚项，以及整个平衡背景圆盘上的有效覆盖半径。证明使用已有有限 n 圆盘能量分解，不调用外部线性渐近项或结晶结论。

## 1. 归一化及主要结论

沿用

~~~math
\Delta_n(z)=\prod_{i<j}|z_i-z_j|^2,\qquad
\sum_i|z_i|^2=n,\qquad
U_n=n^{n/2}\left(\frac{2n}{n-1}\right)^{n(n-1)/2}e^{-n(n-1)/4},
~~~

~~~math
\delta(z)=\log\frac{U_n}{\Delta_n(z)},\qquad
x_i=\alpha z_i,\quad \alpha=\sqrt{\frac{n-1}n},\qquad
r=\sqrt{\frac2n}.
~~~

以下圆心、半径、人口程序均在库仑 x 尺度，\(\sum|x_i|^2=n-1\)。记 \(\mu_0=(2\pi)^{-1}\mathbf1_{|w|\le\sqrt2}dA\)，\(\mu=n^{-1}\sum_i\sigma_r(\cdot-x_i)\)，\(\nu=\mu-\mu_0\)。已有分解给

~~~math
\delta(z)\ge n^2D(\nu),\qquad
D(\nu)=\frac1{2\pi}\int_{\mathbb C}|\nabla(g*\nu)|^2dA,
\quad g=-\log|w|.
~~~

如果 \(B(c,\rho)\) 不含任何点 x_i，且 \(b=(\rho-r)_+\) 满足 \(|c|+b\le\sqrt2\)，则

~~~math
\boxed{\displaystyle\delta(z)\ge\frac{n^2b^4}{16}.}
~~~

这里 c 可以是任意位置，既不要求 c=0，也不要求 c 是重心。更一般地，一组相互不交的上述能量圆盘可直接相加。

对整个闭背景盘都有统一覆盖结论：

~~~math
\boxed{\displaystyle
\sup_{|c|\le\sqrt2}\min_i|x_i-c|
\le2\sqrt{\frac2n}+4\left(\frac{\delta(z)}{n^2}\right)^{1/4}.}
~~~

因此代入任何已证 \(\delta(z)\le E\)，特别是全局最优者已有的有效 \(E_n=O(n)\)，便得到全背景覆盖半径 \(O(n^{-1/4})\)，包括靠近背景边界的圆心。

另对任意固定 T≥0，令

~~~math
e_{n,T}(E)=
\left[\frac{3((T+r)^2+2)E}{n^2}\right]^{1/3}+Tr+\frac{r^2}2.
~~~

则同时对**所有圆心** c∈C、所有 0≤t≤T 有

~~~math
\boxed{\displaystyle
\left|\frac1n\#\{i:|x_i-c|\le t\}-\mu_0(B(c,t))\right|
\le\min\{1,e_{n,T}(E)\}.}
~~~

使用 \(E_n=O(n)\) 后，这给任意位置、半径有界圆盘的统一 \(O(n^{-1/3})\) 人口质量误差。它控制真实二维位置分布，不只控制相对于重心的半径直方图。

## 2. 任意圆心的局部通量不等式

设 u=g*ν。因为 \(-\Delta u=2\pi\nu\)，对几乎处处的 t>0，Gauss 公式给

~~~math
\int_{\partial B(c,t)}\partial_r u\,ds=-2\pi\nu(B(c,t)).
~~~

圆周 Cauchy–Schwarz 因而给

~~~math
\int_{\partial B(c,t)}|\nabla u|^2ds
\ge\frac{[2\pi\nu(B(c,t))]^2}{2\pi t}.
~~~

对 t∈(0,b) 积分，即得真正局部的能量下界

~~~math
\boxed{\displaystyle
\frac1{2\pi}\int_{B(c,b)}|\nabla u|^2dA
\ge\int_0^b\frac{\nu(B(c,t))^2}t\,dt.}
~~~

u 来自紧支撑、有界密度、零总质量电荷，具有有限 Dirichlet 能；上述公式可先平滑再取极限。累计质量连续，故几乎处处的圆周公式足以得到所有所用积分不等式。

这一步保留实际的空间能量区域。不同圆心的全平面旋转平均投影一般不能独立相加；本节可加性的依据是**积分圆盘在空间中不相交**。

## 3. 多空洞及少人口圆盘

如果没有点进入 \(B(c,\rho)\)，半径 r 的平滑圆盘也不会进入 \(B(c,(\rho-r)_+)\)。在 \(B(c,b)\subset\{|w|\le\sqrt2\}\) 内，背景质量为 t²/2，故

~~~math
\nu(B(c,t))=-t^2/2\quad(0\le t\le b).
~~~

代入局部通量式，

~~~math
\frac1{2\pi}\int_{B(c,b)}|\nabla u|^2dA
\ge\int_0^b\frac{t^4/4}t\,dt=\frac{b^4}{16}.
~~~

若 \(B(c_j,b_j)\) 的内部两两不交，就有

~~~math
\boxed{\displaystyle\delta(z)\ge\frac{n^2}{16}\sum_j b_j^4.}
~~~

允许圆周边界相接。真正需要不交的是这些收缩后的能量盘；原先的点空盘可以更大。程序使用有理平方距离 \(|c_i-c_j|^2\ge(b_i+b_j)^2\) 核对条件，重叠时拒绝直接求和。

### 3.1 至多 m 个点的局部缺额

若原构型的圆盘 \(B(c,\rho)\) 内至多有 m 个点中心，令 p=m/n。对 t≤b=\((\rho-r)_+\)，平滑质量至多为 p，因此当 t²/2>p 时，

~~~math
|\nu(B(c,t))|\ge t^2/2-p.
~~~

只要 \(|c|+b\le\sqrt2\)，局部能量至少为

~~~math
J(b,p)=\begin{cases}
0,&b^2\le2p,\\
b^4/16,&p=0,\\
\displaystyle b^4/16-pb^2/2
+\frac{p^2}2\log\frac{b^2}{2p}+\frac{3p^2}4,
&0<p<b^2/2.
\end{cases}
~~~

这正是 \(\int_{\sqrt{2p}}^b(t^2/2-p)^2dt/t\) 的积分。于是 \(\delta\ge n^2J(b,p)\)。如果该下界超过已证 E，便排除“此盘人口≤m”的整类，得到人口下限。m=0 恢复空洞常数；不能再将同一盘的完整空洞代价重复相加。

这里人口是平滑前的点中心数，圆心为任意指定的 c。

### 3.2 一个非空双空洞类

取 n=10000，两个点空盘的中心为 \(c_\pm=\pm1/2\)，半径均为49/100。平滑半径 \(r=\sqrt{2/10000}<1/50\)，所以可以选两个能量盘半径 b=47/100。它们不交且完全在背景盘内。因此

~~~math
\delta\ge\frac{10000^2}{16}\,2(47/100)^4
=\frac{4879681}{8}.
~~~

它大于全局最优者已有的 \(E_{10000}=16705/12\)，故整个双空洞类不含全局最大者。这个条件类非空：库仑尺度取半径 \(\sqrt{9999/10000}\) 的正一万边形即可；其总矩为9999，且距两个中心的距离都大于49/100。程序只复核代数条件和缺额比较，没有宣称数值优化过一万个点。

## 4. 含背景边界的统一覆盖半径

记任意 \(|c|\le R_0=\sqrt2\) 到最近点的距离为 ρ。由 \(\sum|x_i|^2=n-1\) 至少存在一点满足 \(|x_i|\le\sqrt{(n-1)/n}\)，故

~~~math
\rho\le R_0+\sqrt{(n-1)/n}<2R_0.
~~~

开盘 \(B(c,\rho)\) 不含点，但可能越过背景边界。沿 c 到原点方向将圆心移动至

~~~math
c'=\begin{cases}
\max\{1-\rho/(2|c|),0\}\,c,&c\ne0,\\
0,&c=0.
\end{cases}
~~~

则 \(|c-c'|\le\rho/2\)，而 \(|c'|+\rho/2\le R_0\)。所以 \(B(c',\rho/2)\) 同时包含于背景盘与原先的点空盘。应用第3节，

~~~math
\delta\ge\frac{n^2}{16}(\rho/2-r)_+^4.
~~~

若 ρ≤2r，所需覆盖式已经成立；否则开四次方，得到

~~~math
\rho\le2r+4(\delta/n^2)^{1/4}.
~~~

这是一条对整个背景盘都有效的最近点覆盖半径。它不是点间最小距离，也不推出微观尺度 \(n^{-1/2}\) 的最优覆盖。已证尺度为 \(n^{-1/4}\)，不应省略其局限。

## 5. 任意平移圆盘的 CDF 及全位置人口误差

固定任何 c，记平方半径累计分布

~~~math
F_c(s)=\mu(B(c,\sqrt s)),\qquad
A_c(s)=\mu_0(B(c,\sqrt s)),\qquad s\ge0.
~~~

由于背景密度至多1/(2π)，任意平方半径增量都满足

~~~math
0\le A_c(s+v)-A_c(s)\le v/2,
\qquad A_c(s)\le\min\{s/2,1\}.
~~~

这些常数与圆心无关，即使查询盘跨越背景边界也成立。对第2节取全空间并置 s=t²，得到

~~~math
D(\nu)\ge\frac12\int_0^\infty
\frac{(F_c(s)-A_c(s))^2}{s}ds.
~~~

若 \(F_c(s_0)-A_c(s_0)=\eta>0\)，F_c 单调而 A_c 的斜率至多1/2，故向右长2η的区间上，差至少为 \(\eta-v/2\)。于是

~~~math
D(\nu)\ge\frac{\eta^3}{3(s_0+2\eta)}.
~~~

如果 \(A_c(s_0)-F_c(s_0)=\eta>0\)，同样的三角区可放在左侧。由 \(A_c(s_0)\le s_0/2\) 知 \(s_0-2\eta\ge0\)，并得到 \(D(\nu)\ge\eta^3/(3s_0)\)。这也解释了为何不能把此前原点 CDF 的常数6未经修改地搬到任意圆心。

因此对任意 s≤S，

~~~math
\boxed{\displaystyle
|F_c(s)-A_c(s)|
\le\min\left\{1,\left[\frac{3(S+2)E}{n^2}\right]^{1/3}\right\}.}
~~~

实际点人口 P_c(t)=\(n^{-1}\#\{|x_i-c|\le t\}\) 与平滑 CDF 有

~~~math
F_c((t-r)_+^2)\le P_c(t)\le F_c((t+r)^2).
~~~

目标背景在两个半径间的质量差不超过相应环域面积除以2π，故各侧的平滑转回误差至多 \(tr+r^2/2\)。令 S=(T+r)²，便得到第1节同时对所有 c 和 t≤T 成立的 \(e_{n,T}(E)\) 界。

### 5.1 原 z 尺度的1/n校正

原尺度的查询盘 B(c,t) 在 x 尺度变为 \(B(\alpha c,\alpha t)\)。把 x 背景推回 z 后，它是半径 \(\sqrt2/\alpha\)、密度 \(\alpha^2/(2\pi)\) 的均匀盘；它与自然半径 \(\sqrt2\) 背景之间，任意可测集合的概率差至多

~~~math
1-\alpha^2=1/n.
~~~

因为 \(\alpha t\le T\)，原 z 尺度相对于自然背景的所有 t≤T 圆盘人口误差，可安全取 \(\min\{1,e_{n,T}(E)+1/n\}\)。这里仍保留有限尺度校正，没有将两种背景完全等同。

## 6. 纯有理空间人口区间与局部少人口证书

[local_population.py](local_population.py) 在有理中心、查询平方半径 q 上给整数人口区间。程序先向外包围

~~~math
q_-=(\sqrt q-r)_+^2,\qquad q_+=(\sqrt q+r)^2.
~~~

对背景相交面积 \(\mu_0(B(c,\sqrt{q_\pm}))\)，圆盘完全包含、被包含或相离时直接精确计算。一般相交时，完整划分固定外方框 \([-2,2]^2\) 为有限有理网格：

- 整格同时处于两个圆盘内，其面积进入下界。
- 不能证明整格在任一圆盘外的格，其面积进入上界。
- 圆周边界格的实际相交面积未知，不计入下界，并保留在上界。

圆盘与矩形的最近点、最远角点比较全为有理数；最后用已认证的 π 区间乘密度1/(2π)。即使一个格分别可能碰到两个盘、却并未真正碰到它们的交集，保留在上界也仍安全。网格细化时不确定部分只在两条圆周附近，面积趋于零。程序超出完整网格预算就拒绝计算，不把不完整遍历登记为上界。

设相交质量的有理下、上端为 \(A_-^L,A_+^U\)，并令 \(e=[3(q_++2)E/n^2]^{1/3}\) 的向上包围，则人口整数区间为

~~~math
\left\lceil n\max\{0,A_-^L-e\}\right\rceil
\le\#\{|x_i-c|^2\le q\}
\le\left\lfloor n\min\{1,A_+^U+e\}\right\rfloor.
~~~

环带 \(a<|x_i-c|^2\le b\) 可由内外两圆盘的整数界相减，仍保留任意圆心。`spatial_grid_populations` 接受有限个横、纵坐标，完整输出该笛卡尔中心网格上的所有人口区间；这些是空间查询，不是原点构型空间的全局枚举。

`local_deficit_certificate` 实现第3.1节的精确对数少人口罚项；`multiple_hole_certificate` 核对局部空间能量盘不交并相加；`covering_radius_upper` 同时取能量覆盖式和简单总矩上界的较小者；`uniform_disk_discrepancy` 给全圆心、有界查询半径的统一质量误差。

## 7. 接受范围与后续问题

~~~bash
python -B -S -O verify_local_population.py
~~~

[验收报告](local_population_verification.json)包含精确包含／相离面积、已知面积为π−2的透镜对照、完整矩形几何、三角积分常数、局部空洞积分、背景边界的半径减半内盘构造、双空洞排除、少人口罚项、任意中心圆盘与环带、统一分布误差及有效覆盖例。所有接受比较均使用整数和 Fraction；有限检查不替代本文的 Gauss、通量与普遍分布量词证明。

局部空间能量盘不交时可以相加；同一盘的两种完整下界应取最大值。不同圆心的全局径向投影，以及旧的相对于原点的角向投影，通常不正交，不能未经证明重复累加或从平移人口预算中自动扣除。

本节使用的能量来源见[已有有限 n 圆盘分解](../asymptotics/README.md)及[有效径向证明](../radial-angular/RADIAL_LAYERS.md)。对全局最优者输入旧的有效多环下界即可；本文没有确定最优者的各层人口、角度或唯一性，没有给出八点完整锐界，也没有给出微观最优晶格结晶。Gauss 局部化与面积外包是标准工具，本项目整理其有限 n 精确接口，不作全球优先权、外部同行评审或整篇形式化验证声明。
