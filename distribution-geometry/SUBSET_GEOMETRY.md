# 有限子集的薄条带谱容量：二维排布中的方向性人口约束

研究资料与项目发起：**蒋丰灿（Fengcan Jiang）**；本轮推导、程序及交叉审阅包含 OpenAI Codex 协作。2026-10-30。

本节使用用户原稿的完整二阶稳定性范数，控制任意平移、旋转薄矩形内的人口。它保留子集点的方向排序及所有奇数跳距，超出仅保留内部二阶矩或最近点距的压缩。新界不是二维圆盘的锐密度结论，也没有假定晶格或规则角度。

## 1. 普遍条带定理

沿用归一化 `Σ|z_i|²=n`，局部最大点已中心化。令 λ=(n−1)/2，用户原稿稳定性矩阵满足

~~~math
B_{ij}=-(z_i-z_j)^{-2}\quad(i\ne j),\qquad\|B\|\le\lambda.
~~~

出处及限制见[用户修订主稿](../source-review/revised_main.tex)和[旧两点归约](../symmetry-breaking/PAIR_STABILITY.md)。本节不将这个完整算子定理改署为新成果。

设某m点落在任意方向、任意位置的矩形中，长L>0，横向宽W≥0。d₀²取一个已证的最小点距平方下界：

~~~math
d_0^2=\frac{2n}{(n-1)^2}\quad\text{适用于所有局部最大},
\qquad d_0^2=\frac4{n-1}\quad\text{适用于全局最大}.
~~~

后者来自用户既有[严格子集定理](../finite-n/SUBSET_PROOF.md)，n=2的非严格下界由直接计算成立。必须保留薄带条件 `2W²<d₀²`。定义

~~~math
\eta=1-\frac{2W^2}{d_0^2}>0,\quad h=\lfloor m/2\rfloor,
\quad v_k=\min(k,m-k),
~~~

~~~math
A_m(L,W)=\sum_{\substack{1\le k<m\\k\text{ 奇数}}}
\frac{(m-k)^3}{v_k^2L^2+W^2(m-k)^2}.
~~~

则必要条件为

~~~math
\boxed{\eta A_m(L,W)\le\lambda\sqrt{h(m-h)}.}
~~~

两边非负，故平方后完全有理。违反它就排除整个矩形人口类；不要求这些点恰好共线、等距，或其余点处于特定区域。

### 相位、横向宽度与互异横坐标

平移旋转坐标后写 z_i=x_i+iy_i，纵向跨度≤L、横向跨度≤W。B只依赖差值，旋转仅乘一个单位复数，不改变范数。任何两点的横向差≤W；点距下界强迫它们的纵向差满足

~~~math
|x_i-x_j|^2\ge d_0^2-W^2>W^2.
~~~

因此能按严格递增的x排序。对一对点，记d²=|z_i−z_j|²，则

~~~math
-\operatorname{Re}B_{ij}
=\frac{(x_i-x_j)^2-(y_i-y_j)^2}{d^4}
\ge\frac\eta{d^2}.
~~~

取按顺序交错的两组I,J，大小h、m−h；用常数向量u=1_I、v=−1_J测试原算子，就有

~~~math
\eta\sum_{i\in I,j\in J}|z_i-z_j|^{-2}
\le\operatorname{Re}(u^*Bv)
\le\lambda\sqrt{h(m-h)}.
~~~

这里仅用不同点的交叉元，未知对角元没有出现。

### 奇跳排序保留了超出最近邻的信息

奇数k对应的全部i到i+k点对，恰好遍历I×J点对一次。其纵向跨度记t_i=x_(i+k)−x_i>0。每个相邻横坐标间隔最多被v_k=min(k,m−k)个跨度使用，所以

~~~math
\sum_{i=1}^{m-k}t_i\le v_kL.
~~~

函数 `F(t)=1/(t²+W²)` 在所有允许的t上严格凸、递减，因为

~~~math
F''(t)=\frac{6t^2-2W^2}{(t^2+W^2)^3}>0
\quad\text{当 }t^2\ge d_0^2-W^2>W^2.
~~~

又有d²≤t²+W²，Jensen及递减性给出

~~~math
\sum_{i=1}^{m-k}|z_{i+k}-z_i|^{-2}
\ge\frac{(m-k)^3}{v_k^2L^2+W^2(m-k)^2}.
~~~

对奇数k求和即得定理。仅保留k=1会丢失其它奇跳的正贡献；这也是该界不只是重新表述最近点距的原因。

## 2. 微观尺度下，人口条件可以完全不含n

对全局最大构型，定义缩放长度 `ℓ=√(n−1)L`、`w=√(n−1)W`。只要 `w²<2`，上式等价于

~~~math
\boxed{\left(1-\frac{w^2}{2}\right)
\sum_{k\text{ 奇数}}\frac{(m-k)^3}{v_k^2\ell^2+w^2(m-k)^2}
\le\frac12\sqrt{h(m-h)}.}
~~~

这是对每个n≥m都成立的微观条带人口限制，不使用渐近展开、外部线性常数或结晶假设。它描述薄方向上的可装点能力，不能当作所有二维窗口的面积密度锐界。

共线W=0时，令 `a_m=Σ_(k odd)(m−k)³/v_k²`。对所有m有纯有理的较简明必要条件

~~~math
L^2\ge\frac{4a_m}{(n-1)m}.
~~~

偶m时与本判据等价；奇m的原平方判据更强。由可和支配与尾项估计

~~~math
\frac{a_m}{m^3}\longrightarrow\sum_{k\text{ 奇数}}\frac1{k^2}=\frac{\pi^2}{8}.
~~~

其中k>m/2的附加端项仅O(m²)，不影响极限。因此沿m→∞的共线子集序列，本必要条件给

~~~math
\limsup\frac{m}{L\sqrt{n-1}}\le\frac{\sqrt2}{\pi}.
~~~

单纯全局间距只能给领先常数1/2；√2/π约0.4502，更小约10%。这只是共线序列的限制，不声称真实最优构型存在这样的长共线子集。程序还在m=16、20、40、100核验了有限条带长下界已严格超过旧全球最近邻装点下界 `4(m−1)²/(n−1)`。

## 3. 整类排除，并给完整200点非空见证

取n=200，任意位置方向的矩形，L=27/10、W=1/100。若其中至少20点，则仅使用局部基本间距已得到

~~~math
\eta A_{20}>1018,\qquad
\lambda\sqrt{10\cdot10}=995.
~~~

因此该**整个任意矩形角向排布、正宽度人口类**不含局部最大，也不含全局最大。选择全局较强间距只会提高该证书；实际全部有理数见核验报告。

这类并非因旧点距或二阶矩显然不可能。程序生成以下完整200点：

1. 先放20个等距水平点 `x_j=27(2j−19)/380,y_j=0`，0≤j≤19。
2. 枚举整数网格代表 `(a,b)`，1≤b≤9、−9≤a≤9、a²+b²≤97；按 `(a²+b²,a,b)` 排序。
3. 选90个代表，使范数平方和恰为4571；每个代表放入一对 `±(a,b)/7`。实现从最小90项开始，按确定的最大允许增量交换，21次即达到目标；报告保存选中索引和全部交换，接受入口精确重放。

原始构型重心为0，总二阶矩为

~~~math
Q=200+\frac7{18620}=\frac{3724007}{18620}.
~~~

将所有坐标乘 `√f`，其中 `f=3724000/3724007<1`，就得到中心化且总矩200的无碰撞完整见证。20点水平跨度严格小于27/10，且横向宽度0严格小于1/100，故它位于上述被排除的正宽度类内。

程序直接复算全体19900对，确认所有旧两点slack都严格正，并且

~~~math
\min_{i<j}|z_i-z_j|^2=\frac{204120}{10108019}>\frac4{199},
\qquad
\max_i|z_i|^2=\frac{7372000}{3724007}<\frac{398}{200}.
~~~

所选20点及180点补集的质心各自为0，两者也分别通过原严格子集内部矩下界；20点的内部矩约13.429，而旧门槛仅380/199约1.91。没有把内部二阶矩不足重新包装为新的排除。

由于上述旧不等式均严格，20点矩形包含关系也严格，连续性还给出这一见证周围、在中心化且总矩200的可行流形上的非空开放邻域；整类排除本身已由第1节公式覆盖，不需要抽样。

这里只核验了所列旧约束，不声称这组点通过所有其它子集、完整算子或全部历史方法。它是展示新条带判据信息的反例见证，**不是**接近最优的新下界构造。

[实现](subset_geometry.py)对全部奇跳完整求和，若项数超过预算，在返回结果前拒绝；不返回部分求和“通过”结论。[核验报告](subset_geometry_verification.json)包括276个独立跨度计数、96项凸性分子、12项复倒数实部比较、4组不等纵向间隔的直接互作用、全体19900旧两点、6类非法输入拒绝，以及微观缩放的精确恒等式。

一般条带定理由原范数界与排序凸性证明承担；有限点计算只验证实现、明确数值及非空见证。局部和全局间距的适用范围不能混用。这些谱容量是可行性必要条件，不能把其负slack与库仑能量罚项直接相加；也不由满足人口约束推断最优性。本节未确定二维微观最优排布、一般n锐值或八点完整锐界，未作外部同行评审、整篇形式化验证或全球优先权声明。
