# 一般 n 的二维分布：微观覆盖、运输距离与局部人口

研究资料与项目发起：**蒋丰灿（Fengcan Jiang）**；推导、精确程序及交叉审阅包含 OpenAI Codex 协作。2026-10-30。承接 `26c8fcd763340bd06101ca757000f769d5a50a7d`。

本轮将全局最优性、用户已有的严格子集与稳定性条件、可达下界和库仑能量分解联合，用四种互补方法约束点在平面上的分布。原问题仍为 Σ|z_i|²=n 下最大化全部两点距离平方的乘积。

**一般 n 的完整最优构型、精确锐值、结晶结构和八点完整锐界仍未解决。** 下述结论均保留各自的全局或局部适用范围。

## 1. 内盘的微观覆盖：有效常数与明确起点

对每个全局最优构型，在原 z 尺度有

~~~math
\boxed{n\ge64,\quad |u|\le1\quad\Longrightarrow\quad
\min_i|z_i-u|<\frac6{\sqrt{n-1}}.}
~~~

圆心可以任意移动，结论对整个单位内盘同时成立。联合原有严格最小点距 >2/√(n−1)，内盘的覆盖半径与全点集最小距离之比小于3。证明使用全局单点替换得到的加权多项式插值、有限 Gaussian 核近似和分离点集的积分装填，不需要外部渐近余项。

|圆心范围（原 z 尺度）|适用点数|覆盖半径严格上端|
|---|---:|---:|
|平方半径≤1|n≥64|6/√(n−1)|
|平方半径≤3/2|n≥512|6/√(n−1)|
|平方半径≤7/4|n≥4096|6/√(n−1)|

任意固定内盘都可验证同类有限起点。这里没有给背景圆盘边界上的统一微观覆盖定理，也没有确定最佳常数6。粗人口推论例如：n=10⁶、中心0、半径1/10的圆盘内，必有246至10200个点；这不是精确密度。

## 2. 完整二维运输误差达到 n⁻¹ᐟ² 阶

令 η_z=n⁻¹Σδ_(z_i)，μ₀为半径√2圆盘上的均匀概率。W₁是把一个分布搬成另一个时所需的最小平均移动距离，同时控制所有1-Lipschitz统计量。

设 E 是由已证可达下界得到的最优能量缺额上端。对任意 h>0，取

~~~math
\alpha=\sqrt{(n-1)/n},\quad r=h\sqrt{2/n},\quad
\psi(h)=(h^2-1)/2-\log h,\quad
R=\max\{\sqrt2,\sqrt2(n-1)/n+r\}.
~~~

则所有全局最优者满足

~~~math
\boxed{\frac{2\sqrt2}{3\sqrt n}\le W_1(\eta_z,\mu_0)
\le\frac{2r}{3}+\frac Rn\sqrt{E+n\psi(h)}+1-\alpha.}
~~~

上端来自紧支撑库仑运输、平滑耦合和尺度恢复；下端对任意 n 个等权原子都成立。仅输入已有有效初等预算 E_n=n/100+(77/6)√n+35/4（n≥6），就得到有效的 O(n⁻¹ᐟ²) 上界。没有假定最优构型的角度、层结构或晶格。

更强可达下界会立即缩紧分布约束：此前已保存的百点整数见证，给任意百点全局最优者

~~~math
W_1(\eta_z,\mu_0)<0.111199952674.
~~~

由此可排除全部点均距两条正交坐标轴的并集不超过1/5的百点构型类。其非空例子甚至具有仅1/50的径向CDF误差，说明只控制半径仍会遗漏角向集中。

若另沿用仓库已注明的外部线性能量定理及三角试探输入，渐近常数还有

~~~math
\frac{2\sqrt2}{3}\le\liminf\sqrt n\,W_1
\le\limsup\sqrt n\,W_1<\frac{981}{1000}.
~~~

这一窄常数夹逼保留外部输入，没有给出可直接套用0.981/√n的有限起点；也没有证明真正极限存在。运输框架有经典来源，本文给出自含的圆盘常数、项目尺度和有限证书。

## 3. 任意中心的圆盘人口与含边界覆盖

在库仑尺度 x=αz 中，任意圆心 c 的局部Gauss通量给

~~~math
\frac1{2\pi}\int_{B(c,b)}|\nabla(g*\nu)|^2
\ge\int_0^b\frac{\nu(B(c,t))^2}{t}\,dt.
~~~

这使位于不相交空间圆盘中的能量代价可以相加。对空洞、人口不足圆盘均有显式缺额下端；多个圆心的完整全平面能量界不能直接重复相加。

由此得到任意位置、半径有界查询圆盘相对于均匀背景的统一 O(n⁻¹ᐟ³) 人口质量误差，包括跨越背景边界的圆盘。程序提供圆盘、环带和指定空间网格的整数人口区间。n=10⁶时，在 x 尺度中心0或1、半径1/4的圆盘内均必有25688至36814个点。

对**整个闭背景圆盘**，包括边界，另有

~~~math
\sup_{|u|\le\sqrt2}\min_i|x_i-u|
\le2\sqrt{2/n}+4(E/n^2)^{1/4}.
~~~

它在边界仍有效，但只有 n⁻¹ᐟ⁴ 阶；第1节在固定内盘达到更细的 n⁻¹ᐟ² 阶。两条覆盖结论的尺度和范围不能互换。

## 4. 薄条带的谱人口容量

将原稳定性矩阵的交错测试从同圆推广到任意平移、旋转的薄矩形，并对排序后的全部奇数跳距应用凸性，得到带宽、长度与人口的有理必要判据。它适用于所有局部最大者；全局严格间距可进一步加强它。

例如 n=200 时，**任意长27/10、宽1/100的矩形都不能含有20个局部最优构型点**。程序还构造完整200点见证：它通过全部19900对旧两点条件、较强全局点距、半径限制和所列子集矩条件，却被新矩形判据排除。没有声称它通过每一条既有全局必要条件。

共线子集的大人口容量常数由单纯点距的1/2降至√2/π。该结论只针对共线序列，不代表二维最优密度，也不保证真实最优者含长共线点列。
